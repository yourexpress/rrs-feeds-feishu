SPARTA: A Sparse Ternary LLM Accelerator with Adaptive Attention and Unified Datapath for Long-Context Edge Inference

arXiv(cs.AR) · 2026-10-26 · 论文PDF / 每日精选

研究问题 边缘 LLM 受内存与带宽限制，1.58-bit 三元权重大幅省存储，但长上下文推理被 KV 流量与 attention 卡住；现有加速器还对三元线性层与 attention 用分离数据通路。

方法 SPARTA 稀疏三元加速器：阶段感知稀疏数据流（prefill 计算密集、decode 内存密集）；统一计算阵列把三元 SpMM/SpMV 与位串行 attention 映射到共享 PE；自适应两阶段 attention（页级 Top-k 减 K-cache 访问 + token 级 Top-p 减 V-cache 流量）。

关键数字 KV 流量较全 attention 减 4.1-4.8x、较 SOTA 稀疏 attention 方案 1.3-1.5x（任务依赖质量损失）；较 Jetson AGX Orin 生成吞吐高 3.9x、端到端能效高 8.3x；较 AMD Ryzen 7 9700X 分别为 5.0x 与 81.7x。

为什么值得看 三元 LLM 边缘加速器完整方案，KV 流量与注意力同时优化的量化收益齐全。
