Accelerator Choice Is Not Enough: AlphaFold2 Inference on Cloud TPUs

arXiv (cs.DC) · 2026-09-28 · 论文PDF

研究问题： AlphaFold2 用 JAX 编写，同一份推理代码可无改运行在 CPU、GPU 与 Google Cloud TPU 上——这种可移植性是否意味着"选对加速器"就够了？ 方法： 在同一测量活动内，用 Colab CPU、NVIDIA T4 GPU 与专用八芯片 Cloud TPU v5e slice 跑同一 AlphaFold2 推理负载，并用留存 trace 分析新输入形状首次调用的时间构成。 关键数字： TPU 单芯片稳态 0.47 s/call vs T4 13.1 s/call；默认路径只用八片中的一片，按目录价 slice 每预测成本与 GPU 相当；pmap 跨片映射使八芯片吞吐为单芯片 6.5-7.9 倍；首次调用约四分之三的 traced 时间花在 JAX tracing 与编译；五周后重跑两个云基线均未复现（GPU 偏差约 2 倍）。 为什么值得看： 提醒"硬件优势取决于软件执行路径与结果可复现性"，云上 AI 推理选型与成本决策参考。 原文链接：Accelerator Choice Is Not Enough: AlphaFold2 Inference on Cloud TPUs
