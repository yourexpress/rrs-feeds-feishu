Performance Characterization of SPEC CPU 2026 on AMD EPYC 9755 Processor

arXiv（Kunal Kashyap 等，cs.AR） · 2026-09-01 · 论文PDF

研究问题 SPEC CPU 2026 是 2017 年以来行业标准 CPU 基准套件的首次大更新，但尚缺微架构层面的性能画像；AMD EPYC "Zen 5" 上也无 SPEC 分析先例。

方法 在 EPYC 9755 上对新套件做首个微架构级表征：多透镜方法覆盖流水线效率、控制流行为、缓存层级压力与指令构成，同时分析 SPECrate 与 SPECspeed；引入规模分析对比单副本与满系统行为，暴露常规表征看不见的系统级瓶颈。

关键数字 识别出三类行为簇：前端控制流主导型（考验分支预测器吞吐而非准确率）、高效计算型（满规模下受 SMT 争用）、内存带宽受限型（单副本即 L3 过滤差）；SMT 分发争用与 L3 容量干扰等效应仅在满系统利用率下出现。

为什么值得看 面向下一代数据中心处理器的实证地基，架构研究与选型决策都可直接引用。
