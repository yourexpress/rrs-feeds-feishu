Coarse Semantic Blocks for Efficient Training-Free Sparse Attention

arXiv (cs.LG) · 2026-11-03 · 论文PDF / 每日精选

研究问题 免训练稀疏注意力通常依赖逐 token 细粒度选择，prefill 与 decode 提速有限、精度损失大。能否用更粗粒度的语义块同时加速两阶段并保持精度？

方法 提出基于 prompt 专属 key 索引的免训练稀疏注意力：把 key 聚成覆盖非连续位置的大语义块，每个 query 按质心打分选块，再在块内对原始 key/value 做注意力；选择同一块的 query 分组处理，保持 prefill 速度。大块使质心打分与分组处理廉价，同等时间可让每个 query 关注更多 token。

关键数字 在 Qwen3.5-4B 与 35B-A3B 上（NVIDIA H200）：512K token 下相对 dense attention 整模型 wall-clock 提速 prefill 2.3-2.4x、decode 1.7-2.0x，1M 下 prefill 2.9-3.0x；35B-A3B 在五个 RULER 任务（至 1M）、LongBench-v2 与 MRCR（至 256K）上保持接近 dense 的精度。

为什么值得看 用"大语义块+分组处理"的思路把免训练稀疏注意力的 prefill 提速做到 2.4x 且精度接近 dense，是可落地的长上下文加速方案。
