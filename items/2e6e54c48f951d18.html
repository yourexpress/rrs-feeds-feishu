QCPruner: Query-Conditioned Population Coverage for Visual Token Pruning

arXiv（Shengli He 等，cs.CV） · 2026-09-17 · 论文PDF / 每日精选

研究问题：多模态大模型的视觉 token 负载高昂，免训练剪枝要在固定预算下同时保住查询相关证据、避开冗余——现有方法排序、多样化或做覆盖优化，但没有用统一的"每查询效用"同时加权视觉目标与候选代表。

方法：QCPruner 引入双边效用加权，让两种角色都查询条件化：用关键词匹配的查询锚点把两个跨模态线索融合成效用，作用于基于视觉亲和度的覆盖中的视觉目标与候选代表；所得非负 facility location 目标单调且子模，保留标准 (1-1/e) 贪心近似保证，零训练、零参数更新。

关键数字：LLaVA-1.5-7B 上 32/576 token 预算保留 96.1% 未剪枝性能（最强基线 93.9%）；Qwen2.5-VL-7B 上 256/1296 保留 96.7%（基线 92.5%）；在 LLaVA-1.5、LLaVA-NeXT、LLaVA-Video、Qwen2.5-VL 上各预算点平均相对性能最高。

为什么值得看：把免训练视觉 token 剪枝严格框成带近似保证的子模覆盖问题——省 token 的同时还有理论兜底，MLLM 部署侧的实用技术。
