Compaction-Aware Reinforcement Learning For Ascend Triton Kernel Generation

arXiv/cs.LG · 2026-10-09 · 论文PDF / 每日精选

研究问题 用 LLM agent 自动生成高性能 kernel 有望大幅提升开发效率，但有两处硬伤：与执行环境的多轮交互会让上下文持续累积、迅速超出模型有效窗口；用 GRPO 训练长程任务又因依赖终局评估而奖励稀疏，步级信用分配困难。

方法 提出 ATRL（Ascend Triton Reinforcement Learning）后训练方法，把 GRPO 改造为压缩感知的分段级目标；配套轻量 agent harness，级联返回编译、正确性与性能剖析三类反馈，并在 agentic RL 训练与评测中注入昇腾专属知识库，补齐基座模型缺失的平台经验。

关键数字 在昇腾硬件上运行的 NPUKernelBench 与 KernelBench 上，ATRL 在正确性与加速比两项上都超过包括 GRPO 在内的全部基线（摘要未给出具体数值）。

为什么值得看 上下文压缩与步级奖励是长程 agentic RL 的共性痛点，而这篇顺带给出了非 NVIDIA 平台的完整落地证据。
