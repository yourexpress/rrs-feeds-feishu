Claude Projects Rebuilt: From File Folders to Coordinated Agent Sessions

核心话题：Anthropic 把 Claude Projects 从"文件文件夹"重建为"协调式代理会话集合"。

要点：项目现在是"协调器 + 线程"结构：每个线程是跑在独立分支/仓库副本上的 Claude Code 云会话，可再拆 subagent、循环与工作流；两个线程碰同一段代码时以普通 merge conflict 呈现、不做魔法化解。配套两块共享基础设施：线程共读共写的共享记忆，以及收集输入文件与产物的库。发布有成本警告：多线程并发会更快触达用量上限。

关键数字：2026-11-14 发布 beta；首批仅限使用云会话且无存量项目的部分 Claude Pro/Max 订阅者，一周内扩展到更多 Claude Code 用户，之后覆盖 chat、Cowork 及 Team/Enterprise；现有项目不受影响、逐步升级。

为什么值得看：Claude 产品形态的重大转向——"项目"从静态文件夹变成可并行、可后台长跑的协调式工作流，agent 编排的官方新范式。
