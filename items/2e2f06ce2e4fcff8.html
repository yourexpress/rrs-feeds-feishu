HiState: Hierarchical Prefix Cache Management for Hybrid LLM Serving in Agentic Workloads

arXiv (cs.DC) · 2026-10-30 · 论文PDF / 每日精选

研究问题 混合 LLM（全注意力+循环线性层）服务 agent 负载时循环 checkpoint 无法恢复短前缀状态，agent 反复修改回看早期上下文导致缓存命中失效。

方法 观察到前缀复用只需一个与上下文长度无关的循环 checkpoint，把历史 checkpoint 放 SSD、快内存优先放 KV；配自适应间隔控制与统一淘汰。

关键数字 真实 agent 轨迹上 p99 TTFT 较 vLLM-Marconi 最高 5.73x、较 SGLang-HiCache 最高 5.44x。

为什么值得看 针对 agent 工作负载的层级前缀缓存设计，对混合架构 serving 有参考价值。
