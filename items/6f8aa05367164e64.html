T-CCL: Resource Efficient and Performant Collective Communication using Tensor Memory Accelerator

arXiv cs.DC · 2026-10-08 · 论文PDF / 每日精选

研究问题： 多 GPU 大模型执行依赖频繁集合通信，现有通信库为抢带宽或低延迟占用大量 SM，挤占与通信并发的计算资源。

方法： T-CCL 基于 Tensor Memory Accelerator（TMA）做节点内集合通信：把数据搬运与归约都卸载给 TMA，每个集合操作执行为流水化的异步 TMA 操作序列，在保持高带宽的同时大幅降低 SM 侧资源占用。

关键数字： AllReduce/AllGather/ReduceScatter 上比 NCCL 最高快 2.4 倍（资源不受限）与 3.42 倍（资源受限）；GEMM 重叠场景算子级加速从 1.12→1.25（2 卡）、1.04→1.14（4 卡）；作为 vLLM 通信后端端到端吞吐最高提升 1.31 倍，各 batch size 均优于自动调度。

为什么值得看： 通信不占 SM 才是真重叠——对训练与推理的通信-计算重叠都直接可用，已落地 vLLM。
