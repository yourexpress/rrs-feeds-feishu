Not All AI Agents Are Equal: Characterizing Resource and Performance Dynamics

arXiv（Wonmi Choi 等，cs.AI） · 2026-09-17 · 论文PDF

研究问题 LLM 智能体通过迭代推理与工具执行处理请求，延迟、本地资源需求与容器瓶颈跨请求交织，现有生态忽视资源动态、浪费严重。

方法 对检索增强问答、网页搜索、软件编码三类代表性任务刻画并发处理时的资源动态，发现任务相关的 CPU、磁盘 I/O、内存瓶颈，并据此设计 CPU 感知的工具准入与任务感知的 CPU 分配两种优化。

关键数字 CPU 敏感型智能体任务延迟改善约 5.4 倍；跨任务平均延迟较原生智能体降低约 32%。

为什么值得看 「更快的 LLM 响应或更多 CPU 核未必让智能体更快」等反直觉发现，对 agent serving 与部署优化很实用。
