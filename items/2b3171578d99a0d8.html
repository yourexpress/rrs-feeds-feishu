Judged Useless, Queried Anyway

arXiv（NTU/A*STAR 等） · 2026-10-07 · 论文PDF / 每日精选

研究问题： 工具持续返回无用结果时，agent 理应停止依赖它；但实验中 agent 明明判断结果无用却仍继续调用——判断与行动为何脱节？

方法： 在带可控检索源失效的环境中分离"评判"与"行为"：对比 agent 在连续长/短串无用结果后的停止点（排除时钟/期限驱动的停止）；测试 7 个 agent 与多种 prompt 干预，并用 300 个全新问题做预注册复现。

关键数字： agent 把失效源结果判为"无用"的比例高达 97–100%，但大多数极少据此停止；prompt 提示只能改变何时停、改变不了依据什么停；唯有 harness 强制的整合步骤（连续 5 个被判无用的结果后必须作答）让所有模型的停止行为随证据走、预算翻倍也不漂移，且每个模型的失效源成功率都提升；预注册复现确认了该效应。

为什么值得看： 揭示 agent"知道没用还硬查"的系统性缺陷，并给出 harness 层简单有效的修法，对工具型 agent 设计直接有用。
