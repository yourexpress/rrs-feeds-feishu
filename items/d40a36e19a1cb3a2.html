Fast and Memory Efficient Offload Training Framework with Hybrid XPU Computation

arXiv cs.DC · 2026-10-09 · 论文PDF / 每日精选

研究问题 ZeRO-Offload 把优化器状态搬到 CPU 缓解显存不足，但存在 GPU 利用率低、通信计算重叠不完美、offload 不灵活等缺陷。

方法 利用 GPU 的 Direct Host Access（DHA）直接计算 CPU 内存中的数据，形成 GPU 加 DHA 的混合计算：调度器选择哪些参数层走 DHA、其余同时传入显存以缩短前向，反向时再把 DHA 参数载入显存；shadow model 提供统一内存抽象；动态规划算法把梯度也经 DHA offload；ScaleUp-MemFerry 再利用 scale-up 互联带宽做自适应多路径传输。

关键数字 单卡训练最快 1.68×、可训模型大 1.52×（对比 ZeRO-Offload）；8 卡数据并行提速至少 28.1%；华为 CloudMatrix384 上端到端迭代时间较 DeepSpeed 最多降 20.7%。

为什么值得看 DHA 这一少被利用的硬件能力被用出系统级收益，且已在国产 scale-up 节点验证。
