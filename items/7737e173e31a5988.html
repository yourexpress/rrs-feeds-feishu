Introducing Claude Whiteboards, Claude Sheets, and Claude Data

Anthropic · 2026-11-10 · 技术博客 / 每日精选

核心话题 Anthropic 发布 Claude Whiteboards 与 Claude Sheets（测试版），并把 Claude Dashboards 正式更名为 Claude Data 开放正式版，把办公协作放进 Claude 内。

要点 Whiteboards 是与 Claude 实时头脑风暴的共享白板，可自动生成带负责人与时间线的板并转成文档/演示；Sheets 可按提示生成含标签、公式、格式与下拉的表格并协作编辑；Claude Data 新增 certified queries、数据故事与实时共享，图表可带认证徽标。

关键数字 三项功能面向全部付费计划开放；Sheets 目前为简单表格功能，可导出 .xlsx 或 CSV 对接 Excel。

为什么值得看 Claude 生态向办公套件延伸，表格/数据产品的形态值得跟进。
