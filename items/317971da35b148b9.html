Introducing Clef: our open-source decision models, and new RL fine-tuning platform

Cloudflare · 2026-10-01 · 技术博客 / 每日精选

核心话题 Cloudflare 发布自研开源决策模型 Clef 与 Clef-flash（托管于 Workers AI，Hugging Face 上 Apache 2.0 开源），并推出 RL 微调平台，回应 Typesafe AI Jev 带火的"决策模型"概念。

要点 决策模型输出有界结构化结果（类别+概率），供 agent 程序化地路由、升级或转交人工，介于非确定性 LLM 与传统分类器之间，无需为新类别反复重训。Clef 在 Jev Decision Index 上领先且完全兼容 Jev API。Cloudflare 威胁情报团队已用其做域名分类（如 95% 时尚、85% 电商、<1% 钓鱼）。

关键数字 Clef 完成抓取、渲染、分类一个网站耗时 2.2s，最快通用 LLM gpt-oss-120b 同流程需 4.7s 且只返回两个分类——延迟减半、结果更全。

为什么值得看 "决策模型"作为 agent 工作流新原语正在成形，Cloudflare 连模型带 RL 微调平台一起开源，值得动手一试。
