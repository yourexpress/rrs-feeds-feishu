QDA: Closed-Loop LLM Quantization Design with Agents

arXiv · 2026-11-17 · 论文PDF / 每日精选

研究问题 后训练量化（PTQ）的最佳配方因模型和精度而异，专家需为每个新模型重新设计，耗时且常非最优。

方法 QDA 让 LLM agent 闭环设计量化配方：用输出 KL 散度在几分钟内给候选打分、长生成校验失败模式（如重复循环）；提供跨架构兼容的公开 PTQ 方法库加速构建。

关键数字 四个推理模型上 W4A16/W4A8/W3A16 平均超最强公开配方 0.9/1.4/2.2 个百分点，每次搜索约 64 GPU 小时；GLM-5.3-Flash（320B MoE）在 NVFP4 W4A4 恢复 FP8 模型 98.3% 准确率，最强厂商 checkpoint 为 96.9%。

为什么值得看 agent 驱动的量化配方自动设计，直接解决"每模型重做 PTQ"的工程痛点，产物可跑现有 serving kernel。
