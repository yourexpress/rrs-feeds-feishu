Long-Lived Characters, Local Inference: Incremental Memory Maintenance for Game NPCs

arXiv（Zimu Xu，cs.CL） · 2026-09-16 · 论文PDF

研究问题：本地部署的语言模型游戏 NPC 不该每轮对话前重读「一生」——少量记忆修订就会使长可复用前缀失效，准备成本与前台对话及其它角色的维护相互竞争；且事实性记忆错误会污染游戏规则输入。

方法：在量化 Qwen 混合循环-注意力模型上研究增量记忆维护：运行时删除被取代的注意力 KV 项、在真实序列尾部计算替换记录、保留连续的循环状态与未变 KV。实验结合多更新对话回放、固定输入位置消融与注意力诊断。

关键数字：八轮脚本化维护中真实尾部更新保住重要的当前状态与历史绑定；一个位置案例在三次重建中恢复全量重填的数量，而保槽位替代方案重复出现双重扣减错误；注意力分布接近性本身无法解释这些语义差异。

为什么值得看：提出把角色推理状态当作「需维护的历史依赖资源」而非一次性编码，对长寿命本地 NPC 与边缘部署 agent 的记忆工程有新启发。
