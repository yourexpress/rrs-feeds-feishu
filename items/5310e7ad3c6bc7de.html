Norn: Context-Length-Aware Optimization of Weight and KV Cache Placement for Offloaded LLM Inference

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：把权重与 KV 缓存 offload 到 host 内存使 LLM 可跑在单张内存受限 GPU；解码中 KV 不断增长，GPU 内存需求与传输/注意力成本随之变化，但现有方法用静态计算分配与放置，无法适应。

方法：Norn 上下文长度感知 offload 推理：基于离线 profiling 在子层级别协同优化计算分配与放置，预计算多个执行计划及其切换点；解码中随上下文长度增长切换计划，无需预知输出长度即可重叠计算与数据传输；prefill 用 operator-major chunked prefill 避免重复权重传输并自动选择 chunk 大小。

关键数字：Qwen3-14B 与 Qwen3-32B 在两个单 GPU 系统上，端到端延迟较 Pipelined Sharding 最高提速 16.8x，较已知输入输出长度的 oracle 变体提速 4.2x。

为什么值得看：offload 推理随上下文动态换执行计划，单 GPU 大模型推理显著加速。
