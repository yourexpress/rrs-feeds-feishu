mzCache: On-Device LLM Memory Management under Multitasking

arXiv（Hongseung Yu 等，cs.OS） · 2026-09-01 · 论文PDF

研究问题 端侧 LLM 推理处在多任务环境：应用频繁切换造成内存压力，模型权重与 KV cache 被系统驱逐，新请求只能靠慢速存储读回或全量重算 KV，响应性严重受损。

方法 mzCache 面向多任务的端侧 LLM 内存管理：弹性驱逐 LLM 内存，利用移动 SoC 统一内存实现 GPU 零等待推理与 CPU 侧并发恢复；内存切分为细粒度共享缓冲以支持部分驱逐/恢复，混合 swap 与 backward-out 驱逐策略保证任意驱逐态下低延迟恢复。

关键数字 基于 llama.cpp 实现并部署为 Android 应用；相比存储支撑的部分卸载，首 token 时间降低 2.1–5.5×，并在真实多任务场景验证有效。

为什么值得看 把 OS 级内存压力纳入端侧推理系统设计，是手机跑 LLM 走向实用的关键一环。
