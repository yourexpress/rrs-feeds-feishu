Muse Spark Is Now an Open-Weights Model

PyTorch Blog（Meta） · 2026-10-15 · 技术博客 / 每日精选

核心话题 Meta 开放 Muse Spark Open 权重（Muse Model License），称其为迄今能力最强的美国开放权重模型。

要点 816B 总参/42B 激活的 MoE，1M token 上下文，原生多模态（图像、文档、音频、音视频），面向编码与智能体工作流训练，附加安全后训练；与 Muse Spark 1.3 共享基座；SGLang 与 vLLM 首日支持，覆盖 NVIDIA、AMD、Intel；随模型交付 Helion（PyTorch 原生内核 DSL，2026 年 4 月并入 PyTorch 基金会）实现的 RoPE、RMSNorm、量化等算子，TorchTitan 开箱支持 SFT 与 RL。

关键数字 Helion 内核在 NVIDIA GB300 上比 CUDA/CuTe DSL 定制内核快 1.03–3.95 倍；同一批内核直接移植到 AMD MI350 获得相近提升，端到端再提升 3%。

为什么值得看 旗舰开放模型叠加 PyTorch 可移植内核生态的样板，跨硬件内核路线的重要观察点。
