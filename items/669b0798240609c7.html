TokenEconomizer: Learning from Experience to Make AI Coding Agents More Efficient

Microsoft · 2026-11-16 · 技术博客 / 每日精选

核心话题：AI 编程 agent 每天在同一代码库工作却每次从零开始——重复发现事实、加载从不用的工具、反复踩同一错误，能否用仓库历史经验降低 token 成本？

要点：TokenEconomizer 是 UC Berkeley、微软研究院与微软安全联合开源的插件，从会话日志学习仓库知识，不改 agent 或底层模型；三个机制：micro-skills（一行式仓库知识笔记，多会话确认后才进入初始上下文、被矛盾证据推翻即退役）、tool pruning（按仓库历史剪掉不用的工具、保留核心工具）、failure-loop intervention（监视反复失败循环）；profile 显示三类浪费：仓库积累 ≥5 个任务后 30% 工具调用重复早前动作、每轮收到 23 个工具描述但 16 个从未调用、17% 失败任务吃掉 32% 花费。

关键数字：277 个真实 bug 修复任务上成本降 18.4–30.9%、覆盖多个 AI 编码 agent；每个被测仓库成本都下降，任务成功率基本保持稳定。

为什么值得看：不改模型不改 agent 的纯插件式 token 省钱方案，可直接插进现有编码 agent 工作流。
