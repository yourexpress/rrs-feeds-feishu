Introducing Images 2.6

OpenAI · 2026-11-04 · 官方公告 / 每日精选

核心话题： OpenAI 发布 ChatGPT Images 2.6（ChatGPT、Codex 与 API 同步上线）。 要点： 支持 GIF 动图生成（品牌吉祥物/产品镜头动效）；SVG 矢量导出、参考图保持角色/产品/品牌一致性；新增复杂度参数调节模型规划程度；API 提供 GPT-Image-2.6 Flare 与 Sunburst 两个模型，并开放 image markup 标注。 关键数字： 全球用户现每周生成 40 亿张图（日均超 5 亿）；出图提速约 50%；Flare 在 low 质量档最快约 6 秒出图。 为什么值得看： 图像生成进入"动图+矢量+可控规划"的新阶段，创作者与 API 开发者都应关注。
