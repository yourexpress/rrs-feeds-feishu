Selection-Based Structured Reasoning: Toward Efficient Multimodal Search Agents

arXiv (cs.LG) · 2026-10-02 · 论文PDF

研究问题： 多模态 agent 每步先做自由形式推理，小模型生成的冗长推理对动作指导有限，却带来可观的推理成本。

方法： SSR 把推理重构为选择而非开放式生成：高频高层推理用预定义自然语言候选表示，模型按当前上下文似然挑选；teacher-forced 预填充 + 共享上下文 KV cache 实现候选内与跨候选并行打分。

关键数字： 7 个多模态搜索基准、2B/4B 模型；每轮推理延迟降超 90%，每问总推理延迟降 28–54%，成功率与同规模领先 agent 相当。

为什么值得看： 小模型多模态搜索 agent 效率大幅提升而性能不损。
