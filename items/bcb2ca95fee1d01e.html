FISGuard: Defending Against Membership Inference via Fixed Input Subspaces

arXiv（Haocheng Jiang 等，cs.CR） · 2026-08-28 · 论文PDF

研究问题：联邦学习里客户端只共享梯度，但 ProjRes 攻击仅凭「候选表示与服务器可见梯度子空间的投影残差」就能区分训练成员——传统梯度扰动类防御对它失效，怎么办？

方法：FISGuard：用独立公开数据预先构造并固定一个低维表示子空间，限制私有表示经梯度暴露的空间，从而压缩成员与非成员的投影残差差异，同时保留下游任务所需主信息。

关键数字：在 3 个 NLP 数据集、2 个 LLM、Adapter 与 LoRA 两种微调策略下与 5 种代表性防御对比：多数场景把 ProjRes 攻击 AUC 压到接近随机猜测的 0.5，下游性能接近无防御模型，计算开销有限。

为什么值得看：针对几何结构类成员推断攻击的轻量对因防御，隐私-效用折中漂亮。
