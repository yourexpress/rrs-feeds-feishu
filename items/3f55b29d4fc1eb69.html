KVEraser: Learning to Steer KV Cache for Efficient Localized Context Erasing

arXiv / Mufei Li 等 · 2026-09-29 · 论文PDF

研究问题 长上下文 LLM 中，若 prefill 之后才识别出该删的过期/有害片段，能否只做局部修改而不重算后缀？

方法 KVEraser 把被删区间的 KV 状态替换为"学习到的 steering state"，其余缓存原样复用；训练分两阶段：先做通用 span-neighbor 预训练，再做任务特定微调，以获得可迁移的擦除机制。

关键数字 1K–32K 上下文下，擦除后性能几乎追平完全重算，延迟仅增 29.6%，而完全重算延迟增幅为 17.6 倍；在含事实干扰的长文档 QA 与含恶意技能文件注入的工具选择上优于其他近似基线，相对完全重算加速 2.9–10.7 倍；rank-16 LoRA 擦除器只训练约为生成器 0.6% 的参数，效果持平或更好。

为什么值得看 免去"删除即重算"的高昂代价且参数开销极小，对做上下文合规、可撤销 Agent 的团队直接可用。
