RLX: A Unified Multi-Backend Tensor Compiler and Distributed Runtime in Rust

arXiv / Eugene Hauptmann 等 · 2026-09-30 · 论文PDF / 每日精选

研究问题 生产级 ML 栈常把图编译与 kernel 执行拆在不同层次与语言里，后端行为、部署保证与性能回退难以端到端推理。

方法 RLX 用单一 Rust 代码库统一编译器与运行时：一套原语级三级 IR，加透明派发契约——每个算子解析到原生、公共 IR 或重写降级，无法合法化即编译失败；支持 safetensors/GGUF/ONNX/rten 输入、F16/BF16/F64/C64 与 INT4/INT8 量化（AMP/PTQ/QAT），TCP/RDMA 上做张量/流水并行；还扩展到稀疏/稠密线代与 3D 高斯泼溅算子。

关键数字 同一 IR 覆盖 14 种运行时设备（cpu/metal/mlx/cuda/rocm/tpu/hexagon/webgpu 等）与 2 条特种代码生成路径（Cortex-M INT8、FPGA）；与 PyTorch、JAX、TensorRT 等 14 个栈同方法对比，all-MiniLM-L6-v2 各 batch 均最快（batch 32 时 16.6 ms vs PyTorch-MPS 26.7 ms）。

为什么值得看 Rust 一体化编译器+运行时+分布式运行时，覆盖面罕见地广，适合关注推理栈工程化的人。
