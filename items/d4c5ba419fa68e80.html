Mosaic: GPU Sharing with Latency Guarantees through Kernel-Level Interference Prediction

arXiv cs.DC · 2026-10-08 · 论文PDF / 每日精选

研究问题： GPU 常大量空闲、共置（colocation）可提高利用率，但干扰会破坏延迟敏感负载的 SLO；现有方法要么靠粗粒度启发式、要么依赖模拟器特定的预测指标，忽略 thread-block 摆放、内存层级争用与 SM 内资源竞争等多机制干扰。

方法： Mosaic kernel 级干扰预测器，用解析模型 + 轻量学习模型组合显式建模上述机制；配套 MosaicSched 调度器做在线 kernel 准入控制，并在整 GPU 共置与 SM 分区之间选择，以最大化 best-effort 吞吐同时满足延迟 SLO。

关键数字： 四种 GPU 架构上预测误差比既有预测器降低最高一个数量级；全部负载上 p99 延迟保持低于或非常接近目标 SLO。

为什么值得看： 把 GPU 干扰从「玄学调参」变成机制化可预测可调度的模型，共享 GPU 集群运维直接可用。
