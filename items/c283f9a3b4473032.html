ESupNNet: An Error Supervising Neural Network architecture for error detection against soft errors in parameters

arXiv (cs.AR) · 2026-09-23 · 论文PDF

研究问题 CNN 参数中的软错误会导致误分类，需要一种开销小、可与既有保护技术叠加的检测手段。

方法 提出一种利用被保护 CNN 自身诱导出的类间关系的架构来检测误分类错误：资源开销极小，且不需要修改被保护的 CNN，因此可与其他错误保护技术组合使用。

关键数字 在五组现代数据集-模型组合上严格验证（从数据集构造到实验结果采集均做统计显著性检验）：ImageNet-1K 配 ResNet-50 与 EfficientNetV2-Small，CIFAR-10 配 MobileNetV3、ShuffleNetV2-Small（2.0× 输出通道）与深度倍数 1.3 的 MNASNet；单错误检测准确率超过 90%，在多个误码率下检测效果良好，并有望通过超参调优进一步提升。

为什么值得看 端侧小 CNN（尤其唤醒词这类模型）上做容错，这个"旁路监督网络"的开销水平是读者可以直接评估的。
