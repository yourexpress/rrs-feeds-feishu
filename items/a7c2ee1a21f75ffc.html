Storing the Gemma 4 K=V Cache Once: Exact Global-KV Memory Savings in a Paged Serving Engine with Unchanged Attention Kernels

arXiv cs.LG · 2026-11-17 · 论文PDF / 每日精选

研究问题：Gemma 4 31B 全局注意力层中 value 是归一化 key 投影、key 是 value 乘固定权重（旋转位置编码占四分之一维度）；官方报告称该设计可降全局 KV cache 至多 37.5%，但开源 serving 引擎仍存完整 key+value（每 KV head 每 token 1,024 值）。

方法：只存一行 640 值（实数算术下精确），未改动的 paged attention 核通过两个重叠 strided 视图把它同时读作 key cache 与 value cache；在 vLLM 原型中验证 16-bit 31B 模型。

关键数字：输出与模拟逐位一致，432 个最终答案中仅 2 个与 stock 引擎不同（在其 run-to-run 噪声内）；32K-64K token 时每请求稳态解码 KV 内存降 1.34-1.40×；双 A100 + NIXL + CPU offload 下 16K-token prompt 解码 token 数 1.38×、8K 为 1.24×；eager 解码吞吐升 1.30/1.11×，等 batch 下 eager 步骤慢 4-9%。

为什么值得看：利用 Gemma 4 31B 的结构冗余做"只存一次 KV"的精确内存节省，且不改注意力核、输出逐位一致。
