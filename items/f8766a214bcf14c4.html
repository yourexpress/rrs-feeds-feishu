Speculative Safety Honeypot: Toward Proactive Defense Against Multi-turn Agent Attacks

arXiv / Zezhong Wang 等 · 2026-09-30 · 论文PDF

研究问题 LLM agent 多轮交互攻击日益严重，现有检测依赖历史上下文，难以识别被拆分到多轮、隐藏未来风险的深层恶意意图。

方法 受投机解码启发提出 Speculative Safety Honeypot（SSH）：用小型 LLM 构建多 agent 模拟系统，先预测目标 agent 未来行为、异步构建轨迹树暴露潜在风险，再用真实动作校准剪枝轨迹树降低误报；风险判断基于整棵树演化而非单点时刻。

关键数字 摘要未给出量化指标；作为即插即用组件可为现有检测器提供超越当前交互切片的决策冗余。

为什么值得看 把 agent 防御从"回顾式检测"转向"前瞻式预警"。
