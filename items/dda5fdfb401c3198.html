Tessera: Demand-Driven KV Cache Management for Retrieval-Augmented LLM Serving

arXiv (cs.DC) · 2026-09-26 · 论文PDF

研究问题 RAG 与检索型 agent 记忆把检索内容注入 prompt，同一内容可跨请求出现在不同位置或不同前缀之后，常规前缀缓存无法复用——这类记录占 agent 记忆工作负载注入内存 token 的 70% 以上，在线管理难：单元的 KV 状态可能尚不存在、已被驱逐或位于其他节点。

方法 提出 Tessera：分离式 serving 系统，把检索作为 KV 复用的控制平面——模型执行前先暴露所需上下文单元，结合当前需求、检索历史、KV 驻留与生成负载协调缓存管理与请求路由；生成节点并发准备本地缓存、远端缓存与缺失状态，新算出的状态留在请求关键路径之外。

关键数字 RAG 与 agent 记忆工作负载下，匹配请求率时平均 TTFT 相对 SGLang 与 LMCache+EPIC 最多降 3.6×，并在基线饱和的负载率下维持低 TTFT。

为什么值得看 "检索驱动 KV 复用"把缓存管理与请求路由统一进控制平面，对 RAG 服务架构有借鉴意义。
