L2C2: Enhancing Large-scale Chiplets for Agent Long-Context LLM Inference with Sparse and Distributed Attention

arXiv (cs.AR) · 2026-11-25 · 论文PDF / 每日精选

研究问题： 面向 agent 的长上下文推理需求上升，稀疏注意力（SpAt）+ chiplet 是减计算、扩规模的方向，但 SpAt 部署到分布式 chiplet 需要上下文并行做工作负载切分，分布式注意力实现复杂。

方法： L2C2 系统优化：部分预填充阶段提出 Split-Comm Attention（利用 chiplet 高带宽互联以通信换内存访问）并与传统 Ring Attention 组合成 Bi-Mode 适应不同序列长度；解码阶段分析内存访问失衡根因，用静态交错 token 分配 + 动态敏捷缓存均衡适配 SpAt 偏斜。

关键数字： 大规模 chiplet 上部分预填充加速 1.45x、解码加速 1.53x（相对 SpAt 基线）。

为什么值得看： 为 chiplet 上的分布式稀疏注意力提供系统级方案，直指 agent 长上下文推理的硬件瓶颈。
