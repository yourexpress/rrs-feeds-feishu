Measuring the Energy Cost of Completing Tasks with Quantized Language-Model Agents

· 2026-10-23 · 论文PDF / 每日精选

研究问题 量化省内存与能耗，但现有研究要么在单请求上对比量化模型、要么在单一精度下测 agent——精度变化在完整 agent 任务上的能耗权衡从未被刻画。

方法 首次刻画本地部署 agent 的"任务级"量化能耗权衡：构建 29 个带自动 pass/fail 检查的 agent 任务（6 个家族，从单答案 SQL 分析到多步仓库 bug 修复），在裸金属 NVIDIA A100 节点上用 llama.cpp 测量两个开源模型 4-bit 与 8-bit 版本每输出 token 与每完成任务 的 CPU/GPU 能耗。

关键数字 29 个任务、2 个模型、4-bit/8-bit 两档精度、A100 裸金属实测；结果显示 4-bit 的能耗收益（摘要未给出完整数值结论）。

为什么值得看 量化收益的评估口径从逐 token 升级到任务级，agent 能耗评估方法论参考。
