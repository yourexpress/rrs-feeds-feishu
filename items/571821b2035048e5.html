Diminishing Returns of Data in Sparse Autoencoders: Functional Behavior does not Guarantee Feature Reproducibility

arXiv · 2026-10-14 · 论文PDF

研究问题 稀疏自编码器（SAE）通常用数亿至数十亿激活 token 训练，这个规模是否必要？

方法 在 3 个语言模型上训练 4 种 SAE 架构，预算从 5M token 到 500M token 参考规模，分别度量功能行为收敛与学习特征的一对一可复现性两个收敛维度。

关键数字 Gemma-2-2B BatchTopK 上，严格匹配特征比例从 5M token 的 2% 升至 50M 的 29%；随机采样更保激活分布、一般利于重建，多样性采样常改善 AutoInterp。

为什么值得看 SAE 训练可按目标大幅提效，并强调特征级主张必须辅以显式可复现性检查，为更便宜可靠的 SAE 研究铺路。
