DEALS: Decentralized Expertise-Aware Load Serving for Multi-Agent LLM Systems

arXiv (cs.LG) · 2026-09-27 · 论文PDF

研究问题 多智能体系统大多依赖集中控制器或固定协调模式，限制可扩展性与适应性；去中心化动态方案又常需训练专用路由器或调用 LLM 选 agent，计算与协调开销大。

方法 DEALS 去中心化低复杂度框架：每个 agent 维护本地任务队列，路由器依据积压差与成功率决定本地处理还是转发给邻居；执行器在 agent 内外并发处理独立任务，部分完成的任务可被其他 agent 续接恢复。

关键数字 在异构与同质 agent 池上，答案准确率、任务吞吐等多维度均有提升，并自组织平衡 agent 专长与负载（摘要未给出具体量化数值）。

为什么值得看 免训练的纯本地去中心化路由，为大规模多 agent 协作的可扩展性提供新思路。
