From Semantic to Token Communication: The Next Paradigm for Large-Model-Driven 6G Intelligent Connectivity

arXiv（Yu Ma 等，eess.SP） · 2026-09-09 · 论文PDF

研究问题 大模型驱动的语义通信（SemCom）语义表示绑定特定模态/模型/任务，缺少类似"比特"的通用语义单元，制约 6G 互通与规模化。

方法 综述提出 TokenCom：以 LM 原生 token 作为比特之上的通信抽象，在 token 粒度做重要性分配、差错处理与资源分配；梳理 SemCom 三大方向、token 抽象所需传输技术及面向 LM 服务与具身智能的新范式。

关键数字 综述类，无实验数字；价值在概念框架与开放挑战清单。

为什么值得看 把语义通信收敛到 token 这一可操作抽象，AI-native 6G 方向少见的统一视角。
