SchemaFill: Efficient LLM Tool Calling via Slot-Parallel Speculative Decoding

arXiv cs.LG · 2026-10-08 · 论文PDF / 每日精选

研究问题： LLM 工具调用的结构化参数逐 token 自回归生成，多调用、多字段请求延迟高；但后续参数值依赖前面的字段与调用，独立并行生成会与目标模型输出不一致。

方法： SchemaFill 做槽位并行投机解码：无需预知调用序列与参数值，并发地为未来槽位生成候选值，把跨字段、跨调用的候选拼接后在真实输出前缀下由目标模型统一验证，只提交验证通过的 token，分歧处由目标模型纠正。

关键数字： 在 Glaive 与 BFCL 上，端到端吞吐相对自回归解码最高提升 4.05 倍；代码已开源。

为什么值得看： 把投机解码从自由文本扩展到结构化工具调用，多参数、多调用场景收益直接，agent 链路延迟优化可即插即用。
