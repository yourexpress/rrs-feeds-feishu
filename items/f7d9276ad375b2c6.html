Divide, Consult, and Conquer: Capability Laundering Through Aligned LLMs

Microsoft · 2026-09-16 · 论文PDF / 每日精选

研究问题：LLM 安全评测是"一次一个交互"——若弱模型把有害任务拆成多个看似良性的子问题、分别咨询强对齐模型再本地组装呢？

方法：提出 capability laundering（能力洗白）攻击：弱未对齐 orchestrator 分解任务 → 对齐强模型逐个咨询 → 本地合并答案；评测 GPT-5.5、Claude Opus 4.8、Grok-4.3 作为顾问，四个本地 orchestrator，任务集 CyBench / BountyBench / 有害 CBRN 请求。

关键数字：CyBench 上 Gemma-4-31B 借助咨询恢复 8/14 个候选任务能力（详见原文）。

为什么值得看：与越狱不同——没有任何单个回复是有害的，现有单轮护栏完全拦不住；对 agent 时代的 API 安全设计是必读警示。
