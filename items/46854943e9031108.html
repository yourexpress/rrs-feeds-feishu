Performance Analysis of Low-Order, GPU-accelerated Finite Element Kernels using Kokkos

arXiv（cs.PF） · 2026-09-18 · 论文PDF

研究问题：研究低阶、无矩阵（matrix-free）有限元 kernel 的性能可移植性，示例对象是一个源自地球物理模型的向量值变系数 PDE 算子。

方法：kernel 用 Kokkos 编写，在 NVIDIA H100、AMD MI250X、AMD MI300A、Intel PVC Max 1550 四款 GPU 上对比；考察 Kokkos 层级并行与共享 scratch 内存（用于 conforming 离散的共享自由度）在各设备上的表现。

关键数字：摘要未给出具体加速数值；核心观察是：低阶与算术优化使 kernel 算术强度低，性能取决于有限元组装如何映射到内存层级——这一维度上架构差异甚至存在于同一厂商内部；通过线程组大小、占用率与寄存器用量的平衡、kernel 末尾原子累加策略等调优杠杆，可缩小可移植性差距。

为什么值得看：为低阶无矩阵有限元在异构 GPU 平台上的性能可移植问题给出具体案例与调优清单，对地球物理类数值计算移植有直接参考价值。
