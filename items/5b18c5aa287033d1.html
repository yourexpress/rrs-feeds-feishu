Bit-Sparsity Aware Acceleration with Compact CSD Code on Generic Matrix Multiplication

arXiv cs.AR · 2026-11-11 · 论文PDF / 每日精选

研究问题：bit-sparsity 加速在神经网络中效果显著，但如何扩展到同时处理浮点与量化整数的通用矩阵乘场景？

方法：Bit-Cigma 硬件架构：CCSD 编码（基于 CSD 的优化片上稀疏化，成本减半且达最优位稀疏）；分段点积（长 FP 向量的多级指数匹配）；统一支持 FP 与 QINT 数据类型。

关键数字：65nm @ 1GHz 实现；FP32 对比 SOTA Bitlet 达 3.2x 性能、6.1x 面积效率、15.3x 能效，且零计算误差。

为什么值得看：把位稀疏加速从神经网络剪枝/量化扩展到通用矩阵乘，硬件-算法协同设计参考。
