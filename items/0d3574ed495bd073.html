RR-Evict: Fine-Grained Prefix Cache Eviction beyond LRU for Agentic LLM Serving

arXiv (cs.DC) · 2026-09-26 · 论文PDF

研究问题 LLM 智能体通过重复模型调用执行长时任务，前缀缓存避免重复 prefill，但缓存足迹随上下文长度与并发增长；发现"recency synchronization"：agent 历史访问会一起刷新缓存节点，使 LRU 驱逐集中在少数 agent 的私有历史上——被完全驱逐的 agent 回归时几乎要重算全部上下文。

方法 提出 RR-EVICT：细粒度前缀缓存驱逐策略，轮询访问 agent、每次从各空闲轨迹驱逐尾部块，容量允许时为更多 agent 保留可复用前缀；返回的 agent 可复用部分历史、只重算较小缺失后缀；无需预测未来到达或工具延迟，在 SGLang 中实现。

关键数字 对话与编码 agent 工作负载下，相对 LRU：P99 TTFT 最多降 75.4%，P99 未缓存 prompt token 最多降 65.7%。

为什么值得看 针对 agent 场景缓存驱逐的系统性修补，对 agentic LLM serving 的时延稳定性有直接收益。
