How the Dirty Set Moves: Characterizing Schedule Reuse in Incremental Sparse Matrix Multiplication

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题 稀疏矩阵固定、每步仅少数输入行变化（dirty set）的增量稀疏矩阵乘可复用结果，但 inspector-executor 的分块调度在 dirty set 移动后何时仍有利，此前缺乏系统刻画。

方法 在 21 个 SuiteSparse 矩阵与受控的 dirty set 移动模式上，系统比较增量更新、调度复用（分块执行器 + 缓存调度）与全量重算代码。

关键数字 直接按列增量更新比 8 种全量重算实现（含 Intel oneMKL、PyTorch）中最好者快 2.1–8.2 倍；在 837 个工作负载中 779 个优于保留分块调度的执行器；收益来自分块预处理而非调度缓存；仅当分块能把多个非零元合并进同一次输出写时才更快——该结构性质可在测量前预测。

为什么值得看 为增量稀疏计算"何时值得做调度复用"划出清晰边界，对稀疏运行时开发者是实用指南。
