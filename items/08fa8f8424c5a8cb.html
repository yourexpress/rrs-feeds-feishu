Portable to Efficient: Auto-Tuning Hardware-Agnostic GPU Kernels in Julia

arXiv（Floris-Jan Willemsen 等，cs.PF） · 2026-08-21 · 论文PDF

研究问题：硬件无关 GPU 编程模型改善了可移植性与可维护性，但跨多样架构达到高效执行仍然困难。

方法：为 Julia 重建成熟的 Kernel Tuner 自动调优框架，系统探索硬件无关 GPU kernel 的配置空间，覆盖 NVIDIA、AMD、Intel、Apple GPU；在 NextLA.jl 线性代数库的硬件无关 SVD 上验证。

关键数字：最优配置相对中位参数配置带来 3× 到 7× 的 kernel 性能提升，显示调优对硬件利用率的决定性影响。

为什么值得看：「可移植 + 自动调优」的组合示范，异构 GPU 软件可持续开发的现实路径。
