A Modular Event-Driven Software Architecture for Open-Source Industrial IoT Edge Gateways

arXiv (cs.AR) · 2026-10-09 · 论文PDF / 每日精选

研究问题 传统工业设备接入现代云基础设施是软件工程难题：工业物联网常用封闭的边缘控制器、配置繁琐；开源单板机硬件灵活，却缺少把本地串口协议桥接到云端的标准化软件部署框架。

方法 提出面向开源工业物联网边缘网关的模块化事件驱动软件架构：以容器化 Web 技术栈抽象 Modbus 到 MQTT 协议转换的复杂性，可快速配置通往 AWS IoT 等云平台的遥测数据流；并在边缘层设计本地事件引擎直接处理条件逻辑，降低网络延迟。

关键数字 在工业级树莓派 Compute Module 4（CM4）上完成初步部署验证；摘要称系统集成时间大幅缩短、运行稳定性高，但未给出具体量化指标。

为什么值得看 边缘网关软硬件协同的完整参考设计，事件驱动 + 容器化思路对做边缘计算落地、让老旧设备延寿接入云端的工程实践有直接借鉴意义。
