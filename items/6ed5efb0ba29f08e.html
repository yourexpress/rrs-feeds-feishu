PackServe: SLO-Aware Request Scheduling for Agentic LLM Serving at Scale

arXiv (cs.DC) · 2026-09-27 · 论文PDF

研究问题： 大规模集群服务智能体 LLM 负载时，调度需同时满足三点：跨长共享 prefix 保住 KV 缓存复用、达成 token 级延迟 SLO、最小化 GPU 资源；现有调度常顾此失彼——请求合并牺牲缓存局部性、增加 prefill/decode 干扰。 方法： PackServe 用紧凑白盒模型预测 prefill/decode 干扰下的延迟，据此把请求打包到更少的服务实例，在保住 KV 复用与 SLO 约束的前提下，用可用的延迟余量换每实例吞吐。 关键数字： 64 张 H20 上，30ms/50ms TPOT 目标下比 SOTA 调度器少用 16.8%/24.6% GPU 小时；生产集群（1000+ GPU）上资源占用比原调度减 34.7%。 为什么值得看： 有大规模生产验证的 SLO 感知调度器，工程参考价值高。 原文链接：PackServe: SLO-Aware Request Scheduling for Agentic LLM Serving at Scale
