EvolvAttack: Backdooring self Evolving VLM Agents

arXiv · 2026-10-14 · 论文PDF

研究问题：自进化机制让 VLM agent 通过进化记忆持续适应，但也可能让恶意行为只在部署后浮现——静态触发测试无法暴露。

方法：提出自进化后门攻击面：payload 在初始 agent 中休眠、随 agent 进化逐步激活；memory-aware 后门训练把触发器激活与进化记忆状态耦合，触发器不共存于 payload 相关记忆时保持良性行为。

关键数字：3 个 VLM 骨干、4 个 agent 流水线、三种记忆进化方式下，进化前攻击成功率仅 0.5%、100 次交互内超过 95%，静态扫描可能判定 agent 良性。

为什么值得看：揭示自进化 agent 独有、静态扫描检测不到的隐蔽威胁。
