DARIC: A Position-Independent KV Cache Reuse System with Distribution-Aware Recomputation

arXiv cs.DC · 2026-11-06 · 论文PDF / 每日精选

研究问题：agentic 系统与 RAG 中上下文不断变长，位置无关 KV cache 复用依赖重算 token 子集恢复跨块交互，但现有方案 token 选择开销高、质量差且依赖定制执行流——如何系统-算法协同设计？

方法：DARIC：基于经验 KV 偏差分布的自适应 token 选择策略，按偏差模式调度重算；轻量系统架构让独立 KV cache 生成与重算以最小集成开销接入，完整保留推理引擎既有优化。

关键数字：跨多种数据集与 LLM，一致优于 SOTA 方法，TTFT 提速 1.1×–4.5×，生成质量损失可忽略。

为什么值得看：长上下文推理 KV 复用兼顾质量与部署友好，代码已开源（github.com/Lenovo-ICI/DARIC）。
