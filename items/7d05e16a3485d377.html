CoVeR: Coverage-Based Token Pruning for Multi-View 3D Reasoning in VLMs

arXiv（Nhat-Tan Bui 等，cs.CV） · 2026-09-08 · 论文PDF

研究问题：用多视角图像让 2D VLM 做 3D 推理，会产生随视角数增长的数千冗余视觉 token；学习式重要性剪枝在多视角场景会保留少量显著区域的近重复 token，体素化方法又无法精确控预算且会饱和。

方法：CoVeR 是确定性、免训练的选择器，只用 token 坐标、不用任何学习信号，选出能共同覆盖场景每个区域的 token 集合——严格满足逐场景预算、打破体素化饱和平台、避免近重复选择。

关键数字：仅用约 8% 视觉 token 即保留全 token 性能的 93.5%，在全部三个 3D 推理基准上超过此前 SOTA、平均高 3.9 个百分点；即插即用泛化到四个 VLM。

为什么值得看：证明了「空间覆盖率」与 3D 推理性能的关联，并给出简单无学的最优解——多视角 VLM 推理降本的即战力模块。
