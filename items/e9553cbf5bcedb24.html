MatMoE: Matryoshka Mixture-of-Experts with Dynamic Mixed-Precision Quantization for Efficient Inference

arXiv (cs.LG) · 2026-11-01 · 论文PDF / 每日精选

研究问题 MoE 模型参数规模庞大，阻碍资源受限边缘设备部署；现有混合精度量化是静态的，固定每个专家解码全程的位宽，忽视专家重要性的动态变化与系统负载波动带来的延迟约束。

方法 MatMoE 动态混合精度量化框架：① Matryoshka MoE PTQ 算法，让专家在严格内存预算内以多种精度灵活运行；② floor-and-compensation 量化方法消除 Matryoshka 表示中的冗余内存访问；③ 基于路由分数的动态位宽分配，满足动态延迟需求。在 llama.cpp 上实现 CPU 与 GPU 版本。

关键数字 三个现代 MoE 模型上准确率比 SOTA 静态混合精度方法高 4.0%–18.3%；Raspberry Pi 5 上比 llama.cpp 快 1.3–3.7 倍，RTX 4090 与 Jetson AGX Orin 上快 1.2–1.3 倍。

为什么值得看 面向边缘 MoE 部署的动态精度方案，同时回应准确率与动态延迟两个约束。
