MINE: Entropy-coded Memory-efficient Inference for Large Language Models

arXiv cs.LG · 2026-11-06 · 论文PDF / 每日精选

研究问题：单流 LLM 推理强内存受限（每生成一个 token 每个权重都要从内存流一遍，本地/低延迟部署无法批处理）——无损熵编码能否加速？

方法：MINE：核心是 dtANS-LLM，一个为 LLM 推理改造的 GPU 熵编码方案，利用量化后仍存在的权重非均匀分布；暴露压缩率与解码成本的超参数，按 tensor 与 GPU 自动调参得到模型大小与解码延迟的 Pareto 前沿；以 vLLM 插件集成并按内存预算选择最佳 kernel 配置。

关键数字：Llama-3.1-8B-Instruct + 2.1-bit EntQuant checkpoint 上，相对最快基线 RTX 4060 Ti 加速 2.52×、RTX 5090 加速 1.48×，有效比特率 2.24 与 3.43 bits/weight。

为什么值得看：无损熵编码攻内存瓶颈的新方案，开源且直接集成 vLLM。
