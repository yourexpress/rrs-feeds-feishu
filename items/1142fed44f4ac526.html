FlatCake: A Flat KVCache Storage Architecture for LLM Serving

arXiv(cs.DC) · 2026-10-28 · 论文PDF / 每日精选

研究问题 KV cache 复用加速 LLM serving，但现有 DRAM/SSD 分层层级假设被生产负载打破：双峰复用让 SSD 进入关键读路径，DRAM 暂存与驱逐排序又阻塞 SSD 恢复。

方法 FlatCake 把 DRAM 与 NVMe SSD 视为统一 64 位地址空间中的对等介质；利用 KV 块一次性写入、不可变、会话级复用的特性，创建时按会话连续、层主序直接放置目标介质且永不迁移；经 GPUDirect Storage 合并流式读入 GPU 窗口，DRAM/SSD 请求队列解耦防队头阻塞。

关键数字 Claude Code 生产 trace + DeepSeek-V4-Flash 上，负载升高时维持 94% cache 命中（Mooncake 为 64%），消除 Mooncake 6.5–6.7× SSD 读放大，峰值平均 TTFT 降 1.6×，总 token 吞吐提升 1.6×；Llama-3.1-70B 8K–128K 上下文平均 TTFT 较 Mooncake 最多降 2.4×。

为什么值得看 颠覆分层存储假设的扁平 KV 存储设计，实测数据扎实，对长会话 agent 场景价值大。
