ThreadShift: Transparent Thread-Level Offloading on Transient Cloud Resources Using MPKs

arXiv (cs.DC) · 2026-09-26 · 论文PDF

研究问题 瞬时云资源价格低但不可预测，无法安全重启的应用难以利用；现有方案要么改应用、要么粗粒度 checkpoint——能否透明卸载未修改 Linux 应用的线程且在被回收时保持正确性？

方法 提出 ThreadShift：按线程粒度透明卸载计算密集线程到廉价瞬时资源；用内存保护键（MPK）的三项新用法高效跟踪内存依赖、识别每线程内存写并跨机器维护一致性，实现快速细粒度增量 checkpoint 而无需暂停整个应用。

关键数字 x86-64 Linux 实现：线程卸载低至 164µs，checkpoint 比 CRIU 快最多三个数量级；在机器学习推理、密码任务、内存数据处理等负载上，商用云部署成本最多降 56%。

为什么值得看 免改应用的线程级弹性卸载，为瞬时资源利用与容错提供了一条低侵入路径。
