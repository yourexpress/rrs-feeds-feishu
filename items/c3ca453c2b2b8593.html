DisSparse: Pipelined Top-$p$ Sparse Attention for Long-Context LLM Serving

arXiv · 2026-11-21 · 论文PDF / 每日精选

研究问题 长上下文 LLM 推理被 KV 缓存内存需求卡住；固定预算 top-k 稀疏注意力无论注意力质量分布如何都用同一预算，峰值注意力 head 浪费带宽、弥散 head 丢失上下文。

方法 DisSparse 把 top-p（核）稀疏注意力端到端集成进 vLLM：块选择与调度关键路径解耦、双流流水线把选择延迟藏进层计算、单遍直方图 top-p kernel；另用 token 重定位 kernel 处理块内稀疏（固定大小块混入高/低重要 token 导致的预算膨胀）。

关键数字 稀疏分析（块选择）较 SOTA top-p 方法加速 1.17x–1.80x，精度损失可忽略；同内存预算下最大批比密集 vLLM 大最多 8x。

为什么值得看 解决 top-p 在生产服务系统落地的块分配确定性与 kernel 开销两大难题。
