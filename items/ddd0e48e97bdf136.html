TomasuLLM: Out-of-Order Speculative Execution for LLM Agents

arXiv / Jiangnan Yu 等 · 2026-09-22 · 论文PDF

研究问题：编码 agent 等待编译、测试等长耗时工具时处于空闲，但这些工具的结果通常可预测并提前执行。

方法：TomasuLLM 借鉴乱序处理器设计——草拟未来动作、在隔离 copy-on-write 沙箱中推测执行、追踪依赖与副作用、按轨迹顺序验证后提交。

关键数字：SWE-bench Verified 100 任务 1.31×、Terminal-Bench 2.0 28 任务 1.35×、SWE-Marathon 18 会话 1.27×；4,010 次提交验证记录中零误接受。

为什么值得看：把 Tomasulo 算法的思想搬到 LLM agent 运行时——乱序投机执行、顺序提交，思路优雅且工程上零误判。
