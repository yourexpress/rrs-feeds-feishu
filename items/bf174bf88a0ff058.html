Exo-GPU: Safe, Imperative, User-schedulable Programming for Tensor Cores

arXiv（David Zhao Akeley 等，cs.PL） · 2026-09-14 · 论文PDF

研究问题 GPU 达到峰值性能需要软件显式管理计算与数据搬运的并发（异步 tensor core 与 memcpy 指令），但 CUDA 内联汇编/内联函数无安全保证，Triton 等高层抽象又把异步指令藏进编译器后端、限制调优空间。

方法 Exo-GPU：对 CUDA 最小抽象的低层命令式语言，核心思想是把并行与同步视为顺序代码上的注解而非控制流原语——程序员按顺序语义推理代码，编译器验证顺序-并行等价，保证并行执行与顺序解释功能等价。

关键数字 用 Exo-GPU 编写的 H100 GEMM kernel（wgmma、TMA、split-k）在大问题规模上达到理论峰值的 80% 以上，部分场景超过厂商 CUBLAS 库。

为什么值得看 在"可控性"与"可验证性"之间找到新平衡点的 GPU 编程语言设计，tensor core 编程的值得关注的方向。
