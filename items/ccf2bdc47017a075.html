Pareto-Dominant Clarification: Post-Training Coding LLMs via PPO-Lagrangian Budget Constraints

arXiv cs.LG · 2026-10-06 · 论文PDF

研究问题 编码 agent 在指令模糊时应"追问澄清"还是"直接尝试"？每次来回都有用户与系统成本，形成准确率-效率权衡；现有方法不训练可执行澄清预算下的策略，惩罚式方法需按预算水平逐一调系数。

方法 将澄清建模为带约束的马尔可夫决策过程（CMDP），用 PPO-Lagrangian 对 Qwen2.5-Coder-7B-Instruct 做后训练，在期望提问预算约束下优化编码准确率；用 GPT-4o-mini oracle 模拟器在 HumanEvalComm 上评测。

关键数字 未调优的澄清行为是 Pareto 低效的：预算约束策略可同时获得更高准确率与更低澄清率；各预算水平下呈对数形 Pareto 前沿，追加澄清收益递减；训练出的策略在更难（多退化）任务上提问更频繁。

为什么值得看 把"该不该问"变成可优化的预算分配问题，实证表明无约束的交互式 LLM 系统可能在系统性地低效使用澄清。
