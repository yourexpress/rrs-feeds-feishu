KPage: Cross-Block Page Compaction for Hardware-Efficient Sparse Attention

arXiv · 2026-10-20 · 论文PDF / 每日精选

研究问题 长序列视频 Transformer 的稀疏注意力中，3D token 布局常让选中块部分占用、浪费物理 tile 容量——能否跨逻辑块边界把有效 K/V 页压实进大 tile，提升硬件利用率？

方法 KPage 块稀疏注意力方案：加载时直接把有效 16 行 K/V 页跨逻辑块边界打包进大 tile（不在高带宽内存物化压缩张量）；Q 块在 64×256 与 128×128 tile 间路由以减 query 侧填充；精确掩码与 K/V 页打包在前反向保持原稀疏图。

关键数字 五个代表性负载上较 NVIDIA Block-Sparse Attention（BSA）前向 kernel 加速 1.35×–2.06×（几何平均 1.77×），完全占满块上近持平（1.03×）而 3D 部分块布局达 2.29×；物理 QK 对容量从 334.1G 降到 177.5G 而保留 160.6G 有效交互；SVG2 Wan 14B/720p 上较最强精确稀疏基线 1.49×、较 BSA 1.57×。

为什么值得看 系统性解决稀疏注意力"块内浪费"，跨开源稀疏基线全面占优，且合规审查后将开源并提交 PR 给 NVIDIA cuDNN Frontend。
