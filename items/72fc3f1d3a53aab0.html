Bridging Agent Semantics with Spot Capacity: An Elastic and Recoverable Service Model

arXiv（Minchen Yu，cs.DC） · 2026-08-30 · 论文PDF

研究问题：LLM agent 驱动的长时云推理负载中，各次模型调用的紧迫性、冗余度、完成语义与重放成本都不同——现有 MaaS 服务模型（按需/预留/竞价）能否承载 agent 任务语义？

方法：SemSpot 语义感知服务模型：平台发布带价格、完成概率、失败通知时限的短时效要约，agent 运行时按当前任务状态与完成规则选要约；token 级 SemSpot 进一步在长请求内保留平台推理状态与经运行时验证的语义段。

关键数字：对 6 个 agent 基准的 1,535 个案例审计，归纳出 4 类反复出现的工作流结构，并展示该模型带来的不同成本、服务时长与回退行为。

为什么值得看：把「竞价容量」与「agent 语义」接起来的服务模型设计，为 MaaS 经济学和 agent 基础设施都划出了跨层研究议程。
