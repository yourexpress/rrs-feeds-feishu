TripleKV: Predict, Prefetch, Protect -- KV Cache Management for AI Agents

arXiv · 2026-11-18 · 论文PDF / 每日精选

研究问题：LLM agent 在推理与工具执行间切换、反复复用增长中的上下文，高并发下 KV cache 工作集可达数百 GiB，被逐出的块在 agent 返回时触发昂贵的重取、阻塞推理。

方法：TripleKV 三层 KV 缓存管理：工具感知延迟预测器预估工具调用完成时间、提前把所需 KV 块从 SSD 预取到 host DRAM（避开稀缺 GPU 内存）；消除 DRAM 中 GPU 驻留块的重复；victim-cache 在块被逐出 GPU 时从 SSD 回填。

关键数字：数据/web/编码 agent 上关键路径 SSD 读取占比从 45–76% 降至 10% 以下；P95 TTFT 相对带 DRAM/SSD 分层的 vLLM 最高降 49%，比近期 agent-aware 系统低 1.5–7×。

为什么值得看：利用 agent 工具执行间隙做预取，把重取延迟藏进空闲窗口。
