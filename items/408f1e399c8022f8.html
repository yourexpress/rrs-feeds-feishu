Run Native DLA Inference in Python on NVIDIA Jetson AGX Orin Using cuDLA

NVIDIA Technical Blog · 2026-11-13 · 技术博客 / 每日精选

核心话题：在 NVIDIA Jetson AGX Orin 上用 cuDLA 以纯 Python 跑原生 DLA 推理的完整生命周期。

要点：DLA 是固定功能加速器，高效执行卷积/池化等固定操作，层支持少于 GPU；cuDLA 运行时 API 负责创建设备、加载编译网络、注册内存缓冲与提交推理；cuda.bindings.cudla（cuda-bindings 13.3.0，CUDA Python 项目）是 cuDLA C++ API 的薄封装；混合模式工作流中 CUDA 流协调 DLA 与 GPU 预处理/后处理；JetPack 自带 libcudla.so 无需额外运行时；RTX Spark 把同一 API 带到 Windows AI 笔记本。

关键数字：暴露 13 个函数、9 个数据类型、8 个枚举；要求 Python ≥3.10。

为什么值得看：DLA 推理首次纯 Python 可用，嵌入式与 Windows AI 双平台同一 API。
