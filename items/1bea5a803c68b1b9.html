Write Once, Run Everywhere: The Axon DSL for Shape-Safe and Framework-Agnostic LLM Architectures

arXiv（Jacob Nielsen 等，cs.AI） · 2026-08-20 · 论文PDF

研究问题：整个开源 LLM 生态实际依赖单一平台，模型定义的实现、维护与跨训练/推理框架移植是资源黑洞，限制效率与可移植性。

方法：Axon：强类型、Haskell 风格语法的 DSL，让 LLM 架构「一次编写、处处运行」；协作基于语言规范而非某个框架的愿景，可自动编译为 PyTorch、PyTorch+Triton、JAX、MLX、vLLM 的独立实现。

关键数字：467 组推理 benchmark（135M–32B 模型），相对 Transformers 参考实现的中位加速：PyTorch 7%、PyTorch+Triton 12%、JAX 91%、MLX 107%；作为 vLLM 原生架构（PagedAttention + KV cache）中位加速 58%。

为什么值得看：可移植性不以性能为代价反而更快，模型架构工程的新范式。
