The Effect of Low-Bit Quantization on Memorization and Factual Recall in Language Models: A Multi-Model Study

Motivation. Low-bit quantization (INT8/INT4) is a deployment necessity; it is how language models run on phones, laptops, and edge hardware. Its effect on task accuracy is well characterized. Its effect on model behavior, specifically what a model has memorized and how reliably it recalls facts, is not. This distinction matters for copyright, privacy, and test-set contamination auditing, where the question is not "is the model still accurate?" but "does compression change what the model retains and reveals?" This work treats that question as an empirical, measurable one.

Experimental design. We adopt a controlled, pre-registered-style design in which precision is the independent variable and model behavior is the dependent variable. Precision is varied across FP16/bf16, INT8, and INT4 on the same underlying weights, holding prompts, decoding (greedy, temperature 0), and seed fixed, so any measured difference is attributable to precision rather than sampling or prompt variance. The study runs on two independent backends, Apple MLX (Apple Silicon) and Hugging Face Transformers with bitsandbytes (NVIDIA CUDA), so that a finding which appears on both is a real effect of quantization, not a result produced by one library alone.

Measurement instruments.

1. Factuality: closed-book QA on PopQA (N = 100), stratified by subject popularity (Wikipedia pageviews), alias-aware exact-match scoring; precision effects tested with a paired McNemar test and bootstrap confidence intervals.
