Scheduling Data to Compute: Hierarchical Data Pipelining for LLM Training on AMD GPUs

arXiv · 2026-11-03 · 论文PDF / 每日精选

研究问题：LLM 训练中计算单元等待数据（数据还在慢速内存或别的 GPU 上）导致昂贵算力闲置——能否把等待时间作为首要瓶颈，用 AMD GPU 的显式数据搬运硬件特性持续喂饱计算单元？

方法：编排三类数据搬运特性：Tensor Data Mover（TDM）把张量从 HBM 搬到片上内存、转置加载在加载时按计算所需布局重排、System DMA / Remote DMA 经 scale-up 与 scale-out 网络在 GPU 间搬数据；已集成进 AMD 开源框架。

关键数字：TDM 与转置加载在 kernel 级平均分别提速 1.88x 与 1.19x；SDMA 与 RDMA 对计算与通信重叠平均提速 1.16x 与 1.33x。

为什么值得看：首个用满 AMD GPU 全部数据流水线特性的 LLM 训练系统，且已开源，对 AMD 生态训练性能有直接帮助。
