vLLM Delivers Day-0 Support for Kimi K3.1 Pro

vLLM Blog · 2026-11-04 · 技术博客 / 每日精选

核心话题：vLLM 如何在 day-0 支撑 Kimi K3.1 Pro 的稀疏注意力。

要点：K3.1 Pro 是 2.8T 参数（104B active）多模态 MoE、1M token 上下文，全部 24 个 MLA 层加 DSA 稀疏注意力（indexer 每 token 打分、保留 top-2048 再做精确 MLA）。vLLM 用按块打包的单一 KV cache 容纳 MLA latent、indexer keys 与 KDA 状态；prefill 按 token 切分而非按 head；decode 上下文并行（DCP）配精确 top-k 合并。

关键数字：长上下文 decode 每层读约 23% 的 dense MLA 字节（132B index key vs 576B latent）；token-sharded prefill 在 340K tokens 上 TTFT 快 1.69×；DCP8 KV 容量 21.8M tokens vs TP8 3.04M；AgentX 最高 375.9 tok/s/用户（GB300）、815.6（Rubin）。

为什么值得看：稀疏注意力时代的 serving 系统设计范本，KV 缓存与并行策略均可迁移。
