Coding LLMs Can Be Harnessed to Learn Interpretable Models from Data

arXiv · 2026-10-14 · 论文PDF

研究问题：紧凑可解释分类器对应简单程序——LLM 编码 agent 能否用来从数据中学习可解释模型？

方法：简单 harness 反复提示编码 LLM，给定带标签样例后生成规则集中的下一条规则。

关键数字：表格数据上媲美且常优于 SOTA 规则学习方法（小训练集时尤其突出）；文本上大胜（包括另一个 LLM 规则学习器）；优于标准 harness；因编码 agent 不受高度受限假设空间约束，直接产生新类型的可解释模型。

为什么值得看：开辟"构造可解释分类器"这一新编码基准类别，输出质量可用测试误差定量衡量。
