Mayfly: Lifecycle-Aware High-Bandwidth Flash for Recursive Self-Improvement

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：递归自我改进（RSI）让 LLM 通过提议与评估候选变体改进 agent 系统；高并发下即使就绪 session 的 KV 也超出 GPU HBM，offload 到 host 内存/SSD 增加容量却让 session 等待 HBM 空间；高带宽闪存（HBF）可原地服务溢出，但过多读取延长解码、重复写入消耗闪存寿命。

方法：关键洞察是就绪 KV 的读取位置应跟随突发与衰减：溢出 HBM 时按每步带宽上限从 HBF 原位读取，衰减释放空间后回到 HBM。Mayfly 生命周期引导管理：限制溢出期每步 HBF 读取、session 结束归还 KV、保留每个被驱逐块的闪存备份避免状态转换重写、转发 session 结束信号避免 GC 复制死 KV。

关键数字：128 session/代 × 4 个 HBF 站点时，比把 KV 停放在 HBF 快 34%、比 HBM 满时总从 HBF 读快 23%；并发增长收益扩大，256 session × 8 站点达 55%；每块保留一份闪存副本 + 按声明结束时间修剪避免写放大。

为什么值得看：RSI 场景 KV 生命周期管理的系统方案，延迟与闪存寿命兼得。
