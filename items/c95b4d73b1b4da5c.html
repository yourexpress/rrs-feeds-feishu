NovaFabric: Tamper-Evident, Replayable Evidence for Autonomous AI Agent Runs

arXiv（Mohsen Seyedkazemi Ardebili，cs.CR） · 2026-09-11 · 论文PDF

研究问题：自主 AI agent 做出有后果的行为时，第三方能证明什么？现有可观测平台的 trace 可变、无法重放、也无法证明敏感信息已擦除，难满足 EU AI Act、ISO 42001、NIST AI RMF 的审计要求。

方法：NovaFabric 不改 agent 逻辑，把一次运行记录为可移植 Run Capsule（15 实体 schema），以 DSSE 整体签名、RFC 3161 时间戳、Merkle 日志与擦除证明封存；支持四模式重放协议，并可导出证据包供第三方用通用工具核验。贡献在集成（OpenTelemetry、DSSE/in-toto、W3C PROV），而非新密码学。

关键数字：mock 重放 10/10 不依赖在线模型；但工具型负载仅 2/10 完成（缺工具响应替换）；三类篡改全部被拒；声明流完整性 0.652（95% CI ±0.064）；修复后的规则包擦除 14/14 类凭据并保住 9/9 诱饵；diff 定位 140/140 处变更；blast-radius 查询 1000 万边 p99 45.5 ms、1 亿边 167.9 ms；314 机十区域压测 REST 摄取无损但受序列化限制在 61.6 req/s。

为什么值得看：agent 审计从"看日志"升级到"可验证证据"，评测也罕见地坦承短板，可信 agent 基础设施方向值得跟进。
