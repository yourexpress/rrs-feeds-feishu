BitLLM: Efficient Low-Bit, Conversion-Hiding LLM Decoding on Mobile GPUs

arXiv (cs.AR) · 2026-10-31 · 论文PDF / 每日精选

研究问题 低比特量化（4-bit 权重、8-bit 激活）可减小模型体积，但在移动 GPU 上实际效果有限，瓶颈待定位。

方法 识别出两大瓶颈：量化值与浮点值间的频繁类型转换，以及自回归解码中 KV cache 增长导致的动态低效访存。提出 BitLLM 移动推理引擎：对 KV cache 采用自适应布局与打包策略保证解码全程高效访存；整数原生执行管线把类型转换推迟并重叠出计算热路径，让关键 MatMul 阶段留在整数域。

关键数字 相对 LLAMA.CPP、MNN-LLM、LiteRT-LM、MLC-LLM 平均提速 1.78 倍、1.73 倍、1.58 倍、1.47 倍；长上下文生成下每 token 平均能耗最高降 88.9%。

为什么值得看 直击移动 GPU 低比特解码两个真实瓶颈（转换与访存），商用引擎对比数据扎实。
