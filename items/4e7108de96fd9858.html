NVIDIA's SoL-Pi Nearly Halves Agent Token Traffic

AICrier · 2026-09-18 · 技术博客

核心话题：NVIDIA 开源 SoL-Pi——Pi 编码 agent 的扩展，通过融合动作、压缩观察、保留诊断证据与紧凑上下文，把 agent 的 token 流量近乎砍半。

要点：NVIDIA 在 500 个环境、3000 次运行、6 万次 agent-环境交互中检索了约 150 个候选机制，最终保留 4 项技术，针对可预测的浪费：重复验证轮次、超大观察、冗长诊断日志、陈旧上下文。SoL-Pi 从 GPT-5.6 Sol 迁移到未见过的 Opus 5 无需再适配，性能相当而流量与成本下降。扩展为 MIT 许可、使用 Pi 公开 API、opt-in 启用；文中提醒其远程日志缩减功能值得做安全审查。

关键数字：在 51 个 EdgeBench 任务上，GPT-5.6 Sol 与 Opus 5 下均与 Pi 表现相当，token 流量减少 44.7–49.0%，API 成本约降三分之一；但并非全面占优——Terminal-Bench 4 上 SoL-Pi 解出 15 题，Codex 与 Pi 均为 18。

为什么值得看：重点不是更聪明的模型，而是围绕现有模型的更好控制回路——harness 工程正在成为正经的优化层。
