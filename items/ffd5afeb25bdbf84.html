ZipFusion: Fusing Lossless KV Decompression with Attention for Efficient LLM Decoding

arXiv(cs.AR) · 2026-10-24 · 论文PDF / 每日精选

研究问题 无损 KV 压缩方法通常在 GPU 内存中还原后再做 attention，重复 KV 读取与解压开销仍在，解码仍受内存带宽限制。

方法 ZipFusion 让 attention 直接消费无损压缩 KV：协同设计压缩格式与 attention kernel，kernel 用寄存器内简单位运算重建原值，免去单独解压 pass 并缓解带宽瓶颈；压缩释放的内存跨层重分配以存储更多 KV。

关键数字 H100 上解码 attention 较 FlashInfer 约 1.25x 加速；8K 上下文、同 GPU 内存预算下模型解码吞吐最多提升 26.3%；各方法最大支持批下吞吐达最佳无损压缩基线的 2.76x。

为什么值得看 无损 KV 压缩与 attention 融合的工程路线，直接缓解解码带宽瓶颈。
