Multi-step SWE: Can Coding Agents Keep Building on Their Own Code Over Long Horizons?

arXiv · 2026-11-06 · 论文PDF / 每日精选

研究问题：开发者会要求智能体在自己写的代码上继续扩展、升级、优化——现有基准却一次只评一个任务，长地平线连续构建能力如何？

方法：提出 Multi-step SWE，69 个软件工程任务的长期基准，每个任务为单一代码库上 5–15 步依赖链；每步是完整的多小时工程请求、从智能体上一步产出开始，早期设计决策与错误向前传递；覆盖四类工程工作与九种语言，每步锚定现有 truth source 定义指令与验证器。

关键数字：九个前沿模型中最强模型仅达 18.5% 解决率；69 个任务中 38 个无任何模型解决。

为什么值得看：揭示「自我延续构建」是当前智能体的薄弱环节，评测范式从单任务转向长链。
