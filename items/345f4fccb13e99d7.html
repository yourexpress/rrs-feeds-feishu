llama.cpp b11888 common, grammar: add recursive depth limit, make it a requirement (#31153)

llama.cpp（GitHub Releases） · 2026-10-25 · 技术博客 / 每日精选

核心话题 grammar 采样对候选 token 的拒绝逻辑存在栈溢出与误拒风险。

要点 原先 llama_grammar_reject_candidates_for_stack 的深度限制按 token 的码点数量计数，导致任何长度 ≥256 字符的 token 在 grammar 下必然被拒——例如 GLM-4.7-Flash 的 512 空格 token、Laguna-S-2.1 的长空格 token。改为用自己的层级栈遍历码点、不再递归，于是没有限制也没有栈风险，掩码与 master 一致；同时把被拒候选记录为输入中的下标，并补齐若干递归函数与 peg 解析器清理。

关键数字 触发门槛原为 256 字符；作者称 GLM-4.7/Laguna/Qwen3.6/gemma-4 的 json、list、spaces grammar 均快于 master。

为什么值得看 这是"合法输出被静默拒绝"的真实 bug，且命中的是特定模型的保留 token——排查起来几乎没有线索，文中的根因定位值得记住。
