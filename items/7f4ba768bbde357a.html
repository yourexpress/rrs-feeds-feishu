QTestBench: A Test Framework for Evaluating LLM-Generated Quantum Code

arXiv · 2026-10-09 · 论文PDF

研究问题： LLM 已能写经典代码测试，但量子程序具概率性、依赖数值容差，LLM 生成的测试能否区分正确与错误实现尚不清楚。 方法： QTestBench 让模型生成语法/语义/行为三类测试，运行时注入候选解并与独立 checker 判定比对；用 5 个 LLM 评测 8 个 PennyLane QHack 与 10 个 Qiskit HumanEval 任务。 关键数字： 最佳生成器测试质量 QHack 为 0.71、Qiskit HumanEval 仅 0.34——套件几乎都能执行但判别力不足，可执行性高估了测试质量；10 个 Qiskit 任务中 3 个无天然错误解，需 oracle 合成变异体稳定估计。 为什么值得看： 首个跨框架、可复现的 LLM 生成量子测试可信度基准。
