Selective Critique for Cost-Aware LLM Agents in Long-Horizon Decision Making

arXiv cs.LG · 2026-10-08 · 论文PDF

研究问题 长程决策中 LLM Agent 的早期错误会沿轨迹级联放大。引入外部批判/深思可提可靠性，但每步都调用会大幅增加 token 消耗与延迟。

方法 SAG（带门控批判的自改进 Agent）：把"何时调用批判"建模为逐步决策问题，用免训练的轻量门控——基于可行动作上的全局熵与局部 top-2 margin 估计批判效用，近似批判的信息价值（VoI），只在预期收益抵得过成本时调用；配合在线 bootstrapped 自改进，让 actor 逐步内化批判行为、降低依赖。

关键数字 ALFWorld 上任务成功率从 24.6% 提到 78.4%，token 预算与 ReAct 相当，归一化 token 效率提升 3.1×；7B actor+3B critic 达到 14B actor 无批判的水平。

为什么值得看 把"批判调用"从默认全开变成成本感知的稀缺资源分配，工程上立即可用，做 Agent 系统的值得参考。
