XM-Sparse: High-Throughput Sparse-Attention LLM Serving over Scale-up Memory Pools

arXiv cs.DC · 2026-11-17 · 论文PDF / 每日精选

研究问题：生产 LLM 长上下文用稀疏注意力，但 serving 仍须保留完整 KV 历史，GPU HBM 容量限制并发；现有 KV offload 到 host 内存受 PCIe 带宽与 host 容量双重限制。

方法：分析发现即便有 scale-up 内存池，解码吞吐仍被 HBM 容量钳制——热 KV 缓冲与常驻索引器 key 缓存（K-index）占用大量 HBM 且访问模式不同；XM-Sparse 首个基于 scale-up 内存扩展的稀疏注意力 offload 系统：动态 KV 条目用 TMA 检索与注意力做 tile 级流水线融合隐藏延迟，可预测 K-index 访问用 SM 高效 GPU-initiated DMA 预取并避开解码关键路径。

关键数字：DeepSeek-V3.2 与 GLM-5.3 + 模拟 scale-up 内存池：解码吞吐比 PCIe 的 ECHO 高 4.98×、比 HiSparse 高 4.52×，同平台比 naive 集成高 1.34×，覆盖 16K-1M 上下文。

为什么值得看：首个面向 scale-up 内存池的稀疏注意力 offload 系统，按两类缓存的访问模式分别定制 I/O 机制。
