Yggdrasil: Tree-Routed Recurrent Experts for State Tracking and Fast CPU Inference

arXiv · 2026-11-23 · 论文PDF / 每日精选

研究问题：Mamba、线性注意力、DeltaNet 等可并行训练循环提供常数开销流式推理，但难跟踪离散状态，且每步读全部参数，模型容量直接绑定 CPU 延迟。

方法：Yggdrasil 树路由循环专家：每层在大规模树路由专家库中查转移，用当前 token 与下层状态寻址；证明跨层上下文必要（单 token 索引、有限可达状态的非扩张转移层无法做条件重置）；每步走一条树路径、每层读单个专家，活跃权重仅几百 KB 留在 CPU L2，全库驻留 RAM。

关键数字：评估的并行可训练模型中唯一解全部 5 个状态跟踪任务；匹配活跃参数下 enwik8 最低 1.540 bpb、人类基因组 hg38 1.567 bpb；单 CPU 核 6.7μs/5.8μs 步进，比最快流式基线快 3.0x/3.3x；batch 1024 GPU 吞吐最高；Genomic Benchmarks 匹配活跃参数下最强因果模型（平均准确率 86.0%）。

为什么值得看：容量与每步计算解耦 + 离散状态跟踪，CPU 流式推理新范式。
