Extending FunctionGemma for Practical On-Device Mobile Function Calling

arXiv (cs.LG) · 2026-09-23 · 论文PDF / 每日精选

研究问题：端侧助手需要把自然语言映射到本地系统动作的函数调用模型，但现有资源偏 web API 或窄覆盖的移动动作目录，真实 Android 工作流数据缺位。

方法：扩展 FunctionGemma 270M-it：构建 MOBILEACTIONSEXTENDED——约 9500 条 schema 校验的合成对话，覆盖 15 类设备控制（消息、电话、相机/截图、亮度、设备状态、手电筒、应用管理等）；用 TRL 监督微调 completion-only loss 训练专家模型与联合训练组合模型。

关键数字：MOBILEACTIONSEXTENDED 上端到端准确率从基线 29.3%（Google Mobile-Actions 变体 17.2%）提升到 76.5%；组合模型保留 76.5% 并在 MOBILEACTIONSGOOGLE 上达 82.3%（专模型 90.3%），以 8.0 个百分点换取类别覆盖翻倍。

为什么值得看：证明 270M 级小模型可胜任端侧函数调用，数据集、模型与 Android demo 全部开源，低时延隐私助手的实用路径。
