Agentic Coding in the Wild: Characterizing GitHub Copilot at Production Scale

Microsoft · 2026-10-01 · 论文PDF / 每日精选

研究问题 Copilot、Claude Code、Codex 这类 agentic coding 把多步 LLM 推理与工具执行交织在一起，负载特征与聊天机器人有何本质不同？

方法 基于 2026 年 6 月 GitHub Copilot 生产环境采样 trace 做首个生产级负载刻画，并据此设计轻量空闲时间预测器支撑资源编排。

关键数字 数据规模 3.2M 用户、13M 会话、7.61 亿次 LLM 调用、95T token；turn 内 KV cache 命中率平均 90%，跨 turn 降至 55%，模型切换或上下文压缩后剧烈失效；空闲预测器覆盖总空闲时间的 86–90%。

为什么值得看 用真实生产数据挑战现有 LLM-serving 系统的假设（如 cache 复用与调度粒度），是构建 agent-native 基础设施的一手实证基础。
