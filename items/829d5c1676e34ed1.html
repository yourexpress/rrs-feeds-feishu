Byzantine-Resilient Federated Large Language Model via Hypergraph Message Passing

arXiv · 2026-10-08 · 论文PDF

研究问题：联邦 LLM 训练易受拜占庭攻击（恶意更新破坏语义一致性与事实韧性），如何在不访问私有本地数据的前提下防御？

方法：HMP-GAE：超图消息传递图自编码器——低秩模型更新作为超图节点，经迭代消息传递利用多代理高阶语义关系；借助历史 checkpoint 与跨代理关系推理，识别并抑制语义不一致更新。Qwen-2.5 与 Llama-3.2 骨干，AG News 与 Yahoo! Answers 数据集。

关键数字：相比现有防御，全局准确率提升 1.21%、分类语义熵降低 44.08%、困惑度降低 13.34%；优于 GAE 基线（准确率 +1.39%、语义熵 -54.5%、困惑度 -35.5%）。

为什么值得看：把高阶关系建模引入联邦 LLM 防御，语义层面而非仅数值层面的拜占庭鲁棒。
