Rethinking KV Cache Eviction for Agentic LLM Serving

arXiv (cs.DC) · 2026-10-30 · 论文PDF / 每日精选

研究问题 KV cache 给大模型服务带来内存压力，容量不足时需驱逐；但 agent 工作负载会跨轮次反复复用长历史，从序列尾部驱逐会使尾部 token 因更长注意力历史而重算代价更高。

方法 提出 Penelope：保留共享前缀、从剩余历史开头驱逐而保留缓存后缀；协同设计驱逐策略、KV 重算与统一 GPU-CPU 两级缓存管理，返回请求复用已缓存部分、只重算缺失段。

关键数字 在 SGLang 中基于 Qwen3 三种规模与真实 agent 轨迹评测：相较 SGLang，平均 TTFT 最高降 60%、任务完成时间最高降 37%（仅 GPU 缓存）；两级 GPU-CPU 缓存下最高降 76% 与 60%。

为什么值得看 针对 agentic 场景反转传统驱逐方向，实测收益显著，是 KV 缓存管理的新视角。
