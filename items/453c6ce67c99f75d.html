H-Spec: Parallel Speculative Decoding Without a Drafter-Side KV Cache

arXiv (cs.LG) · 2026-09-22 · 论文PDF / 每日精选

研究问题：块扩散草稿器的 drafter 侧 KV cache 带来随并发增长的内存与写入开销，直接复用 target KV 又保不住草稿质量，如何兼得？

方法：混合 target 上下文注入——仅最后输入位置注入 target hidden state，其余原位复用 target KV；据此构建 Mamba-attention 混合并行草稿器 H-Spec，Mamba 并行扫描保住块并行起草。

关键数字：三个 target 模型上平均接受长度较最强基线 +5.0-13.3%，batch 1 token 间延迟加速 5.3-12.6%；并发服务下吞吐更高、KV 占用更低。

为什么值得看：去掉投机解码并发扩展的最大内存瓶颈，零 drafter KV 与块并行兼得。
