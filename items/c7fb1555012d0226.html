BOOST: Concurrent Access to Host Memory and HBM to Accelerate LLM Inference

arXiv（Anish Saxena 等，cs.DC） · 2026-09-11 · 论文PDF

研究问题：GPU 内存分 HBM 与主机内存两级，但现有 serving 系统要么只用 HBM、要么先预取到 HBM——主机内存带宽始终被浪费，如何同时榨干两级带宽。

方法：BOOST 是首个让每波 GPU threadblock 按带宽比例并发访问两级内存的运行时系统，不改 kernel。核心洞察是利用 kernel 访问模式做 wave 感知的数据管理：静态权重用取模式页面放置消除访问比例方差，动态 KV 对则让空闲页池感知 wave。

关键数字：集成进 vLLM 在 Grace Hopper 上评测：同 batch 下 TPOT 较纯 HBM 改善 4.3%（预取方案反而劣化 6%）；高吞吐场景吞吐平均提升 31%，比预取方案高 15%。

为什么值得看：Grace Hopper/Blackwell 这类统一互联架构下，"两级并发取数"是明显趋势，BOOST 给出免改 kernel 的系统级答案，vLLM 用户可直接受益。
