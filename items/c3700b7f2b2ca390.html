ML Drift: Performant & Universal On-device GPU Compute（官方公告+开源发布）

Google AI Edge · 2026-10-10 · 技术博客 / 每日精选

核心话题 Google 开源新一代端侧 GPU 推理引擎 ML Drift，面向手机（Android/iOS）、浏览器与服务器上的大型生成式模型推理，接替 TFLite GPU delegate，已用于 Chrome、YouTube Shorts、Photos、Meet 等产品。

要点 支持 OpenCL、Metal、WebGPU（经 Dawn）、OpenGL ES 3.1+ 四种后端；自研统一计算语言 UCL 实现 GPU kernel 一次编写多后端编译；核心抽象 GpuModel 计算图 + 张量虚拟化；运行时动态生成 shader、算子融合、内存复用（如 GREEDY_BY_SIZE 算法）；支持 prefill/decode 分阶段执行与 FP16/INT8/INT4 量化。

关键数字 官方称相对现有开源 GPU 推理引擎有约一个数量级的性能提升；具体跑分数据原文未列。

为什么值得看 端侧 GPU 推理的重要新基座，做移动端部署、WebGPU 浏览器内推理、端侧 LLM 的工程师值得直接上手评估。
