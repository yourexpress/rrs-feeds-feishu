Xronos: Heterogeneity-Aware Tensor Parallelism for Collaborative LLM Fine-Tuning on Edge CPUs

arXiv（Wonmi Choi 等，cs.DC） · 2026-09-17 · 论文PDF / 每日精选

研究问题：边缘设备协同微调 LLM 的 SOTA 方法多为 GPU 设计、依赖流水并行（PP），但大量边缘平台（IoT 网关、家居中枢、车载）是纯 CPU——PP 在这些设备上为何失灵、怎么办？

方法：分析表明 CPU 同时承担计算与通信导致严重争用；Xronos 改用张量并行（TP）为执行骨干，结合轻量 profiling 与异构感知的张量切分，缓解快慢设备间的 straggler 瓶颈。

关键数字：CPU 设备上 PP 的计算停滞比平均高 5.75x；同构假设的 TP 让快设备空等多达 34%。Xronos 将微调时间缩短 18%（对 TP）至 56%（对 PP），设备空闲时间比降约 5.9x，精度不降。

为什么值得看：把协同微调从 GPU 边缘拓展到更广阔的 CPU 边缘设备群，车联网/IoT 场景的联邦式适配有了新选项。
