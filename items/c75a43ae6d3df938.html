Introducing the new Copilot with Home, Code and Autopilot

Microsoft · 2026-09-25 · 技术博客

核心话题 微软发布新版 Copilot 应用，引入 Home、Code 与 Autopilot 三大新能力，重新定义个人 AI 工作台。

要点 Home 是新的起点，把 Chat 与 Cowork（端到端委托工作）合一，并通过 Office in Copilot 把 Word、Excel、PowerPoint 全能力内置，可直接创建/更新真实可编辑文档；Code 让每个人都能构建自己的解决方案，底层与 GitHub Copilot 同源；Autopilot 是持续、主动、个人的 agent，用户不在时也持续工作；另推出面向 AI 的 FinOps 能力帮助管理 Copilot 与 agent 支出。Home 与 Code 未来几周在 Frontier 计划中开始推出，Autopilot 本月底扩展私人预览。

关键数字 摘要未给量化指标；三个能力分两个时间窗（数周内 / 本月底）推进。

为什么值得看 办公套件与 agent 运行时深度整合的官方路线图，对判断企业 AI 工作流形态演进有直接价值。
