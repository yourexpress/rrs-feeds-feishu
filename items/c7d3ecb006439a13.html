Advancing chip design with OpenAI models

OpenAI · 2026-11-18 · 官方公告 / 每日精选

核心话题：OpenAI 模型在芯片设计上的专家级 PPA 改进——覆盖自研推理芯片 Jalapeño 与 AMD 旗舰 GPU/CPU IP，并给出代际能力评估。

要点：模型以微架构师级水平改写 SystemVerilog RTL，用 Synopsys 工具验证行为保持与 PPA 权衡；对 AMD 旗舰 GPU IP 已见最高 14% 改进且部分改动已进流片与量产设计文件；在两个开源 32-bit RISC-V 核（PicoRV32、Ibex）上以吞吐为指标做代际横评；与 Synopsys 合作训练 GPT-Synopsys 使用 EDA 工具。

关键数字：Jalapeño 向量单元标准单元面积降约 13%、矩阵单元约 10%（硅验证）；乘法器重设计少约 15% 单元面积且延迟两周期降一周期；AMD 旗舰 GPU IP 相对重度优化基线最高 14%；约一年进展在不到 5 个月内实现；评估含 9,881 次计分运行、每 run 约 112,000 token 预算。

为什么值得看：模型在量产芯片设计上产出净新改进的公开实证，芯片设计是"AI 加速 AI"最直接的落地点之一。
