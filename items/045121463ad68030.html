LLBPE: Linked-List Based GPU-Parallel BPE Tokenizer

arXiv cs.PF · 2026-10-06 · 论文PDF / 每日精选

研究问题 每次 LLM 推理都始于分词；BPE 传统上在 CPU 上跑，近年虽有 GPU 实现，但作者指出其瓶颈不在计算而在数据搬运。

方法 LLBPE 用数组式链表表示 token 序列，把每次归约（merge）变成常数时间的指针更新；并把 rank 查表、最小值选择与合并融合进单个 kernel，消除冗余哈希表查询。

关键数字 吞吐最高达现有最优 GPU 实现的 5.2 倍、优化 CPU 实现的 24.6 倍，代价是分词输出存在少量差异。

为什么值得看 思路朴素但有效——用经典数据结构把 GPU 分词的数据搬运瓶颈拿掉；对长上下文高吞吐 serving，分词不再是隐形税。
