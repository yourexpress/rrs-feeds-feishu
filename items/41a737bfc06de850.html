Tree-Ising: Repairing Language Models with Bit-Level Ising Edits

arXiv cs.LG · 2026-11-10 · 论文PDF / 每日精选

研究问题：MIT 近期工作用前沿 LLM agent 读权重写修复（GPT-6 Astra 无梯度修复 Qwen3.5 推理循环，耗 158 agent 轮、8970 万 token、50 次前向请求）——能否把权重空间编程建模为可精确求解的离散优化，绕过昂贵 agent 调用？

方法：Tree-Ising 把修复建模为模型 BF16 权重上的稀疏离散优化：前向统计定义目标（削弱循环方向、强化结论方向、保持生产性 token 上该层输出）；在状态树表示中，允许的编辑为保持共享组指数与尾数的符号翻转与指数移位；目标精确分解为每输出行独立的 QUBO（Ising）问题，GPU 上用模拟退火或量子启发模拟分岔求解。

关键数字：agent 的两层上 MATH-500 达 54.6%，超过 agent 编辑（51.7%），基座模型 7.9%；模拟分岔求解器 55.1% 统计无差异；两个求解器在五个数学 benchmark 全部胜过 agent 编辑；少改 13-17% 权重、BF16 比特翻转少 2.2-2.3×；仅需 4 次前向、零 LLM token，退火配方 GPU 成本约 $0.90。Qwen3.5-2B 上贪婪 GSM8K 从 21.6% 升到 69.4%；概念验证在 IBM Heron 上用 QAOA 跑八变量修复子问题。

为什么值得看：把"读权重修 bug"从昂贵 agent 调用变成 ~$1 的离散优化，权重空间编程的实用化路径。
