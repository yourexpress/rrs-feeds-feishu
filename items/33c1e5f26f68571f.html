EdgeAgent: Orchestrating On-Device LLM inference for End-User Multi-Agent Systems on CPU-GPU Unified Memory Architectures

arXiv (cs.DC) · 2026-10-05 · 论文PDF / 每日精选

研究问题 端侧多智能体 LLM 系统在 CPU-GPU 统一内存（UMA）架构上举步维艰：decode 阶段内存受限导致严重总线争用、多智能体投机解码的起草难度方差极大、工具调用频繁造成停顿，静态批处理彻底失效。

方法 EdgeAgent 跨层协同设计：微架构级绕过图编译器刚性约束，实现零拷贝 UMA 感知张量并行，用非对称内存布局同时打满 CPU 与 GPU；调度级按序列实时可预测性动态分配草稿预算，并用异步挂起-让出机制主动驱逐停滞的智能体。

关键数字 Apple M4 上：仅 UMA 感知执行即较批量投机解码加速 1.29×；叠加智能体感知调度后，极端工具延迟下全系统加速 1.77×。

为什么值得看 端侧多智能体落地的稀缺系统工作，调度与执行两层设计都有直接借鉴价值。
