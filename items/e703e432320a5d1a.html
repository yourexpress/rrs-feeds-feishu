TAO: Tool-Aware Joint Scheduling for LLM-Based Agentic Serving

arXiv(cs.DC) · 2026-10-27 · 论文PDF / 每日精选

研究问题 Agentic 服务在 GPU 集群推理与分布式 CPU 外部工具间交替；现有系统忽略工具返回就绪度（浪费稀缺资源），并用启发式决定准入与 GPU 放置，调度次优。

方法 TAO 工具感知联合调度框架：价值接口融合近期工具就绪度、带时间衰减的节点缓存信用与 token 足迹；动态规划在容量约束下联合选择并放置等待会话。

关键数字 12 组模型-负载-并发设置下，相对各指标最优 SOTA 基线：延迟最高降 26.8%、平均首 token 时间（TTFT）最高降 36.3%、解码吞吐最高增 29.5%。

为什么值得看 把工具执行状态纳入 LLM 服务调度决策，是 agent 场景推理基础设施的一项新思路。
