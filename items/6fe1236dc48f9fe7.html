Grounding Agent Memory in the Real World

Microsoft · 2026-09-10 · 论文PDF / 每日精选

研究问题：持久记忆正进入生产级 agent 平台，但只看已完成轨迹的事后策展 agent 会保留错误、过度泛化局部证据、留存过时知识。

方法：environment-probing curation：给既有异步策展 agent 一组最小权限、只读的"世界工具"，用于检查、限定与刷新候选记忆；不重训模型，任务 agent、检索器、记忆表示与生产写权限全部不变。

关键数字：在基于 GitHub Copilot SDK 的生产级 harness 中验证（详见原文）。

为什么值得看：agent 记忆可靠性的工程化落地——"用环境探针验证记忆"而不是"信轨迹"，思路可直接迁移。
