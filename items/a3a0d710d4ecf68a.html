CUAWright: A Minimal Unified Interface for Digital Agents

arXiv（OSU/微软） · 2026-10-07 · 论文PDF / 每日精选

研究问题： computer-use agent 普遍被绑在领域专用的 GUI harness 上（浏览器/桌面环境配人工预制工具），模型无法直接程序化操作系状态，也不能灵活自造工具。

方法： CUAWright 是一个约 3K 行的极简终端 harness：bash 命令是唯一动作接口，文件系统充当可演化空间，用于动态创建工具和管理上下文——给 agent 一个最小但可编程的统一接口。

关键数字： OSWorld 2.0 上相比已发表的 GPT-5.5 基线，部分奖励相对提升 33.2%、估计成本降低 37.5%；Online-Mind2Web 与长程 Odysseys 基准成功率分别高出 4.7% 与 44.0%；CAD 类任务（CADGenBench、BenchCAD）上相对其他 CLI harness 提升 8.1%–41.6%。

为什么值得看： 结论有普适启发——数字环境远比其 GUI 表面更可编程，极简终端接口可能是 CUA 更优的抽象层。
