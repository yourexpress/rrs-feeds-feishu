DualPace: Decoupled Scheduling and Cooperative GPU--CPU Decoding for LLM Serving

arXiv(cs.DC) · 2026-10-24 · 论文PDF / 每日精选

研究问题 LLM serving 中 KV 缓存随序列增长限制 GPU 并发，CPU 卸载可扩展容量但现有系统仍 GPU-gated，主机内存与 CPU 算力无法作为独立服务资源。

方法 DualPace 把主机变成独立调度的解码引擎：GPU 引擎执行 prefill 与 GPU 驻留解码，AMX 使能的 CPU 引擎独立批处理并推进 CPU 驻留解码；调度解耦、执行协作，CPU 可本地完成整轮解码迭代或选择性调用 GPU Dense Assist，离线 profile 指导硬件特定批处理与路由。

关键数字 解码场景吞吐较 NEO 提升 6.9-43.2%、较 vLLM 提升 11.5-90.6%，延迟同水平；保留 NEO 的 P99 TTFT 优势，同 P99 ITL 下请求率比 NEO 高 7.3-50.5%。

为什么值得看 把 CPU 侧变成真正独立解码资源的 serving 运行时，KV 卸载路线的重要升级。
