Jet-QSparse: Accelerating Agentic LLM Inference with 4-Bit Sparse Attention

arXiv (cs.LG) · 2026-10-31 · 论文PDF / 每日精选

研究问题 长程推理与 agentic 工作负载压垮 KV cache 容量与 decode attention 吞吐，需兼顾缓存压缩与计算加速。

方法 Jet-QSparse：免训练方法，NVFP4 紧凑缓存存储 + Blackwell 张量核原生 FP4 Query-Key 计算；稠密扫描给全部 key 历史打分，选取 128-token 块做稀疏 FP16 value 聚合与 FP32 累加；校准的 key 居中与每序列每层至多两页 BF16 控制量化误差。

关键数字 每 KV 头 128 块预算下四个混合 LLM 在数学推理、代码与 agentic 基准上无可检测精度损失；Qwen3.8-27B 用 64 块时，128K 上下文、batch 16、单 GB300 上端到端 decode 比稠密 BF16 快 1.94 倍；实测 Qwen KV 池 token 容量为 BF16 的 2.58–2.76 倍。

为什么值得看 免训练兼顾精度、容量与吞吐的 4-bit 稀疏注意力，数据覆盖大上下文真实负载。
