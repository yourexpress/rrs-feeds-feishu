Shared KV Caching for Replicated 27B Inference: Correctness Failures and Performance Boundaries

arXiv（Frank Li，cs.DC） · 2026-09-14 · 论文PDF

研究问题 多副本 LLM 推理中，请求在副本间迁移会重复 prefill；共享主机内存 KV 缓存能否既保证状态传输正确、又真正赚回前缀局部性？

方法 工程案例研究：两个单 GPU 27B vLLM 副本共享 256 GiB LMCache 池。定位并修复一个遗漏 CUDA stream 依赖的裸指针回退（受控字节测试在人为延迟下失败、恢复依赖后通过）；以四段 OFF-ON-ON-OFF 对照实验量化收益。

关键数字 768 个实测请求：128k 输入下跨副本首 token 中位时延从 31.715 秒降到 0.605 秒，256k 下从 92.047 秒降到 0.790 秒；六轮会话在 32k/128k 初始上下文分别提速约 35%/45%；固定放置则几乎无收益。

为什么值得看 罕见地同时给出正确性缺陷定位与收益边界条件，是共享 KV 缓存部署的实操参考。
