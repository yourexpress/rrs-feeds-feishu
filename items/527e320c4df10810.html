VETTA: Coordinating Turn- and Token-Level Credit Assignment for Multi-Turn LLM Agents

arXiv cs.LG · 2026-10-08 · 论文PDF

研究问题：多轮 LLM 智能体只有稀疏任务反馈，信用分配存在两个层面——哪一轮回复有用、回复内哪些 token 决策关键；现有方法只覆盖一层。

方法：VETTA 用共享轻量 critic 上的两个独立头联合学习轮级与 token 级价值，沿两条时序计算优势，将轮优势与回复内中心化的 token 残差组合用于 PPO 更新；critic 只保留 actor 初始化 checkpoint 的前几个 Transformer 块以降低价值学习成本。

关键数字：Qwen2.5-1.5B-Instruct 上 ALFWorld 与 WebShop 成功率较 PPO 分别提升 37.5% 与 22.3%；Qwen2.5-7B-Instruct 上分别达 95.5% 与 76.0%；浅层 critic 仍保持强性能且显著省算力。

为什么值得看：双层信用分配的协调设计 + 紧凑共享 critic，在提升 agent 性能的同时压低成本，代码已开源，对 multi-turn agent RL 训练很实用。
