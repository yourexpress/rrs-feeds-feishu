CEMA-Router: Infrastructure-Aware Batch Routing for LLM Inference in Cloud-Edge Systems

arXiv/cs.DC · 2026-10-19 · 论文PDF / 每日精选

研究问题 LLM 被集成进跨异构云边资源的普适应用后，节点在算力、能效、网络条件与所部署模型质量上差异显著，路由需在响应质量、货币成本、能耗与批次完成时间之间取舍；而现有 LLM router 多按模型质量与 token 成本逐查询决策，云边调度器又常忽略模型质量差异，四目标协调不足。

方法 提出基础设施感知的批量路由器 CEMA-Router：把批量路由建模为多目标搜索问题，联合最小化模型质量损失、货币成本、能耗与受长尾任务支配的批次完成时间；用面向路由的 memetic 算法高效搜索，结合最大请求优先的负载感知播种与概率化、评估器引导的 Lamarckian 修复；决策依据部署相关节点画像、动态积压估计与模型质量信号；并实现为含请求管理器、路由服务与剖析器的端到端系统，支持真实云边部署与轨迹驱动仿真。

关键数字 用 RouterBench 轨迹与 GSM8K、MMLU 负载在异构云边测试床上评测，相对 SOTA 方法加权目标在 GSM8K 上最多降低 86%、MMLU 上降低 80%；能耗分别最多降 33% 与 19%；批次完成时间分别最多降 27% 与 30%。

为什么值得看 把"质量/钱/能耗/尾延迟"四个互相打架的目标收进同一个搜索，云边推理的路由决策终于不必再靠拍脑袋。
