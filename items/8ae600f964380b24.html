Recycler: Cost-Free Latent Reasoning via Hidden State Recycling

ByteDance Seed · 2026-10-25 · 技术博客 / 每日精选

研究问题 自回归解码只在离散 token 之间传递信息、丢弃前一步 hidden state 的连续语义，跨步语义因此损失；能否近乎零开销地把这份连续反馈接回来？

方法 借鉴 MTP 头同时传播 token embedding 与 hidden state 的观察，Recycler 让上一步的 hidden state 经一个轻量 adapter 连同 embedding 一起送入下一步，保留跨步语义且解码开销可忽略；配套覆盖预训练、SFT、继续预训练与 RL 的完整训练与推理流程。

关键数字 仅约 2% backbone 参数量的 MTP 头，损失可比肩体积约为其 25% 的独立模型；Recycler 在推理与数学任务上参数效率突出，后期阶段才引入仍有效，表现超过参数多 2–3 倍的模型。

为什么值得看 证明连续 hidden state 反馈本身就是一类可复用的推理增益来源，给"不扩参数只改连接方式"提供了具体做法。
