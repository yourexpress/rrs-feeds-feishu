Breaking the Token Ceiling: Distilling Smaller, Stronger Byte Models

Meta FAIR/华盛顿大学 · 2026-09-11 · 论文PDF / 每日精选

研究问题：共享 tokenization 的蒸馏是常规模型缩小手段，但字节模型（byte model）与 token 模型的蒸馏 scaling 趋势是否一致？

方法：① 提出两种 token logits→byte logits 高效转换：近似（Marginal-It）与精确（End-Of-Token）；② 首次大规模研究同时扫两个维度——tokenization 方案（Tokens / Bytes / Bytes w/ eot）×训练目标（蒸馏 vs 交叉熵），模型按层参数匹配。

关键数字：见原文训练矩阵。

为什么值得看：byte 模型蒸馏的首个系统对比，为"端侧要不要走 byte-level"提供 scaling 依据。
