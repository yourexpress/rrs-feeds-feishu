CarrierKV: An Edge LLM Accelerator with Positional Carrier Decomposition for Low-Bit KV Cache

arXiv · 2026-11-19 · 论文PDF / 每日精选

研究问题：边缘端长上下文解码受 DRAM 限制，因为每生成一个 token 都要读整个不断增长的 KV cache；4-bit 块缩放格式（如 NVFP4）降低流量但掉精度。

方法：发现 key 的大部分能量是「位置载体」（RoPE 随位置旋转的单向量），NVFP4 中它设定多数 key block 的共享 scale、把内容信噪比压低约 5dB；据此提出位置载体分解：RoPE 前移除载体、只存内容残差，直接对 4-bit 码算注意力分数，另设计位置相位引擎逐周期再生成载体的分数项。

关键数字：同 cache 大小下 Qwen3-4B 32K RULER 从 79.4 提到 91.1（FP8 key 为 89.3），32K PG19 困惑度增幅降 1.8~5.9 倍；硬件面积仅增 2.9%、每 token 能量省 13.7%。

为什么值得看：低比特 KV cache 精度-体积权衡的系统性解法，硬件开销极小。
