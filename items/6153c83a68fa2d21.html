Cruella: A Unified Microscaling and Floating-Point Dot-Product Unit for LLM Inference on FPGAs

arXiv · 2026-11-20 · 论文PDF / 每日精选

研究问题：加速器原生执行的数字格式制造时固定，而新 LLM checkpoint 用 MXFP4（MX 格式）；FPGA 可通过 bitstream 采用新格式，但尚无已部署的 FPGA LLM 加速器同时执行 MXFP4 权重与 BF16 乘积。

方法：Cruella 统一点积单元（UDPU）在同一 DSP 阵列与归约流水线上执行两种乘积：per-group 预对齐把流水保持在 BF16 宽度（困惑度变化最多 0.7%）；pre-adder 打包把一个 DSP48E2 乘法器放两个有符号 MXFP4×BF16 乘积并做精确校正。

关键数字：Alveo U55C 上比同等吞吐的分离单元省 23% DSP、36% LUT；MXFP4 权重解码比 BF16 快 1.15×~1.87×；A40 GPU 更快但每 token 能耗是板卡的 0.92×~2.01×。

为什么值得看：让 FPGA 原生执行 MX 格式 checkpoint 的统一单元，资源与能耗双省。
