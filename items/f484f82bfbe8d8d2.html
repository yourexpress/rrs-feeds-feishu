UlaCache: Unified Logical Addressing for Sparse LLM Serving

arXiv · 2026-10-21 · 论文PDF / 每日精选

研究问题 长上下文使 LLM 推理中 KV cache 内存成本大增；稀疏注意力虽降低计算与内存流量，但保留的 KV cache 必须在后续解码步骤持续可用，管理复杂。

方法 UlaCache 围绕统一逻辑地址空间构建：跨越 GPU KV 池与可选 CPU 内存，稳定逻辑引用让分配与物理放置解耦；统一分配与稀疏访问接口支持数据并行（DP）与张量并行（TP）attention；启用 CPU 存储时用 Parallel Bucketed LRU（PB-LRU）并行管理共享 GPU 池。

关键数字 匹配 CPU/GPU 内存预算+推测解码下，H200 峰值解码吞吐较最先进基线 DP 1.16x/TP 1.70x，B300 上 DP 1.73x/TP 2.51x。

为什么值得看 稀疏注意力 serving 的 KV 管理基础设施，逻辑寻址思路简洁，DP/TP 双支持覆盖主流部署。
