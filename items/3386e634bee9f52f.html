Broken Symmetry in BF16 Attention: Why FlashAttention Gradients Blow Up Late in Training

arXiv (cs.LG) · 2026-09-28 · 论文PDF

研究问题 BF16 已是大规模预训练标配（含 FlashAttention 等融合注意力核），但作者用 FlashAttention-3 预训练 450M 参数 Transformer、50B token 时，训练在 25B token 后梯度范数暴涨千倍、loss 比 FP32 注意力高 0.2 nats，且全程无 NaN——BF16 注意力的数值稳定性存在未被发现的隐患。

方法 定位两个根因：① 前向 softmax 中的融合乘加（fused multiply-add）被当作极端输入 NaN 个案从未修复；② softmax 分数梯度每行求和本应为零，BF16 舍入留下非零残差，把 key 的均值泄漏进 query 梯度，训练后期 key 变大、注意力变尖时泄漏放大。提出 GProj（gauge projection），在类型转换后用每行两个秩一修正恢复零和。

关键数字 GProj 将中位 query/key 梯度误差从 219%/13% 降至 0.34%/0.37%（与 FP32 注意力相当），每训练步仅多花 4.7% 时间；从头对照训练达到与 FP32 注意力相同的 loss，而 FlashAttention-3 与 key smoothing 均失稳。

为什么值得看 揭示 BF16 融合注意力核中一个被忽视的守恒律破坏机制，对大规模预训练稳定性有直接警示与可落地的修复方案。
