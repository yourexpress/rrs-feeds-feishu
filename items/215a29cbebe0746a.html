GleanVID: Complementary Token Selection for Efficient Video Large Language Models

arXiv / Shuo Yang 等 · 2026-09-29 · 论文PDF

研究问题 VideoLLM 视觉 token 数量庞大导致推理开销高；现有压缩多依赖与选择无关的独立打分，忽视跨帧互补性、保留了大量跨帧冗余证据。

方法 把视频 token 选择视为渐进证据积累：在有限 token 预算下保留"单帧有信息量 + 跨帧互补"的视觉证据。GleanVID 先按时间新颖性给各帧分配全局 token 预算，再联合考虑局部代表性与子空间互补性选 token，训练无关。

关键数字 仅用 25% 视觉 token，Qwen3-VL 保留原始性能的 98.6%，prefill 延迟降 44.7%；LLaVA-OV-7B 在 25% 保留率下甚至略超原始模型。

为什么值得看 跨帧互补选 token 的训练无关加速框架，视频 VLM 推理优化的有效选项。
