PipeSwift: Revisiting Pipeline Parallelism for Large-Scale Completion-Oriented Agentic LLM Serving

arXiv（Shiju Wang 等，cs.DC） · 2026-09-15 · 论文PDF

研究问题 Agentic LLM 服务以任务完成时间（JCT）为主导指标，而非聊天场景的 TTFT/TPOT 类 token 级 SLO；围绕 token 级 SLO 优化的现有服务设计在该目标下并不最优。

方法 系统性探索调度与并行策略：发现 JCT 由 prefill 与 decode 效率的平衡决定，prefill 优先调度虽 TTFT 与 decode 吞吐最优但 JCT 次优；此前被忽视的流水线并行（PP）因提供有利的 prefill-decode 折中反而利于 JCT。据此构建开源运行时 PipeSwift——JCT 感知调度层 + 流水线集成的多 token 预测。

关键数字 调度策略空间内完成时间最多相差 1.40 倍；在 64 张 H800 上用两个 360B+ MoE 模型回放真实编程与网页搜索 agent 轨迹，JCT 相比 SGLang wide-EP 最高降 1.45 倍、相比 vLLM PP2 降 2.33 倍、相比现有最强开源 PD 分离部署降 1.54 倍。

为什么值得看 为 agent 负载的 LLM serving 提供了"以 JCT 为中心"的新视角和可直接使用的开源系统，做推理服务的人值得一读。
