WUSH-KV: KV Cache Quantization with Data-Adaptive Transforms

arXiv / Jiale Chen 等 · 2026-09-30 · 论文PDF / 每日精选

研究问题 KV 缓存的显存与带宽开销随上下文长度与 batch 增长，是长上下文高效推理的主要瓶颈，需要低-bit 量化又不掉点。

方法 WUSH-KV 用校准数据、基于矩阵乘两个因子的二阶统计构造数据自适应变换：key 与 value 各自独立构造，value 变换折叠进模型权重、key 变换在 RoPE 之后施加；可与截断量化器配对，并证明对 QuEST INT 量化器在温和假设下 WUSH 变换近似最优；已按 OSCAR 式百分位截断仿射量化集成进 SGLang。

关键数字 配 QuEST INT 时逐层重建误差与端到端困惑度均为所测变换中最低；2-bit 下在所评估的全部模型与下游任务上与 OSCAR 变换相当或更优。

为什么值得看 有二阶统计依据、可折叠进权重、已落地 SGLang 的 KV 量化变换，理论-实现-集成链路完整。
