arXiv (cs.LG, cs.DC)

- MultiAlloc: Budget-Aware Precision Allocation for KV Cache Quantization (2026-10-13): splits a fixed KV quantization budget between layer-wise precision boosts and token-wise preservation, using lightweight offline profiling instead of uniform compression. Outperforms single-granularity baselines on Mistral/Llama/QwQ at matched memory budgets — useful when tuning KV memory limits per model rather than applying one blanket bit-width.

- E8 Lattice Key Quantization for Low-Bit KV-Cache Compression (2026-10-11): replaces scalar KV quantization with vector quantization on an E8 lattice that exploits cross-dimension correlation, reaching a 2-bit keys/2-bit values config (previously needing 3-bit keys) for roughly 6x compression with decode throughput matching scalar baselines. Relevant for anyone pushing long-context serving memory limits.
