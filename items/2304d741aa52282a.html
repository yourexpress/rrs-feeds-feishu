Fathom: Per-Query Read Depth for Sparse Decoding over Offloaded KV Caches

arXiv（Vivek Kalyanarangan，cs.LG） · 2026-09-15 · 论文PDF

研究问题 Agent 会话跑到百万 token、多会话并存时，KV cache 及其排序索引只能放主机内存，每步 top-k 的全量 key 扫描成为解码流量的瓶颈。

方法 Fathom 让每个 query 自行决定读取每个 key 通道的比特数：4-bit K cache 按通道主序存为位平面，读 t 个平面恰好等于 t-bit 量化；query 按通道的方差加权重要性以反向注水法分配比特预算。存储复用量化 serving 栈已有的 4-bit K 副本。

关键数字 Qwen3-8B 百万 token 下：GPU 时间较 Double Sparsity/Loki/SparQ r=32 的 136-bit 扫描快 1.67 倍；与 SparQ 68-bit 读同耗时时字节数少 18% 且七组设置中六组注意力误差更低；92 bit 即达最准 136-bit 扫描的步级一致；RULER 风格任务上逐 token 扫描全部匹配精确 top-k。

为什么值得看 把"读多少精度"变成逐查询的预算分配问题，是长上下文 offload 推理的务实优化。
