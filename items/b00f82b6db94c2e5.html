Introducing Tool Retrieval in the Gemini API

Google · 2026-11-19 · 技术博客 / 每日精选

核心话题 agent 连几十上百个工具时，每次请求携带全部参数 schema 会膨胀输入 token、增加延迟、降低工具选择准确率。

要点 Tool Retrieval 让工具库 standby、仅按需加载 schema：加 tool_search 工具并对想延后的工具设 defer_loading: true，模型仍见名称/描述、按名请求，API 在同一请求内加载 schema 并调用；支持服务端检索（无需自建索引）与客户端检索（自管注册表）；与前缀缓存、远程 MCP 服务器打通。

关键数字 正文未给出量化指标。

为什么值得看 工具规模变大时的上下文治理方案，和前缀缓存、MCP 兼容，做多工具 agent 的工程优化可参考。
