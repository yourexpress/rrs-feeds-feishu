KerColle: Unlocking Fine-Grained GPU Concurrency in Vision-Language-Action Models

arXiv (cs.AR) · 2026-09-22 · 论文PDF

研究问题 VLA（Vision-Language-Action）模型是下一代机器人基础模型，但推理吞吐必须满足机器人控制率要求。VLA 分 VLM 与 action head 两阶段，可解耦异步并发。实测 4 个 SOTA VLA：GPU 严重欠利用，原因是 GPU 的 CTA 调度器无法充分重叠两阶段——硬件 thread-block 派发器的 head-of-line blocking 造成。

方法 提出 KerColle 轻量 GPU 调度框架：基于在线 Streaming Multiprocessor 利用率与各 kernel 资源需求，动态共调度以同时 ① 缓解 head-of-line blocking、② 与互补资源需求的 kernel 共调度来高效重叠两阶段。

关键数字 模拟 2 种 GPU 架构、4 个 SOTA VLA 模型：吞吐最高提升 28%。

为什么值得看 揭示 VLA 推理 GPU 利用率低的根因，并给出在 edge GPU 资源约束下提升吞吐的实用调度方案。
