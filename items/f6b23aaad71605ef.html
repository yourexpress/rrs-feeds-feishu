U-Sonic: An Open-Source 8-Channel Ultrasound Transmit IP in a 130 nm RISC-V SoC

arXiv (cs.AR) · 2026-10-02 · 论文PDF

研究问题： 微型超声探头需要可编程、同步的多通道发射（TX）激励，现有紧凑平台要么依赖受限的 MCU 脉冲发生器、要么用闭源固定功能器件。

方法： U-Sonic 开源数字超声 TX 外设，集成进 32 位 RISC-V SoC：8 个脉冲核（参数化支持 16 通道），每核可编程周期/占空比/脉冲数/极性/空闲电平；共享 OBI 总线同步启停任意通道子集。

关键数字： Verilator 对 Python 黄金模型验证 4379 个检查周期并在 FPGA 上确认；IHP 130 nm 布局后 8 通道实例占 14.9 kGE（约 104 kGE SoC 的 14.3%），面积按 1.65 kGE+1.66 kGE/通道扩展。

为什么值得看： 开源 RTL+验证环境，可穿戴超声发射链路的可定制方案。
