Revisiting Cauchy-Schwarz Norm Bounds for SDC Detection in LLM Inference

arXiv · 2026-10-14 · 论文PDF

研究问题 LLM 推理每 token 执行数十亿浮点运算，硬件故障可绕过系统检测造成静默数据损坏（SDC）；ABFT 保护矩阵乘法但开销不小、需阈值区分硬件错误与浮点舍入。

方法 重新审视 Cauchy–Schwarz 范数界（CSNB）作为低开销 SDC 检测：受控故障注入对比 CSNB 与 ABFT，评估验证与阈值确定在多种模型尺寸、批大小、生成长度下的开销。

关键数字 平均而言 CSNB 在稠密线性层保留 ABFT 99% 检测能力，验证开销降 87%、阈值确定开销降 67%；MoE router gate 只保留 55%。

为什么值得看 CSNB 是 LLM 推理稠密层的低开销保护替代，checksum 仍是 MoE router 更优选择。
