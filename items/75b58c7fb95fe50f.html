Energy-Efficient Reinforcement Learning for Large Language Models

arXiv cs.DC · 2026-11-03 · 论文PDF / 每日精选

研究问题：LLM 强化学习的生成与训练阶段对 GPU 需求不同，存在降频省电空间；但响应长度多变、试频本身耗时耗能，在线选频很难——能否自动完成？

方法：提出 EE-RL 在线控制器，为 RL 执行中的生成与训练分别选择频率；与默认 GPU governor 在同一 token 负载上的预测比较候选设置，保留满足吞吐阈值的最省电配置，并随负载变化持续监控调整。

关键数字：H100 与 GB200 固定频率扫描显示每个有效训练 token 的 GPU 能耗最多省 28.2%；EE-RL 在线把收益兑现为最多 16.9% 的能耗下降，吞吐代价很小。

为什么值得看：把 RL 训练两阶段的硬件需求差异变成可在线利用的节能空间，是面向推理/训练一体节能调度的实用方案。
