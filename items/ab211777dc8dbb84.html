When and Why to Use TMA: A Workload-Grounded Characterization of Tensor Memory Acceleration on NVIDIA Hopper GPUs

arXiv(cs.DC) · 2026-10-26 · 论文PDF / 每日精选

研究问题 Hopper TMA 在生产 GPU kernel 中普遍但使用有选择性——同一 kernel 内有些张量用 TMA、有些退回 cp.async/直接全局加载/DSM，实践者面对"该不该用 TMA、用不用 cluster multicast"缺少依据。

方法 H100 上工作负载驱动的刻画：编目 FlashAttention-3 forward 内 TMA/multicast/DSM/cp.async 选择，用定向微基准（传输大小交叉、multicast 缩放）隔离判别特征，产出 Hopper 加载机制选择的经验法则；对比 TMA multicast 与 DSM 竞争广播原语；并扩展到 Blackwell SM100（B200 CUTLASS GEMM）。

关键数字 摘要未给出单一汇总数值；给出 TMA 何时划算、multicast 何时有助/有害的可预测指导，定性分发规则跨代延续、绝对交叉点随张量核与带宽缩放移动。

为什么值得看 专家 kernel 里 TMA 选择的系统刻画，写 Hopper/Blackwell kernel 的选型手册。
