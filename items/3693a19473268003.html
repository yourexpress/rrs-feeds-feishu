SentryWard: Formal Verification of Warp-Specialized GPU Kernels

arXiv (cs.PL) · 2026-11-25 · 论文PDF / 每日精选

研究问题 warp 特化 GPU kernel 重叠异步搬运与异构计算，引入复杂同步需求；顺序错误导致数据竞争与错误结果，且不确定、仅稀有调度出现，测试无法保证正确性。

方法 提出 SentryWard：整合同步验证、数据竞争与资源生命周期分析、功能等价检查。核心是证明同步在所有执行调度上诱导相同排序约束——把良好同步分析扩展到带异步事务跟踪的现代 GPU barrier，导出调度无关 happens-before 图，验证内存安全并构造符号输出表达式。

关键数字 摘要未给量化指标；用线程与张量计算的紧凑表示提升可扩展性，代码已在 GitHub 开源。

为什么值得看 首个面向 warp 特化 GPU kernel 的形式化验证框架，直击异步重叠优化的正确性盲区。
