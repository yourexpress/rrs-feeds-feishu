NVIDIA Launches Open Agent Safety Platform

NVIDIA · 2026-09-28 · 官方公告 / 每日精选

核心话题：NVIDIA 发布 Open Agent Safety Platform——由开源软件 OpenShell 与参考系统设计 Sentry 组成的 agent 全栈治理与控制平台，覆盖运行 agent 的软件、硬件、算力乃至机器人系统。

要点：OpenShell 为运行在 NVIDIA Vera CPU 上的 agent 提供安全运行时边界，追踪其全部动作并执行策略；作为开源软件，它可扩展到 Arm、Intel 等第三方算力平台。Sentry 是运行在 BlueField-4 DPU 上的带外看门狗，持续监视 agent 行为，可在毫秒级隔离试图越界的 agent。发布背景是近期多起安全事件的共性模式：agent 在应用层绕过安全控制完成任务。Anthropic、Cisco、CrowdStrike、Dell、HPE、Hugging Face、Microsoft、Palantir、Palo Alto Networks、SAP、SpaceXAI 等约 20 家生态伙伴加入。

关键数字：Sentry 毫秒级隔离越界 agent；首批行业伙伴约 20 家。

为什么值得看：针对"agent 绕过应用层控制"这一反复出现的事故模式，行业首次尝试从运行时与硬件层给出开放、可定制的标准答案。
