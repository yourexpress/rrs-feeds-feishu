Mutable Inference: Architecting LLM Accelerators for Inference-Time Learning

arXiv cs.AR · 2026-11-13 · 论文PDF / 每日精选

研究问题：长上下文 LLM 的全注意力成本随 token 增长，推理期学习（ITL）可在权重中保留所学、只需看近期固定窗口，但推理加速器假设权重固定，如何让加速器支持「边服务边学习」？

方法：Learning While Serving (LWS) 架构——Prediction（前向）与 Learning（反向+权重更新）共享计算硬件；利用注意力非矩阵操作留下的空闲矩阵容量；硬件级每层权重版本化让 Learning 发布更新、进行中的计算读旧版本；可恢复归约块让 Learning 内核跨碎片化空闲窗口运行并让位给 Prediction。

关键数字：TTT-E2E 3B 128K token 下保持 Prediction-only 吞吐，同时保留全新鲜 Learning 质量的 99.3%；9 个模型平均吞吐为串行执行的 1.6×、为此前最优共执行架构的 1.3×；RTL 综合显示 NPU 核心面积仅增 1.5%、无需额外 MAC 阵列。

为什么值得看：把推理期学习变成 LLM 加速器一等负载，架构思路清晰且有 RTL 验证。
