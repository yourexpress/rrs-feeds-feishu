Attention Quantization for Tabular Foundation Models

arXiv（Jonas M. Kübler 等，cs.LG） · 2026-09-11 · 论文PDF

研究问题：表格基础模型（tabular foundation models）推理优化与 LLM 有何不同——权重与 KV cache 量化那一套是否适用。

方法：作者指出表格模型的架构虽类似 Transformer，但规模与服务模式差异大，优化重心应放在 attention 计算上：对 query/key/value 做 FP8 量化并用显式 FP8 矩阵乘指令加速。关键发现是必须让测试行的量化误差与训练行的量化误差对齐，否则精度大幅下降；并给出 Triton kernel 实现。

关键数字：Triton kernel 较常规 16-bit kernel 最高提速 1.7×；在 TabPFN-v3 与 TabICLv2 上，跨 TabArena 与 BeyondArena 评测无可见精度损失。

为什么值得看：表格基础模型正快速落地，这篇给出与 LLM 经验相反的结论（先量化 attention 而非权重），对做表格推理部署的人是直接可用的工程指导。
