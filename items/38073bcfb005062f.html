Coda: Exploiting Admission Flexibility for Coding-Agent Serving

arXiv (cs.DC) · 2026-10-05 · 论文PDF

研究问题 编码 agent 会话有可复用 KV 状态，但逻辑就绪≠高效接纳：KV 跨存储层级准备成本不等，异构上下文长度混合解码效率差。 方法 Coda 就绪感知接纳层：Tiered-Aging 利用接纳顺序灵活性；Compatibility-Aware 按注意力分组降混合干扰；多 worker 路由层综合 KV 驻留与长度兼容性。 关键数字 单/多 worker 输出 token 吞吐平均 +20.3%、SLO 合规吞吐平均 +70.5%，峰值 29.3%/140.2%。 为什么值得看 编码 agent 服务专项优化，接纳灵活性变现吞吐与 SLO。 阅读原文
