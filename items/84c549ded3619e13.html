Trident: Unifying Guarded Dispatch and Host Execution for PyTorch Triton Workloads

arXiv / Jinjie Liu 等 · 2026-09-30 · 论文PDF / 每日精选

研究问题 PyTorch 里用户手写 Triton kernel 性能高，但设备执行短时端到端时延常被主机侧编排主导；即便 torch.compile 生成原生 host wrapper，每次调用仍要经过运行时管理的特化查找、guard 求值与准备才能到达 wrapper。

方法 Trident 提出特化缓存模块（SCM）：把多个特化的 guard 选择、参数与执行环境准备、主机执行编译进单个可执行模块——调用只进入 SCM 一次，特化命中就全程留在编译代码里，只有出现新特化时才回到 Python；基于 Torch-MLIR 把 guard 与主机编排降为原生代码，同时保留对已优化 ATen 实现的调用。

关键数字 两个 LLM 上模型级端到端时延较 eager 执行最高加速 1.47×，较 torch.compile 最高加速 1.68×。

为什么值得看 精准切中"cache-hit 路径仍要回 Python"的隐性开销，对 Triton 重度用户是即插即用的收益。
