Composable CXL Memory as a Kubernetes-Native Shared Memory for LLM Serving

arXiv（Hongjian Fan 等，cs.DC） · 2026-09-09 · 论文PDF

研究问题 LLM serving 的 KV 缓存跨节点复用缺乏共享内存层：GPU 前缀缓存与 CPU-DRAM offload 都仅限本节点，跨节点只能全量重算。

方法 作者实现一个 Kubernetes DRA 驱动，把可组合 CXL 内存变成可调度集群资源：按需组合 CXL 区域、在各参与主机物化为 DAX 设备、以单一 CDI 名注入 pod，使不同节点的 pod 访问同一物理区域；配套 vLLM/llm-d 共享内存 connector 以该区域为 KV 缓存层，槽位目录内嵌于共享介质、无需外部元数据服务。

关键数字 双节点集群+512 GiB CXL 设备+Qwen2.5-7B-Instruct：外部命中率 95.4–99.5% 时跨节点前缀复用使 TTFT 降低 5.5–36.6×，而本地方案只能全量重算；跨节点与同节点复用的时延差（sharing gap）仅 1–4%。

为什么值得看 CXL 共享内存进入 K8s 调度与 vLLM 生态的可行性验证，是内存解耦路线的重要一环（作者明确定位为可行性研究而非性能评测）。
