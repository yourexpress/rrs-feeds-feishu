TileDRAM: Compiler-Controlled Tile-to-DRAM Layouts for 3D DRAM GPGPUs

arXiv · 2026-10-16 · 论文PDF / 每日精选

研究问题：现代 GPU 编译器有 thread/on-chip 的丰富 layout 抽象，但 CU-local 3D DRAM 上没有 tile→DRAM 布局抽象；常规放置会让结构化 tile 访问撞到 row-buffer 冲突。

方法：TileDRAM 把 GPU Linear Layout 从计算侧映射扩展到 DRAM 放置坐标，按每个 tile 访问签名选 layout，以行缓冲行为单位评估候选；运行时仅做普通地址算术，无需新硬件或 ISA。

关键数字：在 Accel-Sim/Ramulator2 上 108 个 MoE FFN 用例的 full-trace replay：按请求加权的行冲突率从 75.7% 降至 15.2%，几何均速 1.77x；6 条 trace 在 6 种 3D DRAM 组织上几何均速 2.20x；RTX 3090 上地址变换可承受。

为什么值得看：把 GPU layout 抽象延伸到 3D DRAM 放置坐标，让编译器就能显著降冲突，做 GPU 编译器/3D DRAM 的桥梁工作。
