ChatGPT / Codex 文字水印（EU text provenance）

OpenAI · 2026-10-05 · 官方公告

核心话题 OpenAI 为响应欧盟 AI 法案公布文字水印 textGrain 的落地路径与局限。 要点 API 客户即日起全球可选开启水印（默认关）；数周内欧盟区 ChatGPT/Codex 输出加不可见水印；检测器初期限获批机构试用、计划开源；textGrain 向选词加不可见统计信号供检测。 关键数字 假阳性 1% 下 200-token 段落检出约 80%、400-token 约 95%；数学类更低；替换 10% 同义词检出 92%→66%、25%→17%。 为什么值得看 欧盟文本溯源首个主流落地细节，局限量化透明。 阅读原文
