Scaling MoE reinforcement learning on Amazon EKS with EFA and DeepEP with 40% more throughput

AWS Machine Learning Blog · 2026-09-25 · 技术博客 / 每日精选

核心话题 MoE 模型大规模 RL 后训练（RLHF/GRPO）的基础设施挑战：rollout 生成与策略训练的异构算力协同、数百加速卡间高吞吐通信、子系统动态编排。

要点 AWS 把 DeepEP 通信原语迁移至 libfabric、原生支持 EFA，在 EKS 上编排超稀疏 MoE 的 RL 训练。MoE 的专家并行引入动态 all-to-all token 路由，使训练更受通信而非算力约束；rollout 与训练互相拖累的问题通过通信优化与统一编排缓解。

关键数字 48 台 P5en 上超稀疏 MoE RL rollout 聚合吞吐提升 40%，方案可扩展至约千卡规模。

为什么值得看 通信受限的 MoE RL 训练是当前后训练基础设施的核心矛盾，本文给出云上可复用的完整栈方案。
