GPU-resident Execution for Timing-predictable Sensor Processing Systems

arXiv · 2026-10-09 · 论文PDF / 每日精选

研究问题：闭环实时系统里 GPU 只做加速器、CPU 主机仍是每轮迭代的编排者——中断、调度与 CUDA API 开销让端到端延迟不可控，能否让 I/O 与执行全程驻留 GPU？ 方法：提出 GPU-resident Execution 执行模型：传感器输入直达 GPU 显存、触发 GPU 侧处理、到达 GPU 可见输出端点，全程无主机唤醒；在 NVIDIA Holoscan C++ 框架实现并提供参考组件。 关键数字：1080p/60 Hz 工业级相机到显示应用上，光子到显示抖动从 4.83 ms 降到 0.66 ms（7.3×），软件处理抖动从 1.70 ms 降到 0.01 ms（170×）（对比 CPU 驱动的 GPU 显存 RDMA 基线）。 为什么值得看：机器人/AR 等硬实时感知管线对「去主机化」需求强烈，这是 NVIDIA 官方框架背书的系统化答案。
