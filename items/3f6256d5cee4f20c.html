A New Lens on Multi-GPU Communication: API-Level Memory Models for Portable Optimization

arXiv · 2026-10-14 · 论文PDF

研究问题： 设备侧多 GPU 通信 API（rocSHMEM、MSCCL++、GIN 等）缺乏严格内存模型，优化易脆、难移植。 方法： 提出 API 级内存模型定义通信原语的内存语义，抽象底层细节；以 AMD 开源的 rocSHMEM 为例定义模型，并展示形式化松弛如何支持网络数据 cache bypass 且保留标准化接口。 关键数字： collective 通信负载性能最高提升 2.48x；融合计算+通信负载最高 1.77x；SOTA 专家并行通信负载最高 1.18x。 为什么值得看： 为低层设备通信 API 补上语义地基，让细粒度优化可移植、可互操作。 阅读原文
