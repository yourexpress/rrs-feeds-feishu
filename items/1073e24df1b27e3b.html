VenusRL: A Fully Disaggregated Agentic RL System with Priority Scheduling and Scalable Interaction

arXiv (cs.DC) · 2026-10-05 · 论文PDF

研究问题 智能体强化学习通过多轮与外部工具环境交互训练 LLM 智能体，存在两个系统级瓶颈：端到端吞吐受最慢轨迹完成制约、单纯优化单 GPU 利用率反而分散 rollout 进展；工具沙箱按声明内存上限静态过度配置，大量物理内存闲置且同提示词沙箱重复复制近相同状态。

方法 提出全分离式智能体 RL 系统 VenusRL：优先级感知动作调度器用长度预测启发式识别最可能解锁下一训练步的样本组，在批准入、KV 缓存驻留与跨 worker 请求编排中插队；环境资源管理器结合内存感知准入阈值与模板键控页共享池，通过写保护页表项别名与写时复制在保持严格内存隔离下提高每节点沙箱密度。

关键数字 代表性智能体 RL 工作负载上，端到端训练速度最高提升 4.24x，环境成本最高降低 89%。

为什么值得看 智能体 RL 训练系统的两个真瓶颈都有实测显著的解法，落地价值高。
