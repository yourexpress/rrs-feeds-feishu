Let the Gate Decide: Per-Lookup Precision for Quantized Conditional Memory in LLMs

arXiv(cs.LG) · 2026-10-26 · 论文PDF / 每日精选

研究问题 Engram 等条件记忆层挂载大型哈希 n-gram 表，低比特量化先丢长尾事实；按访问频率给更多位的常见补救反而更差——量化误差由什么决定？

方法 发现门控按行缩放检索结果：查找的量化误差由门控加权，频繁 n-gram 门控小、稀有长尾门控大，且可从 1-bit 码算出。GateRQ 每行存为 1-bit 残差码阶梯，level 1 常驻 GPU 算门控，仅对门控排序最高的查找读更深层。

关键数字 免重训将 DeepSeek-V4.1-Flash GPU 表内存降 7.8x，vLLM 吞吐较 FP8 表 +11%–31%；每查找读 1.50 bits 时 PopQA 约损失 1 分、2.10 bits 时 0.2 分。

为什么值得看 用门控信号做逐查找精度分配，直击条件记忆量化长尾失真。
