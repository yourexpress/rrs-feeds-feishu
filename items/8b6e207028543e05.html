TierKV: Long-Context On-Device LLMs via Predictive Multi-Tier KV Caching

arXiv（cs.LG/eess.SY） · 2026-09-18 · 论文PDF / 每日精选

研究问题：移动端 LLM 走向长上下文，KV 缓存随序列线性增长且每步都要访问，成为主导内存瓶颈；低秩压缩、token 驱逐、闪存卸载各有重构开销、不可逆丢失或 I/O 停顿。

方法：TierKV 提出预测式多级缓存优化（PMCO）：解码开始前就从 prefill 隐状态预测未来缓存需求，在设备内存与精度预算下把 token 联合分配到精确、低秩、闪存卸载三层；保留全上下文访问、消除反应式驱逐的循环依赖，闭式求解器在运行时选择分层边界与逐层秩。

关键数字：8 个文本/视觉/音频模型、3 款移动 SoC 上：prefill 吞吐较现有移动端框架最高提升 17.6x，RAM 驻留 KV 缓存减少 12.5–34%，同内存预算下支持显著更长上下文，精度仅轻微下降。

为什么值得看：把 KV 分层从“边跑边驱逐”变成“开始前预测”，端侧长上下文推理的实用新范式。
