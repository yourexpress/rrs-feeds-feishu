SPLASH: Co-Designing Sparse Attention with High-Bandwidth Flash for Efficient Long-Context Inference

arXiv (cs.AR) · 2026-09-22 · 论文PDF / 每日精选

研究问题：长上下文服务中 KV cache 是内存主消费者：HBM 有带宽没容量，高带宽 Flash（HBF）有 TB 级容量与近 HBM 读带宽——KV cache 能否架在 HBM+HBF 层级上？

方法：算法-架构协同设计 SPLASH：跨 HBM/HBF 虚拟化 KV cache 为单一逻辑内存；稀疏注意力按 HBF 整页读取与千级并行 flash 平面的物理特性协同设计，限制 decode 期 KV 读取量。

关键数字：100ms 每 token 延迟目标下单 GPU decode 吞吐较基线提升 3.5x-11.4x；长上下文套件精度保持在 dense attention 的 4% 以内。

为什么值得看：新型存储介质首次被认真纳入 KV cache 层级，长上下文服务成本结构的潜在拐点。
