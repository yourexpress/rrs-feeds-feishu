Do AI coding agents struggle with non-REST APIs?

Microsoft · 2026-11-23 · 技术博客 / 每日精选

核心话题 AI 编程智能体在非 REST 风格 API（POST-only、RPC）上是否表现更差。

要点 微软用虚构库存 API Binstock 以 REST/POST-only/RPC 三种风格提供相同数据与行为（Dev Proxy 模拟、内存数据每次重置），写 15 个任务（5 读 10 写），任务提示只描述期望结果、不点出操作名。对比有/无文档两种条件。

关键数字 1,356 次运行、6 个模型（两家厂商）。有文档时三种风格成功率与失败调用/令牌成本无差异；无文档时 REST 大幅胜出（RPC 成功率 0%、REST 93–97%）。

为什么值得看 用受控虚构 API 隔离了「HTTP 方法」与「端点命名」两个变量，结论直接指导 API 设计：给智能体用的 API 文档比风格本身更重要。
