Programming AMD XDNA NPUs with Open-source Compiler Tools: A FlashAttention Case Study

arXiv（Zhefu Chen 等，cs.AR/cs.LG） · 2026-09-18 · 论文PDF / 每日精选

研究问题：AMD XDNA 这类空间型 NPU 把计算瓦片贴着小本地内存、数据搬运全交给软件——多阶段算子如何摆放中间张量，决定了性能上限。

方法：用开源 IRON 与 MLIR-AIR 流程为 FlashAttention 做映射案例研究，在 XDNA 1/2 上比较四种参考设计（逐算子、两种片上流水、全融合单内核）；融合版把 QK^T 分数留在计算瓦片本地内存、经级联互连归约。Roofline 逐内存级分析给出“融合到越过脊点就停”的判据。

关键数字：XDNA 2 上融合内核端到端达 3.62 TFLOP/s，是 IRON 设计的 2 倍；2K token 以上能效为同芯片集成 GPU 的 5.3–7.2 倍；覆盖 BERT 到 DeepSeek 共 12 个 LLM 配置、最长 128K token；参考设计开源。

为什么值得看：少见的“先算 roofline 再写代码”NPU 映射方法论，做边缘 NPU 算子部署可直接套用其判据。
