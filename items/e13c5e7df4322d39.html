Cleave: Scaling Tensor Program Optimization via Decoupled Algebraic Search and Operator Scheduling

arXiv cs.PL · 2026-10-08 · 论文PDF / 每日精选

研究问题： FlashAttention 等优质 kernel 多为专家手写、ML 编译器难以匹敌；生成这类 kernel 需要同时做计算图代数变换与算子调度，联合搜索空间过大无法遍历。

方法： Cleave 用符号化解耦两步：先在符号 shape 图上做超优化发现变换（等价性检查因此变得便宜，新 Split 算子以符号 split 数沿归约维并行），再在具体 shape 上调度；调度器通过迭代 tiling 与水平融合处理含多归约的图。

关键数字： 常见 LLM 子图上 kernel 比最佳基线快最高 2.8x（平均 1.6x），比 Mirage 平均省 5.9x 编译时间；生产服务 trace 的动态负载上对 FlashInfer 手写 FA2/FA3 后端几何平均加速 1.4x/1.7x。

为什么值得看： 编译器自动生成媲美手写的 attention kernel 是 AI 编译方向的硬指标，代码已开源。
