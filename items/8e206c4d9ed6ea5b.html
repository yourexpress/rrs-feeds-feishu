A model guide for the GPT-6 family

OpenAI · 2026-10-02 · 官方公告 / 每日精选

核心话题 OpenAI 官方发布的 GPT-6 系列模型实用指南，面向要在生产环境中用好 GPT-6 的开发者，覆盖选型、提示词、长任务管理与成本控制。

要点 按工作负载选模型：GPT-6 Astra 用于最难的推理任务，GPT-6.1 Sol 面向复杂编码、研究与 computer use，GPT-6 Luna 适合目标明确的规模化日常任务；同时按任务选择 reasoning effort 档位。成本侧建议用 prompt caching 复用共享上下文、用 compaction 压缩长对话；长任务用 steering、异步工具与委派保持轨道。

关键数字 指南称缓存命中的输入 token 成本最高可比未缓存低 95%（视模型而定）。

为什么值得看 一手官方的模型选型与成本优化清单，适合正在评估或已经接入 GPT-6 的团队对照自查。
