SyclKittens: A Tile Programming Model for Programmers and Coding Agents on Intel GPUs

arXiv cs.DC · 2026-10-06 · 论文PDF / 每日精选

研究问题 新 AI 加速器总是先于「让它变快的 kernel」出现，而编码智能体已能自行编写调优 kernel——但给智能体什么接口，决定了它能写出什么：裸能力接口，还是编码了已知好方法的接口？

方法 在 Intel GPU 上用 3 个编码模型 × 3 个 kernel 做受控实验。随后提出 SyclKittens：面向 Intel GPU 的硬件感知瓦片编程模型，把已知好方法编码进接口——操作数自动放入矩阵引擎布局、经 L1 缓存预取、通过连接 GPU stack 的 fabric 通信。

关键数字 裸 SYCL 加执行反馈下，最强模型 Opus 4.8 写的单卡 GEMM 仅达 oneDNN 的 57.5%；换 SyclKittens 后同预算达 82.1%；人与智能体联合打磨的 kernel 套件在 GEMM 形状上几何平均约达 oneDNN 的 96%；Llama-3.1-8B 推理单卡比 torch.compile 快 1.59 倍，对 oneCCL 多卡解码路径最高快 2.91 倍。

为什么值得看 用受控实验证明「接口里编码领域方法」能把硬件能力转化为性能，开源可用。
