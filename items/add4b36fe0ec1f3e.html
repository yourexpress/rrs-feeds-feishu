Folding Attention Biases into Keys Makes Compacted KV Caches Run on Standard Kernels

arXiv(cs.LG) · 2026-10-27 · 论文PDF / 每日精选

研究问题 Attention Matching（AM）压缩 KV 缓存需给保留 key 的 logit 加偏置，但 FlashAttention 与 vLLM 分页缓存没有该输入——压缩缓存能否直接在标准 kernel 上跑？

方法 把偏置沿每头一个闭式方向（在上下文 query 上拟合）折叠进 key，得到尺寸与 AM 相同、走模型自身 query 路径的普通缓存；输出误差以 query 在该方向投影与 1 的距离为上界。

关键数字 等预算下未修改 vLLM 服务折叠缓存：Qwen3-4B 全部 51 问与 HF 一致、LongBench 200 样本中 180 个贪心输出一致；14 组设置中 13 组精度与 AM 噪声内，12 组可比 KL 全部低于丢弃偏置。

为什么值得看 闭式变换让压缩缓存兼容标准推理栈，免自定义 kernel。
