Only Accepted Tokens Count: An Energy Accounting of Speculative Decoding Under Latency Targets

arXiv(cs.DC) · 2026-10-29 · 论文PDF / 每日精选

投机解码能耗核算：在延迟目标约束下仅计被接受 token 的能耗，量化数据中心每 token 能耗与 batching 摊销

Large language model serving is limited by facility power. Energy per token determines how many tokens a datacenter can serve, while a latency target bounds how quickly each user receives them. During decode, every weight is read from memory for every generated token. Batching amortizes this read across users but makes no individual user faster. Speculative decoding does: a drafter proposes several future tokens, and the target model verifies them in a single forward pass that reuses the same weight read. Because every drafted token must be verified whether or not it is accepted, the energy speculation saves depends on how many drafted tokens are accepted. This saving is hard to pin down. It varies across target models from different attention families and across drafting schemes, and it depends on the text being served. Every drafter we evaluate accepts fewer tokens on conversation than on code, and every trained drafter accepts fewer on Romansh, a low-resource language, than on English.
