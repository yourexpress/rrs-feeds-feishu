BaGuaLu-2: Taming Dynamic Memory Fluctuation for Efficient MoE Model Training over 10,000 GPUs

arXiv · 2026-10-16 · 论文PDF / 每日精选

研究问题：细粒度 MoE 训练中专家负载动态失衡带来严重显存波动；静态预留要么浪费要么 OOM——能否做到"按需"显存供给？

方法：BaGuaLu-2 把显存分配从一次性静态调参改为持续细粒度控制，按 batch 按需给精确的激活显存；并通过系统优化抵消动态管理开销。

关键数字：12,288 GPU 上训练 1040B 参数 MoE，维持 2 EFlops 以上、MFU 35%；较 Megatron-Kuai 与 AdaPipe 平均吞吐提升 1.14x / 1.13x。

为什么值得看：万卡 MoE 训练把"动态显存"从工程 hack 推到系统性能力，做大规模 MoE 训练基础设施的可读蓝本。
