Synapse: An HBM-Coordinated HBF Near-Memory Computing Architecture for Pipelined Agentic AI Execution

arXiv · 2026-11-23 · 论文PDF / 每日精选

研究问题：多 agent 视频推理中模型权重与每 agent KV 缓存可超 HBM 容量；高带宽闪存（HBF）增加容量，但 agent 仍等待 GPU 执行。

方法：Synapse，HBM 协调的近存计算架构：跨 agent 把 HBF 注意力与专家执行和 GPU 计算重叠；减少派发延迟与不必要刷新。

关键数字：三模型下端到端延迟降 48.92-66.60%、吞吐最高 2.98x、每输出 token 建模能耗最多降 64.48%（对比被动 HBF GPU 执行）；磨损仿真显示比整块刷新 HBF 寿命长 46%。

为什么值得看：HBF 近存计算 + 流水化 agentic AI 执行，容量-延迟-能耗三重收益。
