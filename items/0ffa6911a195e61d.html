On Turn-Level Best-of-N Sampling for Scaling LLM Agents

arXiv · 2026-11-05 · 论文PDF / 每日精选

研究问题 推理时缩放（test-time scaling）对长程任务 agent 是否有效？此前引导式搜索依赖专门训练的 critic，能否用现成开源模型直接比较候选动作？

方法 实现 turn-level best-of-N：每回合生成器产出 N 个候选动作，选择器从中挑一个执行（generator-selector 框架），不训练 critic、直接用现成开放权重 LLM 比较候选动作；在长程终端任务上评测准确率与多次尝试的一致性。

关键数字 相比基线在准确率上提升 5~10%，并提升多次重复尝试的一致性；轨迹分析显示 agent 行为转向更优模式——尝试次数减少、指令遵循与调试测试改善。

为什么值得看 验证了"无训练、纯推理时采样"也能显著增强长程 agent，且行为改进可解释，对推理成本优化有直接参考。
