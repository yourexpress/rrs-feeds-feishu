Serving a Revisable World: Versioned Execution for Interruptible Agents

arXiv (cs.DC) · 2026-10-02 · 论文PDF

研究问题： LLM agent 因指令变更、工具失败等修订运行任务时，旧请求的缓冲输出与未完成工作仍可能影响应用，而已完成 KV 状态对后继执行可能仍有价值。

方法： 围绕"版本化执行"重构服务控制面：执行版本拥有发布输出/安装状态的权威；先撤销过时工作、界定剩余执行、认证可继承前缀，后继从该状态运行，旧资源异步回收。在 vLLM 中实现。

关键数字： 受控配对实验中，修订到后继首 token 时间中位降低 17.1%；编码 agent 中断回放无过时输出、各最终版本持续推进。

为什么值得看： 把中止重发变为协调交接，兼顾快速失效与选择性保留。
