LOCAA: An Agentic System for Automated Lossy Compressor Tuning

arXiv cs.DC · 2026-10-09 · 论文PDF

研究问题 用户用数值误差界配置有损压缩器但用质量指标评估，二者关系随数据集与压缩器变化，配置搜索常需穷举。

方法 LOCAA：基于 LLM 的压缩自动调参 agent，压缩回路内搜索（工具集成执行、压缩器感知引导、持久记忆），支持自定义目标与约束。

关键数字 固定比率搜索平均比二分搜索少 1.98 倍、比 FRaZ 少 5.03 倍试验；联合 PSNR 与 SSIM 约束下平均试验 61.5→17（-72.4%）；持久记忆再省 27.9%。

为什么值得看 工具增强 LLM agent 高效调压缩参数的实例，跨三个应用五个压缩器验证。
