PACMI: Provenance-Aware Cascading Memory Invalidation for Long-Term LLM Agents

arXiv cs.LG · 2026-10-06 · 论文PDF

研究问题 长期任务的 LLM agent 依赖长期记忆，但新证据到达后旧记忆会过时——过时记忆可能语义上仍相关、继续影响依赖记录、且保留历史价值，现有方法支持有限。

方法 提出 PACMI：把记忆与新证据表示为带类型依赖边的溯源图；记录归入四状态有效性格，有效性变化沿依赖级联传播，并用结果状态做检索与过时前提检测；配套构建 5 领域、100 案例、300 查询的诊断基准，按节点级、上下文级、答案级分层评估。

关键数字 基准上最终答案准确率最高，与最强基线的配对差异在精确 McNemar 检验下显著；前提检查器在受控查询分布上精确率、召回率、F1 均达 1.0；去掉级联传播后最终答案错误从 3 增至 11（配对差异未达 0.05 显著性阈值）。

为什么值得看 把"记忆过期"当作一等问题处理（溯源图 + 级联失效 + 历史保留），是长程 agent 记忆管理的系统性方案。
