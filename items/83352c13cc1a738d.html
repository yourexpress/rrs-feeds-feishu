KVCMAS: Efficient KV cache Correction for Shared Context in Multi-Agent Systems

arXiv (cs.LG) · 2026-09-28 · 论文PDF

研究问题 提示词专业化的多智能体系统让多个 agent 共享一个模型、扮演互补角色，但 agent 特定前缀会改变同一共享上下文的 KV 缓存，导致每个 agent 重复 prefill 不断增长的上下文并各自构建缓存，计算与内存开销高。

方法 KVCMAS 是在线 KV 缓存校正框架：用紧凑低秩状态表示跨 agent 缓存偏差，沿 agent 工作流无缝链式校正，无需额外参考 prefill；支持动态变化的共享上下文，同时保留精确的首个 agent 缓存。

关键数字 在多个语言与视觉-语言负载上，受控服务轨迹下相对无 KV 缓存共享提供 2.0x TTFT 加速，相对先前 KV 缓存校正方法峰值 GPU 内存降低最多 3.7x，同时保持或提升共享精度。

为什么值得看 多 agent 共享上下文场景的 KV 缓存复用痛点明确，低秩在线校正避免重复 prefill，对高并发 agent 服务有实用价值。
