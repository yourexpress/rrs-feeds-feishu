PrismML Bonsai 2 27B Shrinks Local AI, but the Hardest Tests Still Matter

PrismML launched Bonsai 2 27B on September 17, compressing a 27-billion-parameter model into a 5.9GB package for consumer hardware. The company says PrismML Bonsai 2 27B retains 98.2% of its full-precision counterpart’s aggregate benchmark performance.

That combination changes the local AI calculation. Developers previously had to choose between smaller models that fit comfortably and larger models with stronger reasoning. Bonsai 2 challenges that tradeoff by placing a 27B-class multimodal system within the memory range of laptops and consumer graphics cards.

However, fitting the weights is only the first test. PrismML’s aggregate results are vendor-reported, several packaging formats occupy more than 5.9GB, and the model currently depends on custom runtime components. Its largest question is whether compact local models can remain reliable during long, tool-driven tasks.

PrismML Bonsai 2 27B Packs 27B-Class AI Into 5.9GB

The launch matters because PrismML reduced the language model’s footprint without changing the underlying 27B architecture.

Bonsai 2 is derived from Qwen3.8-27B, a multimodal model that handles text and images. PrismML retained the architecture while converting most language-model weights into a ternary representation.

Ternary weights use three possible values: negative one, zero, and positive one. A shared scaling value lets the runtime translate those compact values into useful numerical operations during inference.

This representation differs from simply deleting parameters or replacing the model with a smaller architecture. Bonsai 2 still contains roughly 27 billion parameters, but each compressed weight requires far less storage than a conventional 16-bit value.
