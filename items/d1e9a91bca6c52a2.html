Anthropic 发布 Prompting Claude Opus 5.5 指南

Anthropic · 2026-09-28 · 技术博客

核心话题 Anthropic 发布 Prompting Claude Opus 5.5 指南，并警告旧的 Opus 5 effort 设置现在会烧 token。

要点 指南记录 Opus 5 到 5.5 的九个行为变化：默认 effort 从 high 降至 medium、thinking 始终开启不可关闭、既有 effort 设置每轮运行更长更贵；新增三类拒绝（biology、cybersecurity、reasoning_extraction）返回 stop_reason 'refusal' 并带 fallback 语义；另给出系统提示词配方，阻止无人值守 agent 以进度报告代替工具调用结束回合。

关键数字 九个行为变化；新增 3 类拒绝语义。

为什么值得看 提示工程直接影响推理成本——"旧 effort 设置现在烧 token"对重度 API 用户是实打实的账单提醒。
