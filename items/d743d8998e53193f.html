When Is High-Bandwidth Flash Cost-Effective for LLM Inference?

arXiv cs.AR · 2026-11-08 · 论文PDF / 每日精选

研究问题 高带宽闪存（HBF）能否让 LLM 推理比加 GPU 更便宜？把权重放在比 SSD 更靠近 GPU 处可减少容量所需 GPU 数，但只有在满足服务目标且成本可回收时才合理。

方法 用公开组件数据模拟：九个密集与 MoE 模型、五个负载、两个 GPU 平台、1–100 GPU 规模，评估固定需求下最小 GPU 数与固定 GPU 数下的吞吐。

关键数字 固定需求下 HBF 在 468 组比较的 98 组中降低满足服务目标所需最小 GPU 数，多数为暂停与短会话场景，63 组在「每 HBF 栈半块 GPU 价格」下仍划算；单短聊用户场景 HBF 让 DeepSeek V3、Kimi K2 等大 MoE 在单张 RTX 4090 满足宽松服务目标（传统 serving 做不到）；100 张 RTX 4090 规模下级联 HBF 把三个大 MoE 离线吞吐提升 16.4–26.5x。

为什么值得看 用系统化模拟回答「什么时候 HBF 值」：省钱与提吞吐出现在不同场景，决策依据清晰。
