BoT-GRPO: Efficient Process-Reward RL for Reasoning via Bag-of-Token Aggregation

arXiv cs.LG · 2026-10-09 · 论文PDF

研究问题 强化学习已成为激发 LLM 推理的核心，但流行算法 GRPO 中 rollout 的每个 token 获得相同 advantage；如何在无价值网络成本下让过程监督更高效——加速收敛并提升最终质量？

方法 BoT-GRPO：把 GRPO 扩展到 token 级奖励模型，用长度不变（length-invariant）的"token 袋"聚合：收集 rollout 中所有 token 级奖励，按来源序列长度倒数加权，相对加权组统计计算逐 token advantage；critic-free，有 token 级奖励时可在 GRPO 处即插即用。

关键数字 React 前端代码生成上编译率达 80%、比 GRPO 快至多 1.9×，收敛快于 GSPO/DAPO/PURE 等变体且最终编译率与 VLM 判定胜率更高；AIME 数学推理上 Pass@k 绝对增益最高 8.1%、步数减半。另得奖励模型配方：信号稳定性比丰富性更重要。

为什么值得看 无 critic 的 token 级过程奖励方案，两个任务上收敛与最终质量双赢，奖励设计经验可直接复用。
