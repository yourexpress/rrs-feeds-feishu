If You Hear It, Help Find It: Orthogonal Knowledge Distillation for Open-Vocabulary Audio-Visual Event Localization

arXiv (cs.LG) · 2026-09-22 · 论文PDF

研究问题 Open-vocabulary audio-visual event localization (OV-AVEL) 用文本查询把事件在时间上定位于视频/音频/语言。不同监督源在时间边界可靠性上有差异：本文配置下视觉教师给出更可靠的边界线索，音频教师虽强且语义信息丰富却不如视觉精确——但这是设置相关诊断，并非对视觉/音频的普遍排序。

方法 提出 OV-OrthKD（reliability-aware asymmetric distillation）：视觉特征迁移塑形「决策对齐」表示；音频特征迁移丰富互补辅助子空间；文本原型锚定 seen/unseen 类别语义；正交损失限制两个 teacher-specific 投影方向重叠；默认训练不把音频教师监督放在 segment-logit 路径上。

关键数字 OV-AVEBench 上 OV-OrthKD 取得 0.816 segment AP；F1@0.5 较官方微调基线整体 +2.7 点、unseen 类别 +3.4 点。

为什么值得看 把「监督放置」作为 OV-AVEL 的设计维度，对多模态知识蒸馏的可解释性与可调性有方法论价值。
