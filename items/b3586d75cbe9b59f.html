DCKV: Learned Transform Coding of the Prompt KV Cache in Hybrid Language Models

arXiv(cs.LG) · 2026-10-27 · 论文PDF / 每日精选

研究问题 混合 LLM 只在少数全注意力层保留 KV 缓存，但该缓存随 prompt 增长、复用需存储或搬运——能否学习端到端可训练的 KV 缓存编解码器？

方法 DCKV 可微编解码器（首个端到端训练的 KV 缓存 codec）：变换、量化与熵模型（以 prompt token 与已解码邻近位置为条件）与冻结语言模型联合优化，同时最小化熵模型码长与模型输出变化。

关键数字 Qwen3.5-2B：压缩 token 比 bf16 少 55 倍以上字节（三个长上下文基准损失 ≤1.8 分）；100 倍以上压缩时损失 ≤3.6 分。

为什么值得看 KV 缓存压缩做成可微端到端学习的首个工作，压缩率显著。
