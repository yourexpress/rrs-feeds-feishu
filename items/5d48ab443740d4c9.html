RISK-KV: Quality-Aware Selective KV Cache Reconstruction for Distributed LLM Inference

arXiv · 2026-10-21 · 论文PDF / 每日精选

研究问题 分布式 LLM 推理的请求迁移与中断恢复依赖历史 KV cache：完整保留/传输状态开销巨大，重放历史 token 又需额外计算。

方法 RISK-KV 质量感知的选择性 KV 重建：用目标层两侧的精确 KV 状态配合跨层岭回归预测缺失层的 attention-projection 输入，再折叠原始 KV 投影矩阵降低预测器存储；以重建导致的 NLL 变化度量风险，低开销拓扑搜索+质量门控选择要重建的层组。

关键数字 三个 LM 上代表性恢复配置省略 18.2%-33.3% 历史 KV，困惑度变化低于 0.5%；512-token 历史的本机恢复实验中比完整 token 重放快 1.51-3.31 倍。

为什么值得看 用预测重建替代全量缓存/重放，为分布式 serving 容错与迁移提供低开销新路径。
