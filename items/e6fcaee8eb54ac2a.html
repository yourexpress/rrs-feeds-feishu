Presage: Prefetch Search via Agent-Guided Experiments

arXiv (cs.AR) · 2026-09-22 · 论文PDF

研究问题：软件预取（prefetch）能有效缓解缓存未命中延迟，但手动插入预取指令耗时且对微架构变化敏感，现有编译器方法泛化性差。

方法：Presage 用 LLM 的语义推理能力驱动预取插入——提议 agent 识别候选点，优化 agent 在循环中迭代改进，组合 agent 处理预取间依赖与干扰。

关键数字：在 81 个负载上几何平均性能提升 10%，SPEC CPU 2026 上降低 2.7% 运行时间（此前 SOTA 失败），相对 SOTA 评测套件提升 17%（SOTA 为 10%）。

为什么值得看：LLM + 编译器优化的交叉应用，用语义理解解决了启发式方法无法泛化的难题，在大规模代码库预取上开辟了新范式。
