Qwen3.8 Flash Next: 3-bit near 16-bit accuracy, with MTP prefix caching

ElioVP Blog · 2026-10-25 · 技术博客 / 每日精选

核心话题 3-bit 量化权重能否逼近 16-bit 精度，长对话里前缀缓存与 MTP 能否同时生效。

要点 10 月 24 日发布的新 3-bit Qwen3.8 Flash Next 权重不改格式、体积与 kernel，只调整各专家输出投影的校准统计、扩充到约 400 万 token 校准集、保留 3-bit 专家之外的 8-bit 共享层；native worker 让 GPU 不再跑 PyTorch，vLLM 只提供 API 与调度。

关键数字 三项文本任务上 3-bit 与 16-bit 的差异均不具统计显著性，HumanEval 低 1.8 点（配对 95% 区间 −5.0 ~ +1.3）；重复 200K token 提示的缓存命中恢复 0.68s vs 冷启动 25.81s；262,144 token 窗口 213.5 tok/s（开 RAM 层）/250.0 tok/s（关）。

为什么值得看 "3-bit 逼近 16-bit"目前只在文本任务上成立，作者自陈并不等价，视觉端亦未验证原生图像输入；而前缀缓存叠加 MTP 对多轮 coding agent 的等待收益更实在。
