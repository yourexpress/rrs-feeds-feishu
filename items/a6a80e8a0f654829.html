Athena's Engine: DeepSeek and Qwen3.8 Next — 1,126 tok/s prefill, 32 tok/s decode, 256k ctx on 1 DGX Spark

NVIDIA Developer Forums (marco.palaferri) · 2026-09-19 · 技术博客 / 每日精选

核心话题：开源推理引擎 Athena's Engine 发布：单台 NVIDIA GB10（DGX Spark / ASUS Ascent GX10）上本地跑 DeepSeek V4 Flash 与 Qwen3.8 Flash Next，满血 262,144 token 上下文，数据不出本机。

要点：prefill 速率随上下文增长几乎平坦；生成速率在 25 万 token 会话中与全新会话持平；上下文可落盘（619MB 文件、空闲时写入），恢复而非重读；双模型共用 “Athena” 一个 API 名，对话中 %switch 即可热切换；DSpark 投机解码输出与常规解码逐位一致。

关键数字：1,126 tok/s prefill、32 tok/s decode；141,519 token 会话恢复仅 2.1 秒（首次读取需 2 分 20 秒）；tool-eval-bench 69 个场景双模型均 91/100；模型热切换实测 46 秒。

为什么值得看：个人桌面跑“准前沿”长上下文模型的体验样本——decode 平坦曲线与上下文落盘恢复是长 agent 会话的刚需特性。
