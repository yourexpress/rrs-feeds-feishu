Native Dual Pools or Shared Paging? Memory Organization for Concurrent Hybrid LLM Serving

arXiv · 2026-10-14 · 论文PDF

研究问题：混合 attention-SSM 服务中，增长的 attention KV 与定长 recurrent/conv 状态分配单元、复用边界、生命周期都不同——内存该如何组织？

方法：在修改版 vLLM 运行时实现四种内存组织：粗共享页基线（S0）、checkpoint 内 recurrent 分页（S1）、conv 槽打包分页（S2）与原生双池（D0），围绕存储成本与服务行为提出九个评估问题。

关键数字：S0-S1-S2 累积细化在主工作点提升完成输出吞吐与尾部完成时间；共享前缀工作负载增益更大；状态追踪显示 S2 中 recurrent-checkpoint 可用性限制联合复用；fresh-seed SHARE/ISOLATE 对比估计出正的保留交互，但主置信区间含零。

为什么值得看：混合模型服务的物理状态表示 + 准入 + checkpoint 生命周期要联合设计，问题清单值得复用。
