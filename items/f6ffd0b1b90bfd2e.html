GigaEdge Spench: An SDK for Practical Streaming Speech Enhancement

arXiv cs.LG · 2026-11-09 · 论文PDF / 每日精选

研究问题：流式语音增强要同时满足 CPU 服务器、移动端与浏览器三种部署环境，如何构建一个可配置、跨平台的实用 SDK？

方法：开源 GigaEdge Spench SDK——增强通道由神经降噪、归一化、动态处理、采样率转换与回声消除模块组合而成（归一化可不带神经模型单独运行）。共享 C++ 核经原生接口支持 ONNX Runtime 与 TensorFlow Lite，提供 Android/iOS SDK 与 WebAssembly 集成；独立流共享模型资源，同流连续帧可单次推理调用处理。发布 8kHz INT8 降噪器与判别式/混合 48kHz FP32 模型。

关键数字：EARS-WHAM v2 上评测并与 RNNoise、DPDFNet2 比较；所有测试的原生与 Web 配置处理文件均快于实时。

为什么值得看：端到端可部署的流式语音增强 SDK，覆盖从嵌入式到浏览器的完整链路，含模型选择/块大小/运行环境的实证研究。
