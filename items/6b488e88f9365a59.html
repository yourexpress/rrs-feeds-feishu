FoldSim: Scaling Cycle-Exact RTL Simulation with Hierarchical Folding and Static Scheduling

arXiv · 2026-11-19 · 论文PDF / 每日精选

研究问题：RTL 仿真时间随设计规模快速增长；CPU/GPU 仿真吞吐受限，FPGA 仿真吞吐高但可扩展性受资源容量约束。

方法：FoldSim 自动框架在单块 FPGA 上做 cycle-exact 仿真：层级折叠把设计层次中的实例映射到共享逻辑、保持独立状态；编译器对可折叠模块类构造静态调度，降低动态同步开销、状态访问可预测；超容量状态放外部内存按需取回；可配置 DRAM 模型分离目标内存时序与 host 延迟。

关键数字：单块 AMD Alveo V80 跑 8-SM GPU 与 1024 节点 Rocket 数据中心（4096 核）；非折叠实现分别需约 16×/200× LUT；数据中心约 1.9GB 状态驻留 HBM；4-SM GPU 完成 1024×1024 GEMM 仅 4.24 秒（软件 RTL 仿真 26 小时）。

为什么值得看：把超大设计的 cycle-exact 仿真压进单块 FPGA，吞吐跨数量级提升。
