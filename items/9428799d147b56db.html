Gemma 4 on Amazon SageMaker: QAT Weights Decode 2.05x Faster Than bf16 on One L4

DEV Community（Google Developer Experts） · 2026-09-26 · 技术博客 / 每日精选

核心话题 在单张 NVIDIA L4 上实测 Google Gemma 4 E2B 的 QAT 4-bit 权重 checkpoint 与 bf16 全量版本的部署差异。

要点 用 SageMaker 实时端点 + AWS 官方 vLLM 容器，QAT checkpoint 以 compressed-tensors 格式（w4a16：4-bit 权重、16-bit 激活）原生加载，切换模型只需改 SM_VLLM_MODEL 环境变量；作者还构建了一套 Python MCP 工具管理端点生命周期。

关键数字 QAT 相对 bf16：解码速度快 2.05×，16 并发吞吐 1.74×，每百万 token 成本约减半，40 题精度评测持平。

为什么值得看 量化感知训练模型低成本单卡部署的实操记录，含配额、区域容量等真实踩坑细节。
