SilverSpoon-KD: A General-Purpose Toolkit for Knowledge Distillation

arXiv cs.LG · 2026-11-17 · 论文PDF / 每日精选

研究问题：知识蒸馏研究手段多样，但工具没有跟上：现有工具包通常只支持有限子集技术与用例。

方法：SilverSpoon-KD 开源 PyTorch 工具包，用单一 API 统一不同蒸馏范式与架构关系，跨视觉、掩码 LM、因果 LM 负载验证，覆盖同构/异构/量化蒸馏；提供首个通用 blockwise 知识蒸馏实现，带独特可扩展特性；在便利性、指标计算与追踪之外，与既有工具包对比吞吐与 GPU 内存。

关键数字：性能与既有工具包持平或更好（吞吐、GPU 内存对比评估）。

为什么值得看：蒸馏工具缺口的一次系统性补齐，通用 blockwise 蒸馏实现是其中独有的能力。
