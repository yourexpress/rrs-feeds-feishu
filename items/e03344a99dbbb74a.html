KV-streams for Efficient Compaction in Agentic Reinforcement Learning

arXiv / Emiliano Penaloza 等 · 2026-09-29 · 论文PDF

研究问题 agentic LLM 扩展受限于 GPU 内存装不下越来越长的上下文轨迹；上下文压实（compaction）被广泛采用，但多数策略要反复 prefill LLM 上下文、拖慢训练吞吐——能否让压实可高效训练？

方法 提出 KV-streams：即插即用，把 KV cache 前向流式传递而非每次压实后清空，兼容任意压实策略；流式 KV 还可充当循环状态，携带早已从上下文消失的信息，且受控实验显示仅 RL 就足以让该行为涌现。

关键数字 三种不同压实策略下训练墙钟加速 2.6–5×，未见性能受损证据。

为什么值得看 "流式 KV 当循环状态"让压实从训练瓶颈变成效率杠杆，agentic RL 训练管线可直接套用。
