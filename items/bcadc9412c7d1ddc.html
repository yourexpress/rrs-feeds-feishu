ModelLess: A Serverless System for Multi-Tier LLM Inference on Shared GPUs

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：LLM 推理平台按产品分 GPU 提供在线、异步、批处理与 rollout 服务，服务爆发间隙卡片闲置而其他工作等待。

方法：ModelLess 无服务器系统：用户声明模型服务、平台持有实例；空闲服务缩到零——实例休眠且权重留在 host 内存（释放约 1s、唤醒约 4s，GLM-5.2 TP8，对比冷启动超 4 分钟），按持有 GPU 时间计费；空闲实例释放的 GPU 借给低层；每层（在线/作业/flex）定义被抢占时可丢失的内容，抢占协议先关准入再释放内存、先持久重入队再中止请求、失败即关闭（fail closed）。

关键数字：回放 1,100 张 H20 卡一周 trace，约 38% GPU 时间（417 等效 GPU）可在粗延迟目标 + 单固定空闲阈值下借出（理想上界，仅在恢复秒级时成立；240s 冷启动时仅余 8%）；单节点单策略 4 小时运行显示，暂停比中止-重入队每持有 GPU 样本多借出 22% token，中位在线延迟相同。

为什么值得看：GPU 资源池化的无服务器 LLM 推理，借出收益量级与边界条件清晰。
