Contention-Aware Flexible Execution for Machine Learning Workloads

arXiv · 2026-11-19 · 论文PDF / 每日精选

研究问题：并发 kernel 执行是 AI/ML 训练与推理的普遍范式，但并发 kernel 争用 GPU 共享资源（核心、缓存、内存带宽）会造成性能下降——到底降多少、如何缓解？

方法：首次大规模特征化并发 kernel 执行：在 AMD MI300X 上用毫秒级采样器做性能与内存行为分析，沿内存/计算受限、大/小 kernel 两个维度给出减速洞察；据此提出 CAFEML 弹性执行，用简单启发式调并发 kernel 的 overlap anchor 与资源分配。

关键数字：仅调度改动、无需 kernel 重写，端到端最高 13% 加速。

为什么值得看：并发争用的系统性特征化 + 零成本调度优化，训练/推理场景通用。
