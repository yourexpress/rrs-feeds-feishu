Causal Attention on CPU: A Cache-Aware and Load-Balanced Scheduling Kernel for Prefill

arXiv(cs.LG) · 2026-10-28 · 论文PDF / 每日精选

研究问题 多 agent 并发长上下文 prefill 会占满 GPU，CPU 是可替代路径，但现有 CPU attention kernel 不适应多级缓存层次、线程调度不佳。

方法 CACPU：分层缓存阻塞（tiered cache blocking）+ 核内任务分发（in-kernel task dispatching）的因果全序列 prefill 注意力 kernel。

关键数字 较 PyTorch SDPA、FlexAttention、SGLang 的注意力 kernel 最高提速 2.01×；集成进 SGLang 后 Llama-3.1-8B 的 TTFT 最高降低 1.74×，精度不变。

为什么值得看 CPU 侧 prefill 卸载的实用 kernel 工程，缓存感知与负载均衡设计对异构调度有参考意义。
