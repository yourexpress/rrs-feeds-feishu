LatentHarness: Learning Latent Actions for Memory and Reasoning via Counterfactual Policy Distillation

arXiv / Xiaoqiang Wang 等 · 2026-09-30 · 论文PDF

研究问题 长上下文推理面临两个互补瓶颈：跨长输入保留证据、跨多步维持计算；现有方法分别用外部记忆与潜推理处理，未统一。

方法 LatentHarness：把记忆访问与潜推理统一为顺序潜动作选择——每步在 THINK（继续计算）、RECALL（从快权重记忆召回证据与中间状态）、EXIT（输出下一 token）间决策。用反事实策略蒸馏训练：把每个动作分支一步、打分其对输出 token 的影响。

关键数字 1.4B 模型在六个通用与长上下文推理基准上相对最强基线提升 2.8% 与 10.0%，运行速度比最强长上下文基线快 5.9 倍。

为什么值得看 统一记忆与推理的潜动作框架，反事实训练信号让策略学会何时记忆优于继续推理。
