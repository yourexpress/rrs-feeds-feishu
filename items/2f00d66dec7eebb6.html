RoadBlock: Rethinking GPU Tensor Core Microarchitecture for Emerging Microscaling Format Support

arXiv cs.AR · 2026-11-04 · 论文PDF / 每日精选

研究问题：自定义 Microscaling（MX）格式的硬件评估局限于独立 MAC 单元原型，忽略真实 GPU Tensor Core 内的系统级集成开销——如何在流片前端到端评估？

方法：RoadBlock，基于 RISC-V Vortex GPGPU 的开源框架，在可编程 Tensor Core 中精确建模自定义 MX 格式；数据大小、scale-factor 大小与 block 大小均为可配置参数，自动为任意格式推导 per-thread 元数据 tiling。

关键数字：原文为框架与方法描述，未给出量化性能数字。

为什么值得看：可在投入硅片前评估格式特定的 Perplexity-PPA 权衡，芯片/硬件评估团队直接可用。
