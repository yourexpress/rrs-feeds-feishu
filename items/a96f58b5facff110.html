Symbolic Basic Block Profiling for Machine Learning Kernels

arXiv（Jingyu Qiu 等，cs.PL） · 2026-08-20 · 论文PDF

研究问题：动态插桩的基本块计数既有运行时开销，又必须实际执行程序——大输入规模下耗时可观。

方法：符号化 profiling：为基本块执行计数生成以输入为自变量的符号公式，无需运行程序；适用面限于 ML kernel 一类程序。技术在 LLVM 中实现，评测 TVM 生成的算子。

关键数字：来自 50 个 ML 模型的 78 个算子中，73 个的符号 profile 与动态插桩结果完全一致，中位加速 15093×。

为什么值得看：把 profiling 从「跑一遍程序」变成「求一个公式」，对 ML 编译器与 kernel 开发是量级级的提速。
