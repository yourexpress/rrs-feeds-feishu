ECO: Energy-Oriented Configuration Optimization for Attention FFN Disaggregated LLM Serving

arXiv cs.AR · 2026-10-08 · 论文PDF / 每日精选

研究问题： Attention-FFN 分离（AFD）的 LLM 服务要省能，需在「部署结构约束运行控制」的层级配置空间里联合搜索，而物理评估昂贵、只能测少量候选。

方法： ECO 从校准的阶段行为与流水线依赖构建结构感知能量先验，用高斯过程学习残差预测误差；成本感知的约束贝叶斯优化按预期节能排测量优先级，兼顾 SLO 可行性、执行成功率与评估成本，返回测过的最低能耗可行配置。

关键数字： A6000/A100 共 16 个场景（Qwen/DeepSeek），在不相交请求上评估的冻结配置平均降服务能耗 40.5%、输出 token 率升 20.7% 且满足 SLO；A6000 场景可行能耗比通用约束 BO 低 33.1%、比遗传搜索低 25.8%。

为什么值得看： LLM 推理能耗优化是真金白银的成本问题，AFD 场景的系统性配置搜索很少见。
