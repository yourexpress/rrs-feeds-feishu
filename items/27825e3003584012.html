Build more responsive apps with the Decisions API

OpenAI · 2026-10-22 · 官方公告 / 每日精选

核心话题 OpenAI 正式发布 Decisions API（基于 GPT-6 Luna），面向受限答案的结构化决策场景。

要点 应用与 agent 在流程中频繁做小决策（分类、路由、下一步动作），其延迟与成本会随规模累积。API 让开发者定义问题与允许答案，返回概率/选择/评分三种答案类型；自公测以来新增原生 GPT-Live 语音集成、上下文 prompt caching、美欧推理驻留，支持原生 JSON 输入与图片指令。

关键数字 从文本/图片/结构化输入做近实时决策，比 Responses API 上 GPT-6 Luna 快至 10x；定价 $0.10/M 输入 token（缓存输入 $0.01/M）；每请求最多 400 个问题，为之前上限的两倍。

为什么值得看 直击 agent 高频小决策的延迟/成本痛点，语音交互（GPT-Live）与批量分类场景尤其值得关注。
