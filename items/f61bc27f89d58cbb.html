Retargetable Compilation for Tensor Kernels via a Unified Layout Abstraction

arXiv cs.PL · 2026-11-10 · 论文PDF / 每日精选

研究问题：现代硬件加速器靠专用指令 + 紧管内存层次达到高性能，指令对操作数强加严格布局要求（张量片段位置、组织、并行单元访问方式）——但现有编译器要么把布局要求散落在手工程序与局部调度规则里，要么只支持单一目标类。如何跨后端统一建模指令布局？

方法：Arknife 可重定向编译器，把指令可见布局作为一等指令语义。核心是约束式布局代数：张量布局把逻辑轴映射到跨并行层级与内存空间的硬件轴；指令操作数声明布局要求，目标提供的修复解决冲突；布局跨程序全局求解。ISA 特定布局事实由目标侧指令描述提供而非硬编码进编译器，重定向复用布局代数与求解器、只定义新目标指令。

关键数字：x86 CPU、Hexagon NPU 与 NVIDIA A100 GPU 三目标评估：A100 上匹配 cuBLAS；x86 与 Hexagon 上比厂商优化库快 2.17× 与 3.78×，比可重定向编译器 MISAAL 快 5.08× 与 4.53×。

为什么值得看：把指令布局从"隐式约定"提为一等语义的约束代数，一次抽象跨三类硬件，重定向成本大幅下降。
