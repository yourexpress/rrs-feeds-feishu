Challenges of building machine learning compilers across varying hardware architecture

Microsoft DirectX Developer Blog · 2026-11-13 · 技术博客 / 每日精选

核心话题：构建跨硬件架构 ML 编译器的挑战——如何同时做到可扩展与高性能。

要点：现有方案（IHV 专有框架、torch.compile、MLIR/Glow/EON 等）各有侧重，但很少独立于硬件厂商与框架同时高性能；图→kernel 映射直观但难以跨演进硬件扩展；MMA 等核心算子需要多级 IR 渐进 lowering，叠加设备无关/设备感知优化、融合/分解、调度与内存管理；兼顾模块化与设备特化的代码生成是主要难点。
