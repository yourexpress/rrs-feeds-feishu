SGA-Sparse: Training Native SwiGLU Gates for Activation-Sparse and Low-Bit LLMs

arXiv cs.LG · 2026-11-08 · 论文PDF / 每日精选

研究问题 激活稀疏可降低单用户 LLM 解码的 FFN 权重搬运，但活跃通道必须足够早被识别以免取来无用权重；预训练 SwiGLU 模型中免训练路由在高稀疏度下远差于用 up 激活路由。

方法 提出 SGA-Sparse：把预训练 SwiGLU LLM 的现有 gate 投影直接训练为 top-k 路由器，端到端更新全部参数、保留原 SwiGLU 激活、不引入辅助路由器参数，把模型转成固定预算激活稀疏模型。

关键数字 约 30B 训练 token 后，1B–8B LLaMA 达成每 token 75–85% FFN 通道稀疏，平均零样本准确率距原密集 checkpoint 仅 0.2–2.7pp；按统一权重搬运口径，2.5-bit 等效模型追平密集 3-bit QAT 准确率，1.5-bit 等效模型优于密集三元模型 1.3pp。

为什么值得看 原生 gate 训练让「高 FFN 稀疏 + 低位权重」同时成立，并给出与低比特量化的统一比较口径。
