AscendGYM: A Cost-Aware Kernel Optimization Benchmark for Real-World Workloads on Ascend NPUs

arXiv cs.DC · 2026-11-13 · 论文PDF / 每日精选

研究问题：Ascend NPU 上 kernel 优化缺少面向真实负载的评测基准——现有基准侧重 kernel 生成，很少评估 agent 在真实输入配置下优化既有实现的能力。

方法：AscendGYM 基准，初始 48 个 kernel 分三档难度；每个 kernel 配的测试用例数据类型与张量形状取自真实训练/推理任务，性能提升可直接映射到对应负载；支持模型评估与 model-harness 评估两种模式，内置 harness 带搜索编排与经验积累；提出新指标 Speedup-Token Score (STS)，联合考虑加速比与 token 成本。

关键数字：48 个 kernel、三档难度、真实负载形状；STS 衡量预算内实际 kernel 优化能力；代码开源在 github.com/SLAI-AITP/AscendGYM。

为什么值得看：昇腾生态首个面向 agent 的真实负载 kernel 优化基准，做 kernel 自动调优的人值得关注。
