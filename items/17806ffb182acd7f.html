Optimal Hydra: Model Heterogeneous Federated Learning for LLMs using Data-Informed Hydra-Nets

arXiv · 2026-10-14 · 论文PDF

研究问题 LLM 联邦微调受客户端资源限制，模型异构 FL 此前只用于预训练，且子网络选择未利用客户端本地数据分布。

方法 Optimal Hydra：面向 LLM 微调的 transformer 异构联邦学习框架，将全局层选择与客户端特定注意力头选择结合、对齐本地数据分布，显式利用客户端数据生成 Hydra-nets 子网络。依据是注意力头在层定义特征空间内具有任务依赖性。

关键数字 三个数据集上显著优于基线方法，同时降低本地资源需求；据称是首个面向 LLM 微调的模型异构 FL 方法。

为什么值得看 数据驱动的子网络定制是异构联邦训练的关键缺口，对端侧/算力不均场景的 LLM 微调有直接价值。
