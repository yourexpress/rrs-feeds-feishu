When Can Prefixes Compile LoRA? Exact Resource-Capped Tests for Frozen Attention

arXiv / Joyanta Jyoti Mondal 等 · 2026-09-30 · 论文PDF

研究问题 固定连续前缀能否在注意力头冻结时替代给定低秩适配器？答案取决于适配器目标，论文给出精确的资源约束测试。

方法 三个条件刻画可编译性：可观测性（内容经 query/注意力划分/值分子进入读数，相等摘要输入存在误差下界）、可实现性（公共 query 下前缀退化为两个聚合变量，范数受限最优为二阶锥规划）、实现（仿射 query 暴露下 2r 个有符号槽近似 rank-r 值更新）。

关键数字 槽值增长为 O(ε^-3/2)；400 次容差检查 float64 全过而 bfloat16 仅 38 过；GPT-2 三个头下受限最优留下 18.4%-74.2% 的投影适配器效应未编译。

为什么值得看 严格界定"前缀能否替代 LoRA"的边界，对上下文压缩与注意力编辑研究有理论价值。
