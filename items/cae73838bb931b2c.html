D2K-Bench: Can LLM Agents Turn Expert Designs into Efficient GPU Kernels?

arXiv (cs.LG) · 2026-10-05 · 论文PDF / 每日精选

研究问题 LLM 智能体生成的 GPU kernel 常不及专家实现，但只看运行时间无法分辨差距来自设计发现还是实现落地。

方法 D2K-Bench 诊断基准：26 个任务、85 种负载，测智能体把专家设计指导转化为高效 kernel 的能力。指导分三层——L1 高层算法洞见、L2 数据流设计、L3 底层优化技巧；有/无指导的配对运行共享任务描述、负载、工具、硬件与 350 轮预算。

关键数字 B200 上五个模型、130 组模型-任务配对：指导使正确率从 93.1% 升至 98.5%，26 任务总性能分从 1.46 升至 1.95；三个全程正确的前沿模型几何均值加速从 1.69× 升至 2.49×。

为什么值得看 定量回答"专家设计知识能被 LLM 消化到什么程度"，并指出仍难落地的设计属性。
