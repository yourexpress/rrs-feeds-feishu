Event-Driven ML Pipeline Orchestration for Manufacturing: An AWS Industry Experience

arXiv cs.LG · 2026-10-08 · 论文PDF

研究问题 汽车制造中跨工厂持续训练产品专用的"物理预测模型 + 强化学习控制策略"模型对，需要编排由制造事件触发的长时 GPU 工作负载，成本与可靠性如何兼顾？

方法 三年产业经验报告：事件驱动云架构，Amazon ECS + EC2 GPU 容量提供者、SQS 消息 + 死信队列、带准入控制的 Lambda 调度器强制集群并发上限，ECS Fargate 上的 Conductor 编排器按周触发依赖感知重训链，全部用模块化 Terraform 多账户 codify。

关键数字 40000+ 生产训练任务，相比常驻 GPU 基础设施成本降低 72–78%；离散事件仿真表明准入控制必不可少（朴素调度丢失 65% 任务），队列排空延迟与 Step Functions 持平且省掉逐任务启动开销。仿真器与 Terraform 模块骨架已开源。

为什么值得看 难得的 ML 训练基础设施长周期实战复盘，事件驱动 + 准入控制的设计取舍与成本数字对工程团队很实在。
