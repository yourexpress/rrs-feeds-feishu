MX-Like Tensor Core for LLM Inference with NPU Integration via Hardware-Software Co-Design Exploration

arXiv/cs.AR · 2026-10-19 · 论文PDF / 每日精选

研究问题 OCP Microscaling（MX）、NVFP4 等块缩放量化格式已广泛用于 LLM 推理，但由共享 scale、权重与激活格式组合张成的设计空间从未被系统探索，该空间上的联合精度—硅面积权衡也未被刻画，NPU 端侧 LLM 部署真正位于 Pareto 前沿的配置仍是未知数。

方法 做软硬件协同设计探索，三点创新：① 定义并系统刻画 MX-like 设计空间下完整的 8-bit scale 格式族，并与非对称权重-激活精度联合分析，找出优于 MX 与 NVFP4 类（无 per-tensor scaling，PTS）基线的配置；② 构建逐格式专用 MAC 数据通路模板，实现跨空间的公平硬件成本评估；③ 开发自动化协同设计流程并集成进开源 SNAX NPU 平台。

关键数字 结论是 scale 格式只在激进的 FP4 量化下才要紧；UE5M3 在 FP4 区间是精度-硬件的优选，相对 NVFP4 类基线把困惑度退化最多降低 25.3%，代价仅为面积 +0.06%、功耗 +0.49%。

为什么值得看 一张"什么场景该选什么 scale 格式"的判据，对正在做端侧 LLM 加速器的人比再一篇 survey 更有用。
