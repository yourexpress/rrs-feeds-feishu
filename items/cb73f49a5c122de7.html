SPIN: Shadow Predictive Indexer for Sparse Attention

arXiv cs.LG · 2026-10-09 · 论文PDF / 每日精选

研究问题 基于 indexer 的稀疏注意力只把少量重要 token 送进核心注意力，但 indexer 每个解码步仍要给整个 KV cache 打分，上下文变长后打分本身成为主要瓶颈。

方法 SPIN（Shadow Predictive Indexer）：用轻量的历史预测识别重要 KV block，避免每个解码步全量打分；并把 KV block 与投机解码作为一等设计考量融入实现。

关键数字 长上下文与 agentic 基准上实现 30–40% 稀疏度且保持任务质量；vLLM 端到端服务中输出吞吐最高 +14.9%，中位 token 间延迟最多降 13.2%。

为什么值得看 瞄准"稀疏注意力的 indexer 自身开销"这个被忽视的二级瓶颈，系统收益经过端到端实测。
