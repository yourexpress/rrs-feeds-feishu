LoopKV: Loop-Aware KV Cache Compression for Serving Looped Transformers

arXiv (cs.LG) · 2026-11-03 · 论文PDF / 每日精选

研究问题 循环（looped）Transformer 每 token 多次应用共享块，如 Ouro 每 loop 保留独立 KV cache，cache 内存限制批量大小；统一比特量化与固定规则无法按各层在各 loop 的敏感度分配精度。

方法 提出 LoopKV：一次性离线 profile 为每个 (loop, layer) 单元选择 4-bit 存储、2-bit 存储或复用最终 loop 的 KV；规划器在预测损伤与存储预算下最小化读取。解码时每个 loop 读 4-bit 值的高 2 位，仅在其注意力权重需要 4-bit 精度处取回低 2 位；vLLM 中单一融合内核执行该计划。

关键数字 单张 RTX PRO 6000 服务 Ouro-1.4B：内存优化版 LoopKV-M 比统一 4-bit 量化（KIVI-4）在同一融合内核与 CUDA graph 上少存 35% KV；16K token 上限、延迟 SLO 下 goodput 达 KIVI-4 的 1.7-2.2x；六个公开基准平均均未显著低于 BF16。

为什么值得看 把 KV 压缩从"全局统一"推进到"逐 loop 逐层定制"，直面循环模型特有的精度-内存权衡，并已集成 vLLM。
