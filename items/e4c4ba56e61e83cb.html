TideKV: Delayed KV Eviction via Layer-Wise Chunked Prefill for Memory-Efficient Long-Context LLM Inference

arXiv/cs.LG · 2026-10-17 · 论文PDF / 每日精选

研究问题 长上下文 LLM 推理长期受制于 prompt prefill 期间的峰值显存。现有 KV 压缩能降解码显存，但通常要求完整 prefill 以保留全局上下文，构建期峰值依然高；在线分块驱逐虽更早降显存，却在每层尚未看全 prompt 时就做选择，可能损害缓存构建与解码。

方法 提出 GPU 内的缓存构建架构 TideKV，采用分层主序的延迟驱逐：在每个 Transformer 层内处理完所有 prompt 分块，只为当前活跃层保留完整 prompt 的 KV，并在层末统一驱逐。

关键数字 多平台上保持所评压缩方法的推理质量与最终缓存大小不变；A100 上 64K 上下文把构建期瞬时占用降低 83.89%；RTX 4090 上 64K 的首 token 时间仅增加 1.06%，并使 128K prefill 可行；TideKV 在 Jetson 上完成 128K，而同等条件的后 prefill 压缩在两个资源受限平台均 OOM。

为什么值得看 "把驱逐推迟到层末"用极小的调度改动换来近 84% 的构建期显存下降，是可以立刻借鉴的工程手法。
