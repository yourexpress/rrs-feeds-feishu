EvoTreeNAD: Genealogy-Guided Evolution for LLM-Driven Neural Architecture Discovery

arXiv · Lishan Yu 等 · 2026-09-24 · 论文PDF

研究问题 LLM agent 驱动的科学发现靠迭代生成与评估，但迭代本身不保证累积进展、昂贵评估又限制探索范围——无种子架构、无手工搜索空间下，如何自主构建可训练架构并保证方向收敛？

方法 EvoTreeNAD 谱系引导进化算法：从空根生长持久谱系（每个新节点=一个完整架构），用节点及其后代计算的 top 百分位值引导谱系选择；Idea Agent 基于选定设计史提变体、Code Agent 实现；每个评估过的变体成为子节点，为后续谱系选择提供证据。

关键数字 CIFAR-10/100 测试错误 2.05±0.06% / 15.09±0.22%，超越对比 NAS/NAD 基线；六个 MedMNIST-v2 任务全部超过所列最强基线；受控 CIFAR-10 实验优于直接生成、best-of-N 贪心延续与全家族均值路由。

为什么值得看 用"谱系+top 百分位"把累积证据制度化，为无先验神经架构发现给出可扩展的进化范式。
