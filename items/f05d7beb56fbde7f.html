An Empirical Cost Attribution of Context-Compression Gateways in Multi-Turn Coding Agents

arXiv (cs.PF) · 2026-09-22 · 论文PDF

研究问题 上下文压缩在基准上"保质量"，是否等于在真实多轮 coding agent 中省钱？两者并不等价，需要逐杠杆成本归因。

方法 在生产级压缩网关 Paritok 上（介于 Claude Code、Codex 与 Claude Sonnet、GPT-5 之间）做受控 A/B，把 token 账单分解为三个独立杠杆：工具 schema 过滤、文件读取与工具输出的内容压缩、历史摘要，分别单独度量。

关键数字 工具 schema 过滤每轮省固定 21K–57K tokens；内容压缩每轮仅省约 2% 缓存计价前缀，但按约 3350·N² tokens 二次累积，约 6 轮内反超前者；Paritok-4B 以 25.7% 压缩率保留 86.5% SWE-bench 质量（论文摘要自述）。

为什么值得看 首个指出"单发压缩基准不能当省钱论据"的多轮成本实测，归因框架可直接用于 agent 成本工程。
