Mira: Memory-Efficient MoE Inference Using Adaptive Caching and Predictive Expert Staging

arXiv / Sanjali Yadav 等 · 2026-09-30 · 论文PDF / 每日精选

研究问题 MoE 很适合部署到资源受限的单 GPU 系统，但专家参数占内存大头、token 级路由动态且倾斜；现有 offload/缓存方案要等 router 输出才搬专家，属被动响应，缓存利用率低且传输难以与计算重叠。

方法 Mira 做算法-系统协同设计：轻量逐层预测器提前两层预测专家用量以主动预取；HOT+STAGE 两级 GPU 缓存按 token 级路由遥测保留高频专家、暂存预测专家；定制专家参数压缩格式减少元数据并提升打包效率；完整运行时统一调度预测器、缓存策略与量化传输以最大化通信-计算重叠。

关键数字 内存受限 GPU 上平均吞吐较 SOTA 基线提升 5.71×，TTFT 加速 11.71×，beam search 推理平均加速 3.84×，精度损失很小。

为什么值得看 "提前两层预测专家"把单卡 MoE 推理从被动换入变为主动 staging，预测器+缓存+压缩一套打通，工程完整度高。
