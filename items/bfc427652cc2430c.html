AlignPred: Error-Controlled KV Cache Compression via Alignment and Predictive Coding

arXiv · 2026-10-14 · 论文PDF

研究问题：长时运行 agent 的 KV 缓存跨轮次/会话保留数小时至数天，压缩持久缓存需在可控重建误差下减少存储。 方法：AlignPred 编解码器：局部正交变换把相关 head/层对齐到公共坐标帧，结合 token 间预测与跨 head/层同 token 预测；残差在误差有界格上量化并熵编码，无需学习型预测器、编码端模式搜索或大型联合变换。 关键数字：三种注意力机制下，同重建误差所需存储少于所测基线；对比 CPU 编解码实现解码快至少 1.6×；LongBench-Pro 128K 上下文近原生任务分数；SGLang HiCache 集成使持久目标 KV 存储减少 42–72%。 为什么值得看：面向"持久 KV 缓存"场景的误差可控压缩，长会话 agent 推理的实用组件。 AlignPred: Error-Controlled KV Cache Compression via Alignment and Predictive Coding
