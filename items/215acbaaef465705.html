ZeroGate: Trust-Preserving Fast Paths for Governed AI Agent Runtimes

arXiv (cs.AI) · 2026-09-23 · 论文PDF

研究问题 把授权决策提前可以缩短 agent 的派发边界，但可能放行载荷/权威/相关状态已变化的动作；能否在不牺牲信任的前提下为治理型 agent 运行时做一条"快路径"？

方法 ZeroGate 把"精确动作审批"与"持久本地准入"分离：签发者签署短时 ActionPass，可信运行时适配器在本地门检查绑定、消费 nonce 前重建最终动作；SQLite 事务把 nonce 消费、配额更新与准入回执耦合；并给出条件性决策保持命题——在审批健全、策略依赖齐备且当前、观察忠实、消费原子四条件下，本地准入通过蕴含同步策略也会授权同一动作。

关键数字 4800 次云尝试中，prepared 模式 worker 从准入到派发的 p95 为 9.802~11.374ms，同步模式为 25.018~334.000ms；但 prepared 模式完整生命周期均值在每个并发水平都更长（摘要明示该边界改进并非净加速）。

为什么值得看 诚实标注"不是净加速"的取舍分析很少见，对治理型 agent 平台的授权架构取舍是难得的审计级参考。
