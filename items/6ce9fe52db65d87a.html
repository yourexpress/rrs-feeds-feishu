Speed Up Image Generation with FLUX 3 Image Klein on NVIDIA Blackwell GPUs

NVIDIA Technical Blog · 2026-11-06 · 技术博客 / 每日精选

核心话题：扩散模型图像生成的推理延迟是设计工具/编辑器的部署瓶颈，如何在 Blackwell 上加速 FLUX 3 Image Klein。

要点：TensorRT LLM VisualGen 运行时组合优化：FlashInfer PrimsTS FP8/NVFP4 GEMM kernel、epilogue 融合、低精度与稀疏注意力、缓存、多 GPU 并行；支持 BFL 预量化 NVFP4 checkpoint；2048×2048 单 B200 基准，附部署说明与 YAML 配置。

关键数字：NVFP4 相比 BF16 的 T2I 提速 1.62×、I2I 1.58×；组合优化后 Base 模型 T2I 最高 3.46×、I2I 4.45×（对比未编译 BF16）；Base 为 50 步去噪 + CFG 3.5，distilled 版 16 步无 CFG。

为什么值得看：官方发布的端到端加速配置可直接复现，Blackwell 上图像生成部署的实用参考。
