llama.cpp b11879 CUDA: fuse FFN gate/up matmuls and GLU in MMQ with interleaved gate/up rows (#29948)

llama.cpp（GitHub Releases） · 2026-10-25 · 技术博客 / 每日精选

核心话题 CUDA 后端能否把稠密 FFN 的 gate/up 两个矩阵乘与 GLU 融合成一次 launch。

要点 面向 prompt 处理，把 gate 与 up 的 matmul 合并为单次 mul_mat_q 启动，GLU 改在写回阶段由寄存器计算并只写一半行；loader 以 gate 权重为第二指针，按 8 行一组把 up 与 gate 交错填入权重 tile，使每线程同时持有 up 值与匹配的 gate 值（MMA tile 的 r 与 r+8 行）；MMA 主循环的 tile、warp 布局、vec_dot 与每线程一个 sum[] 保持不变，融合路径使用常规 tiling（不含 stream-k）并让列 tile 最内层以使相邻 block 共享权重 tile。

关键数字 启用范围为 Q4_K、Q5_K、Q6_K、Q8_0、IQ4_XS，硬件限定 NVIDIA Turing 及更新架构；同一批提交还处理了融合 MMQ 参数断言、hint 检查迁移到 should_fuse、prec_src1 传递与"仅在高效 tiling 且无 fallback 时才融合"的收敛条件。

为什么值得看 这是把 FFN 前向中一次 kernel 启动与一次权重读取省掉的实打实优化，量化到 4-bit 之后 FFN 访存正是吞吐瓶颈所在。
