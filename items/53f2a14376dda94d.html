Inside the Codex sandbox

OpenAI · 2026-11-18 · 官方公告 / 每日精选

核心话题：OpenAI Codex 沙箱的设计与实现——如何在用户现有环境中以文件系统与网络限制约束 agent 命令，而非把计算搬进独立容器。

要点：以权限配置文件定义限制，默认 :workspace 配置（工作区内可写、.git/.codex 只读、广泛读取、禁用网络）；macOS 用 Seatbelt/sandbox-exec、Linux 用 bubblewrap + seccomp-bpf、Windows 迁移到微软 MXC，三平台共享同一沙箱 API；codex-network-proxy 按域规则放行请求，未匹配域可转人工或自动审查；codex sandbox 命令可把沙箱能力复用到自建工具。

关键数字：:workspace 默认禁用网络；域规则支持精确名与通配符、deny 优先于 allow；每子进程继承父进程沙箱约束，覆盖整个进程树。

为什么值得看：防御纵深式 agent 沙箱的工程细节与平台落地差异，对自建 agent 工具链直接可复用。
