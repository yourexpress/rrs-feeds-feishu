Projects redesigned: from folder to conversation

Anthropic · 2026-09-17 · 技术博客

核心话题: Claude Projects 体验重做——从「文件夹」变为「会话式项目」，在 Claude Code 中开启 beta。

要点: 用户只描述目标（如降低结账链路 p75 延迟、下线废弃 v1 端点），Claude 负责拆解、委派、协调并行线程、审查产出并汇总结果；每个线程是独立分支与仓库副本上的 Claude Code 云会话，会开 PR、跑测试；可在主会话或单线程内督导，手机端也可操作，人离开后继续工作。

关键数字: 2026 年 9 月 17 日上线，首阶段仅对使用 Claude Code 云会话、且无既有网页/桌面项目的部分 Pro/Max 订阅者开放，之后逐步扩大。

为什么值得看: Anthropic 把「多智能体编排」产品化为项目管理界面的代表案例，值得关注其协调器设计。
