PQ-HSA: Reusing Product-Quantized Scores for Hybrid Sparse-Approximate Attention

arXiv (cs.LG) · 2026-09-27 · 论文PDF

研究问题： 长上下文解码中 attention 受内存带宽限制，稀疏注意力只读一小部分 key 并把未读 token 权重置零，输出只来自 KV 缓存一小部分，小预算下精度下降、聚合类任务尤甚。如何保留被跳过 token 的信息？ 方法： 在缓存 key 上建倒排文件乘积量化（IVF-PQ）索引，排序后这些近似分数即未选中 token 的注意力 logits。PQ-HSA 对选中 token 用原始 key/value 做注意力，未选中的背景 token 经逐倒排表求和、乘以该表均值后进入同一 softmax。 关键数字： 128K 上下文、1-2% 检索预算下精度优于 Quest 与 SnapKV；8B 模型宏观准确率从 0.71 提到 0.83；H20 上解码 attention 比 FlashAttention-3 快 1.6 倍。 为什么值得看： 把"被丢弃 token"重新纳入 softmax，兼得稀疏注意力的速度与接近全注意力的精度。 原文链接：PQ-HSA: Reusing Product-Quantized Scores for Hybrid Sparse-Approximate Attention
