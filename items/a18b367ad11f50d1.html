ANOR: Scaling Sparse Attention with a GPU-PNM Computing Hierarchy

arXiv · 2026-11-23 · 论文PDF / 每日精选

研究问题 长上下文 LLM 服务须保留每请求完整 KV 缓存，可能超 GPU 显存；CXL-PNM 设备可持全缓存就地算注意力，但现有 GPU-PNM 系统 PNM 为中心，CXL-PNM 带宽远低于 GPU HBM，使 PNM 成瓶颈、GPU 空等。

方法 ANOR 是 GPU-PNM 联合加速系统：利用稀疏注意力的选择局部性，GPU 从近期选择条目缓存算大部分注意力，PNM 只处理 miss；有界缓存更新策略在命中率饱和点停止更新以减链路流量；片上 Early Streaming Buffer 捕获 KV 数据流给 GPU；自适应缓存因子随负载调 GPU 缓存大小。

关键数字 两模型三长上下文 agentic 负载下，解码吞吐较 HiSparse 平均 2.3x、较 PNM 基线平均 2.0x。

为什么值得看 把 PNM 定位为 GPU 内存层级的计算层而非主引擎，纠正 PNM-centric 设计偏差。
