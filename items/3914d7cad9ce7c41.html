Proving LLM-Generated GPU Kernels Correct and Safe: Floating-Point Verification in Lean and VerCors

arXiv/cs.PL · 2026-10-17 · 论文PDF / 每日精选

研究问题 现代模型开发从 PyTorch/JAX/TensorFlow 的高层规格出发，再由编译器降级或工程师手写实现；前沿语言模型能否胜任后者——即从高层基准规格正确生成 GPU kernel——此前并不清楚。

方法 提出一个框架：模型 agent 调用 Velvet（嵌入 Lean 的命令式程序验证器），在一组显式假设下证明高层规格与生成 CUDA kernel 的语义等价；同时要求 LLM 在 VerCors（并行代码演绎验证器）中证明生成 kernel 的线程安全与无数据竞争。

关键数字 摘要未给量化数字；主要贡献是证明"Lean 自动化 + 语言模型引导的证明构造"可验证一大类基础神经网络构件在浮点域上的语义，且浮点验证从不依赖编译代码、始终由 Lean 内核检查。

为什么值得看 把"生成的 kernel 对不对、安不安全"从跑测试抬升到形式化保证，是 LLM 代码生成走向可信的关键一步。
