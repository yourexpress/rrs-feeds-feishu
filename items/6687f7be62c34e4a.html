How OpenAI's Performance Factory keeps ChatGPT fast

OpenAI · 2026-11-19 · 官方公告 / 每日精选

核心话题 agentic 开发节奏让传统性能工程不可持续，OpenAI 用 Codex 构建 Performance Factory 自动化"发现+修复"性能回归。

要点 工程师定义工作流并写 Codex agent 指令；Regression Workflow 在性能告警时开任务，agent 调查慢因、记录发现、提修复供工程师审查，部署后另一 agent 验证是否恢复基线；配套 perf-forensics 技能固化排查流程。

关键数字 三个多月跟踪超 1,700 次调查、根因定位超 600 例——平均每天约 17 次自动化调查。

为什么值得看 OpenAI 把性能工程 agent 化的第一手实践，工作流设计与教训对其他服务团队可复制。
