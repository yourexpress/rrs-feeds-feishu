PipeLink: Contract-Guided Linking of GPU Kernel Components

arXiv(cs.DC) · 2026-10-27 · 论文PDF / 每日精选

研究问题 最快的 ML kernel 是 loader、GEMM 主循环、epilogue、通信阶段等组件的组合，但组件硬编码其在共享 SM 空间中的位置，无法独立编译、分发或替换，跨来源组合只能手工 fork。

方法 PipeLink 契约引导链接器：每个组件独立编译为携带资源契约（需求+承诺）的 LTO 对象；PipeLink 检查契约互容、联合求解 SM 资源的一次性放置、生成组件间传输，vendor LTO 后端将结果折为常量。

关键数字 Hopper/Blackwell 上 51 组配置链接后的 kernel 与整体编译差距在 0.2% 以内；CuTe attention 算子嵌入 ThunderKittens decode megakernel 使解码提速 2.16×；GEMM+SwiGLU 组合在 Blackwell 上比 cuBLAS 快 1.2×。

为什么值得看 让 kernel 组件像软件一样可组合替换而不损失性能，对 kernel 库与推理系统开发者非常实用。
