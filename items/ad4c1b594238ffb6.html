Making Local AI Smarter and Faster

Code Guilds · 2026-09-22 · 技术博客

核心话题 JetBrains 的 Junie local 项目推出 Qwen3.8-3.6-27B-blend 模型，把 Qwen3.6（轻快）与 Qwen3.8（强推理）的权重按 1:1 合并。

要点 27B 参数混合模型无需额外 post-training 或微调；针对本地编码 agent 在「推理深度 vs 延迟」的取舍痛点；项目同时改进了多 token 预测（MTP）的 GPU 开销敏感问题。

关键数字 100 任务内编基准：blend 完成 37、Qwen3.6 完成 34、Qwen3.8 完成 39；blend 输出 token 数比 Qwen3.8 少 71%；30 个共同完成的任务中 blend 用 27.9 万 token vs Qwen3.8 的 93.5 万。

为什么值得看 「权重按比例混合」是低成本的本地编码模型优化路径；71% 的 token 节约对端侧推理效率意义很大。
