SyntheticHLS: Building Diverse Synthetic High-Level Synthesis Datasets using LLMs

arXiv (cs.AR) · 2026-10-02 · 论文PDF / 每日精选

研究问题 LLM 驱动的芯片设计需要训练数据，但 HLS（高层次综合）方向的数据集稀缺，现有工作多靠人工整理或参数化生成，缺少高质量 LLM 生成与多维多样性（代码长度、层次、设计空间、延迟、资源、应用领域）。

方法 SyntheticHLS 用 LLM 生成大规模合成 HLS 数据集：① 迭代反馈引导的变异循环，以成对的 HLS 源码与设计空间规格为输入，逐步把种子设计变异得更复杂、可扩展；② HLS 设计复杂度与设计空间可扩展性的量化指标，作为 LLM 变异的可测目标。

关键数字 交叉验证显示：合成设计训练的 QoR 深度学习模型迁移到常见基准测试集表现良好，反向则不成立；迭代变异得到的设计是最具泛化性的训练语料；指标引导的变异持续提升目标复杂度/可扩展性且不退化非目标指标。框架、数据与评测均已开源。

为什么值得看 "指标引导 LLM 变异"的数据合成范式可迁移到其他 EDA/系统领域的数据稀缺问题。
