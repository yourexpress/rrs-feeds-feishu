Zero-SM NCCL: A Systematic Guide to Designing and Deploying SM-Free GPU Communication

arXiv cs.DC · 2026-11-13 · 论文PDF / 每日精选

研究问题：NCCL 等 GPU 通信库用 SM 做数据搬运与同步，拖慢重叠计算且代价随互连带宽增长，能否完全不占 SM 完成通信？

方法：Zero-SM NCCL——不启动任何 SM kernel 完成 scale-up 域内外的通信：用 CUDA stream 内存操作同步、copy engine 在域内异步搬数、流序 CPU proxy 驱动网络 RDMA；支持 AllGather/AlltoAll 等数据搬运集合以及单边 ncclPutSignal/ncclWaitSignal API。

关键数字：GB200 NVL72 与 B200 NVL8 上 AllGather 带宽最高比 NCCL 传统 SM kernel 高 1.36×，重叠 GEMM 的中位减速从 33% 降到 4%（每操作延迟更高）；Megatron-LM 训练中 FSDP 加速最多 3.5%、单边 put 加速流水并行最多 15%；但小消息与 host 受限负载反而吃亏。

为什么值得看：SM-free 通信的系统指南、含明确适用边界，NVL72 时代训练栈值得一读。
