GeoMesh: Workload-Balanced and Sign-Compressed Geo-Distributed LLM Training

arXiv（Changyong Shin 等，cs.DC） · 2026-09-16 · 论文PDF

研究问题 跨地域分布式训练 LLM 面临现实困境：各区域 GPU 速度与显存不一、广域网带宽低。分析显示同步方法中快 GPU 最多 20.9% 的运行时间在等慢节点，所有 worker 平均 65.8% 的运行时间耗在同步上；异步方法减少等待却因过期更新损害精度。

方法 GeoMesh 是面向异构 GPU 的同步跨地域训练框架：按各 GPU 能力分配合适的批大小与内步数做负载均衡，让快卡做更多有效功而非空等；通信侧交换压缩的符号化伪梯度（附轻量幅值与 token 计数），通信量降近 32 倍。

关键数字 在异构 GPU 与 Azure 衍生的 WAN 上：达到目标困惑度的时间较代表性基线最多缩短 70.2%；落后者与 WAN 导致的 GPU 空闲分别最多降 8.0 倍与 5.6 倍；零样本精度与基线相当。

为什么值得看 负载均衡 + 符号压缩双管齐下，为「用地理分散的异构算力训大模型」提供了精度无损的同步方案。
