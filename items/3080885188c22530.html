Lachesis: Lifetime-Aware KV Cache Placement for Agent Serving across HBM and High-Bandwidth Flash

arXiv cs.AR · 2026-10-08 · 论文PDF / 每日精选

研究问题： Agent 及子 Agent 跨大量请求累积 KV cache、吞掉大量内存；高带宽闪存（HBF）容量高一个数量级且读带宽达 HBM 级，但写入寿命有限。

方法： 洞察是按生命周期放置：短命数据进 HBM，让 HBM 吸收 agent 运行的大部分写入、少写 HBF；分析 agent harness 行为，识别时间、结构、worker 间三个生命周期分化轴；Lachesis 作为 harness 与推理引擎间的放置层，写时按寿命选 HBM/HBF，段不再被读即释放。

关键数字： trace 驱动仿真中 HBF 寿命比 HBM-first 放置延长 1.19–3.13x（达 3.3–12.2 设备年）；在紧 SLO 允许的满载 24x7 运行下，多 agent trace 上 HBF 寿命超过其五年保修。

为什么值得看： agent serving 时代的新存储分层问题，HBF 写寿命的量化解法，问题定义新鲜。
