NORmal: Architecting 3D Ferroelectric NOR Flash as Main Memory -- From Co-Fabricated BEOL Arrays to 200B-Class Multi-Agent LLMs in a Smartphone

arXiv(cs.AR) · 2026-10-29 · 论文PDF / 每日精选

研究问题 智能手机上的 agent 团队（大 planner 指挥并行 worker 长会话）需要 200B 级模型和远超手机 DRAM 的上下文；现有方案把 flash 当存储：UFS 饿死按 token 权重流式，移动 HBF 需重设计 SoC 且无法吸收持续 KV 写。

方法 NORmal：首个面向 3D 铁电 NOR flash 的主存架构。共制造并实测 BEOL 3D FeNOR 阵列（密集 3-bit MLC + 快速高耐久 SLC，传感低于 7.5ns），经阵列下 DRAM 仿真桥接入未修改的 LPDDR6 总线成为字节可寻址 load/store rank；按可变性与寿命而非热度放置 agent 状态，动态跨 agent 阶段划分子通道。

关键数字 生产 agent trace 服务级仿真中，较 UFS 卸载快 8.9–28.0×，距无限 DRAM 理想仅差 0.4%；256K token 以上会话较 HBF 快 2.8–6.3×，每 token 内存能耗低 8.1–17.8×。

为什么值得看 用铁电 NOR 做主存支撑手机端 200B 级多 agent LLM，硬件实测+仿真数字惊艳，端侧大模型方向值得关注。
