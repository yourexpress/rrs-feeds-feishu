A Measurement Study of LLM Inference Trade-offs Across Edge Continuum Hardware

arXiv（Maysam Khatib 等，cs.DC） · 2026-09-08 · 论文PDF

研究问题 LLM 越来越多作为智能 Web 服务后端，但跨边缘连续体部署时要平衡质量、延迟、模型体积与能耗，缺乏受控的实测依据。

方法 在 Jetson AGX Orin 与近边缘服务器（CPU-only 与 GPU 两种模式）上对多款开源 LLM 及其量化变体做固定 QA 负载的受控测量，GPT-4o 作云端精度与延迟参照；报告精度、模型体积、逐 token 解码延迟、prefill 延迟与整体执行能耗，并做 Pareto 前沿分析。

关键数字 GPU 服务器计算侧延迟最低，Jetson Orin 实测能耗最低，CPU-only 全面垫底；参数量与权重文件大小均不能可靠预测实测精度或延迟；计入流式分发开销后，仅看算力侧指标会导致次优部署。

为什么值得看 边缘 LLM 选型的实测数据集，"算力侧指标好 ≠ 部署决策对"的提醒对端侧落地很实在。
