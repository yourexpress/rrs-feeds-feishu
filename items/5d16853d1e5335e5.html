CMM-MP: A Novel Memory Pooling Architecture using Purpose-built Memory Device with CXL and Ethernet

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题：内存密集型工作负载需要百 TB 级 GPU/CPU 可寻址内存池，但纯 CXL fabric 受成本/规模限制，纯 RDMA 又延迟偏高；能否把两者结合做成专用内存池化器件？

方法：CMM-MP 把 CXL 与以太网融合为单一内存池化器件，把发现、组合、后端网络数据通路全部 offload 到器件侧，对上层暴露为一台逻辑大内存设备，同时支持 pooling 与 sharing 两种用法。

关键数字：单器件延迟 2.7 μs、吞吐最高 23 GB/s；在 Valkey+YCSB、DiskANN 等真实负载上延迟与吞吐均显著优于 RDMA 方案。

为什么值得看：CXL 内存池化的硬件/系统协同工程落地范例，做大内存池化与可组合内存基础设施的可参考样本。
