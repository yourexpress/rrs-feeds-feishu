From standards to software: Microsoft's ongoing work on OpenAPI and developer tooling

Microsoft · 2026-10-01 · 技术博客

核心话题 微软发布 OpenAPI 与 JSON Schema 相关的标准与开发者工具链更新，规格正从"后台管道"变成开发者体验基础设施。

要点 OpenAPI 3.2.0 新增 HTTP QUERY 支持、设备流安全支持与流式数据描述；JSON Schema 2020-12 引入 $dynamicRef/Anchor 解决递归 schema 的脆 $ref 链；案例：Microsoft Foundry 用 TypeSpec 转换工具导入 OpenAI 的 OpenAPI 描述，统一生成 SDK、API 参考、服务端代码并做契约测试；作者强调 LLM 概率性输出下，详细规格能提升生成代码的可靠性。

关键数字 未给出具体量化指标（原文以特性说明为主）。
