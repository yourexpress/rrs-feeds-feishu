Intelligent transcription with Gemini 3.5 Transcribe

Google DeepMind · 2026-08-18 · 技术博客

核心话题：Google 发布 Gemini 3.5 Transcribe 语音转写模型，主打"智能转写"——把原始音频直接变成干净、排好版的文本。

要点：双 API——Live API 实时流式（亚秒延迟）与 Interactions API 录音转写（带说话人归属和词级时间戳）；自动处理自我更正、去口头禅、自动排版；支持 function calling、自定义词汇、85+ 语言自动检测、最多 3 个说话人识别。

关键数字：Artificial Analysis 测得平均 WER 流式 4.0%、非流式 2.6%；FLEURS 基准流式 5.50%、非流式 5.04%，均优于 Chirp 3；最终转写延迟改善 70%。

为什么值得看：转写从"听写"升级为"理解意图+清理+调度任务"，做语音 agent、会议纪要、实时字幕的开发者可直接接入。
