REAL Loss: Optimizing Real Expected Acceptance Length for Speculative Decoding

arXiv cs.LG · 2026-11-10 · 论文PDF / 每日精选

研究问题：投机解码加速由期望接受长度（EAL）决定，但标准训练目标（交叉熵、KL、TV）只做分布匹配，近期的 block-level 目标也只是 EAL 的代理而非精确形式——有的在目标分布续写上平均后期接受率而非被接受 token 选择的验证分支，引入可反转梯度方向的协方差 gap。能否直接优化真实 EAL？

方法：推导 REAL loss——用路径权重做无偏估计、Rao-Blackwellization 降方差，端到端优化真实期望接受长度。受控 loss 级对比：Qwen3.6-35B-A3B 目标 + Domino drafter。

关键数字：REAL 在 9 个任务子集、5 个评估种子上的概率服务接受长度全面胜过 WTV、VSD、DBLast 与静态 LK 基线；仅改训练 loss，drafter 架构与推理过程零改动。参考实现已在 GitHub 开源。

为什么值得看：把投机解码训练目标从"代理"精确化为"真实 EAL"，只换 loss 即可提升，落地成本极低。
