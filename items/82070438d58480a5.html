DeepSeek v4 Flash Vision Exp is Released as Open Weights（讨论帖）

NVIDIA Developer Forums · 2026-09-19 · 技术博客

核心话题：NVIDIA 开发者论坛上的讨论帖：DeepSeek v4 Flash Vision Exp 以开放权重发布后，社区用户交流自建推理服务的部署经验。

要点：帖中用户分享自维护推理分支的实测参数：未做任何缓存优化的情况下，3.5M 的 KV cache 仍留有可观内存余量，估计可上调到 4–6M 区间；其运行框架每 200k token 压缩一次上下文、预留 16k 输出，总上下文预算约 2.4M；同时更新了长 prefill 阈值参数，并回合了两个默认关闭的 tool call 修复（来自 vLLM 主干）。

关键数字：KV cache 3.5M 时，主节点内存余量 116/121 GB、工作节点 115/121 GB；上下文压缩策略为每 200k 压缩、16k 输出预留、总预算约 2.4M。

为什么值得看：开放权重视觉大模型在大显存 GPU 上自部署的一手参数经验，自己跑 vLLM 类服务、规划 KV cache 与上下文预算的人可作参考。
