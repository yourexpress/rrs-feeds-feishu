Airbnb expands access to GPT-6 Astra

OpenAI · 2026-09-23 · 官方公告

核心话题： Airbnb 与 OpenAI 达成新协议，为工程和产品团队扩大 GPT-6 Astra 等前沿模型的访问权限。

要点： 此举建立在 Airbnb 此前使用 Codex 的基础上。GPT-6 Astra 的应用已超越编码：帮助追踪复杂 bug、设计系统架构、头脑风暴工程方案。Airbnb 内部测试中，用 Astra 完成策略文档等非编码任务仅需 3–4 轮迭代，而其他模型需 20+ 轮。同时用于搜索、欺诈检测、客服和保险理赔等场景。

关键数字： 非编码任务中迭代轮次从 20+ 降至 3–4；协议覆盖 OpenAI API 和 Amazon Bedrock 双通道。

为什么值得看： GPT-6 Astra 在企业级落地的大客户案例——从编码工具升级为全栈工程赋能平台，迭代效率提升近一个数量级。
