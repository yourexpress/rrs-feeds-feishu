What Should Federated LoRA Share? FedSAIL via Input-aware Subspace Alignment

arXiv (cs.LG) · 2026-09-26 · 论文PDF

研究问题 联邦 LoRA 需识别跨异构客户端共享的更新结构；已有研究报告训练后的 LoRA 投影矩阵跨客户端强相似，但这种一致性可能由共同初始化诱导、独立初始化下坍缩为随机重叠——且只靠参数相似性会忽略局部输入分布的影响。

方法 引入输入感知 action 矩阵：用局部层输入的二阶矩统计加权适配器更新；实证发现参数相似性消失时，该矩阵的主导右奇异方向仍跨客户端强对齐，且保留任务条件差异、随网络深度自然变化；据此提出 FedSAIL——估计共享 action 子空间正则化局部训练，同时保留客户端特定系数。

关键数字 多个基准上一致优于竞争联邦 LoRA 方法，并显著降低通信成本——摘要未给具体数值。

为什么值得看 从"参数相似"转向"输入感知几何对齐"，为联邦 LoRA 的共享结构提供了更稳健的基础。
