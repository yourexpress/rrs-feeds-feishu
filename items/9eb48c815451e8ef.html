AlignQuant: Tile-Aligned Mixed-Precision Quantization for Efficient LLM Generation

arXiv cs.LG · 2026-10-08 · 论文PDF / 每日精选

研究问题： 细粒度混合精度量化的局部精度选择与 GPU 规整的存储/计算单元冲突，压缩难以转化为实际加速。

方法： AlignQuant 后训练量化：以 GPU 兼容的二维权重 tile 作为精度分配、紧凑存储与执行的共同单元；prefill/decode 联合校准，用 LM loss 梯度加权的投影输出扰动为 tile 评分；每个 tile 只存一种选定表示，相位特化 kernel 复用打包模型、把低比特权重展开为 INT8 与 8 位激活计算。

关键数字： 3B–14B 四个 LLM 上生成加速最高 2.50x（相对 BF16）并保持质量；评测覆盖 3 种 GPU、上下文至 64K tokens。

为什么值得看： 直击「混合精度好看但不提速」的落地痛点，实现已开源。
