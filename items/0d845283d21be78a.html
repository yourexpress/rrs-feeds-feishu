Bridging the Vendor Gap: Enabling AMD GPU Support for Awkward Array via ROCm/HIP for the HL-LHC Era

arXiv (cs.DC) · 2026-09-22 · 论文PDF

研究问题 Scikit-HEP 分析栈（尤其 Awkward Array）是 CUDA-first 的，而 El Capitan、Frontier、LUMI 等超算均为 AMD 加速器，面向 HL-LHC 如何在多厂商 GPU 上保住分析吞吐？

方法 rawkward：Rust 支持的核引擎，为 Awkward Array 的嵌套、变长数据结构增加 ROCm/HIP 后端；总结一小组可复用优化模式（循环扁平化、128 位向量化加载、拆分融合核、profile 引导的启动配置），Rust 宏分发层保持单一后端无关调用点。

关键数字 朴素 CUDA→HIP 移植在不规则核上损失 5–10 倍性能；优化后在双路 MI210 节点上相对 128 核 EPYC 7763 加速 1.03–12.5 倍；Rust CPU 核相对现有 C++ 核几何平均运行时比 0.37 倍（论文摘要自述）。

为什么值得看 GPU 跨厂商性能可移植的实战配方，wavefront 与 warp 的差异分析及优化模式对一般 HPC 核开发同样适用。
