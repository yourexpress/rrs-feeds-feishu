More Powerful Constant Value Checking with SMT Solving

arXiv cs.PL · 2026-10-06 · 论文PDF

研究问题： Checker Framework 的 Constant Value Checker 靠有限语法类型规则，常无法验证复杂代码的类型良好性。 方法： 引入 SMT 求解扩展：把语法规则检查失败的表达式转为一阶逻辑公式，用可满足性判定其良好性；并新增可依赖其他变量表达式的依赖类型。 关键数字： 面向 Java 的 pluggable type system，基于 Checker Framework 实现。 为什么值得看： 把形式验证工具（SMT）嵌入实用 Java 类型检查器，提升常量取值约束的验证能力，静态分析方向值得一读。
