Formally verifying agent-written full-stack web apps with PDD Kit

Microsoft · 2026-11-05 · 技术博客 / 每日精选

核心话题 AI 编码 agent 单次可生成数万至数十万行代码，逐行人工 review 无法扩展；而测试只验证 agent 写出的东西、不验证你要求的东西，如何保证代码符合用户意图成为工程痛点。

要点 微软研究推出 PDD Kit：把用户意图转成 Verus 形式化规格，用证明器验证 agent 代码对所有输入满足规格，证明无法覆盖处回退到测试；已在 GitHub Next 的 Chopin 中验证 Pet Store（Rust 店面前端）登录逻辑，Verus 还顺带发现了既有 bug，开发者只需审意图、不必逐行读生成代码。

关键数字 文中未给出评测量化指标；描述 agent 单次可产出数万至数十万行代码的规模背景。

为什么值得看 把形式化验证从专家小众场景拉到日常软件开发，直接回应"agent 写代码后如何可靠 review"这一核心问题。
