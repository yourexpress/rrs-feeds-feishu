The enterprise guide to securing coding agents

Anthropic · 2026-11-23 · 技术博客 / 每日精选

核心话题 Anthropic 发布企业规模化部署编码智能体（Claude Code）的安全指南。

要点 指南分「界定风险」与「约束风险」两部分：前两章给出评估编码智能体的六个问题（含 SSO/RBAC、数据条款、审计日志等 SaaS 级要求），并列出四大 agent 特有风险——凭据泄露与权限滥用、未审计依赖与扩展、数据外渗、提示注入；后三章讲 Claude Code 可部署的分层防御与集中管控（检查权限、有界环境）。

关键数字 面向 Claude Team/Enterprise 计划；指南未给出统一量化指标，以风险清单与防御框架为主。

为什么值得看 编码智能体已从写代码走向审阅、测试、合并 PR，安全负责人可直接套用其选型问题与防御层清单。
