Embedding Graph Kernel Entropy (EGKE): Fine-grained Hallucination Detection for LLMs from Embeddings

arXiv · 2026-10-14 · 论文PDF

研究问题：基于语义熵（SE）/核语言熵（KLE）的幻觉检测依赖单独加载的 NLI 分类器估计语义相似度，计算开销显著。

方法：EGKE 是 KLE 的变体：用 BGE embedding 上的 RBF 核对稠密句向量直接算相似度，替换 NLI 派生的语义图；保留 KLE 的 graph Laplacian、heat kernel 与 von Neumann 熵公式不变，在连续嵌入空间做对称且计算高效的比较。

关键数字：30 个实验设置（多问答数据集+开源 LLM 家族），AUROC 与 AUARC 上达到与 SOTA 方法竞争的幻觉检测性能。

为什么值得看：去掉 NLI 分类器依赖的轻量幻觉检测，部署成本更低。
