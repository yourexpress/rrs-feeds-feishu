- Chrome DevTools MCP 1.13.0 — logpoints and network mocks for coding agents

Chrome DevTools MCP 1.13.0 lets AI coding agents set logpoints in a live page and mock its network requests. The mocks can block a request, serve a local file or fetch from another URL. The release also ships a long list of fixes.

- deepseek-v3-jax — DeepSeek V3 in 190 lines of pure JAX

deepseek-v3-jax is an MIT-licensed, 190-line JAX version of the DeepSeek V3 architecture. The 36.2M-parameter model trained in about 2.6 hours on a MacBook Air M5. The author calls it an architecture demo, not a strong language model.

- Plannotator — review your coding agent's plans and diffs in a browser

Plannotator is an open-source local review tool for coding agents. You annotate an agent's plan, diff or HTML output in the browser and send the feedback back. Version 0.28.64 shipped on 13 November as the repo trends on GitHub.

- WSJ: Nvidia backed buyers' loans — so they could keep buying its GPUs

The Wall Street Journal reports that Nvidia backed AI cloud firms and data-center builders with credit support so they could keep buying its chips. Interim CEO Colette Kress pushed to limit these deals before Jensen Huang left. Nvidia has not confirmed.
