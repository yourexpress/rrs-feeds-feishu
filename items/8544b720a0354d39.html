Clean: Second-order LLM Training at Linear Memory Cost via Nyström Sketching

arXiv cs.LG · 2026-10-06 · 论文PDF / 每日精选

研究问题 LLM 训练存在显存-曲率权衡：Adam 类省显存但丢掉跨参数曲率信息；SOAP 类全曲率方法收敛快但显存代价随模型维度二次增长，难以承受。

方法 Clean 用随机 Nyström 方法近似 SOAP 的左右预条件子，把优化器显存复杂度从二次降到线性；再把低秩子空间外的分量重新积分，保住低秩近似之外的曲率信息。另有低精度变体 Q-Clean 激进压缩优化器状态。

关键数字 LLaMA-1.3B 预训练上 Q-Clean 比 Muon 省 50%+ 优化器显存且性能有竞争力；Clean 优化器状态占用比 AdamW 还小，同时达到 AdamW 最终性能的墙钟时间快 26%；并首次让 13B 模型在单张 80GB GPU 上完成预训练。

为什么值得看 把二阶优化的显存门槛打到一个 80GB 卡可及的范围，对算力受限团队是实打实的可选项。
