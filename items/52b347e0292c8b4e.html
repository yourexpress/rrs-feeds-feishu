Operator-Valued Q-Learning: Compositional Bellman Recursions for Order-Sensitive Decision Making

arXiv · 2026-11-23 · 论文PDF

In quantum pulse sequences, spacecraft attitude control and in-hand reorientation, actions act on a hidden physical state as non-commuting operators, so the outcome of a plan depends on the order of its actions. We let the value function carry this structure: each Q(s,a) is an N x N operator, and the Bellman backup applies the action's dual map to the continuation value, Q(s,a) = K_a^*(R(s,a) + gamma E V(s')). Unrolled along a plan, the recursion builds the ordered product of the actions' operators, and the value at any latent state is a linear trace readout. It is exact for policies that do not observe the latent, the backup contracts for unitary and orthogonal dynamics, and an asynchronous operator TD scheme learns it with almost-sure convergence. Classical values live in a lattice, so a maximum over actions exists; self-adjoint operators form an anti-lattice (Kadison) and have none. An operator log-sum-exp still gives one operator per state-action pair whose readout upper-bounds the value of every policy at every latent state.
