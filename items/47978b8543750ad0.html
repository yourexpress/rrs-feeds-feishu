Minions: A Dynamic and Distributed Virtual GPU Cloud Built on Idle Apple Silicon Devices

arXiv · 2026-10-09 · 论文PDF / 每日精选

研究问题：集中式 GPU 资源贵、弹性差、排队久，而现代 Apple Silicon Mac 的 GPU 在日常使用中大量闲置——能否聚成一台「虚拟 GPU 云」跑大规模推理？ 方法：Minions 是聚合 macOS 设备闲置 Apple Silicon GPU 的动态分布式虚拟 GPU 云，提供灵活的推理任务执行、容错与资源利用率管理，让团队不新增采购就用上现有硬件。 关键数字：文中以系统构建与经验验证为主（推理、故障注入等多负载评估），未给出统一汇总的加速/吞吐数字。 为什么值得看：对小团队是「把办公桌上的 Mac 变成推理集群」的低成本路线；对大厂也是峰时弹性算力的备用池思路。
