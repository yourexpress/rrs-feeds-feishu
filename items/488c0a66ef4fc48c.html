Rust's Type Checker Implementation Is Unsound: An Empirical Study on Soundness Bugs in rustc

arXiv（Yusung Sim 等，cs.SE） · 2026-08-28 · 论文PDF

研究问题：Rust 号称类型安全，但官方编译器 rustc 确实存在「本应拒绝却被接受」的健全性 bug——它们长什么样、如何被发现、现有工具能抓住多少？

方法：实证研究 2022-01 至 2025-09 期间 GitHub issue 中 30 个疑似健全性 bug，逐案分析受影响特性、症状、后果、触发条件与生命周期；并评估 AddressSanitizer、Miri、Chalk、a-mir-formality 及官方文档作为测试谕示的潜力。

关键数字：30 个案例；implied bounds 与 trait object 触发的 bug 可危及内存安全；多数 bug 自特性引入起潜伏很久才被发现；Chalk 与 a-mir-formality 尚不成熟；现有文档常无法精确描述语义。

为什么值得看：对「Rust 保证内存安全」给出冷静的边界画像，对语言工具链与形式化验证从业者都很有参考价值。
