Trading Depth for Time in Recurrent Transformers

arXiv（cs.LG） · 2026-09-18 · 论文PDF

研究问题：循环 Transformer 靠时间循环增加计算深度——把每个 token 的高层隐状态喂给下一个的计算；额外计算花在更多时间步上，还是花在更深的物理层数上更划算？

方法：用 Latent Recurrent Transformer（LRT）做受控对比：在相邻词表 token 之间插入隐式"思考 token"，与词表 token 同样穿过 L 层、共享骨干参数，在预测下一个 token 前多一轮隐状态精炼；把它与不带思考 token 的 2L 层 LRT 对比——两者解码时每个词表 token 都执行 2L 个 Transformer 块，但思考 token 版参数更少。

关键数字：在 16 层与 20 层的混合专家 NanoChat 骨干上，单个思考 token 让浅模型与双倍深度模型的差距缩小到 0.006 与 0.004 bits per byte 以内，用约少 48% 的总参数恢复了 67% 与 81% 的提升。

为什么值得看：为"时间思考"替代物理深度提供了干净的量化证据，是参数效率视角下循环架构设计的有趣数据点。
