Beyond the Boundary: Optimal Grid Dispersion by Spread, Reverse, and Collect

arXiv · 2026-10-14 · 论文PDF

研究问题：网格图上的确定性 dispersion——k≤n 个 agent 从任意初始配置（同点或任意分布）分散到不同节点，本地通信模型能否匹配 Ω(√k) 时间下界（k=o(n) 时此前的开放问题）。

方法：Spread-Reverse-Collect（SRC）算法基于几何原语——S 形并行扫描 + 简单优先级规则；与旧算法"先聚到边界再散开"不同，每次扫描从 agent 当前位置出发，碰到边界就反向折回继续，无需知道网格大小、在无限定向网格上原样运行。

关键数字：任意 k≤n 在 O(√k) 同步轮内完成分散，每 agent 用 O(log k) 位持久内存，同时匹配时间与内存下界。

为什么值得看：解决本地通信模型下的开放复杂度问题，几何构造简洁优雅。
