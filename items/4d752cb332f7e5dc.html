ESL-former: Event Sparse Linear Transformer for FPGA-Accelerated Malware Detection

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题 基于 Transformer 的恶意软件检测有潜力，但自注意力的计算与内存成本使其难以部署到资源受限的边缘 FPGA。

方法 提出事件稀疏线性 Transformer（ESL-former）：不构造显式注意力矩阵，直接从 Linear Transformer 累积的键值状态推导 token 与通道重要性；贡献感知打分函数度量各 token/通道对线性注意力状态的扰动，剪掉冗余；硬件上用 Top-K 活跃 token 缓冲与压缩单元替代二值掩码执行，将活跃 token/通道重组为稠密定长数据流，让处理单元执行规则乘累加。

关键数字 摘要未给出具体量化指标，结论为在保持恶意软件分类精度的同时降低硬件成本。

为什么值得看 把 Transformer 安全检测落到功耗敏感的边缘 FPGA，线性注意力 + 稀疏化 + 硬件重组的协同设计值得借鉴。
