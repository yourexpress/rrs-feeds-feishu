LiquidCP: Decoupling Attention Tasks from Communication and Kernel Boundaries in Context Parallelism

arXiv (cs.DC) · 2026-11-03 · 论文PDF / 每日精选

研究问题 上下文并行（CP）把长序列切分到多 GPU 做训练/推理：变长训练与全 prefill 下注意力均衡放置会致 token 负载不均，ring 执行在每个计算/通信步重复开销；stage 串行 decode CP（DCP）中长任务阻塞依赖工作、GPU 空闲。

方法 提出 LiquidCP，用统一的 Transfer/Compute/Reduction 任务模型（带 tile 级依赖）解耦注意力任务与通信、内核边界。训练与全 prefill 用 MegaRing：BuddyRing 放置均衡注意力与 token 负载，前向注意力中合并就绪 KV 区域摊薄开销；decode 与混合批次用 MegaDCP：联合建模注意力及其依赖归约的完成来选 history-KV 切分。共享持久 GPU 常驻引擎执行两种设计。

关键数字 8x H100 上相对各配置最快基线：MegaRing 核心注意力几何平均提速前向 1.23x、反向 1.18x，Transformer 层加速 1.08-1.16x；MegaDCP decode-only 1.20x、混合批次 1.35x；vLLM + KV prefix cache 下平均 TTFT 提速 1.22x。

为什么值得看 统一了训练与推理的 CP 执行模型，把注意力从通信与内核边界中解放出来，是序列并行执行的最新系统化方案。
