TAP: Efficient Long-Horizon Agent Pruning via Trajectory-Anchored Recovery

arXiv cs.LG · 2026-10-09 · 论文PDF / 每日精选

研究问题 长程 agent 任务需反复调用模型，推理成本高昂；为问答设计的既有剪枝方法直接套用到 agent 上会严重掉点，问题出在"剪什么"和"怎么恢复"。

方法 提出首个面向 RL 训练 agent 的结构剪枝框架 TAP：交互锚定教师轨迹、学生逐段生成响应，冻结教师监督学生前缀；并用恢复目标的梯度在已恢复学生上迭代重打分通道，替代一次性剪枝。

关键数字 剪去 60% FFN 通道后，7B agent 在 ALFWorld 与 WebShop 上分别保留 99.2% 与 88.0% 的任务成功率，单任务 GPU 时间约降 22% 与 17%。

为什么值得看 证明长程 agent 可在有限恢复预算下做激进结构压缩，直接降低 agentic 推理账单。
