uGDS: A User-Space Development Kit for High-Performance GPU Direct Storage

arXiv · 2026-10-22 · 论文PDF / 每日精选

研究问题 GPU Direct Storage（GDS）三大局限：控制路径每次 I/O 都过内核、流有序路径强加全序、闭源用户态引擎难诊断难定制。

方法 uGDS 开源用户态 GPU Direct Storage 库：宿主机 CPU 在用户态管理整个 NVMe 命令生命周期，payload 走 PCIe P2P DMA 不占用 GPU 计算；统一跨厂商抽象（CUDA/AMD HIP）、负载感知调度、端到端透明；最小内核模块仅用于一次性特权设置。

关键数字 A100 + Samsung 990 PRO 上批量读带宽最高 12.12× GDS、批量写 30.69×；4KiB 同步写延迟降 84.1%；单流 5.49 GiB/s（GDS 仅保留 40.8%）；LMCache 中 TTFT 中位降 62.7%、goodput 提升 2.63×。

为什么值得看 开源 + 用户态 + 跨厂商，数据密集型 GPU 应用的实用加速层，已用于 LMCache。
