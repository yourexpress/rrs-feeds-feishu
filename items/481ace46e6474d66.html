Hybrid Parallel Bessel KAN Model: a Kolmogorov Arnold Network: integrated framework for developing a novel architecture to reconstruct the fused-basis approach via a parameter free quadratic interaction

arXiv · 2026-10-14 · 论文PDF

研究问题： KAN 网络扩展到空间数据时默认 B-Spline 基有局限，混合多基函数的单片叠加会引发几何重叠、参数爆炸与数值病态（κ(G)≈10¹⁶）。

方法： Parallel BesselKAN 把 B-Spline 与低阶 Bessel 分支隔离为并行处理流水线，用无参数二次交互集成，充当高效的内部集成、绕开单片稳定性瓶颈。

关键数字： 参数足迹压缩 35%，MNIST 准确率 97.99%；纯视觉任务上标准 MLP 仍有硬件速度优势。

为什么值得看： 为混合基 KAN 的稳定缩放提供可行路径，指向 Convolutional KAN 等空间扩展。
