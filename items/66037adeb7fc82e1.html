Tenon: A Unified Programming Framework for Retargetable PIM Compilation

arXiv · 2026-11-19 · 论文PDF / 每日精选

研究问题：各类 PIM 器件编程栈碎片化（指令序列到类 C 语言不一），且紧耦合的计算-存储使数据布局成为一等优化目标，现有 PIM 编译器缺乏统一表示。

方法：Tenon 把 PIM 编译目标建模为计算/存储单元嵌套网格加合法数据传输路径；将 GPU 编译器的 F2 线性布局代数推广到 PIM，按负载与目标规格自动构造最小移动数据布局。

关键数字：6 个 PIM 后端（5 个商用 + AttAcc），商用后端匹配或超越厂商/专家/编译器基线，几何平均提速最高 1.20×、单项最高 3.65×；GPT-13B 解码在 AttAcc 上比 SOTA PIM 编译器 DCC 快 1.2–1.3%。

为什么值得看：负载一次表达、跨 PIM 目标族可移植编译，性能可移植性好。
