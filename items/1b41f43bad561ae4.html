Kwai Summary Attention V2 Technical Report

arXiv · 2026-10-14 · 论文PDF

研究问题： 混合 KSA-Full 架构中摘要 token 带来两个瓶颈：各层摘要压缩块大小必须一致、难以灵活压缩 KV cache；full attention 层忽略摘要 token 仍付出二次预填充计算成本。

方法： KSA V2 让摘要 token 承担双重角色——既是 KV 内存又是稀疏索引器，从而在不损失精度的前提下实现更灵活的 KV cache 压缩并降低 full attention 层计算开销。

关键数字： 实现更灵活的 KV 缓存内存压缩，同时减少 full attention 层计算成本。

为什么值得看： 快手摘要注意力架构的第二代技术报告，指向长上下文推理效率优化。
