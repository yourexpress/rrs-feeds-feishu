DSLHyPE-a DSL kernel language for the Exascale Hyperbolic PDE Engine ExaHyPE

arXiv（Timothy J. R. Stokes 等，cs.MS） · 2026-08-18 · 论文PDF

研究问题：超算 PDE 求解器中，物理项（C/C++）与数值格式如何解耦，让研究者只改数值方法、不动物理实现？

方法：双语 DSL——物理项用原生 C/C++ 表达，数值格式用 Python 嵌入式 DSLHyPE 描述；编译器把 Python 描述降到 MLIR，并经翻译 pass 与同样映射到 MLIR 的原生代码集成，优化交给既有 MLIR pass；数值表示与物理实现尽可能久地保持分离。

关键数字：在引力波求解器与物质演化求解器上演示可行，覆盖 x86 CPU 与 H200 GPU（摘要未给性能数字）。

为什么值得看：ExaHyPE 这类百亿亿次级引擎的开发体验改造，科学计算 DSL 与 MLIR 结合的参考案例。
