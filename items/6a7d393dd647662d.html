Accelerating CPU Speculative Decoding via Unified Graph Execution and Transactional KV Isolation

arXiv · 2026-10-17 · 论文PDF / 每日精选

研究问题 推测解码在 CPU 上部署面临严重系统瓶颈：draft 与 target 图之间的上下文切换延迟，以及 KV cache 回滚时的内存分配开销。

方法 SubTernary 执行框架：统一图缓存 + 事务化 KV 隔离。两模型编译进单一内存 arena、配持久线程池，投机 token 走静态 scratchpad 实现零拷贝指针复位，彻底规避动态重分配与线程同步；并集成 256-bit AVX2 三元 SIMD 内核作为低位案例。

关键数字 消融显示系统运行时贡献 35.0% 吞吐增益，三元内核额外贡献 6.0%；相对 llama.cpp 推测解码 1.35x、相对自回归解码 3.99x 加速，回滚延迟保持 O(1)。

为什么值得看 CPU 端 LLM 推理优化稀缺，消除上下文切换与回滚开销的系统设计对端侧/无 GPU 部署很有借鉴。
