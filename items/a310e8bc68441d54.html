HAWK: Heterogeneity-Aware KV Cache Transfer for Efficient GPU-NPU Phase-Disaggregated LLM Inference

arXiv · 2026-10-21 · 论文PDF / 每日精选

研究问题 GPU 适合 prefill、NPU 更适合 decode，异构 GPU-NPU 分离式推理需要把 KV cache 从 GPU 传到 NPU，但设备间通信机制与张量布局不同，传输困难。

方法 HAWK 传输机制：建立 RDMA 直传路径处理跨设备传输，在 NPU 侧分配张量布局感知的 RDMA 缓冲区以匹配目标张量布局，把数据从 GPU 常规连续 RDMA 缓冲区编排传输到对应 NPU 缓冲区，传输后可直接消费、无需额外重排。

关键数字 商用 GPU+NPU 系统上，同 SLO 约束下性能达 GPU-only 系统的 7.88% 以内，功耗效率最高 1.26x、成本效率最高 1.72x。

为什么值得看 GPU-NPU 混合部署是推理降本趋势，跨异构设备的 KV 传输优化对落地有直接价值。
