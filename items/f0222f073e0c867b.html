mKernel: Fast Multi-GPU, Multi-Node Fused Kernels

arXiv（Ziming Mao 等，cs.DC） · 2026-09-11 · 论文PDF

研究问题 大模型分布式训练与推理中通信成为瓶颈；tile 级融合 kernel 性能好，但现有融合大多局限于单 NVLink 域，跨节点无解。

方法 mKernel 把持久 kernel 的 SM 划分为计算与通信角色，片上控制器运行时自适应调比例；分层组织数据移动以最小化跨节点流量；通过 RDMA verbs 上的轻量命令队列与 host 代理从 GPU 驱动网络，同一 kernel 可跑 InfiniBand 与 AWS EFA；并发现 IBGDA 相对 host 辅助的 GPU 发起通信收益甚微。

关键数字 实现张量、序列、专家并行共 5 个 kernel；两个 16-GPU H200 集群上 GEMM+AllReduce 最高 1.72x、Ring Attention 最高 1.88x。

为什么值得看 把 tile 级计算-通信融合扩展到多节点，对网络选型还有反直觉的实证结论。
