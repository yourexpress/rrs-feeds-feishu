A Fast, Programmable GPU-to-CPU Invocation Layer for GPU-Initiated Communication

arXiv · 2026-11-18 · 论文PDF / 每日精选

研究问题 GPU 设备发起通信的主流做法（GPUDirect Async）把传输控制放 GPU 线程，反向 offload 到 host 代理线程被视为慢速回退路径。

方法 KIWI 论证反向 offload 可超越 GDA、应成为一等通信路径，并把它暴露为可编程接口，让用户定义负载特定的通信操作；KIWI-P2P（SHMEM 类库）与 KIWI-EP（MoE 分发/合并内核重构）基于它构建。

关键数字 亚微秒级单程 device-to-host 延迟、每秒数亿次操作；AMD GPU 上专家并行通信延迟最多降 2.3×，vLLM 每 token 输出时间最多降 29%。

为什么值得看 扭转"反向 offload 是次选"的既有认知，可编程接口对 MoE 等负载友好，源码已开源。
