Measuring GPU Memory Traffic on the NVIDIA GB10 Without C2C Telemetry

arXiv · 2026-11-23 · 论文PDF / 每日精选

研究问题：GB10（DGX Spark 等）的 GPU 无本地内存，L2 miss 都经 NVLink C2C 访问 CPU die 侧 LPDDR5X，但软件不暴露该流量计数器，如何实测？

方法：用 GPU 的 5 个 L2 sector 计数器，经 CUPTI 采样接口每 10ms 采样（进程不附加到工作负载），实测 GPU 内存流量并分离 copy engine 流量与 GPU kernel 读 miss/写；方法以开源工具发布。

关键数字：大流式传输与已知尺寸对比：Acer GN100 内一致 0.28%、DGX Spark 0.005%；跟踪搬运总量、排除 L2 复用数据；SMMU 计数器数的是地址翻译而非字节；实测 Mistral 7B 解码每 token 读 13.47 GiB（权重+KV 缓存），为 NVIDIA 标称带宽的 83%。

为什么值得看：无专用遥测硬件的系统上测量 GPU 内存流量的实用开源方法。
