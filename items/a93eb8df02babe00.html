Start and Restore GPU Workloads in Seconds with NVIDIA Snapshot

NVIDIA Technical Blog · 2026-11-10 · 技术博客 / 每日精选

核心话题 NVIDIA 开源 Snapshot：面向 Kubernetes 的 GPU 负载 checkpoint/restore 系统，把已初始化的推理负载（含 CPU 与 GPU 内存）固化为工件，秒级恢复而非分钟级冷启动。

要点 提供 Checkpoint 与 Restore 两种操作，恢复时跳过权重加载、编译与图捕获；支持跨 rank 的多 GPU MoE 模型（TP/DEP/DCP 并行）；vLLM、SGLang、TensorRT-LLM 均有现成示例。

关键数字 全部测试配置下副本 45 秒内恢复，比冷启动快 8×~36×；Crusoe 把 GLM-5.3 就绪时间从约 8 分钟降到 31 秒；Saturn Cloud 把 vLLM 启动从 2~8.5 分钟降到 6~34 秒（HGX B300）。

为什么值得看 AI factory 弹性扩缩容与故障恢复的关键基础设施，数字具体可量化。
