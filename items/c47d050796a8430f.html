PLoQ: A Prompt-Specific Low-Rank Basis for 4-bit Quantization of LLM Activations

arXiv · 2026-11-20 · 论文PDF / 每日精选

研究问题：低比特激活量化难在少数主导方向决定量化范围；SOTA 方法离线校准后把变换折进权重、对所有 prompt 固定同一子空间，每个 prompt 的独特方向不受保护。

方法：PLoQ prompt 自适应低秩分解：量化前提取主导激活分量、单独量化、在层内 GEMM 中恢复且不改权重；低秩基在 prefill 时从每个 prompt 估计、解码全程复用。

关键数字：同 bit 宽（激活平均约 4.2 bit）下在 1B~70B 六个 Llama/Qwen 模型上全部胜过 SOTA 混合精度量化，最高恢复 SOTA 仍损失的困惑度的 46%；Llama-3.1-8B 8k token 仅增 4% prefill、8% 解码开销。

为什么值得看：激活量化的 prompt 自适应路线，模型规模覆盖全。
