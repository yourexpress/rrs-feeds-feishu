VestigeKV: The NoPE-MLA KV Cache Carries Its Own Sparse-Attention Signal in a Vestigial Branch

arXiv（WenJie Fan，cs.LG） · 2026-09-03 · 论文PDF

研究问题 长寿命 KV cache 必须在未来的 query 存在之前就压缩好——而按已观测注意力选 token 在此失效：NoPE-MLA 模型上 H2O 与 SnapKV 在 8 倍压缩下 needle 检索只剩 0.00 与 0.33，因为 token 的重要性尚未被观测到。

方法 VestigeKV 利用 cache 自带的信号：NoPE-MLA 的 64 维解耦分支是 RoPE 的"遗迹"，训练将其 repurposing 成显著性通道；只读每行 11% 即可把 cache 划分为受关注层与 GPU 驻留归档层，行永不离开，每步由经认证的 query 自适应触发器访问。不训练、不量化，所有质量效应都归因于选择与调度。

关键数字 Kimi Linear 48B 上，8k~65k 上下文检索在 8 倍压缩保持 1.00、32 倍 0.96，与全行选择零差距；每步扫描仅读约 26% 的字节；双节点 sglang 部署交叉点约 40k 上下文，256k 时 1.18 倍、496k 时 1.39 倍。

为什么值得看 占据了"免训练 × query 无关"这一稀疏注意力文献的空缺象限，并证明该机制为 NoPE 独有。
