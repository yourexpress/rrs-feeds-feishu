ProxyFormer: A Dual-Stream Proxy Architecture for Ultra-Long Context and High-Resolution Generation

arXiv（Zhongpan Tang，cs.LG） · 2026-08-24 · 论文PDF

研究问题：注意力计算与 KV cache 随序列长度二次增长，是超长上下文语言模型与高分辨率生成模型的核心瓶颈。

方法：ProxyFormer 基于代理 token 的双流架构：每层把局部细粒度特征自底向上压缩到少量代理状态，昂贵的全局交互只在代理空间进行，再自顶向下解压回局部流；局部流跨层保留，缓解一次性压缩的不可逆信息丢失；配多级分解压缩、逐层动态压缩率与仅代理 KV cache 推理。

关键数字：16GB 显存 batch=1 下标准 decoder 只能训约 2 万 token，ProxyFormer 压缩比 64 时可训约 70 万；64K 窗口训练的模型在 1,048,576 token 多针检索上保持 92%~95% 准确率；8K 窗口外推到 256K 准确率超 94%。

为什么值得看：用很小的代理空间承载全局交互还能保住检索精度，超长上下文与高清生成两条线都给了可行性证据。
