CliffCompaction: Cost-Efficient Compaction for Long-Horizon Coding Agents

arXiv (cs.AI) · 2026-09-23 · 论文PDF

研究问题： 编程 agent 处理复杂任务时上下文窗口很快被占满——如何在有限上下文下自动压缩而不损失性能？

方法： 提出 CliffCompaction，一种自动压缩技术，在有界上下文下将成本降低最高 50%，同时在 Terminal-Bench 上保持或提升性能，在 KernelBench 上达到新 SOTA。

关键数字： 成本降 50%；等成本下 Terminal-Bench 涨 10+ 个百分点；并行 test-time scaling 下 Kimi K2.6 可匹敌 Opus 4.7。

为什么值得看： 对长周期编程 agent 的上下文管理给出了实用方案——压缩做得好，小模型也能靠 test-time scaling 匹敌大模型。
