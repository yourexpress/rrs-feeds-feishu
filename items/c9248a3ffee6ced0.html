AttSVD:Prompt-Adaptive Low-Rank KV Cache Compression via Attention-Guided SVD

arXiv cs.LG · 2026-10-08 · 论文PDF / 每日精选

研究问题： 自回归 Transformer 的 KV cache 随上下文线性增长、长上下文时主导内存；主流免训练方法沿序列轴驱逐低重要性 token，选择不可逆。

方法： AttSVD 改沿「特征轴」低价存储、不丢任何 token：对每个 prompt 在线做注意力引导的截断 SVD，只保留注意力真正读取的方向，按保留 rank 比例削减每头持久 KV 内存；提供 accumulating/streaming 两种解码期缓存策略，以及逐矩阵能量规则与注意力感知基截断两个自适应细化。

关键数字： 多模型、agentic 基准与全套 LongBench 上与稠密 cache 持平，KV cache 内存最多只用 50%。

为什么值得看： 不丢 token 的 KV 压缩新路线，还免费给出每头有效秩等可解释性洞察。
