A Systematic Method of GPU Verification on Subsystem Modelling

arXiv · 2026-11-23 · 论文PDF

ARM Fast Model is a software modelling system for simulating multiple systems IPs integrated in a subsystem. Fast Model allows customer to run whole software stack as early as system IPs' specification is just ready. In this paper, we talk about a systematic method to enable GPU modelling and make whole system software stacks executable for both CPU and GPU in the integrated modelling environment, and eventually the major GPU IP can be verified. With our solution, we can directly run commercial benchmarks like Antutu and GFX Bench in Android target system with underlying ARM Fast Model mobile subsystem support. This was unbelievable in the past due to 3D rendering simulation for GPU verification is very slow. We also introduce some special techniques to improve performance. Eventually the whole software stack can directly work on real hardware without any changes as soon as the first tape-out is ready.
