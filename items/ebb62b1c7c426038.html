Scalable Placement for Disaggregated LLM Serving on Heterogeneous Edge Fleets

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：边缘 LLM 服务受有限计算资源与设备异构性制约，突发需求下拥塞与排队显著增加响应延迟；把模型复制到多个流水线实例可提升服务容量，但设备分组、副本分配与跨设备层划分联合构成大型组合优化问题。

方法：Spade 可扩展运行时高效放置规划器（异构边缘集群上带流水线复制的分离式 LLM 服务）：支配剪枝丢弃劣质副本候选、递归消除包含它们的更大候选，大幅收缩搜索空间；water-filling 层划分 + 有界多维背包公式在拥塞感知目标下优化放置。

关键数字：30 设备（5 种硬件类别）合成集群 441ms 找到最优放置；遗传搜索基线 + DP 划分约需 2 小时且拥塞目标仍差 19.7%；10 种设备类型集群上剪枝消除 99.6% 候选放置，同时与穷举产生相同幸存候选集。

为什么值得看：异构边缘集群 LLM 放置的实用可扩展规划器，剪枝效果显著。
