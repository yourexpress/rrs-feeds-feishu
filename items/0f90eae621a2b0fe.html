EdgeKernelBench: Unified LLM-Driven Kernel Generation for Edge Backends

arXiv/cs.LG · 2026-10-17 · 论文PDF / 每日精选

研究问题 LLM 在服务器 GPU 上生成 kernel 已见成效，但边缘部署硬件异构、软件栈割裂、资源预算紧张，跨多种边缘后端的 LLM kernel 生成尚无系统研究。

方法 提出 EdgeKernelBench：统一 IR 部署框架捕获可复用的计算、调度与访存决策，经编译器接口连到各目标后端；配套分层边缘工作负载基准，覆盖从单算子到紧凑模型图。以 TVM 为参考编译器实例化并跨异构边缘后端验证。

关键数字 单次生成下最好模型 Correct@1 达 64.5%，Fast@1.0 却只有 25.5%。作者据此提出按分层 IR 组织优化的 LEKA，在 agent 评测子集上 Fast@1.0 达 43.5%，直接生成为 13.0%、Claude Code 为 26.1%（LEKA 与 Claude Code 用同一基座模型与优化预算）。

为什么值得看 正确率与性能之间这道巨大落差说明"能跑通"远不等于"跑得快"，而这篇同时给出了边缘端可复现的评测基线。
