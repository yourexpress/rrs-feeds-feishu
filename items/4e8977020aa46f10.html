HeatCache: Thermal-aware Energy-efficient LLM Inference Scheduling for Chassis-level Liquid Cooling in Sustainable Edge Server Rooms

arXiv（Rui Lu 等，cs.DC） · 2026-09-11 · 论文PDF

研究问题：机构级边缘机房部署多 GPU LLM 推理耗电发热巨大；为节能被要求抬高环境温度设定值，却加剧热节流与硬件老化、威胁 SLO，如何调度求解。

方法：HeatCache 面向商用机箱级 AIO 液冷 GPU 的热感知节能推理调度器：把 AIO 液冷回路当作临时热缓冲、以"热量预算"度量，基于 HeatiTS 的电气信息热量需求估计，在热安全与 SLO 约束下以最小化能耗为目标调度请求。系统实现在 vLLM 之上。

关键数字：计算能耗最多降低 18.0%，热节流暴露减少 81.7%，即使环境温度高达 48°C，SLO 违约率仍低于 0.9%。

为什么值得看：把冷却回路的物理热容变成调度资源，思路新颖且数字扎实；对自建边缘推理机房、面临节能考核的团队直接有借鉴意义。
