Byzantine-linearizable Single-Writer Multi-Reader Register in the GPU-Inspired Shared Memory Model

arXiv · 2026-10-14 · 论文PDF

研究问题：GPU 共享内存缺乏访问控制、任意线程（含指定 writer）可能 Byzantine 行为——原子寄存器语义能否维持？

方法：在 GPU 启发的共享内存模型中构造 Byzantine-linearizable 单写多读（SWMR）寄存器：CAReg 用常量内存、以可量化的概率容忍无效读；SnapObject 维护有界窗口的认证写、消除无效读，通过 lock-free 与 wait-free 变体容忍至多 n-1 个 Byzantine 进程。

关键数字：SnapObject 容忍至多 n-1 个 Byzantine 进程，提供无无效读的变体。

为什么值得看：把容错寄存器理论落到 GPU 无访问控制的现实约束下，分布式计算基础原语新解。
