Scalpel and Brush: Pruning and Targeted Weight Editing of a Small Language Model by a Single LLM Agent

arXiv (cs.LG) · 2026-11-24 · 论文PDF / 每日精选

研究问题： LLM 能编辑另一语言模型的权重，但结果有多少真正来自 agent？随机编辑、提示指令或标准流程能否复现同样效果？

方法： 把修复与剪枝统一为稀疏权重编辑（以 BLEU 为例）：三项任务——定向权重修复（"brush"）、结构化 MLP 神经元剪枝（"scalpel"）、层移除+修复——交给 DeepSeek Harness agent（DeepSeek-V4.1-Flash），每任务最多 50 次开发评估，Qwen2.5-Math-1.5B-Instruct 上每任务独立跑 3 次。

关键数字： 最多改动 0.0084% 权重使 ODE 测试 BLEU 提升 24–32%；移除 12.5–15% 神经元使模型缩小 9.4–11.2% 且 BLEU 损失 ≤0.01；GoEmotions 宏 F1 从 0.100 升至 0.396–0.451（测试集）。

为什么值得看： 严格对照揭示：一旦给出干预位置与形式，无 LLM 的标准流程可复现大部分性能——agent 的真实增量需要更严谨的归因。
