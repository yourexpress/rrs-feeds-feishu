PN-Mix: Pair-Norm Guided Mixed-Precision Key Cache Quantization for Efficient Long-Output LLM Inference

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题 长输出推理受 KV cache 内存与带宽瓶颈制约；2-bit 低比特量化严重损害精度，已有混合精度 key cache 方法仅凭 key 统计估计通道重要性。

方法 在 RoPE 通道对层面做注意力 logit 扰动分析，发现 query-key 对范数积大的通道对上量化误差对 logit 波动贡献显著；据此提出 PN-Mix：把更高精度分配给显著通道对，一次在 prefill 阶段识别、整个解码阶段复用。

关键数字 平均 2.26-bit 精度下，平均准确率持平或优于使用 2.32–2.39 bit 的已有混合精度方法（推理、代码生成、AIME 基准）；Pareto 扫描中可平滑降至 1.5 bit，而对比基线在 2.25 bit 以下明显跳水。

为什么值得看 为低比特 KV 量化给出可操作的通道对显著性判据，对推理/代码等长输出场景尤其有用。
