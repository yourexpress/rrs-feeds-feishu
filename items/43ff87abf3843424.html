Coco: An Agentic Copilot for the Hardware--Software Co-Design Lifecycle

arXiv (cs.PL) · 2026-10-05 · 论文PDF

研究问题 ML 模型与加速器协同设计需对尚不存在的系统做高置信结论；仿真数据不在 LLM 语料中、无文献可检索，naive chat-with-your-data 恰在关键处幻觉。 方法 Coco 代理平台：数据仓库自动注册仿真 sweep 进关系 schema（agent 以 SQL 取数）；类型化 API 工具库；UX 导航兼作 agent 上下文。 关键数字 摘要仅报告早期部署，方向为缩短 time-to-simulation 与 time-to-insight，无具体数值。 为什么值得看 把协同设计论证为独立 agentic 领域：数据须检索而非记忆。 阅读原文
