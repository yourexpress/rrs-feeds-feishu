Trajectory-Aware Policy Optimization: Closing the State Distribution Gap in Long-Horizon LLM RL

arXiv · 2026-10-09 · 论文PDF

研究问题 长程自回归 rollout 中，局地策略失配会沿轨迹复利放大为严重状态分布偏移，现有 GRPO/GSPO 只控制 token 或序列级失配，导致训练不稳定乃至坍缩。

方法 提出 TAPO：从 off-policy 策略梯度理论导出状态分布修正并并入 RL 目标；用几何均值估计器降方差，配合长度感知的动态裁剪防止跨轨迹的过度更新。

关键数字 在 8 个竞赛级基准上显著超越现有 LLM RL 算法：数学推理较 GRPO 提升最高 48%、算法编码提升 12%，训练稳定性大幅增强。

为什么值得看 直击长程 LLM RL 的状态分布偏移这一根本限制，理论推导+工程手段结合，是强化学习训练 LLM 的重要进展。
