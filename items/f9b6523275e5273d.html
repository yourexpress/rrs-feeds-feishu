Decode Token Parallelism: Memory-Efficient Distributed Attention Parallelism for Scalable LLM Decoding

arXiv cs.DC · 2026-11-09 · 论文PDF / 每日精选

研究问题：高并发长上下文 LLM 服务需要随 decode 池增长的 KV 容量与注意力带宽，但现有并行策略各有权衡——数据并行复制权重限制 KV 容量，张量并行在 KV-head 数处停止扩展，DCP 分片序列却增加跨节点部分注意力聚合。如何同时扩展容量与带宽？

方法：提出 Decode Token Parallelism（TKNP）decode 池架构，解耦权重放置与注意力归属：单份模型按平衡层块分布到各节点，持有块的活动节点用节点内张量并行执行全批次投影与 MLP，每个节点对自己请求的本地 KV 计算注意力。仅当前 token 激活跨网络，稠密 all-reduce 留在 NVLink 内，注意力无需跨节点合并部分结果。

关键数字：vLLM 实现，Llama 3.1 405B 与 Nemotron-4 340B 在最多 64 张 H100 上，长上下文高并发吞吐比 DCP 最高提升 1.7×、比数据并行最高 2.06×（相同 GPU 数）。

为什么值得看：不复制权重也不跨节点聚合注意力的新并行维度，直接缓解长上下文 decode 的 KV 扩展瓶颈。
