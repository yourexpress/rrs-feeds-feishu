One-Sided Expert-Parallel All-to-All for Mixture-of-Experts Inference over NVLink

arXiv cs.DC · 2026-11-09 · 论文PDF / 每日精选

研究问题：MoE 推理每层需要两次 all-to-all（dispatch 与 combine），推理时每 GPU 处理 token 少，小批量下不随 token 数增长的固定开销主导延迟——如何消除这些固定成本？

方法：提出 NVLinkOneSided 单边 EP all-to-all（限单 NVLink 域内 GPU）：源 rank 不先交换元数据即把 token 推入目标 GPU 的 rank-major 缓冲区，grouped GEMM 原地读取而非逐专家拷贝。提供 Fence 与 Sentinel 两种同步协议，分别面向高吞吐与低延迟场景；模块化接口，与量化格式无关、与计算后端解耦。

关键数字：Blackwell GPU 上 dispatch+combine 比 DeepEP 快 1.2-3.0×（小批量下增益最大）；MoE 层整体比 DeepEP+DeepGEMM 快 2.4×；每 GPU 128 token 内甚至超过融合版 DeepGEMM MegaMoE，解码场景仍具竞争力。

为什么值得看：小批量 MoE 推理的通信范式改进，直接降低解码延迟，接口设计易于集成进推理框架。
