Inside Arm CSS for Mobile 2: The AI-native compute platform for mobile

Arm 技术博客 · 2026-09-08 · 技术博客 / 每日精选

核心话题：Arm 发布面向 agentic AI 的下一代移动计算平台 CSS for Mobile 2——从"答题"到"替用户把意图变成行动"（收集上下文、规划动作、协调应用）的算力底座。

要点：两大新计算引擎：Arm C2 Ultra CPU（带 SME2 可伸缩矩阵扩展）把响应式端侧 AI 带上 CPU；Mali G2-Ultra NX GPU 引入专用神经网络加速器，让 neural graphics 原生跑在 GPU 上。平台按"完整 agentic 工作负载"整体设计：CPU 负责可编程计算与系统编排，CPU/GPU/系统 IP/软件工具协同优化，重点解决各计算引擎间的数据搬运效率与任务级协调。

关键数字：官方未给出逐项性能数字，定位为平台级发布。

为什么值得看：下一轮旗舰手机 SoC 端侧 AI 算力的走向标——agentic 工作流对异构协同与数据搬运的要求，会直接约束端侧模型（含语音管线）的性能预算。
