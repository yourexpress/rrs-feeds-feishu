A thousand fewer paths to root

OpenAI · 2026-11-04 · 官方公告 / 每日精选

核心话题：安全研究从「每个发现单独调查」转向可规模化的系统流程——自主漏洞发现-利用-补丁流水线。

要点：流水线先定位 Linux 内核安全相关部分，静态扫描候选发现，在隔离环境动态复现，生成 PoC 证明可利用性，再生成补丁，最后由人类安全研究员审查；输出根因分析、最小崩溃 PoC、候选补丁与完整 exploit。

关键数字：单次运行识别并分析 2308 个候选内核发现，动态复现 1724 个漏洞，产出 948 个本地提权（LPE）exploit；总 API 成本 1,213,430 美元（约 1,279 美元/LPE）；对照历史 Pwn2Own/TyphoonPWN 赏金，948 个 exploit 的假设估值约 1890 万–6630 万美元（约 16–55 倍成本）。

为什么值得看：OpenAI 把「发现-验证-修补」做成闭环并量化成本曲线，AI 安全研究的规模效应样本。
