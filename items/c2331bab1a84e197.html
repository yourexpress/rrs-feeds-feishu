Translating KV Caches Between Hybrid-Attention Language Models: MLA Latents, Linear-Attention States and Sparse-Attention Indexers

arXiv cs.LG · 2026-11-09 · 论文PDF / 每日精选

研究问题 一个模型接管另一模型的对话通常须重读全部历史；KV cache 翻译把源 cache 映射成目标自身格式，使目标从完整上下文继续而无需重读——对 GQA 已可行，但开源前沿模型如今缓存压缩潜变量（MLA）、稀疏注意力索引器 key 与定长线性注意力状态。

方法 复现 KV-Lingo 于 GQA 对，再为每类对象给出捕获/注入位置与达到原生质量的机制：MLA 潜变量用逐 token 线性映射翻译；循环状态用闭式校正复制或用目标自身循环重放合成；研究 16–48B 规模两个混合对的双向翻译（Kimi-VL-A3B ↔ Kimi-Linear-48B、Qwen3.5-27B ↔ Qwen3.8-27B）加稀疏注意力目标。

关键数字 从源层 0 MLA 潜变量解码 token id 使 needle 召回从 0.09 升至 2–32K 的 0.99、64K 的 0.83–1.00（最长训练 prompt 的 8 倍）；混合全 MLA 方向每个任务指标都在原生质量配对置信区间内；64K token 时首 token 时间比重读短 18.7x 与 46.8x。

为什么值得看 把 KV 翻译从 GQA 推进到 MLA/线性注意力/稀疏索引器混合架构，为模型间无缝交接对话提供完整配方。
