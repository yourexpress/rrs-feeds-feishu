Gen-TAS: A Generative AI-Aided Hardware-Software Task Allocation Framework for FPGA-GPP Heterogeneous Systems

arXiv（Mary Kong 等，cs.AR） · 2026-08-28 · 论文PDF

研究问题：FPGA-GPP 异构系统里哪些任务放 FPGA、哪些放通用处理器？面对延迟、通信、资源、功耗各异的用户目标，传统设计空间探索高度依赖专家经验。

方法：Gen-TAS：知识锚定的 LLM 框架——任务图分析 + RAG 把 LLM 推理锚定到历史实现知识上，生成多个可解释分配策略；人在环选择 + 确定性后端把 LLM 决策落成可复现的 FPGA SoC 实现。

关键数字：CNN 与 SDR 负载、多个 LLM 上验证：延迟导向目标下较全 GPP 基线分别最高加速 2.45× 与 92.53×；其他目标则会策略性地以部分加速换通信、资源或 FPGA 功耗收益。

为什么值得看：把 LLM 引进硬件任务划分这个硬决策场景，且保留可解释性与可复现性，是「AI 辅助硬件设计」的扎实样例。
