CPU-Eval: Evaluating Large Language Models for CPU Hardware Code Generation

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：VerilogEval 上 HDL 生成通过率已超 90%，缺乏区分度——如何为 LLM 生成硬件代码提供一个更有挑战、贴近实际开发任务的基准？

方法：构建 CPU-Eval，从六个 CPU 设计（含已流片家族，覆盖嵌入式小核到可跑 Linux 的无序核，SystemVerilog/Chisel/SpinalHDL 三种语言）提炼 339 个 HDL 生成问题，让 LLM 执行真实的 CPU 开发任务。

关键数字：七个 SOTA LLM 在 CPU-Eval 上平均 pass@1 比 VerilogEval v2 Spec-to-RTL 低 45.14 个百分点；子模块源码行数越多 pass@1 越低；较少使用的 HDL 上 pass@1 更低。

为什么值得看：暴露了 VerilogEval 高通过率掩盖的模型能力差距，并提示细粒度模块化设计与按目标 HDL 验证模型熟练度的工程策略。
