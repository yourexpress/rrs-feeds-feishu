Redesigning source control at Anthropic

Anthropic · 2026-10-13 · 技术博客 / 每日精选

核心话题 Claude 驱动的编码让源代码控制成为瓶颈：Anthropic 日均合并代码变更从 2026 年 5 月约 2500 次涨到 9 月的 3 万+ 次，主分支历史近 100GB，CI 每天约 2500 万次检出。

要点 弃用 git 自建版本控制系统 Scion，5 个月完成 monorepo 全量迁移，同期交付评审系统 Antique、代码搜索与权限体系；此前靠数百个内部 git 镜像与浅克隆扛负载，随合并频率上升愈发难运维。

关键数字 日合并 2500→30000+ 次；主分支历史约 100GB、压缩工作副本 25GB+；朴素全量拉取将产生 600PB+/天 git 流量。

为什么值得看 「AI 写代码快过人类基础设施」的第一手工程实录，是 agent 开发基建即将踩到的坑的预演。
