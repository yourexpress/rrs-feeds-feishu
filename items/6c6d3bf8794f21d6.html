GPU-CFR: 80x Faster Counterfactual Regret Minimization by Compiling the Game to Static Dataflow and CUDA Graph Replay

arXiv（Boning Li 等，cs.DC） · 2026-09-10 · 论文PDF

研究问题 CFR 是少数 CPU 仍快于 GPU 的大数值负载：每轮扫数十亿状态博弈树、数百万次小 gather/scatter，GPU 上 kernel 微秒级完成，启动与调度开销主导。

方法 洞察：固定博弈下 CFR 迭代除数值外一切在首轮前已知。GPU-CFR 把博弈一次性编译为静态数据流（扁平数组、预计算索引、按深度批处理），静态 chance folding 等削减框架操作，CUDA Graph Replay 一次录制、单次图启动重放。

关键数字 单 A100、8 个博弈：比此前最快 GPU CFR 快 29.8~80.4 倍，比 LiteEFG（CPU）在四大博弈上快 14~258 倍；编译表示本身在 8 线程 CPU 上已比 GPU 基线快 2.2~51.1 倍且逐位复现参考迭代。

为什么值得看 "编译整个迭代+Graph 重放"对一切结构固定的迭代算法都是可迁移范式。
