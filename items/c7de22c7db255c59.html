Agent Lightning v1.0: A 3,500-Line Lightweight Agentic RL Framework for Training Agents with Real Harnesses

Microsoft Research · 2026-10-07 · 技术博客 / 每日精选

核心话题： 微软亚洲研究院发布 Agent Lightning v1.0——约 3,500 行代码的轻量级 agentic RL 框架，并提出 Harnessed Agentic RL 训练范式。

要点： 核心思想是让部署用的 agent harness 直接参与 RL 训练，不再需要在训练框架内重写 agent（训练的就是部署的）；agent 经框架内的 LLM proxy 访问模型，harness 代码零改动；agent 以标准 Kubernetes job 运行，自建集群、云 K8s 或本地均可，不依赖付费商业沙箱；代码量小到可以读懂、改造和扩展。

关键数字： 完整 coding agent 训练示例中，基于开源数据集仅约 6,000 条训练样本，把 Qwen3.5-9B 在 SWE-bench Verified 上的 Pass@1 从 41.8% 提升到 56.4%，净增 14.6 个百分点。

为什么值得看： "训练即部署"范式加上可复现的完整 pipeline，把 agent RL 的门槛降到小团队可及，数据效率数据也很有说服力。
