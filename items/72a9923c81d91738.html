Build trusted autonomous agents for your team with Microsoft Foundry

Microsoft · 2026-11-19 · 技术博客 / 每日精选

核心话题 企业 agent 规模化后 ROI 未跟上，卡点在"与团队协作"——没有自己身份的 agent 只能借用户权限在 Outlook/Teams 里行动，事件触发无登录用户、群聊归属不明两大场景断裂。

要点 Foundry 让 agent 以组织命名成员身份常驻：微软 Entra agent 身份（不借凭据）、按人方式授权、有问责经理与组织位置、独立邮箱/日历/OneDrive/Teams 呈现、完整审计轨迹；以 agent-as-a-service 蓝图构建，一次建成可复用全组织。
