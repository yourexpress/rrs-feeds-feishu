Sparse Planning in Visual World Models via Cost Gradients

arXiv cs.LG · 2026-10-09 · 论文PDF

研究问题 基于 token 的世界模型支持细粒度潜空间规划，但反复处理大空间 token 网格使动作搜索昂贵。

方法 COSTGRAD：免训练、目标条件的空间 token 选择器，按规划代价对每个输入 token 的梯度范数排序；重要性直接来自下游控制目标而非单纯预测，并可与 CEM 搜索缩减结合。

关键数字 AdaLN 条件预测器在 50% 稀疏度下，四个连续控制基准中三个匹配或超越全 token 规划，每个环境规划步实测加速 2.6 倍；结合 CEM 缩减总加速约 5 倍；但在 concat 架构上纯 COSTGRAD 优势消失（梯度选择在 concat 上产生更多动作路径漂移）。

为什么值得看 揭示稀疏世界模型规划中"选择器-架构兼容性"这一设计轴。
