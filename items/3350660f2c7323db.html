Fairly Compensated Distributed Information Retrieval and Augmentation for AI Agents

arXiv (cs.DC) · 2026-09-22 · 论文PDF

研究问题 自治 AI agent 越来越依赖外部分布式知识源；去中心化信息市场里检索 agent 需先评估数据质量与相关性，但数据提供方又不能在保证付款前泄露——在无中心仲裁、信任缺失的多 agent 环境下构成公平悖论。

方法 提出「公平补偿」的分布式信息检索与增强协议：检索 agent 在不学习明文的前提下对候选文档进行安全评估与排序，仅当有效信息成功交付时数据提供方才得到补偿；基于密码学基础设施做安全性分析并实现原型系统。

关键数字 摘要未给出具体性能数字，仅说明实现与现有密码学基础设施兼容，保留机密性、正确性、完整性与公平性。

为什么值得看 给出「信任缺失 + AI agent 经济」场景的密码学基础设施级解决方案，是 agent-to-agent marketplace 的关键底座。
