Towards a Cloud Fog Edge System for Smart Building

arXiv (cs.DC) · 2026-10-02 · 论文PDF

研究问题： 建筑实时数据学习需要去中心化、隐私保护且少依赖外部云的方案，人道主义场景尤重数据主权、能效与基础设施约束。

方法： 主张"建筑即数据中心"，用轻量 Kubernetes 式编排框架在低功耗低成本微控制器（Arduino 生态）上部署 AI；提出基于 KOptim 与 FIWARE 的云-雾-边架构及耦合方法论。

关键数字： 两个新在线学习算法用真实世界轨迹做了实验评估。

为什么值得看： 把边缘计算落到资源受限环境，传感器/微控制器上原位学习。
