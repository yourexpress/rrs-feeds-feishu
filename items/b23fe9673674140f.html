Memory Control Signals Emerge Before Action in Long Horizon Agents

arXiv 预印本 · 2026-09-23 · 论文PDF

研究问题 长程语言模型智能体不断累积交互历史，计算成本上升、关键信息更难保留；现有上下文管理聚焦如何压缩/检索，却少有人问：模型在动作发生前是否已经在内部表征中编码了"该压缩/该召回"的需求？

方法 研究每个 agent 动作前的隐状态，发现压缩与召回需求已编码在内部表征里，且无法用简单上下文长度或交互进度解释；据此提出 PaMER（Preaction Memory with Evidence Retrieval），状态引导压缩 + 外部证据检索，PaMER+ 增加步级证据选择，只恢复当前任务所需历史。

关键数字 在 WorkBuddyBench 上跨多种上下文管理基线与模型骨干评测：大幅降低上下文消耗，同时保持有竞争力的任务性能（摘要未给具体数值）。

为什么值得看 "先于动作的隐式记忆信号"为上下文管理提供了新的触发依据，长程 agent 的记忆工程可以不再只靠外部启发式。
