Integrated GPU Core for Mamba-3

arXiv cs.AR · 2026-11-16 · 论文PDF / 每日精选

研究问题：Mamba-3 的 MIMO 计算、指数梯形离散化与 RoPE 引入密集/逐元素/顺序操作，融合后仍执行低效——kernel 启动多、数据移动大、寄存器压力降低 warp 占用与延迟隐藏。

方法：RescuCore 专用 GPU 执行单元：集成进每个 SM 子分区，与 CUDA/Tensor Core 共享寄存器文件、共享内存与 warp 调度器；稠密投影留常规资源，RescuCore 流水化离散化、归一化、RoPE、MIMO、循环状态更新与输出门控。

关键数字：论文未给出摘要级量化数字（摘要截断）。

为什么值得看：为 SSM 特化的 GPU 核，直击 Mamba-3 混合模型的 kernel 碎片化与数据移动。
