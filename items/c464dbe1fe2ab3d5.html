VeriPy Source-Preserving Verification and Compatibility Checking for Python Components

arXiv (cs.PL) · 2026-10-05 · 论文PDF

研究问题 让 Python 程序与其形式化保证持续对齐是长期维护难题：规格必须描述实际运行的实现，更新必须保留既有调用方依赖的行为。

方法 提出 VeriPy，把上述义务纳入带注解 Python 组件的统一工作流：开发者与智能体以 Python 注释表达契约、不变量与证明钩子，用源码定位诊断精化受检辅助引理；直接编码器产出 Dafny 或 Lean 工件并保留可执行主体与依赖的显式模型；关系积检查更新后的组件是否仍接受旧输入并保持返回值与建模异常。工作流把源码级证明开发与函数验证、向后兼容连接起来，并记录每个保证适用的假设。

关键数字 摘要未给出量化指标；代码开源。

为什么值得看 面向"带形式保证的 Python 组件"的可维护验证工作流，与智能体开发场景契合。
