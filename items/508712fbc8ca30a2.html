llama.cpp b12233–b12239 releases

llama.cpp (GitHub Releases) · 2026-11-10 · 技术博客 / 每日精选

核心话题 llama.cpp 连续版本发布（b12233–b12239）的更新要点汇总，覆盖推理引擎的修复、API 增强与平台支持扩展。

要点 各版本亮点：修复 Hexagon 后端 64 位 FastRPC 句柄关闭截断问题；server responses API 支持 text.format.json_schema 到 completions 的转换；聊天在设置 tools 时 response_format 不再使用 lazy grammar 等。发布矩阵涵盖 macOS（Apple Silicon/Intel/iOS）、Linux（CPU/ARM 多架构、CUDA 12/13、ROCm、Vulkan、SYCL、OpenVINO、Snapdragon 等）、Windows 与 Android 多后端。

关键数字 文本未给出性能数字；更新集中在正确性修复与 API 兼容性。

为什么值得看 llama.cpp 是本地 LLM 推理的事实标准引擎，跟踪版本节奏与平台覆盖对自部署用户最实用。
