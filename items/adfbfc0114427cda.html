DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression

arXiv（DeepSeek-AI 等，cs.CL） · 2026-09-17 · 论文PDF / 每日精选

研究问题：长程智能体普及后模型负载越来越"输入密集"：prefill 计算昂贵，庞大 KV cache 挤压 HBM 与 SSD 容量及传输带宽——如何进一步压低部署成本？

方法：DeepSeek-V4.1-Flash：552B 骨干参数的多模态 MoE，支持 100 万 token 上下文；因果编码器-解码器（CED）架构让 decode 每 token 激活 16B、prefill 仅 8B 参数；CSA2（Compressed Sparse Attention 2）跨层 KV 复用叠加 FP4 KV 缓存；部署侧 SWA Bounded Replay 优化持久 KV 足迹；45T token 多模态语料预训练并做全面后训练。

关键数字：全局 KV cache（常驻 HBM）降至每 token 890 字节，约为 DeepSeek-V4-Flash 的 1/4；持久 KV 足迹（SSD/主机内存）约为 1/8；性能仍显著优于基线。权重已在 HuggingFace 开放。

为什么值得看：把 KV cache 压缩推到字节级预算的完整工程叙事——架构、注意力机制、部署优化三层协同，是长上下文推理成本优化的标杆样本。
