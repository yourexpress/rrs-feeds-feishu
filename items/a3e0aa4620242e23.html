Rethinking Soft Tokens for Parallel Decoding in Diffusion Language Models

arXiv / Kodai Kawamura 等 · 2026-09-29 · 论文PDF

研究问题 扩散语言模型并行生成会产出各自合理却彼此矛盾的 token；soft token 缓解了这一问题，但它究竟为何有效？

方法 在冻结的预训练 DLM 上研究以排除额外训练的干扰；发现常规 soft token 构造与预训练嵌入空间之间存在几何失配，据此提出免训练的几何感知 soft token 构造方法；对 soft token 反馈的分析表明，仅"保留预测不确定性"不足以解释它如何重塑后续预测，实验证据显示它更倾向于偏好连贯的 token 序列。

关键数字 在 4 个预训练 DLM、4 个数学与代码基准上，方法优于标准并行解码与免训练的欧氏距离 soft token 基线。

为什么值得看 纠正了"soft token 就是保留不确定性"的通行理解，给出可解释的替代说法；冻结模型上的对照设计也让它成为少见的干净因果证据。
