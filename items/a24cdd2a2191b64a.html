Beyond Masked Sparsity: SNACK Enables Truly Sparse Neural Networks on GPU

arXiv cs.LG · 2026-10-06 · 论文PDF / 每日精选

研究问题 稀疏神经网络与动态稀疏训练理论上能省算力、显存与能耗，但多数 GPU 实现只是"稠密张量 + 二值掩码"，理论收益几乎拿不到。

方法 SNACK：只存储、只计算非零连接的真稀疏 GPU 层，提供简单 PyTorch API 在稀疏范式下完成连接重构与梯度反传；自带 SNACK-COO 自定义 COO 格式 SpMM CUDA kernel，针对大模型训练与单流推理典型的小 batch、高稀疏场景做 batch 到 SM 的映射调优。

关键数字 kernel 级比 Dense+Mask 快至 7 倍，95% 稀疏度下与 cuSPARSE/Sputnik/FlashSparse 相当；90% 稀疏度单层训练加速 8×/3.7×、推理 4×/2×（对 Dense+Mask/全稠密），显存省 72%；端到端 GPT-2 峰值训练显存降 40%，99% 稀疏度下图式推理延迟降 4.8 倍。

为什么值得看 把"伪稀疏"变成"真稀疏"的系统工作，API 友好、收益可复现，做稀疏训练的人值得上手试。
