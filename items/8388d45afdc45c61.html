DEdit: Iterative Draft Editing for Speculative Decoding

arXiv / Longxuan Yu 等 · 2026-09-29 · 论文PDF / 每日精选

研究问题 扩散式 drafter 一次并行预测多个 token 可加速投机解码，但各 token 独立预测，前缀一出错整段草稿被丢弃——如何修复早期错误、保住后续仍有价值的预测？

方法 DEdit 让扩散 drafter 除常规并行解掩码外，还能以 token 到 token 预测迭代编辑草稿：后续预测作为双向上下文修复前面错误、延长被接受前缀。配套 ProposalMix 训练方案按首轮置信度混合草稿预测与真值 token，教模型"修错不改对"。

关键数字 在 Qwen3-4B/8B、七个基准上取得评估 drafter 中最高的宏平均接受率与加速比，贪心解码下宏平均加速分别达 5.72× 与 5.97×；ProposalMix 使有害编辑减半。

为什么值得看 把"编辑"引入投机解码草稿阶段，消融显示双向上下文是收益关键来源，对做 LLM 推理加速的人有直接借鉴。
