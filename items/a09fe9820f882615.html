ValueDiff: Value-Geometric KV Cache Eviction for Sink-Suppressed LLMs

arXiv · 2026-09-20 · 论文PDF / 每日精选

研究问题：QK 归一化、门控注意力等新架构让持久注意力 sink 变弱，而现有 KV 驱逐几乎都依赖 sink——对这类"弱 sink"模型该用什么信号？

方法：ValueDiff：按 token value 向量到 cache 均值的 L2 偏差排序驱逐；同一分数可由"最大熵假设下最小扰动"推出。

关键数字：RULER 2k 预算下七弱 sink 模型保留 dense 的 88~99%；LongBench 4k 平均 92%（最强先前 83%）。

为什么值得看：KV 驱逐从"看 key 几何"切到"看 value 几何"。
