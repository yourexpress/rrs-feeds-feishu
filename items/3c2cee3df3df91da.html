Kraken: LLM-based Speech-to-Speech Translation via Low-bitrate VQ and Dual-path Source Conditioning

arXiv（Hayato Futami 等，cs.CL） · 2026-09-11 · 论文PDF

研究问题：语音到语音翻译（S2ST）中，speech LLM 难以预测高码率语音 token，且训练数据要求说话人身份与韵律理想对齐，两个瓶颈如何同时缓解。

方法：Kraken 用基于单层向量量化、以重建自监督（SSL）特征为目标的低码率 token 作为输出；另设独立的 token 到波形解码器 Autowave-X，同时以源语音为条件增强非语言信息（说话人、韵律）迁移，从而放松训练数据的对齐约束。整体在预训练 LLM 上加语音特征输入与低码率 token 输出，再接 Autowave-X 声码器。

关键数字：基于 Qwen3-8B 构建，用 15 万小时多语多任务语音数据训练；翻译质量优于 SeamlessM4T-Large v2 与 Qwen2.5-Omni，说话人与韵律迁移能力也更好（摘要未列具体分数）。

为什么值得看："低码率 token + 源语音条件化解码"的拆解思路干净有效，对做语音翻译与跨语言语音生成的团队有直接参考价值。
