Previewing the Model Hardware Standard

Anthropic · 2026-08-27 · 官方公告 / 每日精选

核心话题：Anthropic 开放 Model Hardware Standard（MHS）研究预览——让 AI agent 安全操作物理设备（显微镜、液体处理器、机械臂等实验与制造仪器）的共享规范，与 HHMI Janelia 合作起源。

要点：实验室/工厂设备集成通常要数周到数月、需专人定制，MHS 把集成缩到数小时甚至分钟；agent 可逐步推理实验步骤、实时更新参数、编排 7×24 自主实验，部分场景能从硬件错误中自恢复。适用于任何带可编程接口的设备，模型无关，任何 agent harness 可经 MCP 等标准协议接入；先与科研/机器人/制造伙伴共建安全评估，之后开源。

关键数字：集成耗时从"数周到数月"降到"数小时或数分钟"。

为什么值得看："AI 操作物理硬件"走向标准化 + 安全评估的第一手规范，对机器人/自动化方向的技术选型有参考价值。
