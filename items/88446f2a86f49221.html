Integral DeltaNet: Improved Linear Attention with Adaptive Memory Integration

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：线性注意力把历史压进固定大小状态，内存碰撞损害长上下文理解；DeltaNet 的 delta 规则与门控虽缓解碰撞，却可能丢弃对未来预测有用的信息——如何兼顾？

方法：提出 Integral DeltaNet，维护两个互补循环状态：快速更新的 delta 状态捕捉当前键值关联，积分状态保留 delta 状态的加权历史；读出时自适应组合两者以访问不同时间尺度的信息；并推导分块并行公式实现硬件高效训练。

关键数字：340M 与 1.3B 参数模型分别在 15B 与 100B FineWeb-Edu token 上从零训练；相对强循环基线在语言建模、常识推理、真实与合成检索、长上下文理解与长度外推上整体更优；同时比较训练吞吐、激活内存与解码时延/内存。

为什么值得看：双状态设计直击线性注意力「压缩即丢失」的根本矛盾，长上下文场景有实测收益。
