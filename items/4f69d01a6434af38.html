Systolic Linear Attention: Co-Designing Tile-Grouped Gated Delta Attention for TPUs

arXiv cs.LG · 2026-11-04 · 论文PDF / 每日精选

研究问题：Gated DeltaNet、Kimi Delta Attention 等门控 delta 线性注意力层为 GPU 调优（小 tensor-core tile + 快速向量寄存器），直接移植到 TPU 会让每个矩阵 tile 空一半、瓶颈卡在向量运算——如何围绕 TPU 的 256x256 脉动矩阵单元重构？

方法：提出 Systolic Linear Attention（SLA）：把 key 加宽到 256 配分组 value head、把衰减门分组为四个 64 通道 tile、用块矩阵乘积在单个融合 kernel 内完成 chunk solve，把整个层重塑到矩阵单元上。

关键数字：TPU v7x 上完整 SLA-R4 层比开源 Tokamax KDA kernel 快 1.6x~2.5x（精确 chunk 求逆时 1.4x~2.4x）；2048 芯片 v7x 预训练研究中 6.5B~63.1B 稀疏 MoE 模型训练快 11%~24%，困惑度相当或略低。

为什么值得看：为 TPU 定制线性注意力的软硬协同设计，直接给出训练侧提速证据，对 TPU 用户有实操价值。
