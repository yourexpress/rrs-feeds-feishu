ResidualQuant: KV Cache Quantization for Looped Transformers with 2-Bit Residuals

arXiv cs.LG · 2026-10-09 · 论文PDF / 每日精选

研究问题 Looped Transformer 靠循环复用共享 block 提升参数效率，但 KV cache 随循环数增长成为内存瓶颈，限制 batch 与吞吐；现有 KV 量化在激进低精度下精度损失大。

方法 观察到各循环间 KV 状态高度相似：ResidualQuant 以最后一轮 KV 为参考，其余循环用低精度残差表示，配合最小二乘缩放、残差旋转与按循环混合精度，压到 INT2 仍能精确重建。

关键数字 混合精度设置下精度接近 BF16，理论 KV 存储减少 80.7%，同内存预算下比旋转式基线精度最高 +13.0%；RTX 5090 上定 batch 解码吞吐最高 2.73×，支持 2× batch 后峰值吞吐最高 4.15×。

为什么值得看 把循环架构的结构冗余直接变现为 2-bit KV 压缩，是架构-压缩协同设计的漂亮案例。
