Introducing GPT-6.1 Terra

OpenAI · 2026-10-26 · 官方公告 / 每日精选

核心话题 OpenAI 发布新模型 GPT-6.1 Terra——面向规模化电脑操作与高吞吐专业工作的快速高效模型。

要点 相比 GPT-5.6 Terra，视觉推理、电脑操作（computer use）与写作显著提升；标准 API 价格比 GPT-5.6 Terra 与 GPT-6.1 Sol 低 50%；在 Agents' Last Exam、OSWorld 2.1、MMMU-Pro 等基准上以更低成本接近旗舰表现；事实错误率大幅下降，Terminal-Bench 4.0 编程完成率翻倍。

关键数字 标准 API 价格降 50%；中等推理下 Agents' Last Exam 比 GPT-5.6 Terra 高 15 分、成本约 1/3；错误率低推理 53.6%→16.7%、最高推理 4.3%；Terminal-Bench 4.0 最高推理完成率 50.3%（GPT-5.6 Terra 为 21.5%）；比 Claude Opus 5.5 token 效率高 3 倍以上、价格为其 1/4。
