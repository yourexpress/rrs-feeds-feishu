Direct-Operable SIMD Bit-Slicing: A Framework for Memory-Efficient Predicate Evaluation

arXiv（Arunkumar Mathiyazhagan，cs.PF） · 2026-08-26 · 论文PDF

研究问题：Java 对象头与内填带来显著内存开销，数据密集系统里谓词求值能否直接在压缩数据上进行？

方法：基于 Project Panama Vector API 的位切片框架：行式数据转置为并行位平面，用 SIMD 指令在压缩流上直接求值复杂过滤、无需解压；支持整数、long 时间戳、double（IEEE 754 保序变换）与字典编码字符串。

关键数字：内存占用最多降 8×；TPCDS 模型数据 5,000 万行上五种重过滤查询较标量扫描提速 2.4–10.8×；时间戳、小数、字典字符串扩展基准提速 1.5–43×。

为什么值得看：从"解压再算"到"边存边算"的 Java 落地样本，内存受限分析型负载可直接参考。
