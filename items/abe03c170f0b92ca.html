Genie 4 is now available

Google · 2026-11-18 · 技术博客 / 每日精选

核心话题：Google DeepMind 向 Google AI Ultra 订阅者开放新版 Project Genie 体验：Genie 4 世界模型、Genie 3 升级、Project Genie agent 与社区画廊。

要点：Genie 4 支持会话中实时改写世界（换天气、加角色、重定向动作），并首次配实时原生音频（环境音到角色对话）；Genie 3 更新含最长 3 分钟单次生成、世界链接、360° 全景图种子、实时世界内事件；Project Genie agent 以自然语言对话编排多模态模型创建世界；画廊含精选与社区共创世界；所有输出带 SynthID 水印并过安全检查。

关键数字：Genie 3 单次生成从 60 秒延至最长 3 分钟；向 Google AI Ultra 订阅者开放，AI Pro 用户可加入 waitlist。

为什么值得看：交互式世界模型从研究原型走向产品的关键一步——实时编辑 + 原生音频 + 对话式 agent 编排。
