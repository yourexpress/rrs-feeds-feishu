AgentKV: Phase-Aware KV Eviction for Agentic LLMs

arXiv（Taowen Tony Liu 等，cs.LG） · 2026-09-14 · 论文PDF

研究问题 Agentic serving 的 token 消耗比聊天负载高几个数量级，而现有 KV 驱逐方法用最近 token 作代表 query 打分，假设未来注意力与近期相似——agentic 生成的未来 query 是 think/act/tool 等阶段的混合，该假设失效。

方法 AgentKV：为每个阶段维护一个小 query buffer，对缓存 key 按各阶段 query 的并集打分（主角分析显示各阶段占据可区分的 query 子空间）；并实现了持久多轮 serving 路径，跨轮携带压缩 KV 状态、在线压缩保留的 KV 页。

关键数字 在 2 个模型、6 个任务域、各 3 档 KV 预算下，任务得分平均超 R-KV 5.5 分、超 Tri-attention 5.3 分；相对全量 KV 的 SGLang，输出 token 吞吐最高提升 1.80x。

为什么值得看 针对 agent 长链路推理的 KV 管理方案，阶段感知的视角新颖且已开源。
