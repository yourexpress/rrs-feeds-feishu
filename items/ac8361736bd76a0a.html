SE-GoS: Self-Evolving Graph-of-Skills for Skill Library at Scale

arXiv（Dawei Fu 等，cs.AI） · 2026-09-08 · 论文PDF

研究问题 LLM agent 的技能库扩到数千条后检索成为瓶颈；现有 Graph-of-Skills 等方案留下一个问题：历史执行痕迹能否系统蒸馏成更好的、可泛化到未见任务的检索图？

方法 SE-GoS 是一个免训练框架，在保留原检索流水线的前提下从执行痕迹演化技能图：拓扑演化（从执行证据发现/剪枝技能关系）、边权演化（按历史有效性强化检索相关关系）、描述演化（用执行反馈优化面向检索的技能描述）。

关键数字 SkillsBench 上三个 LLM 一致提升：代表性设置下一轮演化 reward 从 52.4% 升到 59.4%、输入 token 较全量加载减约 1/3；演化后的图迁移到不相交 held-out 划分上比静态 GoS 基线高 5.4 分。

为什么值得看 不训练、不改检索算法、不动技能内容，纯靠执行经验演化检索基础设施——skill library 规模化的一条实用路线。
