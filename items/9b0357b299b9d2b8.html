MetaKernelBench: Measuring GPU Kernel Knowledge Transfer Beyond Code

arXiv cs.LG · 2026-10-06 · 论文PDF / 每日精选

研究问题 GPU kernel 优化 agent 会把经验存进知识库或蒸馏成技能，但现有 kernel benchmark 只评单次实现的正确性与速度，没人度量"沉淀下来的经验换个 DSL 还有没有复用价值"。

方法 MetaKernelBench：74 道题分属六个融合子图家族，每题给出仅 DSL 不同的 CuTe DSL 与 TIRx 变体；agent 先独立做一变体并把所学蒸馏成自然语言技能，该技能作为唯一额外输入条件化同一模型在另一 DSL 上的新尝试，在匹配预算下与独立尝试对比正确性与端到端运行时。

关键数字 六个模型、两个迁移方向上配对提升幅度从 -19% 到 +29%；四个模型双向均有收益，但每个模型每个方向有 16%–45% 的题目出现退化；源尝试强于目标独立尝试时 71% 改善，反之 54% 退化。

为什么值得看 揭示"经验蒸馏迁移"并不稳——效果取决于源尝试相对水平，对 agentic kernel 优化方法评估补上关键维度。
