BeaconKV: Key-Value Cache Compression Guided by Beacon Queries for Efficient Large Reasoning Model Inference

arXiv（Janghyeon Kim 等，cs.LG） · 2026-09-04 · 论文PDF

研究问题 大型推理模型靠长 CoT 换取解题能力，但 KV cache 随序列线性增长、长推理轨迹常超 GPU 显存。现有压缩法用近期 query 估计未来 token 重要性——这一假设在长程推理中失效：某些解码步会生成"思维重访 token"（TRT），重新关注遥远上下文。

方法 系统分析发现 TRT 对应的 query 在嵌入空间聚成少量相似组。据此提出免训练的 BeaconKV：维护每个全局 query 簇的紧凑代表（beacon query），无需存全部 query 历史即可预判哪些 KV 对会被重访。

关键数字 四个开源 LRM 与多个推理基准上总体优于现有压缩法：最高 5.8 倍显存削减、吞吐提升超 4.3 倍，且几乎保持完整 cache 的精度。

为什么值得看 "重访 token 聚簇"这一观察直接指出了近期-query 代理的根本缺陷，并给出极简替代——长 CoT 推理部署的实用压缩方案。
