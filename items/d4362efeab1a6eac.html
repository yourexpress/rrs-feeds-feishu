MOLT: A Fine-Grained GPU Memory Sharing System for LLM Serving with Opportunistic Fine-Tuning

arXiv cs.DC · 2026-10-06 · 论文PDF / 每日精选

研究问题 LLM 服务按负载扩副本，但副本内显存仍大量闲置：加副本要分钟级，而副本所需显存秒级波动，自动扩缩容最小单位是整个副本，回收不了这些碎片。把 PEFT 微调与推理共置能利用闲置显存，但推理必须在秒级内回收显存，现有共置系统要么常驻、要么按整个训练样本粒度回收且丢弃进行中的训练步。

方法 MOLT：细粒度显存共享——允许推理回收正在运行的微调步为反向 pass 保存的单个激活，微调步继续运行、反向时重算这些激活；在 CPU-GPU 异步与张量并行下保证只回收无在途 GPU 工作访问的显存。

关键数字 四个模型部署（24B–70B）、H100 SXM 与 B200 上 trace 驱动负载下，推理 SLO 达成率保持 ≥99.7%，完成的微调工作量是丢弃式共享的 1.9–3.3 倍。

为什么值得看 把 serving 集群的显存碎片变成可调度的训练资源，混部系统设计的新思路。
