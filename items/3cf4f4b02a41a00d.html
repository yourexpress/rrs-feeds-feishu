LoRA-generating hypernetworks for efficient on-device LLM generative personalization

arXiv (cs.LG) · 2026-09-22 · 论文PDF / 每日精选

研究问题：端侧 LLM 算力受限但使用模式高度个人化，如何在设备上可行地做生成式个性化？

方法：训练超网络把用户上下文 token 映射为适配该用户的 LoRA；部署后每用户完全在端侧合成个性化 LoRA——像 ICL 只需前向传播，又像 PEFT 改权重、不拉长输入；架构部分复用目标 LLM 权重，附加存储极小。

关键数字：摘要未给具体数值；在多个代表性个性化数据集上对比 ICL 与 PEFT 基线，专注较少被研究的长文本生成任务。

为什么值得看：端侧个性化在 ICL 与 PEFT 之外的第三条路，存储与延迟账算得清楚。
