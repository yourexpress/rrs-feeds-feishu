PaNGEA: Parallel Node Generation and Exploration Algorithm on GPU

arXiv (cs.DC) · 2026-10-05 · 论文PDF

研究问题 寻找高质量可行解的 primal 启发式是混合整数优化（MIO）求解器的重要组件，GPU 加速在连续优化中已见潜力，但 MIO 的 primal 启发式如何高效上 GPU 仍待探索。

方法 提出 PaNGEA，一个 GPU 友好的 MIO primal 启发式：用线性松弛求解配合为 GPU 批量执行设计的局部搜索探索受限子问题；不依赖单一启发式逐步固定变量，而是利用 GPU 批处理并行生成并探索多个子问题。

关键数字 283 个 MIPcc26 与 MIPLIB 实例上，单节点 primal 启发式相对 CPU 版本平均 gap integral 降低 8-18%；并行生成探索多节点再进一步降低 12-19%。

为什么值得看 GPU 批量并行打开 MIO primal 启发式新路径，加速效果在公开基准上得到验证。
