LoopVQ: Sub 1-bit KV Cache Quantization for Looped Transformers

arXiv (cs.LG) · 2026-11-03 · 论文PDF / 每日精选

研究问题 循环 Transformer 每 loop 步各存自己的 key/value，KV cache 随 loop 步数线性增长成为主要内存瓶颈；同时各 loop 步对量化的敏感度差异大。

方法 提出 LoopVQ：沿 loop 轴联合编码多个 loop 步的通道，并微调码本以匹配全精度模型输出。与现有面向标准 LLM 的 KV cache 向量量化方法正交，可组合使用。

关键数字 0.5 bits/元素时，在通用、长思维链推理、长上下文检索任务上（Ouro 与 Huginn 模型）超越现有 KV cache 向量量化方法；与 TaSQ 组合在 0.25 bits/元素仍保留大部分 BF16 精度。SGLang 实现中，32K token 上下文解码延迟近乎减半，1.4B 与 2.6B Ouro 模型峰值服务吞吐相对 BF16 基线最高提升 4.3x 与 6.1x。

为什么值得看 首次把子 1-bit KV 量化做到循环模型上，利用 loop 轴冗余实现近半解码延迟削减，吞吐提升显著。
