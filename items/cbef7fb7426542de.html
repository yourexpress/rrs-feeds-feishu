SpliTEE: Improving LLM Inference on Trusted Hardware with Differentially Private GPU Outsourcing

arXiv（Shashie Dilhara Batan Arachchige 等，cs.CR） · 2026-09-14 · 论文PDF

研究问题 用户 prompt 可能含敏感信息，TEE 内跑 LLM 可保护隐私，但现有 TEE 以 CPU 为主、远慢于 GPU；Slalom 式拆分推理需加密中间结果，开销可观。

方法 SpliTEE 把拆分推理扩展到 LLM：用差分隐私而非加密保护发给 GPU 的中间表示——先证明不做遮蔽时 prompt 重构攻击能以近 80% 准确率还原输入；再给出 LLM 关键函数的全局敏感度分析以界定噪声规模，DP 避免量化、模型保持浮点域。基于 Intel TDX 实现。

关键数字 在 Llama-3.2-3B 与 Qwen3-4B 上：比 TDX 内纯 CPU 推理快近 2 倍，比加密式 Slalom 快 5~15 秒且精度更高；即使攻击者知晓 DP 机制也无法重构出比无关 prompt 更多的信息。

为什么值得看 机密计算与 DP 的务实组合，为隐私敏感 LLM 服务提供了可量化的中间路线。
