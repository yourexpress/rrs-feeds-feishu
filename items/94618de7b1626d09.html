xAI Galaxy 活动收官：发布企业级 Voice Agent API 与 Builder

xAI · 2026-09-18 · 官方公告

核心话题：xAI 为期三天的 Galaxy 开发者活动收官，发布企业级全双工 Voice Agent API 与可视化工作流构建工具 Voice Agent Builder。

要点：语音能力由 Grok 端到端多模态音频流驱动，不是传统 ASR+LLM+TTS 拼接；支持对话中低于 100 毫秒的打断响应与情绪语调调节；面向自主呼叫中心工作流，可直接对接 CRM 后端，覆盖自主客服与销售场景。

关键数字：会话响应（打断延迟）低于 100 毫秒。

为什么值得看：头部厂商把语音 agent 作为企业级 API 产品推出，端到端多模态音频流 + CRM 直连是观察语音交互落地形态的重要参照，做语音产品与呼叫中心自动化的人值得关注。
