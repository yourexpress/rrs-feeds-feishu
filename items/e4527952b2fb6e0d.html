NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling Capabilities

NVIDIA · 2026-09-18 · 论文PDF / 每日精选

研究问题：开源语音对话多为半双工，能否在单一模型里全双工交互并原生调工具？

方法：流式语音编解码器+decoder-only LM，并行输出 agent 文本与函数调用两条流，配 RNN-T 增量转写与流式 TTS 说话。

关键数字：FDB 1.0 被打断后 100% 接管、响应质量 4.33/5；VoiceBench 归一化均值 55.1；FDB 3.0 工具选择 F1 82.5%。

为什么值得看：证明全双工+语音+工具调用可塞进一个开源模型。
