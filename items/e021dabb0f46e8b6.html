Introducing run-assert-eval: Find the risk, fix it, prove it

Microsoft · 2026-09-24 · 技术博客 / 每日精选

核心话题 微软开源 VS Code skill「run-assert-eval」：从一个 prompt 出发，自动完成智能体风险发现、失败率度量、运行时策略生成与修复效果复验的闭环。

要点 它把三件已有工具串成一条流水线：Clarity 先做威胁建模（补「没人想到写下来」的风险），ASSERT 把书面需求转成严格评估，ACS（Agent Control Specification）在智能体行动点执行运行时策略。解决了此前两个痛点：书面需求覆盖不全、各步骤靠人工连接且容易破坏测试集可比性。

关键数字 官方示例中，账单支持智能体跨客户数据泄露在基线 40 场适用对话中出现 12 次（30.0%）；加治理后 34 场中仅 2 次（5.9%），且允许行为零违规。

为什么值得看 把「Agent 运行时治理」从理念落成可复现的开源工具链，且给出了「冻结测试集、一次只改一个控制」的量化验证范式，做 Agent 安全的团队可直接借鉴。
