Bringing Bobium Brawlers to Android with Arm SME2

Arm Community Blog · 2026-11-04 · 技术博客 / 每日精选

核心话题：生成式 AI 从云端 API 走进游戏内运行时，端侧推理如何与游戏循环共存。

要点：Arm SME2 让部分 AI 负载在 CPU 本地运行；三类任务分工——小语言模型生成卡牌/卡组数据、图像模型生成生物立绘、embedding 分类器做内容审核；小模型走 SME2 CPU 优于 Vulkan GPU，大模型 GPU 做 prefill + CPU 逐 token 生成；从 Rust 直接调用 SME2 微内核、权重加载时打包一次、整层融合减少小 kernel 调度开销。

关键数字：内容审核须在交互中响应，目标小于 200 毫秒；整层融合带来 2–5 倍提速（视模型大小）；INT4 用于量化语言模型、BF16 用于图像模型。

为什么值得看：端侧生成式 AI 游戏的真实工程实践，CPU/GPU 协作与工作负载放置的完整案例。
