llama.cpp v0.7.0 Release Notes：LiLiCorr 推测解码、MoE 主机内存 GPU 缓存（--moe-cache-mib）

llama.cpp（GitHub Releases） · 2026-10-15 · 技术博客 / 每日精选

核心话题：llama.cpp v0.7.0 发布：新增 LiliCorr 推测解码、为主机内存中的 MoE 专家引入 GPU 缓存，并一次性接入大批新模型。

要点：--moe-cache-mib 把驻留主机内存的 MoE 专家放进 GPU 侧 LRU 缓存、直接在 GPU 上执行，专家缓存还支持多 GPU 共享；LiliCorr 推测解码在 DFlash 之上用小 draft transformer 选候选；GLM5-Next 支持 MTP 推测解码与优化稀疏注意力路径。Server 侧围绕 common_chat_session 重构 chat 会话 API，格式化输出改为 parts 数组，默认端口从 8080 改为 9931（Docker 容器内仍 8080），Web UI 新增完整模型管理器；ggml 更新到 v0.27.0。

关键数字：专家被 offload 时解码最高加速约 2.2×；新模型包括 K2 Horizon（dense 与 MoVA）、Prism Bonsai 2 27B 三值模型、EmbeddingGemma-2（文本+视觉+音频）、LiquidAI d1/d1-omni、MiniCPM-V 4.7、Nemotron Super 3.5 VL / Nemotron Bolt 74B A9B、maion-coder 及多款决策模型。

为什么值得看：MoE 主机内存专家 offload 场景拿到实用的解码加速路径，多模态、嵌入与决策类模型生态扩展明显。
