The Token-Energy Law of LLM Decode: Active Bytes and Realized Time Account for Joules per Token

arXiv · 2026-10-20 · 论文PDF / 每日精选

研究问题 高效部署 LLM 需要理解模型架构、硬件与服务设置如何共同塑造每生成 token 的能耗——能否给出一个紧凑、可解释的每 token 能耗模型？

方法 提出 Token-Energy Law：GPU 板级每输出 token 能耗由两个核心维度决定——活跃字节（单次解码迭代内共享的稠密权重 + 每请求读写的私有 KV 历史）与实现解码时间（解码时长/输出 token 数）；两者与时间合成仿射形式，系数按模型与硬件/运行时配置校准。

关键数字 三模型 BF16 解码、NVIDIA Hopper 与 Blackwell GPU（含 Hopper 双卡张量并行）实测；固定系数+观测解码时间下，留出条件均值能耗估计与实测最大偏差 3.73%。

为什么值得看 一个定律统一解释 batch 摊销共享权重、长上下文推高私有 KV 需求、吞吐决定时间成本，能耗建模可直接复用。
