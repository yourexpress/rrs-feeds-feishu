DeepSeek Harness v0.2 Brings Official Desktop Apps to Its Open-Source Agent Harness

DeepSeek · 2026-10-03 · 技术博客

核心话题： DeepSeek Harness v0.2 带来官方桌面应用及多项开源 agent harness 能力更新（v0.2.1-alpha.1 发布）。

要点： 新增实验性 Claude Code Mods 兼容层；插件管理页支持"让 Agent 创建插件"；新会话可预填未发送提示，恢复草稿/切换工作区保留文件与引用；Markdown 预览展示 YAML 头部字段；支持 --public-url 反向代理入口；新增开发者工具组合包（会话原始日志、双向定位、Host 调试）；自动化任务改为 Web 内置能力。

关键数字： 版本 v0.2.1-alpha.1（10 月初发布）。

为什么值得看： 开源 agent harness 桌面端官方化与插件生态增强，自托管 agent 工作流值得跟进。
