vSkipper: Translating Dynamic Layer Skipping into LLM Serving Gains

arXiv / Wei Da 等 · 2026-09-30 · 论文PDF / 每日精选

研究问题 动态跳层让每个 token 只执行部分层，但现有 skipper 依赖专用生成循环、无法接入现代 serving 引擎，跳层省下的计算换不成时延收益——FlexiDepth 平均跳过 Llama-3-8B 32 层中的 8 层，用标准生成循环解码反而比基座模型慢 14.6–21.0%。

方法 vSkipper 作为虚拟化层让动态跳层可插拔进 serving 引擎，同时保留连续批处理、定形 batch、分页 KV 缓存与捕获的 decode 图：在每个被路由层按 skipper 决策给 token 分组，仅当预测有利可图时才走路由执行；基于 SGLang 实现，用官方 FlexiDepth checkpoint 在与上游 SGLang 完全相同的条件下评估。

关键数字 上游负载曲线拐点处平均端到端时延 GSM8K 降 36.8%、BBH 降 13.6%；饱和时请求吞吐提升 11.3%/7.4%；无统计可分辨的额外质量损失；代码以 SGLang fork 开源。

为什么值得看 首次把逐 token 内部跳层在现代 serving 引擎里变成真实吞吐收益，虚拟化层做法通用性好。
