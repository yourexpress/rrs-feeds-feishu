Exploiting Native Hardware Heterogeneity: Custom GPSIMD Operators for Accelerating Emerging LLM Memory on AWS Trainium

arXiv cs.DC · 2026-11-09 · 论文PDF / 每日精选

研究问题 LLM 新兴内存模块（如 DeepSeek-V4.1-Flash 的 Engram）混合不规则整数工作（64-bit n-gram 哈希、稀疏表查找）与稠密计算（GEMM 与 gate）；GPU-FPGA 系统可拆分到不同设备加速 5.9x，但 AWS Trainium 的 GPSIMD 引擎只能通过固定内置指令调用，官方自定义算子工具链不支持 Trainium 2/3 且不能与 NKI 同用。

方法 构建工具链：为 GPSIMD 核编译 C++ 自定义算子，注入到 Trainium 3 上 NKI 内核编译出的 NEFF 中，在当前软件栈内扩展 GPSIMD 可定制性。

关键数字 相对手调 NKI 基线：两个 GPSIMD 算子在 decode 阶段把 n-gram 哈希加速 1.79x、表检索最高 4.95x、整个 Engram 计算最高 1.14x。

为什么值得看 在 Trainium 上绕过官方工具链限制、把自定义算子注入 NEFF 的方法，对利用该平台原生异构算力有直接参考价值。
