BenchmarkAnything: Agent-Driven Construction of Simulator-Ready Microarchitecture Benchmarks

arXiv cs.AR · 2026-10-09 · 论文PDF / 每日精选

研究问题 体系结构研究长期依赖仅含数十个负载的 SPEC 套件，评估面过窄会导致"架构过拟合"——核在 SPEC 上优秀，在真实负载上却平庸。

方法 不再手工维护静态套件，提出 agent 驱动的工作流：AI agent 自主把任意开源仓库转化为模拟器可用的干净、无干扰二进制，使负载采集高度可扩展；并用 agent 生成的套件与 SPEC 做对比分析。

关键数字 从公开仓库快速收获数百个多样化应用组成套件；作者报告其性能评估保真度高于 SPEC，并揭示出静态套件无法暴露的新架构洞察（摘要未给更多量化指标）。

为什么值得看 把 benchmark 构建本身交给 agent，是"AI for 体系结构研究"的实在案例，对做模拟器评估的人很有启发。
