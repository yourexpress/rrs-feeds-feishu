PhOSv1: Efficient Scaling of Model Sleeping on a Single Server for Autoscaling with GPU-Context Deduplication

arXiv(cs.DC) · 2026-10-29 · 论文PDF / 每日精选

研究问题 model sleeping 靠暂停预启动引擎实现近零成本扩容，但每个睡眠模型须驻留 GPU context，成本随模型数线性增长。 方法 观察到睡眠模型 context 大量重复：驱动 context 可共享、kernel 二进制因公共算子高度重叠；PhOSv1 用 API remoting 把各引擎 GPU context 分配委托给中心 daemon 去重。 关键数字 扩容时间与 vLLM 原生 sleep 持平，GPU 内存占用显著下降，多模型端到端服务性能提升。 为什么值得看 单服务器可承载远更多睡眠模型，缓解扩容与性能两难。 阅读原文
