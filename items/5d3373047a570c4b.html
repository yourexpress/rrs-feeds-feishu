FOREST: Coordinating Tree-based HBF, RRAM, and HBM for Efficient Speculative LLM Inference

arXiv · 2026-11-20 · 论文PDF / 每日精选

研究问题：投机解码各阶段资源需求不同：目标验证要高通量访问大权重集、串行草稿在紧延迟下跑紧凑模型、长上下文注意力处理增长的 KV cache；GPU 中心 SD 用共享 HBM 中心内存与通用计算造成容量/带宽/计算错配。

方法：FOREST 异构内存中心架构协调 HBF、3D 堆叠 RRAM 与 HBM 三种存储计算树：计算对齐 3D RRAM 做低延迟草稿；跨树数值协同把块缩放 Q/K/V 预处理移到 HBF/RRAM 根板、在 HBM 树做 BFP 注意力；HBF 感知的设计空间探索揭示带宽-计算配给与模型规模的权衡。

关键数字：6 个 SD 配置（32B~405B 目标模型）上最高端到端 5.5× 加速、11.46× decode 吞吐、16.5× decode 能效（对比 A800 基线）；TCO 模型下 token 生成成本效率最高 6.73×。

为什么值得看：SD 从 GPU 中心转向内存中心的系统级重构，数字亮眼。
