GUMPIM: Unitary and Malleable Memory for Processing-in-Memory with Guaranteed PIM Pages

arXiv · 2026-10-16 · 论文PDF / 每日精选

研究问题：DRAM PIM 受内存交织与虚拟内存限制，可用 PIM 粒度受限；强行隔离 PIM 内存又会让 CPU 内存带宽下跌、引入额外数据搬运——如何兼得？

方法：GUMPIM 用统一可塑内存空间允许交织 CPU 页与非交织 PIM 页共存，带"保证 PIM 页"分配；提出双轨内存管理 + PIM DRAM 动态地址映射硬件 + PIM 辅助页迁移；无需改动商用 DRAM 标准，硬件修改只局限在 PIM-enabled DRAM。

关键数字：保持了 CPU 内存带宽，PIM 任务 offload 几乎零拷贝（具体基准数字详见原文图表）。

为什么值得看：把"PIM 内存隔离损失"与"PIM 内存墙"两难命题一起解决，做 PIM 系统/硬件的人必读。
