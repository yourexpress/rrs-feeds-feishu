CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling（arXiv 2610.06829）

arXiv（Yifan Zhang 等） · 2026-10-06 · 论文PDF

研究问题 开源 Web Agent 用强化学习训练依赖弱监督：二元任务成功信号太稀疏，前沿模型评判器每步调用太贵且部署时未必可用。

方法 CLIFT 围绕共形自验证构建训练与测试时扩展：训练中 agent 回答自身 rollout 的自然语言验证问题，共形认证器只保留与训练期评判器一致的 URL 条件信号、赋带符号信任权重并混入每步奖励；测试时冻结复用，通过共形轨迹选择做保守多数投票，全程无需外部评判器。

关键数字 WebArena Infinity 上达到开源 agent SOTA；VisualWebArena 上开放模型训练的银行迁移到 GPT-5.5 并在标准评测下达到 SOTA；Online Mind2Web 上零样本翻译认证题库即提升在线 agent。

为什么值得看 把昂贵评判反馈转化为可复用训练信号与免评判器的测试时扩展信号，对 web agent 的 RL 训练有直接实操价值。
