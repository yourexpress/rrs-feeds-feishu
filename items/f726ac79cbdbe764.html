DynBranch: Speculative Subgraph Reuse for Dynamic Agentic LLM Serving

arXiv (cs.DC/cs.AI/cs.LG) · 2026-09-25 · 论文PDF / 每日精选

研究问题：Agentic LLM 工作流在运行时才决定执行分支，下游计算即使可预测也必须等分支解析，形成"分支解析屏障"；缓存无法隐藏它，因为标识可复用结果的 key 在解析前未知。

方法：DynBranch 让未解析的分支在解析前就可寻址：以稳定坐标标识候选子图，使其在分支解析期间投机执行，完成结果可跨后续请求复用；两级控制器仅当期望收益超过负载代价时才准入该投机工作。系统位于 model-API 边界，无需改动 agent harness 或模型执行引擎。

关键数字：4 个 agentic 负载、Qwen3-32B、4×H200：平均时延较各负载最强基线降至多 32%，较无复用基线降 46–66%；在其他骨干模型及 Qwen3-8B/RTX 4090 消费级部署上收益依然成立。

为什么值得看：把投机执行从 token 级扩展到子图级，直击 agent 服务特有的串行化瓶颈，且工程上即插即用。
