TriFleetRCA: On-Premise LLM Root Cause Analysis for Kubernetes

arXiv (cs.DC) · 2026-09-22 · 论文PDF

研究问题：远程站点的 Kubernetes 根因分析面临两个挑战：生产日志不能发给云端模型，本地 GPU 同时限制模型和上下文窗口。

方法：TriFleetRCA 在单块本地 GPU 上运行——按 pod/namespace/cluster 三个范围收集证据、模板去重 + BM25 排序、经 ingest guard 过滤 runbook 后返回根因及支撑证据行。

关键数字：命中率 0.85/0.90/0.95（三档范围）；去重使命中率从 0.75 升至 0.90 且 token 开销不变；含毒 runbook 被 guard 100% 拦截；中位延迟 1.6 秒（2,200 prompt token）。

为什么值得看：本地 GPU 根因分析的完整方案，特别关注了 runbook 投毒这一安全隐患，且将引用质量与准确性分开评估。
