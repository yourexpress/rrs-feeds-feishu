More Performance From Every Byte: How Full-Stack Codesign Solves AI's Memory Challenge

NVIDIA Blog · 2026-11-05 · 技术博客 / 每日精选

核心话题 大模型、长上下文与 agentic 应用推高 GPU 显存压力，NVIDIA 主张以全栈协同设计（full-stack codesign）而非单纯堆 HBM 来应对。

要点 GPU HBM 是最快也最贵的一层，模型权重与 KV cache 竞争有限容量；下方 CPU 内存、本地 SSD、共享存储按更低每比特成本逐层扩展。做法是压缩须存内容、放到合适层级、并在 GPU 需要前取回；agentic 推理轨迹单请求上下文可达 300 万 token，加剧 KV cache 膨胀；更大 HBM 只有带宽搬得动才有用。

关键数字 从 Blackwell Ultra 到 Vera Rubin 平台，单 GPU HBM 容量约增 3%，而 agentic 每美元吞吐最高提升 30 倍（SemiAnalysis AgentX 口径）。

为什么值得看 解释"显存不够"为什么不是简单加 HBM 的问题，给出 AI 工厂内存/存储层级设计的第一手工程视角。
