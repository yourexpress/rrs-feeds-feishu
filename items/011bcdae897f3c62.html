Grouped Value Attention: Efficient KV Caching via On-Demand Key Reconstruction

arXiv（Vishesh Tripathi 等，cs.AR） · 2026-09-08 · 论文PDF

研究问题 KV cache 是 Transformer 解码的主要瓶颈：内存占用与读取流量随序列长度增长；GQA 通过共享 KV 头压缩成本，但每步仍要同时存 key 和 value。

方法 提出 Grouped Value Attention（GVA）：只存分组 value，content key 用一个可学习线性映射按需重建，推理时该映射可吸收进 query、无需物化 key；另设一个小型共享 decoupled RoPE 通道缓存位置 key。

关键数字 所研究配置下持久化 cache 标量较对齐 GQA 减少约 45–47%；350M 参数 + 30B FineWeb-Edu tokens 训练中，16 维位置变体五任务平均 44.18，GQA 44.36、MLA 43.88——接近 GQA 精度。自定义解码内核已开发，端到端推理性能评估中并计划开源。

为什么值得看 在 GQA/MLA 之外给出第三条 KV 压缩路线（存 V 重建 K），做长上下文推理优化与模型架构设计都值得跟进。
