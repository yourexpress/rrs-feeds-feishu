PrefixBench-H100: Characterizing Prefix Reuse and Time-to-First-Token in H100 LLM Serving

arXiv（Omkar Shewale 等，cs.PF/cs.LG） · 2026-09-17 · 论文PDF / 每日精选

研究问题：vLLM、TensorRT-LLM 都支持前缀 KV 复用，但何时真能显著降低 TTFT、何时会被调度、缓存粒度、并发或显存压力抵消？缺乏系统刻画。

方法：PrefixBench-H100 在单张 H100 上结合受控合成 trace 与聊天/检索风格负载，变化共享前缀长度、后缀多样性、到达模式、并发、输出长度与缓存配置，采集 TTFT、ITL、端到端时延、吞吐、命中率与显存数据。

关键数字：给出了前缀复用显著降低首 token 时延的工况区间与缓存压力侵蚀收益的区间；缓存有效性对并发与输出长度基本不敏感，跨运行时的残差差异主要来自缓存之上的调度层。

为什么值得看：不谈新算法，专画“前缀复用的实用边界”，部署长系统 prompt / RAG / agent 负载时可按图索骥。
