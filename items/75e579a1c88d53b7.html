Progress-Aware Distillation for Mitigating Stagnation in Small Language Model Agents

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题 用蒸馏把 agent 能力迁移到小模型（SLM）时，随交互轨迹变长，学生模型易出现"进展停滞"：困在反复失败的策略循环里难以推进，该现象跨模型、跨任务域普遍存在。

方法 提出进度感知蒸馏（ProD）：显式检测学生生成轨迹中的停滞并施加惩罚，把学生与教师之间的停滞差距编码为自适应裕度，动态惩罚潜在停滞行为；迭代施加该过程使学生逐步逼近教师行为。

关键数字 在 0.6B–8B 的 8 个 SLM、域内与域外基准上，ProD 显著缓解进展停滞，同时提升蒸馏 SLM agent 的成功率与任务完成效率（摘要未给具体百分比）。

为什么值得看 指出小模型 agent 蒸馏的一个共性失效模式并给出训练侧解法，做低成本 agent 的团队值得参考。
