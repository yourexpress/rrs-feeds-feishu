PRISM: Predictive Runtime In-place Scaling and Model Selection for Edge Microservices

arXiv（Uwe Gropengießer 等，cs.DC） · 2026-08-22 · 论文PDF

研究问题：时延敏感的边缘 AI 服务要在严格 deadline、输出质量与受限算力/能耗间权衡，而静态 CPU 配置浪费资源——推理成本随输入、模型变体与运行时状态显著变化。

方法：PRISM：预测引导的运行时框架，联合选择模型变体与 CPU 配额；基于容器级能耗监控与轻量回归模型，在 deadline、资源与离线 QoR 约束下原地调整各流水线阶段，最小化预测的 CPU 封装能耗。

关键数字：ALPR（车牌识别）流水线逾 52,000 请求：检测阶段比最强静态配置省 36% 能耗、平均 CPU 配额不到一半且成功率相当；识别阶段接近静态最优性能且 CPU 配额更低。

为什么值得看：预测式原地伸缩在真实边缘微服务流水线上的实战验证。
