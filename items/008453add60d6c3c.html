EpiLoRA: Fusing Many LoRA Adapters into Low-Precision GEMMs for Serving and RL

arXiv (cs.DC) · 2026-11-02 · 论文PDF / 每日精选

研究问题 多租户 LoRA 推理中，基座模型已降至 FP8/FP4 低精度，但 adapter 仍作为独立小 GPU 内核在 GEMM 旁执行，其延迟在每次解码中占比越来越大。

方法 提出 EpiLoRA（vLLM 插件）：观察到 GEMM 只需在 epilogue（写输出阶段）用到 down-projection，于是先启动 down-projection，再让低精度 GEMM 作为依赖内核并行流式加载权重，并在 epilogue 中叠加各租户的 up-projection。

关键数字 在 NVIDIA Hopper 上单 adapter 解码每 token 耗时比 vLLM 最快配置低 24%；多租户下 adapter 内核吞吐在多数 GPU-模型组合上超过 vLLM。利用引擎 FP8 权重训练 LoRA RL 无需 16 位副本，27B 模型可在单张 48GB GPU 上训练。

为什么值得看 把 adapter 融合进低精度 GEMM 内核本身，同时优化推理与服务端 RL 训练，对多租户 LLM 服务架构有直接参考价值。
