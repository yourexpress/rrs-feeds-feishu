GPT‑6 Cyber: Advancing the frontier of aligned cybersecurity agents

OpenAI · 2026-11-05 · 官方公告 / 每日精选

核心话题 OpenAI 发布面向网络安全研究的模型 GPT-6 Cyber，主打更强的漏洞发现/利用能力与更可靠的授权范围内行为。

要点 ExploitGym 得分 48.5%（GPT-5.6 Cyber 为 32.1%）；对齐评测中无部署提示时 99.93% 测试不越界利用范围外服务、加提示后 100%；已用于实际安全研究：开发 948 个 Linux 提权 exploit、发现 81 个 Firefox 此前未知的高危漏洞，Mozilla 已修复其中多个；新 Web 渗透评测中漏洞召回 40.3%（GPT-6 Astra 为 32.0%）；被 Preparedness Framework 评为 Critical 级。

关键数字 ExploitGym 48.5% vs 32.1%（相对提升 51%）；948 个 Linux 提权 exploit；81 个 Firefox 高危漏洞。

为什么值得看 安全领域专用前沿模型的代表性进展，展示了"能力更强 + 边界更稳"如何同时成立。
