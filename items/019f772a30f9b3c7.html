PULSE: Unlocking Practical Image Compression on Single-Thread CPU

Microsoft Research Asia / 中科大 · 2026-09-16 · 论文PDF / 每日精选

研究问题：学习型图像压缩效果好，但在 CPU 等资源受限硬件上算不动——如何做到单线程 CPU 上实用的神经编解码？

方法：PULSE 编解码器：解码端用 5.2 kMAC/pixel 超低复杂度神经接收器实现多平台低延迟；熵编码用整数线性 CDF 预测 + meta prior 做到位精确；为在极紧预算下找回压缩性能，引入"启发式探针引导的 agentic 演化"——人-LLM 协作迭代改进架构。

关键数字：单 CPU 线程 126ms 解码一张 1080p 图像；压缩性能对标 HM，感知优化后可与 MS-ILLM 等更大的感知编解码器竞争；代码已开源（microsoft/GenCodec 仓库 PULSE 目录）。

为什么值得看：用 LLM agent 参与架构搜索，把"极限低复杂度"与"压缩率"同时拿下——端侧图像压缩和 AI 辅助编解码器设计两条线都能借鉴。
