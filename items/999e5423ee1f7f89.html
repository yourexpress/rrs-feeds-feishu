Grok Voice 大升级：新增 21 个多语言旗舰语音并推出 Voice Agent Builder

xAI · 2026-09-25 · 技术博客

核心话题 xAI 大幅升级 Grok Voice：新增 21 个多语言旗舰语音并推出 Grok Voice Agent Builder 平台。

要点 语音库扩至 26 个，面向客服、角色扮演、内容解说、广告、辅导等场景设计；5 个经典语音（Ara、Eve、Leo、Rex、Sal）经重训后节奏、措辞与重音更自然；Agent Builder 把这些语音集成进实时语音 agent API 与 TTS API；全部语音原生支持 25 种以上语言，并新增 [pause] 等语音控制标签精细调节节奏；即日起可在官方 Playground 试听。

关键数字 新增 21 个旗舰语音，总数 26；原生支持 25+ 语言。

为什么值得看 多语言语音 + agent 构建平台的组合，是语音交互生态向开发者开放的重要信号。
