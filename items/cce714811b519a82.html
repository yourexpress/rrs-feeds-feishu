Gemini Decisions API: Fast, calibrated multimodal decisions

Google · 2026-11-11 · 技术博客 / 每日精选

核心话题 Google 推出 Gemini Decisions API 与新模型 Gemini Decision 1，为封闭集决策（工具选择、策略检查、模型路由、上下文评分）提供快速、带校准置信度的多模态接口。

要点 不再逐 token 生成答案，而是单次前向给候选选项打分；支持文本/图像/音频/视频/PDF 多模态输入与最多 1000 个独立问题；提供三种决策原语：noul（是/否）、choice（2~255 选项多选）、score（有序评分），每个答案附 0~1 置信度供路由到兜底或人工。

关键数字 端到端延迟 150~250ms（模型计算中位 50~100ms）；定价 0.10 美元/百万输入 token、输出 token 零计费；共享基准上比 Gemini 3.5 Flash-Lite Interactions API 便宜近 5 倍。

为什么值得看 为高频受限决策场景提供专用原语与校准置信度，工程落地价值明显。
