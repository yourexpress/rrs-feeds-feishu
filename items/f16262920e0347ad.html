Efficient KV Cache Migration for Geo-Distributed LLM Inference in Collaborative Edge Computing

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题 协同边缘计算中边缘服务器易断连或过载，而云端 KV 迁移方法（跨 GPU 直传、从输入重算）不适配带宽受限的边缘环境。

方法 EdgeFlow 混合迁移方案：KV 缓存直传与基于激活的重算并行推进，以计算-通信重叠压缩迁移时间；把多节点迁移建模为优化问题，用改进的线性规划松弛加二部图技术设计 2-近似算法。

关键数字 在真实分布式 LLM 推理平台上，迁移时间最多降低 45%。

为什么值得看 直击边缘 LLM 推理的有状态迁移痛点，算法带近似比保证，兼顾鲁棒性与效率。
