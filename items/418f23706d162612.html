Resource-Efficient Speculative Decoding for Long-Context LLM Serving

arXiv (cs.AR) · 2026-09-27 · 论文PDF / 每日精选

研究问题：投机解码靠 Draft 并行验证省 Target 调用，但长上下文下 KV Cache 撑爆显存；现有 offload 方案要先回传完整 KV 历史，既慢又浪费验证轮内跨 query 的 KV 共享。

方法：SpecStream 不等完整 KV 恢复即开始验证，利用 KV 传输期间的算力空泡在同卡上并发 drafting；只 offload Target 已提交的历史，候选回滚留在 GPU 本地；每个流式 KV 分块服务轮内全部 query，配在线 softmax 与 Target 优先调度。

关键数字：相对 offload 基线平均吞吐加速 1.41 倍（Qwen3）/1.32 倍（InternLM2.5）；相比 Target/Draft 分卡的并行投机解码，单卡输出吞吐平均高 55.4%；任务质量接近 SGLang 投机解码。

为什么值得看：把「KV offload 的等待时间」变成「Draft 的干活时间」，显存受限下支撑更多并发请求，长上下文 serving 的实用系统工作。
