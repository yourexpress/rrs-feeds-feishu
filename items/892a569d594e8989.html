Contexture: Runtime Context Eviction for High-Throughput Agent Serving

arXiv · 2026-11-20 · 论文PDF / 每日精选

研究问题：LLM agent（Hermes、OpenClaw、Codex 等）反复重发不断增长的执行历史，推高共享 GPU KV cache 需求并限制服务吞吐；现有上下文缩减方法缺全局 cache 状态可见性，运行时 KV 管理器又缺工具执行信息。

方法：把 token 追溯到产生它的工具操作，发现后发操作取代先发输出与相关轮次，64% 的最终历史 token 被识别为可移除候选；Contexture 把 harness 完整对话历史与模型执行上下文分离，结合工具执行信息与共享 KV 压力/前缀驻留的全局可见性做运行时驱逐。

关键数字：SLO 下吞吐比无驱逐/压缩/AgentDiet/Continuum 最优者高 20~73%；live-agent 平均准确率 +1.4 个百分点、最差 -3.7（observation masking 为 -3~28）。

为什么值得看：模型无关的 agent 服务 KV 瓶颈解法，吞吐与精度双收。
