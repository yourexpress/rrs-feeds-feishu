NariQ: Sub-3-Bit Quantization for Long-Horizon Agentic Tasks

arXiv · 2026-11-19 · 论文PDF / 每日精选

研究问题：长程 agentic 任务需在 100K+ token 上下文中多步调用工具，而多数低比特量化按短文校准、以困惑度评判，与真实使用场景错位。

方法：NariQ 是一种 trellis-coded 训练后量化方法，用 BF16 模型在 agent 会话中生成的 token 进行校准，而非静态文本。

关键数字：Qwen3.8-27B 在 3.0 与 2.5 bit/weight 下，DeepSWE、Terminal Bench、AIME、RealWorldQA 均与 BF16 持平；而已有 ≤3bit 量化在 DeepSWE 上最多只解出 BF16 的 72% 任务；2.0 bit 检查点则落后。

为什么值得看：据作者称首个在 ≤3bit 下于长程 agentic 任务匹配全精度版本的量化，已发布 GGUF 与 llama.cpp fork。
