RPTune: Learned Context Curation for LLM Catalog Search

arXiv (cs.IR) · 2026-10-02 · 论文PDF

研究问题： 目录可放进长上下文的小商家（SMB）可用全目录提示做检索，但 LLM 并非均匀利用长上下文，塞满上下文不等于能有效选品。

方法： RPTune 端到端框架：编码器-重组器策展器按下游 LLM 反馈对商品排序剪枝，再用自动生成的目录监督做 LLM 后训练，以上下文相对奖励提升选品效果。

关键数字： 7 个真实商家、每家 100 条复杂对话查询；上下文策展最高提升 31.4 个百分点，后训练再平均提升 10.3 点。

为什么值得看： 闭源与开源权重 LLM 上均稳定提升搜索精度，长上下文目录搜索的务实方案。
