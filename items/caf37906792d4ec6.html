GPT-6 Astra, Sol, and Luna for production AI agents in Microsoft Foundry

Microsoft（Azure Blog） · 2026-09-22 · 技术博客

核心话题 Microsoft Foundry 上把 GPT-6 系列扩展为三档——Astra、Sol、Luna——面向生产型 AI agent 的不同负载画像。

要点 Astra 负责高难度推理、软件工程和 computer use；Sol 偏通用与企业级 agent/编码/复杂知识工作；Luna 偏高效高吞吐的数据抽取、摘要、路由与客服。三档可按任务画像分场景部署；建议用评估而非凭直觉选型，关注 cost-per-task 而非 token 单价。

关键数字 摘要未给出参数或基准分数；Astra/Sol/Luna 全部支持 28 个 Global 区域的 Standard 部署。

为什么值得看 微软在生产 agent 场景下对 GPT-6 进行分层产品化；可与 Google Vertex AI、AWS Bedrock 的同类模型档位策略对照。
