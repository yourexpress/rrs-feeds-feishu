Learning from Unreliable Trajectories: Adversarially-Robust Federated Q-Learning

arXiv cs.LG · 2026-10-08 · 论文PDF

研究问题 联邦强化学习中多个 agent 协作学最优 Q 函数，若部分 agent 是恶意的、发送任意损坏信息，协作带来的样本效率收益还能保住吗？

方法 Robust Async-Fed-Q：基于 epoch 的算法，agent 端对 Bellman 最优算子做方差缩减估计，服务器端做鲁棒聚合。给出高概率有限时间保证：诚实 agent 间的协作统计收益保留，恶意 agent 的影响随每个诚实 agent 数据量增长而衰减、无限样本极限下消失。

关键数字 配套信息论下界刻画了对抗损坏不可避免的统计代价，构成对抗鲁棒联邦强化学习首个近乎匹配的上下界；epoch 式设计还显著改进异步采样下联邦 Q 学习已知的最佳通信复杂度。

为什么值得看 理论闭环漂亮：鲁棒聚合 + 方差缩减拿到近匹配上下界，做联邦/分布式 RL 理论的必读。
