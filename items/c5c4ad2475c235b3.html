LLM Agent-Based Design of RISC-V CPUs with FPGA-in-the-Loop Evaluation

arXiv(cs.AR) · 2026-10-29 · 论文PDF / 每日精选

研究问题 LLM agent 设计 CPU 时，长程 RTL 仿真动辄数小时，短诊断运行又可能漏掉后期才出现的性能劣化——评估成本拖累设计决策。

方法 开发 FPGA-in-the-Loop 开发环境：LLM agent 直接在 FPGA 上实现 CPU 候选，用板上性能计数器实时测量引导设计决策；人工监督下把单周期 RV32I 核演进为三宽乱序 RV32IM 核。

关键数字 最终设计在 Artix-7 FPGA 上 130 MHz 达 5.61 CoreMark/MHz；同一候选跑 8000 次 CoreMark 时，FPGA 评估（含实现）比单线程 RTL 仿真快 9.6×；板测还发现一个短诊断运行表现提升、长程却劣化的候选，引导了根因分析与修复。

为什么值得看 LLM 自动设计 CPU 的工程闭环范例，板上评估替代长仿真的思路对硬件自动化设计有直接价值。
