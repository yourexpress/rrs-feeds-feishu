Dual-QK: Sharp Queries and Flat Keys for Prunable 2-bit KV Caches

arXiv cs.LG · 2026-10-09 · 论文PDF / 每日精选

研究问题 KV cache 低比特量化加 query 通道剪枝可省存储与读量，但旋转式量化要求同一正交变换同时施加到 query，会打散 query 能量，削弱"少数大分量保留、多数小分量剪枝"所需的分离度。

方法 Dual-QK 用成对的非正交 query/key 变换化解冲突：部分 key 白化加 query 对齐基，既平衡 INT2 量化的 key 尺度，又把 query 能量集中起来支持动态通道剪枝；另配 channel-0 保护与 bucket 相对 RoPE 保住长上下文低比特精度。

关键数字 128K 上下文下 6.8× KV cache 压缩、KV 读量估计降 8.3×（相对未剪枝 BF16）；40% query 通道稀疏下多数任务优于 OSCAR；SGLang 实现解码吞吐最高 3.75×。

为什么值得看 把量化与剪枝的耦合矛盾讲透并给出配对变换解，长上下文推理优化可直接借鉴。
