Dual DeltaNet: Value-Side Memory Reorganization for Linear Attention

arXiv(cs.LG) · 2026-10-28 · 论文PDF / 每日精选

研究问题 线性注意力/SSM 靠固定大小循环状态保持历史关联，delta 规则能减少干扰，但不考虑相关 value 特征在状态中的分布——能否从值侧重组内存？

方法 把状态视为 d_k 个地址存储 d_v 维值的库；在 Kimi Delta Attention 基础上加"值侧 delta 规则"（用当前值特征重排其占据的地址），形成双面 delta 规则；推导 chunkwise 并行训练算法与 rank-2 递推提升推理算术强度。

关键数字 与 KDA、GDN-2、Mamba-3 相比，DDN 在语言建模、零样本下游任务与检索上整体最强，训练/推理开销相对 KDA 仅小幅增加。

为什么值得看 线性注意力内存管理的机理级改进，代码开源，对高效序列模型有直接价值。
