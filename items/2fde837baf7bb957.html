LLM-Based Multi-Agent Collaboration for Constrained Multi-Objective Container Placement

arXiv cs.DC · 2026-10-08 · 论文PDF

研究问题 数据中心容器放置要同时最小化功耗、最大化亲和偏好，并满足多资源容量与反亲和硬约束。固定规则不适应动态集群，元启发式方法慢且易陷局部最优。

方法 LLM 驱动的四智能体闭环 ReAct 协作框架：功耗智能体与亲和智能体就竞争目标辩论，放置智能体用容忍门控仲裁（TGA）化解冲突，重排智能体以单调改进规则（MIR）做放置后精炼；所有智能体只在环境提供的确定性、可行性过滤后的候选表上推理，天然满足硬约束。

关键数字 Google Cluster Trace（100 应用、25 机器）上：较功耗贪心基线功耗低 8.36%、亲和度高 39.30%；消融显示多轮辩论、TGA、MIR 任一移除都会同时恶化两项指标。

为什么值得看 多智能体辩论 + 可行性过滤的组合让 LLM 调度决策既灵活又不越界，是 LLM-for-系统优化的一个清晰范式。
