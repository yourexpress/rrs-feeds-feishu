ServerBench: How can your coding agents design specialized LLM serving systems?

arXiv · 2026-11-05 · 论文PDF / 每日精选

研究问题 编码 agent 能否自主设计"支撑自己运行的"专用 LLM 服务系统？现有基准未评测这一 agentic 系统设计能力。

方法 提出 ServerBench：agent 面向统一目标——"每美元收益"（延迟达标的每美元 GPU 成本可产出 token 价值），在会话依赖、延迟约束与正确性要求下协调实现与运维决策；用有状态回放保持会话依赖，独立验证器检查提交的系统；评测 11 个编码 agent 模型 × 3 种部署。

关键数字 Claude Sonnet 5.5 在 Gemma E4B 上达到 2.97 美元/美元，为 vLLM 参考的 4.87 倍；33 次运行中 22 次产出通过验证的系统，13 次超过最强基线；三个发现：高价值设计协调容量提升与负载选择、agent 通过任务相关实验解读性能反馈、可靠交付需验证优化引入的执行路径。

为什么值得看 把"agent 写服务系统"变成可量化基准，且给出性能-成本权衡下什么样的设计决策真正有效。
