DASC: Decay-Aware State Compression for Hybrid Linear-Attention Serving

arXiv（Yanqi Yu 等，cs.LG） · 2026-08-31 · 论文PDF

研究问题 混合线性注意力架构（GDN / KDA 等）显著抑制 KV 增长，但原地 recurrent state 更新让前缀复用必须存 state checkpoint，完整存储又带来内存压力与重复 prefill——checkpoint 能否压缩？

方法 分析 Gated DeltaNet 与 Kimi Delta Attention 的衰减结构，发现不同 head/通道保留前缀信息的时间尺度差异显著（retention horizons）；DASC 据此从模型权重推导保留期、选出长保留期 state unit 打成 ragged checkpoint，并在 TP rank 间均衡；复用时对省略单元零填充或有界后缀重放。

关键数字 Kimi-Linear 上保守配置接近全缓存精度，KDA 状态 checkpoint 压缩 2.63 倍；固定内存预算下平均 TTFT 降 42.6%、输入吞吐升 68.4%；Qwen(GDN) 呈现同样趋势。

为什么值得看 线性/混合注意力 serving 正热，DASC 是首个系统化处理其 state checkpoint 压缩的方案，且直接面向 TP 推理引擎落地。
