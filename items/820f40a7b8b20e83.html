PATTON: Enabling Commodity PIM for Production LLM Serving

arXiv（Hangyeol Kim 等，cs.AR） · 2026-09-10 · 论文PDF / 每日精选

研究问题：PIM（存内处理）只能加速 memory-bound 的 decode attention，而生产 LLM serving 引擎要动态分配、填充、共享、缓存、回收 KV 块——在商用 PIM 上支持这套生命周期，Value cache 面临"GEMV 效率 / 单 token 写效率 / 内存容量"三者的根本冲突。

方法：PATTON：在商用 PIM 上解决物理内存分配、块到地址映射与命令生成，支撑 KV cache 全生命周期管理。

关键数字：见原文实验部分。

为什么值得看：PIM 从"加速单一算子"走向"生产级 serving"的系统性设计，体系结构方向的高价值参考。
