Coordinated Mixed-Precision KV Cache Quantization for Efficient LLM-based Multi-agent Systems

arXiv cs.LG · 2026-11-06 · 论文PDF / 每日精选

研究问题 LLM 多智能体系统中多个 agent 的 KV cache 同时驻留内存成为瓶颈，各模型独立做量化会忽略不同 agent 的精度需求差异，损害集体推理。

方法 提出 CoMixKV 协同混合精度 KV 量化框架：在线敏感度估计（基于近期 query/key/value 的局部注意力误差界，无需校准数据、试量化或额外模型前向）+ 共享内存预算下的跨 agent 联合位宽分配；分配随 agent 启停与新观测动态刷新，只作用于新量化块。

关键数字 平均 3-bit 下 Gemma-4-31B-it 上准确率 68.35%，超过最强量化基线 0.59%；Qwen3-32B 上峰值 KV cache 内存降 32.08%，相对 FullKV 推理加速 1.38x。

为什么值得看 首个在共享内存预算下跨同时驻留 agent cache 联合分配精度的混合精度 KV 量化框架，多智能体推理优化的新维度。
