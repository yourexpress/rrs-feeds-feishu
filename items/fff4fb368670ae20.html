MonoMoE: An Efficient Fused Mega-kernel for Quantized MoE Decoding

arXiv（Yu Gong 等，cs.AR） · 2026-08-19 · 论文PDF

研究问题：MoE 解码阶段的 token-major 组织在少 token 命中每个专家时产生 tile padding、短命 grid 与多阶段暴露——如何重做 kernel 组织？

方法：权重大头（weight-major）持久化 megakernel：完整 decode-step token tile 放在张量核细粒度 N 维，CTA 按专家权重 tile 划分；持久 grid 一次启动融合路由、top-k、量化、两段专家投影、激活与归约，warp specialization 重叠辅助工作。已集成 vLLM，开源进 FlashInfer 仓库。

关键数字：H200 上完整 routed-MoE 算子比 vLLM Triton Grouped GEMM 最高快 1.54×；比 FlashMoE-FP8 快 2.20–3.84×；FP8 模型端到端单 token 时间最多降 18.7%，精度保持。

为什么值得看：MoE 解码 kernel 的范式级优化且立即可用，推理侧工程直接受益。
