MCP-GRANITE Benchmark: GRANularity Interface TEsting for MCP-Based LLM Agents

arXiv (cs.DC) · 2026-09-22 · 论文PDF

研究问题 LLM agent 通过 MCP 等标准化协议使用工具时，工具接口设计——功能如何被分解为工具——成为影响 agent 能否选对工具、构造有效参数的关键因素；在边缘/IoT 场景下尤其重要（资源受限、模型规模受限）。

方法 公开 MCP-GRANITE 基准框架，把工具接口粒度作为受控变量；81 个多步场景覆盖 9 个域、4 个粒度级（从细粒度原始工具到单一工具）；评估 9 个本地部署模型（268M–20.9B 参数）、共 8,748 次试验。

关键数字 4 工具接口最优：任务完成度比细粒度原始工具高 16.4%、比单一整体工具高 33.6%，参数准确率近翻倍；3.2B 模型在最优粒度下表现超过 20.9B 模型在错配粒度下的表现。

为什么值得看 把「工具粒度」实证为 MCP agent 的关键设计维度；对边缘/IoT 部署 LLM agent 的工程决策有直接指导。
