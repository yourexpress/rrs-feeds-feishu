Block Sparse Flash Attention

arXiv / Daniel Ohayon 等 · 2026-09-29 · 论文PDF

研究问题 LLM 长上下文推理/多文档任务受注意力二次复杂度制约——能否在保持质量的前提下做训练无关的注意力加速？

方法 提出 Block Sparse Flash Attention（BSFA），FlashAttention 的即插即用替代：先算精确 query-key 相似度选每个 query 的 top-k 重要 value 块，再把逐块最大分数与校准阈值比较，跳过约 50% 被剪块的运算与内存搬运；只需一次性在小数据集上校准逐层逐头阈值，提供 CUDA kernel。

关键数字 Llama-3.1-8B 上 LongBench 端到端最高 1.13× 加速、精度仅降 1.1%；Needle-in-a-Haystack 最高 1.24×、精度降 1%；注意力 kernel 本身最高 1.38×；与 SpargeAttention、MInference、FlexPrefill、XAttention、BLASST 五个基线对比，并在 Qwen2.5-7B、A6000/H100 上验证。

为什么值得看 训练无关、精确选块而非预测重要性，长上下文推理加速可直接落地。
