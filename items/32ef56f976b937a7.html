MegaOps: A Kernel Overlapping Framework with PyTorch-like Modularity and Megakernel Performance

arXiv cs.DC · 2026-11-12 · 论文PDF / 每日精选

研究问题：kernel-per-operator 范式的整核依赖屏障使 SM 空闲、计算通信串行化、无法跨 kernel 预取；megakernel 融合消除屏障但牺牲模块化——能否兼得？

方法：MegaOps 把依赖 kernel 放到独立 CUDA streams，按生产者写入/消费者读取的中间张量 tile 粒度强制依赖；采用相同数据 tiling 的任何两 kernel 无需修改即可组合。

关键数字：Llama3/Qwen3 在单 H100/A100/L40 与 4xA100/8xH100 多卡评估；匹配手调 ThunderKittens megakernel 吞吐，decode 吞吐 1.09-1.10x、prefill 0.98-1.10x 对比最佳基线，且复用现成 Triton/cuBLAS/cuDNN kernel。

为什么值得看：模块化与 megakernel 性能兼得的框架设计，工程落地价值高。
