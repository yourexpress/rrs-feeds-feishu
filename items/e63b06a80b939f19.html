io_uring in Oracle Database: A Hybrid Storage I/O Architecture at Production Scale

arXiv · 2026-09-19 · 论文PDF

研究问题 如何把 io_uring 引入生产级多进程 RDBMS（Oracle Database）的存储层。

方法 每进程独立 ring 上下文消除进程间同步；共享缓冲区注册机制（已进入 Linux 主线内核）；出错时透明回退 libaio；最终采用混合架构：同步读写保留 pread/pwrite，异步批量 I/O 用 io_uring。

关键数字 Oracle 26ai 内部构建评测：TPC-C 吞吐持平、服务器 CPU 利用率降 1.2 个百分点；TPC-H 单查询 CPU 降 8.5%（几何均值）；纯写路径单次写 CPU 降 29%、吞吐升 34%；OLTP 同步读无改善、超大 I/O 下 CPU 反升。

为什么值得看 少见的生产级 io_uring 集成实录，「收益集中在异步批量 I/O」的结论对数据库与存储引擎选型有直接参考价值。
