Seamless Deployment of Machine Learning Inference at the Far Edge: An Empirical AWS IoT Greengrass Architecture for Industrial Predictive Maintenance

arXiv · 2026-10-14 · 论文PDF / 每日精选

研究问题 工业预测性维护的云中心架构把全部遥测回传云端，付出时延、带宽与韧性代价。

方法 基于 AWS IoT Core + IoT Greengrass v2 构建混合云边架构：边缘本地机器学习推理 + 选择性云同步；在真实 AWS 设施上部署纯云基线与混合架构两种配置并实测对比。

关键数字 云回传带宽减少 86.8%（每 200 读数窗口 63.6 KB 降至 7.2 KB），决策时延降低 256 倍（云端往返 23.1 ms 对本地 0.09 ms）；边缘无云参与仍保持异常类 F1 0.84 与 91% 召回率。

为什么值得看 Greengrass v2 预测性维护少见的端到端实测，带宽与时延收益都给了明确数字，工程参考价值高。
