SPMW: A Grid-Based Programming Model for Scalable Accelerator Design

arXiv cs.PL · 2026-11-06 · 论文PDF / 每日精选

研究问题：现代加速器靠规律性硬件结构复现计算获得高性能，但设计工具常用顺序程序或扁平化模块表达，遮蔽共享模式、导致重复编译——如何让网格规律性贯穿整个编译过程？

方法：提出 SPMW（Single Program, Multiple Connected Work Units）网格化编程模型，把网格规律性作为一等抽象，解耦局部工作单元行为与网格连接、数据投递。Python 前端 + MLIR 编译器，每种 kernel 配置只综合一次供多个硬件实例复用；支持并行编译与函数仿真加速设计迭代。

关键数字：32×32 脉动阵列的 GEMM 延迟相对 AutoSA 降 4.36×，kernel 到 RTL 并行编译快 619×；FFT 延迟比 HP-FFT 低 2.65×；mini-TPU 上并行函数仿真比 Vitis HLS C 仿真快 18.4×；五个编码 agent 用 SPMW 比 SystemVerilog 少用 7.51× token。

为什么值得看：首个在编译全流程保留规律性的加速器编程模型，同时利好硬件设计迭代与 agent 生成。
