Evaluating Inference Compute for Generative AI: A Framework for Enterprise Workloads

arXiv cs.AR · 2026-10-08 · 论文PDF

研究问题 LLM 部署从单轮补全转向 agent 轨迹（规划、调工具、测试时推理），颠覆了推理硬件经济学：对话服务靠大批次摊薄权重读取，而 agent 轨迹顺序依赖、等效 batch=1，单 token 解码延迟（TPOT）主导任务完成时间。

方法 用 roofline 分析与闭式 episode 延迟模型论证：该范式青睐权重驻留片上 SRAM（Cerebras WSE-3/3T、Groq/NVIDIA LPU）或编译器管理分层内存（SambaNova SN40L/SN50）的加速器；并提出四层评估框架（硅片、服务系统、agent episode、企业），含 goodput@SLO、单成功 episode 成本等指标、六任务族基准协议与 TCO 模型。

关键数字 逐步可靠性随轨迹长度指数复合——2% 的单步失败率即可抹掉 20 步 agent 的 2 倍解码优势；文中性能数字均公开并标注证据等级，另提出 7 条可证伪假设。

为什么值得看 少见地把"agent 时代的推理硬件选型"系统化：token 吞吐排名很可能与长程任务的单成功任务成本排名背离。
