Physically Partitioned KVCache Format for CPU--GPU Load Balancing in MoE Inference

arXiv（Enda Yu 等，cs.DC） · 2026-09-13 · 论文PDF

研究问题：单卡长上下文 MoE 推理必须把 KVCache 溢到 CPU，而「传回 GPU 算注意力」与「CPU 原地算」要求相反的物理状态，现有 KVCache 抽象只有存储语义，无法表达动态负载均衡。

方法：InplaceKVCache 在写入时即固定每字节的物理驻留，按设备亲和性与访问模式两维划四区，把负载均衡变成纯调度问题；WriteScope 沿序列维划分 CPU/GPU 份额，用可移植 roofline 模型加在线反馈随序列长演化定最优 CPU 份额。

关键数字：32GB 显存下在 3 个 MoE 模型（DeepSeek-V2-Lite、Qwen3-30B-A3B、Mixtral-8×7B）支持 100 万 token 聚合规模推理；长上下文（≥8K）几何均值加速 A100 上 1.5–2.5×、V100 上 1.4–1.7×，而 vLLM、SGLang、KTransformers 即使 KV 预算翻倍也跑不动。

为什么值得看：单卡百万 token MoE 推理的硬核系统工作，「写时定驻留」的抽象设计很漂亮。
