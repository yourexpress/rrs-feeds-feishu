Compiling Linear Datalog to SQL for Program Analysis

arXiv（Amir Shaikhha 等，cs.DB） · 2026-09-05 · 论文PDF

研究问题：Datalog 是表达静态程序分析的利器，但近年递归 SQL 引擎进步显著——现代关系引擎能否直接作为 Datalog 求值后端？

方法：提出一套编译框架，将 Linear Datalog 程序经中间语言 Midlog 翻译为等价的递归 SQL，并自动恢复函数依赖暴露为 schema key，解锁数据库引擎的标准查询优化。

关键数字：Umbra 后端 8 线程下几何均值加速 5.46×（最快接近一个数量级）；DuckDB 单线程与 Soufflé 持平、8 线程仅 0.68×；生成的 SQL 无需任何引擎修改即可运行在 7 个数据库系统上。

为什么值得看：为"用通用数据库引擎跑大规模程序分析"给出可行性与边界证据，也指出了关系引擎完全支持 Datalog 还缺什么。
