Distance-KV: Exploiting Relative Distance for Efficient Long-Context Inference

arXiv (cs.LG) · 2026-09-26 · 论文PDF

研究问题 LLM 推理的内存与解码时延随上下文长度快速增长；KV cache 压缩方法按 token 重要性或跨头 attention 差异选择性保留，但忽略了检索能力随相对距离显著变化这一结构。

方法 提出 Distance-KV：在层、注意力头与相对距离的联合空间学习静态 KV 保留模式；模式在冻结语言模型下离线学习、跨输入复用，无需在线重要性打分即可剪枝压缩 KV cache。

关键数字 三个骨干模型、四个长上下文基准上整体最优，RULER 128K 上超过最强压缩基线最多 9.3 点；Llama-3.1-8B-Instruct 128K 下 KV 内存降 65.4%、相对 Dense 解码加速 1.66×。

为什么值得看 把"相对距离"确立为长上下文检索的结构性维度，为更高效的推理方法设计提供新思路。
