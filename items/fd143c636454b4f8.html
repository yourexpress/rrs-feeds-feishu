ResidualKV: Residual-Based KV Cache Compression for Efficient Long-Context Inference

arXiv / Jitai Hao 等 · 2026-09-30 · 论文PDF

研究问题 长上下文推理两大耦合瓶颈：KV 缓存内存随上下文线性增长、注意力计算平方增长；现有方法常顾此失彼（不可逆驱逐/全缓存保留/全历史重建）。

方法 提出 ResidualKV：把 KV 缓存分解为全局检索引用的稀疏集 + 其余 token 的紧凑量化残差码，配合稀疏注意力按需重建；动态步长调度把引用增长从线性压到近似对数。

关键数字 Llama/Qwen/LLaVA-OV/Qwen3-VL 上仅用 13%-16% KV 存储与 30% 注意力计算维持近全缓存性能（LongBench）；多模态匹配预算下 8%-10% 存储 + 10% 计算；解码加速最高 1.5x（含 KV 量化）与 3.4x（不含）。

为什么值得看 证明全局跨 token 冗余可支撑精确、省内存又省算力的长上下文推理。
