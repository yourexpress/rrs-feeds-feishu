Denoising Blocks, Not Tokens: Efficient Compressed Continuous Diffusion with Branching Token Realization

arXiv cs.LG · 2026-10-09 · 论文PDF / 每日精选

研究问题 扩散语言模型每步仍按 token 维护生成状态，序列多长状态就多长，限制了并行生成带来的吞吐收益。

方法 Branching Latent Diffusion（BLD）：利用连续 DLM"一个连续状态可表多个 token"的自由度，把 1024 token 压成 64 个块潜变量（16×）；每个潜变量由局部自回归分支解码、所有分支并行；潜变量分组生成、以已生成组为条件。

关键数字 同 GPU 端到端：生成 FLOPs 降低 80× 以上，吞吐比同规模 ELF-L 基线高 6× 以上；相比自回归基线吞吐高 6×+、延迟低 4×+；局部流畅度与多样性保持竞争力，长程一致性仍是挑战。

为什么值得看 把扩散从 token 级状态搬到压缩潜序列，带来数量级效率提升，代表了 DLM 架构的新方向。
