The Redis Guy Wrote a Local LLM Engine That Refuses to Be General. That's Why It Works.

DEV Community（作者 Ashraf） · 2026-10-03 · 技术博客 / 每日精选

核心话题 Redis 作者 antirez 开源本地推理引擎 ds4，主动走「窄而深」路线，两周收获约 23k stars。

要点 只支持少数模型（DeepSeek V4/V4.1 Flash、GLM 5.x、Qwen 3.8 Flash Next），且必须用项目自产 GGUF；MoE 路由专家压到约 2bit 非对称量化、敏感部分保高精度；KV cache 压缩并按 prompt hash 持久化到 SSD 续用；约 95GiB 的 n-gram 表直接磁盘读，使约 42GiB 权重在 64GB Mac 上可行；服务暴露 OpenAI/Anthropic 兼容 API。

关键数字 65K 上下文下 Mac 生成速度从 39 降到 27 t/s；独立报道 M5 Max 约 35 t/s。

为什么值得看 「反通用化」把加载、KV、工具调用、HTTP 服务整体调通，是本地长会话 agent 降本的实用样本。
