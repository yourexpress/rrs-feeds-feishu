Building always-on agents

Anthropic · 2026-11-13 · 技术博客 / 每日精选

核心话题：Always-on agent（常驻代理）的架构原语——它如何被事件唤醒、跨会话保持状态、主动行动。

要点：常驻代理并非真的"永不停机"，而是大部分时间休眠、周期性被唤醒执行 run；每个 run 在 session 内完成一次工作并保存状态。外围架构由五个原语构成：事件收件箱（inbox，事件先入持久队列再由 worker 取走，避免并发竞争与崩溃丢事件）、定时器、记忆、权限、发件箱（outbox）。官方建议一个用户一个 inbox，事件按来源唯一 ID 去重。

关键数字：在长视野编码基准上，Opus 5.5 每解决一个任务的成本比 Opus 5 低 78%，而典型负载只低 40%——模型智能变便宜是常驻代理复兴的主因。

为什么值得看：Anthropic 官方工程指南，把"常驻代理"从概念拆成可直接落地的五件套架构，做主动型产品可直接照抄。
