Validating Hybrid-State Cache Recovery for GLM-5.3-Flash with vLLM and LMCache

arXiv（Frank Li，cs.DC） · 2026-09-14 · 论文PDF

研究问题 混合架构语言模型的外部缓存传输可能"成功"却从不一致状态恢复——KV 与循环状态错位时服务照常输出，错误隐蔽。

方法 在 45 层 GLM-5.3-Flash（RedHatAI NVFP4 量化版）上以 vLLM + LMCache、四路张量并行复现一个完全命中恢复失配（恢复全 prompt 状态但调度器少记一个 token），用严格前缀查找对齐恢复，再以共享计算校正、匹配检查点调度、固定每 rank 内核配置建立数值对照。

关键数字 九长度串行负载中与修改后重算对照的一致率从 34/36 提升到 36/36（每条 64 个 token ID）；72 对 256-token 续写全部通过；120 请求串行性能研究中 CPU 重载使首 token 时间降低 46%~64%、总请求时间降低 1.9%~7.0%。

为什么值得看 混合状态模型缓存集成的排错范本，作者明确划出证据边界（单模型版本、受控配置），工程态度可信。
