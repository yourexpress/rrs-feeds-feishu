Beyond Selection: Token Parameterization for Extreme Visual Token Compression

arXiv / Rui Zhong 等 · 2026-09-29 · 论文PDF

研究问题 视觉 token 压缩能提升 VLM 效率，但在极端压缩预算下，token 剪枝会破坏视觉 grounding，而可学习 resampler 又增加参数量、注意力开销与训练复杂度——能否从"token 参数化"视角重做压缩？

方法 将压缩拆成两部分：(i) 基变换与结构化截断（保留子空间/可压缩性）与 (ii) 坐标组织（优化与跨模态对齐），形式化为两个耦合目标 compressibility 与 learnability；据此设计轻量四步编码器 Braco：变换基截断、输入无关的基-坐标嵌入、预算相关正交重参数化、轻量池化学得的空间残差 token。

关键数字 在 23×–64× 压缩下形成最优精度-效率前沿，144× 下仍具竞争力，达到 95.2% 精度、prefill FLOPs 相对未压缩上界降 84.2%–86.7%；相对先前方法精度持平或更高，端到端加速最高约 36%，压缩器延迟/FLOPs 低 16.6×/78.8×。

为什么值得看 极端压缩预算下"剪枝 vs resampler"之外的新路线，视觉 token 压缩选型可读。
