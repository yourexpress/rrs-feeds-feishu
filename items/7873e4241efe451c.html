Persistent Context Graphs for Efficient Memory Compaction in LLM Agents

arXiv / Jingbo Yang 等 · 2026-09-30 · 论文PDF

研究问题 长时程 agent 交互历史让记忆压缩成为必需：现有方法摘要历史或压缩 KV 缓存，常为保留信息增加模型计算；新用户请求会改变哪些历史重要，但 KV 过期后重估历史需重新编码。

方法 ReCAP：把注意力来源的重要性分数与消息间依赖链存进轻量持久上下文图；每个新请求把存储重要性与新请求相关性线索结合，沿依赖链选择消息与支撑上下文，选择过程不产生额外模型调用。

关键数字 相对 Codex 默认摘要压缩，Qwen3-Coder 与 gpt-oss 上压缩与冷恢复估计延迟降约 95%；SWE-Together 每次调用历史上下文约减半且任务质量相当；Lost-in-Conversation 代码任务比全历史准确率高 19.8 与 41.2 分。

为什么值得看 零额外模型调用的记忆压缩，延迟大幅下降同时任务质量保持甚至提升。
