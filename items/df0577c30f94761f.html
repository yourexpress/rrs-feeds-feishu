IsoMoE: Placement-Invariant Hybrid CPU-GPU MoE Inference with Lossless 12-bit Experts

arXiv · 2026-11-20 · 论文PDF / 每日精选

研究问题：混合 CPU-GPU MoE 推理把部分专家卸载到 CPU 以单 GPU 跑更大模型；专家放置随 GPU 空闲内存变化、应只影响速度，但现有混合引擎的贪心解码输出随放置改变（两设备算术不同）；且解码受 CPU 内存带宽限制。

方法：IsoMoE 保证输出与专家放置无关：GPU expert kernel 逐位重放 CPU kernel 的算术；内存布局让 CPU 用 AVX-512 点积指令高效计算无损 12-bit 专家；双 micro-batch 流水重叠 CPU/GPU 计算且不改输出。

关键数字：三种 MoE 模型上不同放置下输出逐位一致；每个设置都快于最强基线，平均解码加速 1.26×、最高 1.54×。

为什么值得看：可复现性（bitwise 一致）与速度兼得的混合推理系统，代码开源。
