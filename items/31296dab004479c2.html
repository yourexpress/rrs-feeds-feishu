Interactive Debugger for Performance Portable Python HPC Kernels

arXiv（Ivan Grigorik 等，cs.DC） · 2026-09-07 · 论文PDF

研究问题 PyKokkos 等框架把 Python 嵌入式 DSL 编译到多线程 CPU 与各类 GPU，但这类代码没有交互式调试器——开发者只能靠 print、框架断言或退回 CPU 执行（后者还可能掩盖设备特有 bug）。

方法 PKDB：首个面向 GPU/多线程 Python kernel 的交互式调试器，支持断点、单步、变量检查，不改源码、保持真实设备上执行；两个利用 Python 动态性的高阶能力：暂停中执行任意 Python 表达式或整个 kernel（live evaluation）、运行中热替换并重载 kernel（仅重编译该 kernel）。

关键数字 在 Intel/AMD/NVIDIA CPU 与 NVIDIA/AMD GPU 上实测开销有限，达到日常可用水平。

为什么值得看 补齐 Python HPC 生态长期缺失的调试基础设施，性能可移植 kernel 的开发体验会因此明显改善。
