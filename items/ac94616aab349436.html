PatchKV: Efficient KV Cache Recovery for Dynamically Edited LLM Contexts

arXiv (cs.DC) · 2026-09-23 · 论文PDF / 每日精选

研究问题：长时运行的 LLM agent 工作流经常修改上下文的中间片段但保留长后缀；改动后的因果历史与旋转位置使后缀的离线 KV 状态无法精确复用——全量重算浪费 prefill 工作，无差别复用又传播陈旧状态。

方法：PatchKV，profile 引导的后缀保留式修订恢复系统：把相邻上下文版本分解为精确前缀、更新段与对齐后缀；用离线的长度条件漂移模型预测编辑局部脏区，辅以从存储注意力中选出的稀疏非局部块，块取整为固定修复集；其余后缀块用冻结的逐块精度标签从 CPU 内存恢复，走反量化 + RoPE 校正 + KV 页放置的融合路径。

关键数字：三个模型 × 三个长上下文问答负载上，恢复 TTFT 平均加速 2.51–3.85×（相对全后缀重算）、1.26–2.06×（相对 CacheBlend）；9 个设置中 6 个 F1 持平或更高，其余差距在 1.36 分内。

为什么值得看：agent 反复改写历史是常态而非例外，这篇把"增量修 KV"做成了可部署系统。
