Characterization of Request and Token Energy Costs for LLM Inference Workloads on GPU Platforms

arXiv（Prabhu Vellaisamy 等，cs.PF） · 2026-08-28 · 论文PDF

研究问题：LLM 推理按 token 计费，但 GPU 能耗按推理窗口发生——只看「每 token 能耗」会得到什么误导性结论？

方法：提出分解式能耗模型：一次性 prefill 与生成启动成本 + 每输出 token 的边际步能耗；在 H100/H200 上对 dense 与 MoE 模型，按模型、阶段、batch、上下文、输出长度五维扫描请求级与 token 级能耗。

关键数字：Llama-3.2-1B 在 H200、batch-16、上下文 4K：输出从 10 增至 512 token 时，token 能耗从 7.46 降到 0.72 J/token，但总窗口能耗从 1.19 升到 5.93 kJ；10 token 输出下 batch-16 vs batch-1 的收益从上下文 512 时的 6.31× 缩到 4K 时的 1.17×。

为什么值得看：定量证明「降低单 token 能耗」与「降低请求总能耗」可能背道而驰，MoE 还会放大这一效应——能效优化必须双指标并看。
