Reorienting the Vector Axis: Restructuring FlashAttention for Long-Vector Processors

arXiv · 2026-10-21 · 论文PDF / 每日精选

研究问题 FlashAttention 及其后续工作几乎都面向 GPU；长向量处理器（单向量寄存器可容 512 个单精度数）上向量化哪条循环是一阶决策，GPU 内核移植后性能大幅损失。

方法 将 PyTorch CPU FlashAttention 移植到 2KB 向量寄存器的 RISC-V CPU 后提出两项技术：转置 score tile 与运行输出使 query 沿连续轴（单参数即可匹配机器向量长，且两类 reduction 消失）；把 softmax 多项式系数移入标量寄存器消除溢出。

关键数字 原移植仅达峰值浮点吞吐的 16.2%；两项技术联合使整核周期减少 1.84-2.08x（head=64），浮点利用率升至 29.7%，softmax 向量内存指令减少 78.7%；同设计 FPGA 评分更高，达 2.71x。

为什么值得看 非 GPU 长向量架构的 attention 优化稀缺，对 RISC-V/边缘向量处理器有直接参考。
