Decoupling Memory from Context: Structured Memory for Token-Efficient Test-Time Continual Learning

arXiv (cs.LG) · 2026-10-05 · 论文PDF

研究问题：LLM agent 在线部署需不断吸收领域知识、从经验中适应，但持续向共享上下文追加信息会带来 token 成本膨胀、上下文窗口受限与性能随上下文扩张而下降。

方法：统一形式化“上下文优化”，把记忆系统更新解释为对模型上下文的优化更新过程；提出 GraphMemory 轻量图记忆，累积、精炼、组织并连接可复用策略，每次查询只检索相关子图。

关键数字：有界检索下检索量随处理样本数增长保持恒定；与基线相比记忆构建 token 减少约 81–85%，下游性能相当。

为什么值得看：测试时持续学习的记忆设计有了原则性框架，检索成本恒定，对企业级 agent 落地实用。
