AgenticSizing: A Large Language Model-based Multi-Agent Framework for Analog Circuit Sizing

arXiv (cs.AI) · 2026-09-23 · 论文PDF

研究问题： 模拟电路尺寸设计（sizing）因巨大的设计空间和强性能折衷而极其耗时——LLM 多 agent 框架能否理解电路拓扑并协同优化？

方法： AgenticSizing 框架先分析电路拓扑、将网表分解为功能块和子结构并提取轻量设计知识；planner 协调多个 agent 做设计空间探索。

关键数字： 相比现有方法，核心优势在于显式的拓扑理解和知识复用，而不只是"盲调参数"。

为什么值得看： 超越简单电路模块的模拟电路自动化设计，多 agent 协作 + 拓扑理解是 LLM for EDA 的重要方向。
