Metal Sandbox: Isolated Execution and Command Scheduling for GPU Coding Agents on Apple Silicon

arXiv cs.LG · 2026-11-12 · 论文PDF / 每日精选

研究问题：Apple Silicon 上训练/评估生成 Metal kernel 的模型需原生 macOS 工具与并发 agent 会话，但会话在模型请求、开发命令与 GPU 执行间交替，GPU 大量空闲。

方法：Metal Sandbox 提供受限 per-instance 文件访问、原生命令执行与跨 Mac 命令级调度：并行命令并发，串行命令共享每节点执行槽，等待命令可迁移到可用 Mac 并把结果返回原 agent；集成 Harbor 支持任务执行与自动验证。

关键数字：四台 Mac mini M4 集中负载下命令吞吐 1.68x-2.05x；16 条静态 agent 轨迹估计 4 会话/节点持续吞吐增益 2.14x；动态调度降低平均工具等待 18.8%、批处理耗时 22.3%；开源。

为什么值得看：GPU coding agent 的调度基础设施，Apple Silicon 生态直接可用。
