Unified AI Gateway: A Framework for Joint Model Routing and KV Cache Management

arXiv（Jiaxun Lu 等，cs.DC） · 2026-09-07 · 论文PDF

研究问题 LLM 推理日益跨多个规模、能力、价格、供应商各异的模型，开发者要付两笔成本：模型选择与切换的集成成本，以及 KV cache 不可用/不兼容时的重建成本。

方法 定义并分析统一 AI 网关：边缘部署的 AI 流量枢纽，协调模型路由、KV cache 管理与算力放置；请求时在质量、延迟、成本、资源约束下联合选择目标模型、执行位置与 KV cache 动作；后台持续优化缓存的放置、复制、检索与生命周期；综合 KV cache 复用、压缩、跨模型映射等现有证据讨论集成挑战。

关键数字 8 种典型负载的分析级仿真：TTFT 加速 1.25–13.28×，输入成本收益 1.20–6.16×。

为什么值得看 把 KV cache 当一等公民纳入路由决策的系统视角，仿真收益可观，做 LLM 网关/推理调度的人值得读。
