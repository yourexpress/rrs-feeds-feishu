Native Block-Quantized Matrix Multiplication and Explicit K/V Residency with Dual-View Access for LLM Inference on RISC-V Vector Processors

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：LLM 推理中部分关键执行状态跨多条指令持续存在，难以在 RVV（RISC-V 向量扩展）以单条操作语义表达与利用。

方法：按数据状态生命周期定义特化边界，提出 Quantized Block Streams（QBS）与 Attention/KV Context（AKV），同时保持 RVV 可编程性：QBS 把原生块格式处理、块遍历、整数计算与有序 FP32 累加统一为单一执行流；AKV 维持本地 K/V 驻留、按计算方向提供对齐的操作数视图，注意力算术仍留在 RVV。

关键数字：cycle-accurate RTL 评估中，QBS 对投影计算与矩阵乘的几何平均加速为 35.68x 与 51.34x；AKV 解码注意力较 Tiled RVV 加速 1.45x；总面积 +12.65%；投影负载上每面积吞吐与能效分别提升 46.63x 与 19.78x；适用于多种块量化格式与不同注意力组织的模型。

为什么值得看：RISC-V 向量处理器上 LLM 推理的原生块量化 + 显式 K/V 驻留完整方案。
