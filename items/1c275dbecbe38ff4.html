Less is more: learning what to profile for GPU kernel optimization

arXiv(cs.LG) · 2026-10-27 · 论文PDF / 每日精选

研究问题 LLM 自动优化 GPU kernel 的效果取决于可用硬件信息；现有系统用预定义 profile 策略，把"该采集什么"排除在优化之外——更多指标一定更好吗？

方法 证明采集更多指标不单调提升优化效果，最有用的信息因 kernel 而异；理论分析表明异质 profile 效用下 kernel 条件化选择可胜过任何单一固定配置；AutoProfiler 从优化反馈学习确定性 profile 树（REWRITE/SPLIT 迭代精化）。

关键数字 KernelBench 上受约束 profile 预算下优于固定配置；树构建完成后任意 kernel 快速取 profile、LLM 重写器只调用一次。

为什么值得看 把"profile 什么"本身变成可学习维度，kernel 优化系统设计新视角。
