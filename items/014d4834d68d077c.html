MaskCoFT: Masked Co-Adaptive Fine-Tuning for Memory-Efficient MoE Inference

arXiv (cs.LG) · 2026-09-28 · 论文PDF

研究问题 MoE 语言模型常超出单 GPU 内存，专家卸载把多数专家放主机内存、按需加载，解码速度取决于每个 token 要取多少个专家；缓存与预取只能推进到路由允许的程度。仅路由器微调可重塑路由复用专家，但专家保持冻结、无法适应新路由送来的 token。

方法 MaskCoFT 提出掩码协同自适应微调：仅用交叉熵损失同时训练路由器与专家；微调时可学习二值掩码把每层 Top-K 路由限制到专家子集，专家适应被重定向来的 token；推理时学习到的掩码变成软先验重排专家，每个专家仍可选。

关键数字 对 Mixtral-8x7B（模拟每层 4 专家 GPU 缓存）与 DeepSeek-V2-Lite（12 专家）分别减少每 token 专家获取 23.7% 与 10.1%；真实卸载系统中每输出 token 时间最多降 16.4% 与 5.5%；九个基准平均精度高出基线 0.92 与 0.53 点。

为什么值得看 让专家与路由器一起适应卸载场景，在精度不降反升的同时显著减少专家搬运，是 MoE 服务优化的直接增益。
