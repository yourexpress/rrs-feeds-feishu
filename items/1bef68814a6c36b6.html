A Production-Grade, High-Efficiency Agentic RL Framework for Frontier LLMs with Validated Recipes

arXiv · 2026-10-14 · 论文PDF

研究问题： 主流 RL 框架在前沿 LLM 的 agentic 任务（工具调用、多轮交互、长程决策）后训练中日益笨重。 方法： 提出 LoongSage：agent 原生全异步 RL 框架，核心仅约 14K 行；基于 Megatron（分布式训练）与 SGLang（高吞吐推理），单一控制器进程编排、GPU 组件封装为 Ray actor；AgentFlow 统一白盒/黑盒 agent 执行，滑动窗口约束轨迹陈旧度，TransferMesh 按最快可用传输路由权重；Teacher Manager 支持多教师在线蒸馏且不占 GPU 内存。 关键数字： 核心约 14K 行代码；经四次完整训练运行验证，任务奖励稳步提升、训练-推理差距受控，异步管线消除同步空闲气泡。 为什么值得看： 轻量生产级 agentic RL 框架，直击采纳、调试与部署开销痛点。 阅读原文
