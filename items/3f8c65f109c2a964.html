A Simplified Layout Algebra for GPU Kernels

arXiv · 2026-10-09 · 论文PDF / 每日精选

研究问题：NVIDIA CuTe 布局代数的组合、补、除、积等运算被至少六个交互的适用性条件守护，这种复杂度是领域固有的还是表示选择的产物？ 方法：给出一个「每个布局都标明输入输出所在空间（逻辑/物理/线程值）」的简化布局代数：逻辑与线程值空间要求双射，物理空间只要求无别名（广播须显式标记）；组合条件简化为「f 的值域恰为 g 的扁平坐标集」，并证明当复合可化简为布局时存在最粗形式。用 OCaml 实现、在 Rocq 中证明判定过程正确。 关键数字：验证方式为在代数内重现 CuTe 的组合、补、除等运算，并据此重新推导 CuTe 的原子与使用模式（文中未给出运行时数据）。 为什么值得看：对写 GPU kernel 的人是「把 CuTe 讲明白」的形式化教材，也示范了如何用类型化空间消除库 API 的隐式约束。
