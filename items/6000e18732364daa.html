Windows 宣布「hybrid intelligence」平台战略（MAI Code 1.1 Flash 本地运行、MXC 沙箱 GA）

Microsoft · 2026-10-07 · 技术博客

核心话题：微软把 Windows 重新定位为「混合智能」平台，AI 代理按任务在本地或云端运行，并大规模引入开源权重模型。

要点：MXC（Microsoft Execution Containers）沙箱在 Windows 11 全面可用，可限定代理访问的文件与网络，代理须自证身份以便 IT 区分操作；已获 OpenAI Codex、GitHub Copilot、Replit、LM Studio 等支持；配套本地模型路线：MAI Code 1.1 Flash、Nvidia Nemotron、DeepSeek V4 Flash 上 RTX Spark 设备。

关键数字：MAI Code 1.1 Flash 137B 参数（6.8B 激活）、3-bit 精度、体积缩小近 80%、256K 上下文；Nemotron 70B+ 参数、2-bit 约需 20GB 内存。

为什么值得看：Windows 的代理安全基础设施 + 大模型本地化路线图，直接关系端侧 AI 生态走向。
