A fresh start after the A.I. hangover: After Microsoft struck out with many users over Recall, Copilot buttons in every app and the “Copilot+ PC” brand, the company is now declaring Windows a platform for “hybrid intelligence.” A.I. agents are meant to run either locally on the PC or in the cloud, depending on the task, protected by built-in security features. Alongside that comes the Surface Laptop Ultra, a notebook with Nvidia’s new RTX Spark chip that is available for preorder now.

Agents in a Sandbox

At the core of the announcement is the idea that Windows should be the most secure environment for A.I. agents. Agents run around the clock, use tools, write code and access files, often without anyone watching every step, Pavan Davuluri, Microsoft’s head of Windows, argues in the company’s announcement. To that end, Microsoft Execution Containers (MXC) are now generally available on Windows 11. These are sandboxes built into the operating system that let companies define which files and networks an agent can access. Every agent has to identify itself so that I.T. departments can tell its actions apart from those of the user. Rules can be rolled out across a company via Intune and Agent 365, although Microsoft concedes in the fine print that governance at scale may require additional services.

MXC is already supported by OpenAI’s Codex, GitHub Copilot, OpenClaw, Replit, LM Studio, Nvidia’s OpenShell and Unsloth. Anthropic’s Claude Code, Perplexity, Manus, Box and Raycast are among those set to follow. Meta’s agent Muse is also coming as a native Windows app with MXC integration. For mini PCs, which many people now use as always-on machines for agents, Microsoft promises setup in a few clicks instead of tedious configuration in the terminal, starting with OpenClaw.
