BitSparse: Compact Activation Storage for ReLU Feed-Forward Networks

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题 稀疏 ReLU/ReLU² 激活的回潮带来第三种训练显存优化机会：对激活缓存本身做无损压缩。

方法 BitSparse 是 GPU 驻留的无损压缩格式：压缩与重构由定制 Triton kernel 实现并融入 autograd 函数，反向传播时精确还原缓存；支持 BF16 与 FP8，可选符号位打包逼近理论压缩极限；另提出预分配缓冲系统，变长张量分配时避免主机同步。

关键数字 Modded-NanoGPT 与 Nemotron-H 上每 token 显存分别降 31% 和 30%，实用序列长度下开销不超过 1%。

为什么值得看 在重计算检查点与有损压缩之外新增一条无损、GPU 原生的训练内存优化路线。
