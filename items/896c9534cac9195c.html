Symphony for Text Generation: Benchmarking Clinical Note Generation

arXiv cs.LG · 2026-10-08 · 论文PDF

研究问题：环境式病历自动生成系统（ambient documentation）快速普及，但其产出的临床病历质量到底如何，缺乏严格刻画。

方法：发布 MedConv——300 例英语、丹麦语、德语多语种临床问诊数据集；结合 ACI-BENCH 基准，将临床 AI 平台 Corti 与两款基于通用 AI 的主流商用环境抄写软件对比。评测框架结合蕴含指标与基于 PDSQI-9 八个维度的 LLM 成对评判。

关键数字：Corti 的 API 化文本生成能力与领先商用抄写软件持平或更优；其可配置 API 能针对具体文书场景微调质量维度。

为什么值得看：为多语种临床文书生成提供了可复现的对照评测方法论，并公开数据集，对医疗 AI 落地的质量评估有直接参考价值。
