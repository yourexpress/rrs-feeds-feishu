GraMRAG: Orchestrating Multi-Agent Multi-Step Reasoning via Graph Memory with Reinforcement Learning

arXiv（Zhongyu Wang，cs.CL） · 2026-09-12 · 论文PDF

研究问题 多智能体 RAG 在复杂多模态推理上受限于推理深度与记忆结构，存在检索不足与「状态盲」（看不到自己已走过的推理轨迹）。

方法 GraMRAG：视觉-文本桥接推理统一多尺度实体裁剪与 ReAct 式视觉工具链；多模态记忆图把 agent 推理形式化为动态 DAG，显式建模动作-观测依赖以缓解状态盲、抑制冗余检索；TAPO（Topology-Aware Policy Optimization）利用图拓扑识别关键路径并定向剪枝，实现多步推理轨迹上的细粒度信用分配。

关键数字 在多个高难度多模态 benchmark 上持续超过现有基线，复杂长程推理达到 SOTA（摘要未给具体数值）。

为什么值得看 把 agent 记忆从「日志」升级为可优化的拓扑结构，RL 信用分配到节点级，设计完整自洽。
