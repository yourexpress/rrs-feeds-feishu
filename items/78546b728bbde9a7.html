TinySense+: Entropy-Aware CSI Compression for Scalable and Adaptive Wi-Fi Sensing

arXiv · 2026-11-06 · 论文PDF

Wi-Fi human pose estimation requires high-rate channel state information (CSI), making communication a bottleneck when sensing is offloaded from resource-constrained devices. Effective compression must therefore preserve pose information while accommodating different communication budgets. We present TinySense+, an efficient compression framework for scalable Wi-Fi-based human sensing with entropy-aware transmission and test-time rate adjustment. The framework uses a vector-quantized generative adversarial network to encode CSI into discrete latent indices shared between an edge device and a server. A causal Transformer predicts conditional index probabilities for arithmetic coding, while a differentiable rate-distortion objective balances expected code length, CSI reconstruction, and pose accuracy. Prefix-conditioned latent completion reuses the entropy model to infer an omitted suffix, allowing the transmitted prefix length to change without retraining the encoder. We evaluate the framework on MM-Fi and WiPose datasets and prototype it on Raspberry Pi and Jetson Nano devices connected to an RTX 8000 server.
