Dual-Cache Latent Space Communication between Heterogeneous Language Models

arXiv（Jiyao Liu 等，cs.AI） · 2026-08-20 · 论文PDF

研究问题：多 agent LLM 系统靠文本通信把自回归解码放上关键路径；现有 KV 翻译协议（C2C、LCF-X）或要求共享上下文，或仅压缩 sharer 单侧、无跨层联合记忆、且假设层数与 KV 几何匹配。

方法：XKV 三重解除限制：学习查询注意力池化双 cache；接收方对齐的层 token 自注意力加学习层映射调和不同深度；共享位置解码器让每个接收方 cache 位置按原生 KV 几何检索 per-head 门控残差。双模型冻结，仅训练翻译器。

关键数字：45 个数据集-模型对上宏观分最高；ROPES 较 LCF-X +4.6 EM/+4.2 F1；训练参数少 76%、翻译快 10.3x（5.8 vs 59.9ms），端到端较文本通信快 6.8x。

为什么值得看：异构模型潜在空间通信目前最完整的解法，多 agent 降延迟的硬选项。
