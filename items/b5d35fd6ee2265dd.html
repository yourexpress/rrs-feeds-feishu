UnsafeChecker: Finding Soundness Bugs in Rust Safe Abstractions

arXiv（Xizhe Yin 等，cs.PL） · 2026-09-09 · 论文PDF

研究问题 Rust 库常在 safe API 后封装 unsafe 裸指针操作，一处失误即破坏安全契约；现有工具不懂 Rust 契约或缺深度语义建模。

方法 UnsafeChecker 静态分析：MIR 上流敏感抽象解释，维护所有权/有效性/布局三元状态，报指令级 UB 与逸出 safe API 的契约违例。

关键数字 RustSec 基准检出 32 个 CVE、覆盖 36/53 个 bug（召回 67.9%、精度 51.6%）；crates.io 新发现 83 个 crate 的 114 个未知 bug，45 确认、27 已修复。

为什么值得看 有实战战果的 Rust 安全抽象检测器，底层库与供应链安全实用。
