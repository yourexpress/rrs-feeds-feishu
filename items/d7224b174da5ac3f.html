Kernel Autoresearch for Open-Ended Model Discovery

arXiv cs.LG · 2026-10-09 · 论文PDF

研究问题 自动核设计两难：固定语法保证有效性但限制搜索空间，无限制程序则不再保证有效性。

方法 Kernel Autoresearch：编码 agent 以程序写核，构造合约保证有效性，质量-多样性档案保留高表现核，新颖性筛选引导探索。

关键数字 压力测试中 22-58% 通过数值检查的 LLM 生成核在别的尺度/维度下失败；从十个酶速率律发现的核在五个未见机制上误差低于调优 ARD 与深度核；人工精化再降 5.7% 预测误差、7.8% 优化遗憾。

为什么值得看 开放式核发现的 agent 化框架，产出可解释、可复用的归纳偏置。
