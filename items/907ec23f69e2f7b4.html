Vision Token Pruning via Query-Vision Interaction Decomposition

arXiv(cs.LG) · 2026-10-23 · 论文PDF / 每日精选

研究问题 VLM 视觉 token 数量大导致推理成本高，现有基于 query 的剪枝多用注意力/动态启发式，未显式利用 query-vision 交互的底层结构。

方法 观察到 transformer attention 中 query/key 投影自然诱导的交互矩阵近似低秩、少数主导潜在模式承载 query 相关语义；据此提出 QViD，免训练的 query 感知视觉 token 剪枝方法。

关键数字 摘要未给出具体数值；图像与视频理解基准上、匹配 token 预算下持续提升性能，且在激进压缩区间增益最大。

为什么值得看 把低秩结构洞察直接变成免训练剪枝，VLM 推理成本优化的即插即用思路。
