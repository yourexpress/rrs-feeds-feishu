ECAS: An Edge-Controlled Agentic System for Validation-Gated Scientific Application Execution

arXiv（Baixi Sun 等，cs.DC） · 2026-09-13 · 论文PDF

研究问题：LLM agent 直连 HPC 会暴露凭据与执行权，不给权限又要人全程盯——如何在保留边缘控制的前提下闭环执行科学计算任务？

方法：ECAS 三分架构：云端 LLM 提方案与修复、用户控制的边缘代理掌凭据/状态/执行权并执行策略、HPC 系统计算。核心机制是验证门控执行：产物先过静态检查与小规模验证，失败用脱敏反馈触发修复，验证与策略全通过才放行目标规模运行。

关键数字：3 个科学应用、2 套 ALCF 生产系统、6 类注入故障下，闭环修复把成功率从 0/6 提到 6/6；验证门挡下全部 3 次目标规模失败；技能条件化把成功率从 4/6 提到 6/6。

为什么值得看：「云推理、边缘控权」的职责划分是 LLM agent 接入敏感基础设施的可落地范式。
