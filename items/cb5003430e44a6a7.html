MeltKV: Memory-Aligned KV Cache Compression via Variable-Bit Packed Vector Quantization for Long-Context LLMs

研究问题：长上下文 LLM 中 KV 缓存主导内存与推理延迟；现有向量量化可压到 sub-4-bit，但忽视内存对齐与解码速度。

方法：MeltKV 内存-延迟协同优化的 KV 缓存量化框架：内存对齐的可变比特索引打包，按分组 key 通道自适应位宽并在标准数据类型内紧凑存索引；head-wise 码本共享降低码本总量。

关键数字：KV 压缩至 sub-4-bit 级别；具体压缩率与加速数据见论文（摘要截断未给出）。

为什么值得看：长上下文服务的 KV 缓存压缩新路线，内存对齐与解码速度并重。
