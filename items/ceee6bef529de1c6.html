DynaTE: Accelerating Diffusion LLMs via Dynamic Token Execution

arXiv (cs.AR) · 2026-10-09 · 论文PDF / 每日精选

研究问题 扩散式大语言模型（dLLM）能双向并行细化、缓解自回归解码的串行瓶颈，但其并行迭代细化与面向顺序解码的 AR 加速器不匹配，现有 dLLM 加速器又把所有 token 一并保留执行，忽视各 token 细化价值与执行需求的差异。

方法 DynaTE 是软硬件协同架构，让加速器执行随解码中的 token 状态动态适配：跳过低价值 token 计算实现自适应执行，维度可重构 PE 阵列在不同活跃 token 模式下维持高利用率；通过 FLDD 在当前迭代内细化少量局部依赖 token 以减少去噪迭代轮数，Merge-Split-Merge 数据流隐藏串行开销；流式词表引擎交错处理 LM head 的多 token 流。

关键数字 在两个代表性 dLLM 上，比现有最先进 dLLM 加速器快 2.05–2.78 倍、能效高 2.99–3.93 倍；比 Jetson AGX Orin 快 2.55 倍、能效高 6.07 倍。

为什么值得看 dLLM 推理加速尚属早期，这是「按 token 状态动态调度」方向的代表作，做新范式推理硬件的同学值得细读。
