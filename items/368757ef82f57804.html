HiPerfCC-KVCache: Accelerating Confidential LLM Serving with Hierarchical KV Caching

arXiv · 2026-11-21 · 论文PDF / 每日精选

研究问题 分层 KV 缓存靠保留 GPU 外可复用状态减少重复 prefill，但 GPU 机密计算（CC）下受保护的传输可能抹掉收益。

方法 表征 Hopper/Blackwell 上批量 KV 拷贝在长时间 CPU 侧处理期间持有驱动锁、阻塞独立服务的机制；据此设计 HiPerfCC-KVCache：管理资源生命周期、有界备份提交间优先就绪 token 回读、辅助上下文共享 GPU staging 并行 KV 恢复；在 SGLang 中实现，不改硬件与驱动。

关键数字 H200 最高负载下输出 token 吞吐几何平均 1.74x（最高 2.72x），首 token 延迟平均降 36%、最高 59%；RTX PRO 6000 Blackwell 上几何平均 1.28x（最高 2.20x）。

为什么值得看 机密 LLM 服务场景的分层 KV 缓存，定量揭示驱动锁与传输并行瓶颈。
