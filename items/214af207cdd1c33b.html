KernelMosaic: An Open Dataset and Agentic Framework for CUDA Kernel Generation

arXiv cs.LG · 2026-11-10 · 论文PDF / 每日精选

研究问题：训练 LLM 生成高效 CUDA kernel 需要覆盖多样化计算需求与迭代优化的监督数据，这类数据如何系统化构建？

方法：KernelMosaic 开放数据集配对多样化 CUDA 任务与可验证实现及轨迹；人类引导审查 + 多样性感知选择，任务以自然语言描述、参考程序、数学规格及其交集表达；agentic 框架引导强 LLM 完成实现、正确性修复与性能优化。

关键数字：小开源模型 SFT 后 KernelBench L1/L2/L3 正确率从 4%/0%/0% 升至 88%/82%/16%；各层级快于 PyTorch eager 的任务占比均提升；轨迹监督显著优于直接响应。

为什么值得看：为 CUDA kernel 生成提供首个大规模、带验证轨迹的监督数据集，agentic 优化闭环可直接复用。
