OVAL: Output-Aware Local Page Bases for KV Cache Retrieval

arXiv cs.LG · 2026-10-06 · 论文PDF / 每日精选

研究问题 长上下文推理的注意力要扫不断膨胀的 KV cache；页稀疏注意力把每个 KV 页压缩表示后按 query 检索子集，但现有检索方法估计的是注意力分数或页相关度，其目标并不直接约束近似误差对值加权注意力输出的影响。

方法 OVAL：输出感知的页编码——从 key 与 value 的联合结构导出，同时保留准确检索所需的 key 信息；免训练，推理时无需额外的 value 相关统计，构建后存储开销与 decode 打分代价和仅 key 谱表示相同。

关键数字 摘要未给具体百分比；在长推理、长上下文理解与长生成基准上一致优于仅 key 谱基线，与近期 KV cache 压缩/检索方法相当，长推理基准上 avg@k 表现强，解码开销 modest。

为什么值得看 把 KV 检索目标从"分数估准"换成"输出误差别大"，视角正且工程代价不变，长上下文 serving 可直接借鉴。
