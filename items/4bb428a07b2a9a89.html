Introducing Claude Haiku 5.5

Anthropic · 2026-10-07 · 技术博客 / 每日精选

核心话题： Anthropic 发布 Claude Haiku 5.5，定位为有史以来最便宜、最快、能力最强的小模型，面向高并发、成本敏感任务。

要点： 主打摘要、压缩、数据库查询、分类等快速重复型负载，也适合作为 Opus 5.5 / Sonnet 5.5 的子代理处理编码工作；是首个支持可调 effort 档位的 Haiku 模型，用户可在成本与智能间取舍；对齐评估较 Haiku 4.5 大幅改善（失准行为更少、配合滥用意愿更低）；网络安全护栏比 Sonnet 5.5 宽松（放开更多防御性任务）但仍禁止渗透测试；同步把 Sonnet 5.5 缓存读价格减半。

关键数字： 平均运行成本比 Haiku 4.5 低约 75%；Sonnet 5.5 在多数 agentic 负载上随之便宜约 20%；10 万 token 以内的提示约占旧 Haiku 请求的 90%，是该定价最划算的区间。

为什么值得看： 小模型价格战再升级，agent 编排里"子代理层"的成本结构被重新改写，成本敏感型 agent 架构值得重新算账。
