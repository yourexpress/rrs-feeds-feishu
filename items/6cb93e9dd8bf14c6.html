PrismStencil: Transforming Stencil Computations into Matrix Multiplications

arXiv · 2026-10-14 · 论文PDF

研究问题 Stencil 计算是科学工程核心负载，Tensor Core 加速虽有新机会，但现有张量化方法冗余计算多、数据复用不足。

方法 PrismStencil 张量化算法：提出矩阵与 stencil 网格点的新型映射；多维向量映射适配 stencil 的多维数据依赖；统一 gather-scatter 张量化方案利用 Tensor Core 矩阵维度相对尺寸减少冗余；cross-product 数据复用机制利用相邻 stencil 更新的重叠增强复用。

关键数字 NVIDIA A100 上代表性 stencil 核平均加速 2.13×（FP64）、2.17×（TF32），对比 SOTA Tensor Core stencil 方法。

为什么值得看 把 stencil 高效搬到 Tensor Core 的系统化方案，对 HPC 数值内核加速有直接价值。
