In this paper we provide an introduction to some of the efficient features of the Raspberry Pi Pico (RP2) family of microconroller boards (RP2040 and RP2350). More exactly, we show how to use PIO (Programmable Input/Output) and DMA (Direct Memory Access) to program the RP2 boards for efficient DAC (Digital to Analog) and ADC (Analog to Digital) conversions. Using OP-AMPS (Operational Amplifiers) we also show how to build a minimal electronic frontend interface for signal input/output. Finally, we integrate all these components into a product, the O-SCOPE, which is a practical and easy to use oscilloscope and wave function generator. The RP2 component of the O-SCOPE is built using Micropython, while the user interface is developed using vanilla Javascript and it runs on the web browser of any computer, interacting with the RP2 board via the Web Serial API. The O-SCOPE web interface is hosted on GitHub Pages such that it is directly accessible everywhere using a web browser, such that no local installation is required.
