A Controlled Experimental Evaluation of Configuration and Cache Architecture in LLM Serving Engines

arXiv cs.DC · 2026-11-04 · 论文PDF / 每日精选

研究问题：多 agent LLM 应用跨请求重复大部分 prompt token，vLLM 与 SGLang 以不同粒度复用共享前缀缓存，默认部署基准显示巨大性能差距（通常归因于缓存）——但其他配置差异是否被混淆了？

方法：在 Kubernetes 上搭建可复现测试台与种子化多 agent 负载生成器，分别在厂商默认配置与对齐 chunked prefill 两种条件下对比两引擎；SGLang 两臂配置相同，作为跨独立部署的内部对照。

关键数字：默认配置下 vLLM 的中位 TTFT 最高达 SGLang 的 64x；对齐单一设置（chunked prefill）消除最大处 78% 的容量差距与 30%~67% 的延迟差距；剩余尾延迟优势为 2.4~6.4x，与缓存感知的等待请求排序一致。

为什么值得看：用受控实验拆穿「差距全归缓存」的归因，给出六条引擎对比建议，评测方法论价值高。
