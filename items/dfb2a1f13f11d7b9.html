Integrating a Python Dynamical core into ICON

arXiv（Mauro Bianco 等，cs.DC） · 2026-08-21 · 论文PDF

研究问题：地球系统模型向 exascale 迁移受制于单体 Fortran 代码库与维护繁重的编译器指令；高级 DSL 常因集成繁琐失败，Python 编排是否真有不可接受的 HPC 开销？

方法：用 GT4Py DSL 与 DaCe 数据中心优化框架，把 Python 版 ICON 动力核心无缝集成进原 Fortran 模拟代码；数据流优化与自动 kernel 融合从单一可移植 Python 源生成优化设备代码。

关键数字：生产级全球模拟中，Python 动力核心比高度优化的 Fortran+OpenACC 实现快 20–30%；耦合设置下总时间改善 10%。

为什么值得看：实测反驳「Python 必然拖累 HPC」的成见，全球气候建模现代化的可信路线。
