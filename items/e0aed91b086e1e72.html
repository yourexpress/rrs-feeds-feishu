One Size Does Not Fit All: Setting Inference Depth from the Questions a Deployment Actually Asks

arXiv（Jerry Kaplan，cs.CL） · 2026-09-12 · 论文PDF

研究问题：部署场景的 prompt 分布其实很窄（客服只看投诉、代码工具只看 Python），但每个 token 都付全模型算力。已知流量分布时，推理深度能省多少？

方法：冻结模型，在中间层挂一个小型 readout 提议 token，置信度测试决定提前退出还是跑完剩余层；只用模型自身输出做监督，按部署定制退出阈值。

关键数字：1.5B 模型半深度下，算术题 96% token 可提前退出、中文解释仅 8%；按部署校准阈值使退出率最高提升 59 个百分点；token 级保真度最高的配置下，60 道算术题全模型全对、早退只对 10–28 道。

为什么值得看：揭示 token 级保真度这一早退领域主流指标在有标准答案的任务上会严重误导，且「按部署调阈值」是唯一值得的定制——端侧小模型推理的直接参考。
