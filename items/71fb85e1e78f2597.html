Process then Retrieve: Investigating the Origins of the Modality Gap in Vision-Language Models

arXiv cs.LG · 2026-07-20 · 论文PDF

研究问题 视觉语言模型（VLM）中模态差距（modality gap）的起源是什么？论文考察嵌入层各模态 token 的信息密度差异是否造成这种不平衡。

方法 通过机制分析对比文本与视觉 token 的语义密度，观察早期层处理顺序；用视觉 token 位置替换为语义上最接近的文本 token，测量早期层注意力的变化。

关键数字 摘要未给出具体量化指标；核心发现是文本 token 以远低于视觉 token 的语义密度进入模型，驱动早期层先处理文本表征再与视觉融合。

为什么值得看 为 VLM 模态差距提供了可操作的机制解释，对改进多模态推理架构有直接参考价值。
