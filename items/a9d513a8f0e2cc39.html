Bringing Elastically Deterministic Data Loading to TorchTitan with Zephon（补录：10-16 发布，昨日窗口漏检）

PyTorch Blog（Meta） · 2026-10-16 · 技术博客 / 每日精选

核心话题 普通数据加载器会随 GPU 数量改变数据顺序，使消融实验与跨规模续训不可复现；Zephon 把「弹性确定性」数据加载带进 TorchTitan。

要点 在训练作业内即时完成 tokenize、打包、shuffle 与混比，利用空闲 CPU；从 16 卡 step-150 checkpoint 换到 8/32/64 卡续训，每个全局 batch 的 SHA-256 与基线完全一致，loss 曲线重合。

关键数字 标准加载器下 8–64 卡的分差最高 0.82 分（DCLM Core v1）与 0.64 分（FineWeb 套件），约为数据策展评估阈值的 4 倍；Zephon 将其压到 0.05 与 0.011 分。

为什么值得看 GPU 数量是消融里的隐性混淆变量，是大规模训练团队的共性痛点；在 agent 并行实验与故障迁移时代尤其重要。
