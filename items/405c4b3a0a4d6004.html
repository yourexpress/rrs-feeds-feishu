LifeVal: Evaluating AI Model Performance on Personalized Agentic Consumer Tasks

arXiv · 2026-11-05 · 论文PDF / 每日精选

研究问题 现有 agent 评测集中在编程等任务，缺少对"个性化数字超级助理"最该自动化的日常消费任务的覆盖与度量。

方法 构建 LifeVal 基准：覆盖 148 类消费任务（理财、搬家、求职、找托儿等），通过 3800+ 消费者代表性样本的支付意愿调查构建活动分布，并交叉对照美国时间使用调查等数据；任务用真实 ChatGPT 对话与记忆、参考文件、个人情境做个性化，创作者须通过专业门槛（真实完成一年以上）并撰写 rubric，任务须通过至少三轮人工质控。

关键数字 覆盖 148 类任务，对应年支付意愿超 1.7 万亿美元；样本 3800+ 消费者；每任务至少 3 轮人工质控。

为什么值得看 首次以经济价值（支付意愿）锚定 agent 评测任务选择，把"个人助理"类 agent 的评估从玩具任务拉到真实生活场景。
