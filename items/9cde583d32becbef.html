KVE-KD: Key Visual Evidence-Guided Knowledge Distillation for Vision-Language Models

研究问题：视觉-语言模型蒸馏中，现有方法对视觉 token 施加统一监督或依赖静态 token 选择，会把任务相关线索与背景噪声混淆，损害跨模态推理。

方法：提出 KVE-KD，由教师动态定位任务相关视觉 token 并聚焦特征蒸馏：以预生成前的最终文本 token 作为统一语义锚，通过迭代移除视觉 token 贡献分析锚表示变化来定位目标跨模态融合层；在该层用锚条件注意力分布对视觉 token 排序，以归一化熵选出关键视觉证据引导蒸馏。

关键数字：六个基准上超越 SOTA 跨模态蒸馏方法，复杂推理与细粒度视觉理解任务增益尤为明显，且不引入任何推理期开销。

为什么值得看：动态聚焦任务相关视觉证据、抑制背景噪声，是无推理开销的轻量蒸馏改进。
