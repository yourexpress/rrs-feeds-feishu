Self-Reflection Fine-Tuning: Enhancing Agent Security against Prompt Injection Attacks from Failure Experience

arXiv cs.LG · 2026-10-06 · 论文PDF

研究问题：LLM 智能体在工具增强环境中高度依赖外部输入，易受提示注入攻击劫持任务目标；现有静态对齐难以泛化到自适应攻击。

方法：提出自反思微调（SRFT）——让智能体在被注入攻击破坏的轨迹上从自身失败经验学习，由专家模型生成对比"不安全 vs 最优"行动的结构化自反思推理；基于 Llama-3.1-8B-Instruct 与 Qwen3-8B 实例化为 SR-Agent。

关键数字：在静态与自适应提示注入基准上显著降低攻击成功率，同时保持任务性能，并展现对自适应攻击的强泛化。

为什么值得看：从失败经验中反思学习为构建安全鲁棒 LLM 智能体提供了新训练范式，代码已开源。
