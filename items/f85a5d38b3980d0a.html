01WHAT IT SOLVES

这个项目解决什么问题？

llama.cpp 定位为通用 LLM 与 VLM 推理运行时，底层基于 ggml 张量库，以纯 C/C++ 无外部依赖的形式提供。其核心角色是本地与边缘推理的事实级引擎，与上游 PyTorch/Hugging Face 等训练生态互补，常被 Ollama、LM Studio、Jan 等本地工具链作为底层依赖。通过 1.5 至 8 位整数量化、CPU+GPU 混合推理以及十余种硬件后端，让大模型可以在从树莓派到服务器集群的多样设备上运行，同时提供与 OpenAI 兼容的 HTTP 服务接口与 GBNF 语法约束，便于嵌入到应用工作流中。

02CORE CAPABILITIES

核心能力

纯 C/C++ 实现且无外部依赖

以单库形式提供推理能力，便于嵌入、移植与裁剪

多硬件后端覆盖

支持 Apple Silicon、CUDA、HIP、Vulkan、SYCL、OpenCL、RISC-V、CANN 等十余种平台

1.5 至 8 位整数量化

提供多种低比特量化方案以降低显存占用并提升推理速度

CPU+GPU 混合推理

模型参数超出显存时可由 CPU 补足，扩展可运行模型规模

内置类 OpenAI 的 HTTP 服务与 GBNF 语法

通过 llama-server 提供本地 API 接入与结构化输出能力
