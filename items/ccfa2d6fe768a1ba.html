Dissecting GPU Utilization for LLM Inference on Nvidia Hopper

arXiv（Mohammad Siavashi 等，cs.PF） · 2026-09-11 · 论文PDF

研究问题：单一 SM 利用率百分比会把多个机制压成一个数，让 LLM 推理看起来"算力打满"却掩盖真实效率，decode 阶段尤其严重。

方法：在 H100 NVL 上用 FlashAttention-3 与 cuBLASLt 跑 vLLM，扫冷 prefill、热 prefill、decode 三阶段及序列长度、batch 两个维度；指出 Hopper 的 bf16 GMMA 以固定 64 行矩阵片段执行，小 batch decode 的真实 token 行只能填充片段的一小部分。作者用八个经计数器验证的视图（各锚定一个 NCU 计数器或显式公式）替代单一利用率数字，把利用率缺口映射到片段填充、占用率上限、停顿特征、wave 量化与 kernel 选择等具体机制。

关键数字：覆盖 4 个生产模型、6 种逐层 kernel 角色；核心数字事实是 GMMA 片段固定 64 行（摘要未列其他具体数值）。

为什么值得看：做推理性能调优的人常被"利用率很高但不快"困扰，这八个视图是一套可直接照做的诊断方法论。
