Twindex: Index Cache Offloading with Coarse-to-Fine Selection for Long-Context Sparse-Attention Serving

arXiv · 2026-11-18 · 论文PDF / 每日精选

研究问题：长上下文解码中主 KV 移到 host 内存后，indexer cache 成为 HBM 瓶颈——在 Qwen 上占单请求 HBM 的 63%、DeepSeek V4.1 上 75%（1M tokens）。

方法：Twindex 在 HBM 只保留紧凑的 indexer cache 副本、完整 cache 放 host；每步副本先选更大候选集，模型自己的 indexer 再从 host 原始行中取 top-k；副本=共享成分+压缩残差（离线学一次），不改模型权重、运行在 CUDA graphs 内。

关键数字：1M tokens 现代 GPU 上比仅 KV offloading 多容纳 1.78×/1.62×/3.03× 请求（Qwen/V4.1/GLM-5.2）；host 不限制批大小时 decode 吞吐达 1.44×/1.25×/2.54×；平均基准分数最多低 3.1%。

为什么值得看：把长上下文稀疏注意力服务的 indexer 瓶颈用粗到细两级选择解开。
