InferSlice: A Reference Architecture for SLO-driven LLM Inference over a Telco Wide-Area Network

· 2026-10-23 · 论文PDF / 每日精选

研究问题 主权、合规、延迟与资源就近要求使集中式云不适合部分 LLM 推理服务——电信运营商有地理分布的算力与网络，但现有 serving 框架是为紧耦合数据中心设计的。

方法 提出 InferSlice 参考架构：面向电信基础设施的 SLO 驱动 LLM 推理，整合网络切片、GPU 分区、弹性服务与可观测性；由 BT 牵头、布里斯托大学与 NVIDIA 合作，在英国国家规模 WAN（JOINER）上落地，评估服务分层差异化、弹性扩容、客户端-边缘带宽瓶颈及张量/流水线/数据并行与 prefill-decode 分离的可达性。

关键数字 摘要未给出具体性能数值；架构已在英国国家级 WAN 上实现并评测。

为什么值得看 电信广域网上的 SLO 驱动 LLM 推理参考架构，边缘推理部署新场景。
