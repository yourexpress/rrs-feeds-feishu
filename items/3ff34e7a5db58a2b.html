SlimKV: Joint Token-Feature KV Cache Compression with Reconstruction-Free Beacon Attention

arXiv (cs.LG) · 2026-10-05 · 论文PDF

研究问题 长上下文 LLM 服务越来越受 KV 缓存内存制约：token 级压缩（逐出/凝聚）有信息丢失风险，特征级压缩可减小每 token KV 维度但常需全维重建才能施加位置编码，限制解码加速。

方法 提出 SlimKV，与查询无关的 token-特征联合压缩：用低秩感知训练把长上下文压缩为带潜在 KV 表示的信标记忆态，配合层自适应秩分配；并利用"移除 key 侧 RoPE 对信标 token 影响远小于原始 token"的位置非对称性，在 K-RoPE-free 约束下训练信标 KV 投影，实现解码期潜在空间注意力、规避重建延迟。

关键数字 LongBench 上 16x/32x 压缩优于基线，4x/8x 保留未压缩模型 96% 以上分数；128K 长度下注意力加速最高 7.34x、端到端解码 3.38x。

为什么值得看 token 与特征双维度联合压缩且免重建，实测加速显著。
