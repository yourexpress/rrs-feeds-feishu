FlashQLA: Efficient Context Parallelism for Gated DeltaNet

arXiv · 2026-11-24 · 论文PDF / 每日精选

研究问题：Gated DeltaNet（GDN）通过循环状态更新获得线性复杂度，但块间顺序依赖限制了并行度，尤其长上下文小 batch 场景——如何提升其上下文并行效率？

方法：提出 FlashQLA：衰减感知准备降低边界状态预处理开销；Dual CP 跨并行层级共享 summary 计算把序列并行扩展到多 GPU；负载自适应 Auto CP 与 CP 感知 kernel 协同设计进一步提升执行效率。

关键数字：单 GPU 上相对 Flash Linear Attention（FLA）前向加速 1.7–3.1×、后向最高 4.4×；八 GPU、上下文最长 1M token 时 Dual CP 相对 FLA KCP 前向最高 4.8×、前向后向合计 4.4×。

为什么值得看：针对 GDN 类线性注意力长上下文训练/推理的并行瓶颈给出了系统化解法，数字直接可用于选型。
