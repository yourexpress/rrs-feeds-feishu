WeightBridge: An Efficient Weight Transfer Library for Reinforcement Learning

arXiv (cs.DC) · 2026-09-23 · 论文PDF

研究问题 权重传输（把更新后的参数从 trainer 传播到 rollout 生成器）正成为 LLM 强化学习系统的性能瓶颈；现有方案只在部分配置下高效，跨不同模型、并行布局与同步模式时或低效或缺乏支持。

方法 提出 WeightBridge 权重传输库：自动提取 trainer 与 rollout 权重布局的对应关系，规划并执行无冗余、负载均衡的权重传输；暴露小而通用的 API，协调不同同步模式下的 worker。

关键数字 跨多种模型、并行布局与同步模式，相对最先进开源 RL 框架平均减少 GPU 停顿时间最高 42 倍；一个 coding agent 无需人工指导就把 WeightBridge 集成进两个不同 RL 框架，验证 API 通用性与易用性。

为什么值得看 RL 训练中权重同步的"最后一公里"常常被低估，这篇用统一抽象一次性覆盖多样配置，工程参考价值直接。
