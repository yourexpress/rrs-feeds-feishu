Superfluid: Local AI Server for Distributed LLM Inference

arXiv cs.DC · 2026-11-13 · 论文PDF / 每日精选

研究问题：本地 LLM 服务面临两种新压力——单设备上多 agent 共享一个交互式模型；跨设备上开发者拥有多台不同厂商机器但各自只服务单运行时、大部分时间闲置，如何统一？

方法：Superfluid 开源本地 LLM server——单设备用隔离 worker 进程驱动 llama.cpp/MLX/BaseRT，一个调度器把交互请求排在 agent 工作之前、公共 prompt 只计算一次、每个 token 先写持久日志再达客户端；跨设备把机器群变成单一 API 端点，异构硬件按实测速度分活，可随时加入/失败而不丢请求。

关键数字：Apple M5 Pro 上 Qwen3.8-27B，8 个 agent 工作时聊天首 token 1.5s（llama-server/Ollama/mlx_lm.server 为 291–612s）；6 台三厂商机器 64 模拟用户 1 小时服务 5,041 请求全部完成，吞吐 112→534 tok/s、中位首 token 99→12s；12 台 Mac Studio M3 Ultra 上 384 agent 的 38,563 请求以 10,656 tok/s 零失败完成。

为什么值得看：本地多机 LLM 服务的开源方案，边缘/私有部署团队可直接使用。
