From Experience to Expertise: Adoption-Aware Memory Learning for Data-Scarce NPU Kernel Synthesis

arXiv (cs.LG) · 2026-09-28 · 论文PDF

研究问题 高性能内核是高效加速器执行的基础，但需要专家调优与漫长手工优化。LLM 编程 agent 有望自动化，但其 CUDA 知识难以迁移到数据稀缺的领域专用架构（DSA，如 NPU）；训练后适配依赖稀缺专家数据，记忆学习 agent 的均匀信用分配又给"被采用"与"未采用"经验相同奖励目标，可能偏置检索排序。

方法 SAGE 是持久自改进的 NPU 内核综合 agent：采用追踪效用估计（ATU）结合显式采用记录与内核评测结果做采用感知信用分配；效用门控整合（UGC）用正效用与跨算子重复采用挑选并抽象可复用规则进有界驻留上下文。

关键数字 NPUKernelBench 上 SAGE 执行率达 95.5%（最强受控基线 84.1%），86.9% 的已解算子优于 torch_npu；配 GLM-5.3 时稀疏 flash attention 相对 torch_npu 参考加速 43.99x。

为什么值得看 采用感知信用分配 + 选择性整合让 agent 跨任务积累硬件特定知识，是 NPU 内核自动化的前沿尝试。
