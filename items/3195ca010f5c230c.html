Qwen3.8-Omni-Flash: Omni Senses. Agentic Delivery.

阿里 Qwen · 2026-09-18 · 技术博客 / 每日精选

研究问题：全模态模型如何从"理解音视频内容"走向"规划任务、调用工具并完成创作"，让音视频成为 Agent 的核心载体而非单纯感知输入。

方法：原生全模态模型 + Agentic 工作流：长音视频按需感知（由粗到细多轮取证定位关键片段，不逐帧处理）；多说话人音画协同识别（端到端说话人切分+转录+身份对应，视觉解指代歧义）；配套开源 Qwen-MM-Plugins（含 Video2Note、Omni Skill Creator）与 Qwen-Live Harness；另有 Realtime 变体支持流式音视频交互与空间音频"听声辨位"。还演示了"大模型研发小模型"：Agent 12 小时内自主构建 3,413 条数据迭代训练 Qwen2.5-Omni-3B 的四川话识别。

关键数字：1M 长上下文；29 项评测较 Qwen3.5-Omni-Plus 均分提升超 25%；每小时音频输入价格降 98%、音视频降 93%；AliMeeting 说话人分离 DER 从 88.11 降至 3.35、cpWER 从 89.61 降至 17.18；Agentic 理解使 OmniVideoBench 准确率 63.4→67.8 且 token 消耗降 45.7%；四川话 CER 25.79%→15.30%（相对降约 40.7%）。音视频能力接近 Gemini 3.8 Flash，音频能力整体超过。

为什么值得看：多说话人识别与会议场景指标（DER/cpWER）、方言 ASR 的 Agent 自训练范式，与语音感知/端侧语音算法方向直接相关；价格降一个量级也改写了全模态 API 的成本假设。
