Live Migration of Gated DeltaNet Requests: Exact Catch-Up and the Cost of Log Backlog

arXiv · 2026-11-19 · 论文PDF / 每日精选

研究问题：流式 Gated DeltaNet（GDN）请求的实时迁移，需要在相同权重的工作节点上于正确 token 边界恢复循环状态。

方法：适配快照、批量重放与 token catch-up，并设计紧凑 update-log 迁移路径；exact catch-up 保持原生单 token 解码、在测试输入上逐位匹配参考实现；用 prior-based 与 probe-calibrated 选择器按用户中断、源释放或输出率选择路径。

关键数字：1,350 次纯 GDN 试验 × 两个 GPU 部署：紧凑日志在全部 90 个配置中 handoff gap 最短；80 个完整配置里 exact catch-up 总是最早释放源；10 MB/s 时 32-step replay 把中位 gap 从 445–464ms 降至约 81ms；40 个历史 KV 对齐 Qwen 配置回顾性选择使平均 gap 降 13.9%。

为什么值得看：混合状态模型实时迁移的系统研究，量化精确追赶与日志积压的权衡。
