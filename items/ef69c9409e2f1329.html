Agentic TCAD Calibration Workflow for Oxide Semiconductor Transistors

arXiv（Gyujun Jeong 等，physics.ins-det） · 2026-09-10 · 论文PDF

研究问题 氧化物半导体晶体管的 TCAD 实验校准耗时且依赖专家：多组物理模型与参数集可复现同一测量转移特性，局部拟合无法唯一确定器件物理。

方法 首个针对流片底栅 In-W-O（BG-IWO）晶体管的 agentic 校准工作流：LLM agent 基于测量-TCAD 残差与局部灵敏度测试，选择有界参数修正或评估新增物理模型，只接受改善器件指标的更新；Sentaurus 负责器件物理仿真。

关键数字 2%-W 参考器件经 5 次 agent 建议更新得到固定校准模型，多指标目标 J 降低 14.3 倍；变漏压测试 Vth/Ion 最大误差 36.1 mV/0.022 decade，变沟长测试 46.2 mV/0.062 decade，证明模型跨偏压与几何可迁移而非局部拟合。

为什么值得看 LLM agent 进入器件建模的完整闭环案例，且用变组分测试提供工艺敏感洞察，对"半导体+AI agent"交叉方向有直接参考价值。
