Mask-Aware Execution for Efficient JEPA Training

arXiv · 2026-09-19 · 论文PDF

研究问题 JEPA 训练流水线存在多掩码分支重复执行、目标侧冗余计算与内存受限的 token 路由，开销随掩码数增长，限制 GPU 效率。

方法 M-JEPA 在不改变学习目标的前提下，把掩码无关计算与掩码相关路由分离：共享 context encoder 执行、带反向支持的融合路由/切片、对目标 token 并集的稀疏 target encoder 执行、面向稀疏输入的 masked patch embedding。

关键数字 A100 上实现 5 种 JEPA 变体：2–10 个掩码下端到端训练最高加速 1.7x；高稀疏度下 patch embedding 加速 4.75x。

为什么值得看 JEPA 正成为潜在世界模型的构件，执行层重构是不改目标的加速杠杆，对多掩码自监督训练收益直接。
