Uncovering the Memory Hierarchy of Modern NVIDIA GPUs for Accurate Simulation

arXiv cs.AR · 2026-11-10 · 论文PDF / 每日精选

研究问题 LLM 等 AI 负载对 GPU 显存系统提出空前要求，但现有工作仍依赖过时的显存层次模型，无法刻画现代硬件的复杂度，导致性能刻画失真、优化策略被误导。

方法 提出 GemAtlas，首个对现代 NVIDIA GPU 显存层次做系统性逆向工程的工作：通过细粒度 SASS 级基准，揭露多级 cache 的 set 关联度、slice 路由与 set-indexing 哈希函数、替换策略、一致性行为与互联拓扑等未记录的微架构细节，并将其集成进 SOTA GPU 模拟框架。

关键数字 平均绝对百分比误差（MAPE）在 4 块 GPU 上从 31.69% 降至 22.24%；真实 LLM 算子的 MAPE 从 34.04% 降至 23.98%。

为什么值得看 把模拟精度差距归因到具体微架构细节的系统性工作，对 GPU 性能建模与架构优化研究者直接有用。
