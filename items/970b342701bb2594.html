CPL: A Compact C-like Systems Language with Explicit Low-Level Control

arXiv（Nikolay Fot 等，cs.PL） · 2026-09-04 · 论文PDF

研究问题 能否设计一门保留 C 对内存、布局与机器接口直接访问能力、但语法更小巧的系统语言？类 C 语言是否比现代范式更适合做编译器实验？

方法 CPL（Cordell Programming Language）：提供原始值、指针、数组、带方法容器、联合、泛型函数、重载、入口点与 section 控制、系统调用与内联汇编；刻意不提供类、内建方法、标准库或内存保护。论文描述语言设计、编译器流水线、目标后端与静态分析架构，并用可复现微基准评测原型后端。

关键数字 x86_64 与 i386 微基准显示其代码生成质量可与 GCC、Clang 等生产级编译器及 TinyC、SmallerC 等小型编译器相比。

为什么值得看 一门"更小但不更弱"的类 C 语言完整实现记录，对编译器教学、原型验证与嵌入式系统编程都有参考意义。
