Better prompt caching for GPT-6

OpenAI · 2026-09-22 · 官方公告

核心话题 OpenAI 为 GPT-6 推出改进的提示词缓存：默认更高命中率，并为持久 agent 提供一整套监控与控制工具，降低 API 成本。

要点 30 分钟窗口内复用的共享前缀可享缓存折扣；新增 Prompt Caching Dashboard（命中率、输入构成）与诊断工具（对比近期请求定位模型/工具/设置/输入变更导致的 miss 并估算受影响 token 数）；显式缓存断点让开发者自选缓存前缀；可在不破坏缓存的情况下通过 configuration_update 调整 reasoning effort；建议工具定义保持稳定、新指令追加到上下文尾部、启动时预热共享上下文。

关键数字 缓存输入最高 90% 折扣；共享前缀复用窗口 30 分钟（官方博客数据）。

为什么值得看 直接影响长时运行 agent 的 API 成本，"追加而非修改以保缓存"等技巧值得写进 agent 开发工程规范。
