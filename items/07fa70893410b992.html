Ascend-SpMM: Accelerating Sparse Matrix-Dense Matrix Multiplication on Ascend NPUs

arXiv (cs.DC) · 2026-11-01 · 论文PDF / 每日精选

研究问题 SpMM 是图神经网络与科学计算的基础内核，但昇腾 NPU 上优化研究基本空白；Cube/Vector 物理解耦与单线程标量指令派发带来独特挑战。

方法 Ascend-SpMM：内存中心成本模型量化硬件亲和性，指导冲突受限的密度感知任务映射——稠密区域走高吞吐 Cube 路径、稀疏残差走灵活 Vector 路径，并给出跨处理器冲突的理论上界；配套层级感知流水线与轮转环形缓冲隐式同步定制子内核。

关键数字 相对各矩阵最强 NPU 基线取得 12.70–20.55 倍几何平均加速；端到端 GNN 训练最高加速 6.8 倍；与最先进 GPU 实现性能竞争。源码已在 GitHub 开源。

为什么值得看 昇腾 NPU 上首个系统性 SpMM 框架，映射策略与同步机制对其他国产芯片有参考价值。
