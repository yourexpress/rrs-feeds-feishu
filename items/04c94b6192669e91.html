MODAIC: Coordinated Asynchrony for Decentralized Multimodal Learning

arXiv · 2026-10-14 · 论文PDF

研究问题 多模态去中心化学习让异构边缘设备在不共享原始数据下协作，但模态集不同造成耦合的计算与通信瓶颈；带宽受限下多模态 agent 成为热点，更新错过聚合窗口、变陈旧或被低估，损害最差 agent 准确率。异步消除全局阻塞却不协调跨模态交互与及时更新交换。

方法 提出 MODAIC（Modality-Decoupled Asynchrony with Interleaved Coordination）：无等待系统，协调局部模态进度、点对点更新投递与异构计算带宽下的聚合——层次化异步让模态独立推进同时强制互惠特征交换；负载感知更新获取重叠训练与通信、限制并发服务负载、复用迟到更新；共识感知对等选择用轻量元数据考虑更新可用性、参与度与损失相似度。

关键数字 AVE 上 200 Mbps/agent 时 1000 秒内多模态最差 agent 准确率比最强基线提升 11.0 个百分点；云测试床 time-to-accuracy 最多降低 30%。

为什么值得看 系统化解决多模态联邦/去中心化学习的同步瓶颈，实测增益显著，对边缘多模态协作训练落地很有参考价值。
