Run vLLM inference with INT4 quantization on Arm servers

Arm Learn · 2026-09-09 · 技术博客 / 每日精选

核心话题：Arm 官方学习路径——在 Arm 服务器上构建 vLLM 并以 INT4 量化跑大模型推理的完整流程。

要点：四步走：① 为 aarch64 构建带 oneDNN 与 Arm Compute Library（ACL）的优化 vLLM；② 用 llmcompressor 把示例模型 DeepSeek-V2-Lite 量化到 INT4；③ 用 OpenAI 兼容 API 起服务，理解序列与 batch 限制；④ 用 LM Evaluation Harness 对比 BF16 与 INT4 的精度，量化损失一目了然。

关键数字：环境要求最低 32 vCPU、64 GB 内存、64 GB 空闲磁盘（Ubuntu 22.04+、Python 3.12）。

为什么值得看：Arm 服务器端 LLM 量化部署的可复现操作手册——量化→服务→评测的闭环对任何 aarch64 推理落地都有直接参考价值。
