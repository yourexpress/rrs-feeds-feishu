State of Thought Enables Endogenous Reasoning

arXiv · 2026-09-16 · 论文PDF

研究问题 测试时计算是提升 LLM 能力的主线，但现有推理范式依赖外部强加的控制——固定推理程序或受限搜索空间的高代价扩展，泛化与效率都受限。能否让模型内部推理状态自己主宰推理如何展开？

方法 State of Thought（SoT）提出内生推理范式：从模型内部信息转移中提取紧凑的动力学-几何状态，用冻结骨干上一个 582 参数的控制器，按当前状态选择性激活有用的历史推理支持，把推理重构为「状态条件下的证据过程」而非外部规定的 token 链。

关键数字 跨 3 个 LLM、16 个数据集：定量/通用/符号与代码/长上下文四类推理分别提升 1.34/1.62/1.76/2.51 倍，同时生成 token 减 62.6%、端到端时延降 44.6%；2 个 VLM 规模、3 个推理任务上平均准确率较推理基线 +3.8 点，token 少 74.9%、时延低 73.5%；免训练/仅嵌入设定下仍保留 38.2%/36.5% 平均增益。

为什么值得看 用极小参数代价撬动「状态驱动推理」，效率与性能同升，是 test-time compute 赛道值得关注的轻量化路线。
