Mojo 1.1 编程语言发布

OpenNet · 2026-09-17 · 官方公告 / 每日精选

核心话题：Mojo 1.1 发布：面向 GPU/AI 系统编程、由 Chris Lattner（LLVM 创始人、Swift 作者）主导的语言进入可接受外部贡献的阶段。

要点：Mojo 语法基于 Python、类型系统接近 C/C++，兼具 Rust 式内存安全（生命周期追踪、借用检查）与 unsafe 指针、SIMD 指令、TensorCores/AMX 等硬件扩展的直接访问；编译到 MLIR，支持 JIT 解释与 AOT 编译，可调用异构系统的 GPU/加速器资源。1.1 的变化：t-字符串与隐式转换处理提速带来编译时间缩短、生成代码性能提升；LSP 支持常见拼写纠错；新增省略可推断类型名的语法（如 SIMD[.float64, 4]）；String、SIMD、List 等标准库 API 稳定化；闭包参数从编译期处理向统一运行期闭包迁移。

关键数字：编译器与工具链以 Apache 2.0 许可发布（含 LLVM 例外，允许与 GPLv2 代码混用）；本版无独立基准数字。

为什么值得看：AI 基础设施底层语言生态的重要变量——若 Mojo 成熟，"Python 写原型、Mojo 出产品"的单语言路径会改变高性能计算栈的分工。
