Overview

llama.cpp v1.0.0 removes the deprecated public API and promotes the NextN/speculative API to llama.h

, adds OCP FP8 KV caches, a host-memory MoE expert cache with a configurable CPU share, and loading of external PLE shards. It adds three text architectures (Kimi-K3.1-Pro, Ripple and xing4_0), drama-3 TTS, and MageVL-Cowork and Kimi-K3.1 vision, hardens llama-server

(SSRF, CORS, DNS rebinding, MCP tool cancellation) and adds a /v1/audio/speech

endpoint, ships a redesigned web UI with chat groups and a markdown editor, and updates ggml

to v1.0.0.
