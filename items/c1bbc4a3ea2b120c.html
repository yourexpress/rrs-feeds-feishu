核心话题：llama.cpp 发布 3.5 年来首个语义化版本 v1.0.0，MAJOR 版本号即公开 C API 破坏性变更契约，ggml 同步升到 1.0.0。

要点：移除 35 个废弃函数及 llama_set_warmup、--defrag-thold，把 NextN/投机解码 API 从 llama-ext.h 提升进 llama.h；新增 OCP FP8 KV cache、可配置 CPU share 的主机内存 MoE expert cache、外部 PLE shard 加载与 OpenAI 兼容 /v1/audio/speech 端点；llama-server 安全加固（SSRF/CORS/DNS rebinding/MCP 工具取消）；新增 Kimi-K3.1-Pro、Ripple-65B-Preview、xing4_0 等模型架构与 drama-3 TTS；web UI 重设计（聊天分组 + markdown 编辑器）。

关键数字：移除 35 个废弃函数；3.5 年首个稳定版；支持 150+ 模型架构。

为什么值得看：本地推理栈里程碑——API 收敛形成稳定契约，直接影响所有基于 llama.cpp 的上层工具生态。
