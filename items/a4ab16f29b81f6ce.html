Rust for Secure Backend Development: A Critical Review and Extended Vulnerability Comparison with Node.js and Django

arXiv（Md Zarzees Uddin Shah Chowdhury 等，cs.PL） · 2026-08-23 · 论文PDF

研究问题：Rust 以消除内存安全与并发漏洞著称，但它在后端 Web 开发场景中的安全水位到底比 Node.js、Django 强多少？

方法：先按 SANS Top 25、OWASP Top 10、19 Deadly Sins 三套框架批判性复评 Rust 对 C/C++/Java 的漏洞分级研究，指出其缺乏实证、访谈样本小等缺口；再用同一套三级分类（极难发生/有防护/无防护）对 Rust 与 Node.js、Django 做并排代码实验，覆盖越界写（CWE-787）、释放后使用（CWE-416）、竞态（CWE-362）。

关键数字：摘要未给量化指标；结论基于三类 CWE 的代码级对比实验与三套安全框架的分级。

为什么值得看：结论冷静——Rust 的编译期保证主导系统层，但应用层上托管框架内建防御更强；Rust 用于 Web 需要配套安全措施，不能只靠语言本身。
