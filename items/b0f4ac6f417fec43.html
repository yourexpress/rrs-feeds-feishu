Optimizing the Phi-2 Small Language Model for Real-time Chatbot Applications Using Parameter-Efficient Fine-Tuning (PEFT) with QLoRA Quantization

arXiv (cs.LG) · 2026-09-27 · 论文PDF

研究问题： 面向实时聊天应用，如何在移动与边缘计算约束下优化 Phi-2 这类小语言模型（SLM），既大幅降低内存占用又保持响应准确率？ 方法： 用参数高效微调（PEFT）结合 QLoRA——4-bit 量化 + LoRA——对 Phi-2 微调，显著减少内存占用；用 ROUGE 指标评估微调后模型在摘要任务上的表现。 关键数字： 原文未给出具体数值；仅报告 ROUGE 指标在摘要任务上有显著改进。 为什么值得看： 验证资源受限环境下 SLM 微调的可行性，为端侧实时 AI 应用提供低成本部署路径；方法偏常规，作为参考案例阅读即可。 原文链接：Optimizing the Phi-2 Small Language Model for Real-time Chatbot Applications Using PEFT with QLoRA
