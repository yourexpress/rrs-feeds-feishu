Long Text to Predictive Features: LLM-Guided Blockwise Feature Engineering via Executable Program Search

arXiv (cs.LG) · 2026-10-09 · 论文PDF

研究问题：工业风控系统依赖结构化数据模型，长文本中大量有价值信息难以利用——人工特征工程费力，而让 LLM 处理每个实时输入又不满足部署要求。

方法：LLM-BlockFE 离线把长文本转换为可执行特征程序，在线推理零 LLM 调用；程序由不可变代码块增量追加构建、用下游模型评估候选特征；针对贪心搜索易陷次优，引入基于深度校准信用分配的块级回滚，并交错推进多条独立搜索轨迹减少冗余探索。

关键数字：两个公开 + 两个私有数据集上，较各集最强基线 AUC 绝对提升 0.0069–0.0358；5 个已部署金融风控应用上 KS 绝对提升 0.02–1.56 个百分点。

为什么值得看：离线构造可执行特征程序兼顾长文本信息与在线延迟约束，且有生产部署的实测收益背书。
