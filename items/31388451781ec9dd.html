Semantic-TVM: Structure-Preserving Trustworthy Virtual Memory for Memory-Augmented and Tool-Using Agents

arXiv（Yu Li 等，cs.AI） · 2026-09-14 · 论文PDF

研究问题 带记忆与工具调用的 Agent 把检索到的记忆、工具动作、中间观察发给远程 LLM 时会暴露精确隐私值；整段遮蔽虽防泄露却丢失执行所需信息，还可能在后续观察中侧漏。

方法 提出可信虚拟内存（TVM）闭环运行时：精确值留在本地，远程模型只见受保护视图。Rule-TVM 整体替换受保护字段，Semantic-TVM 则由可信本地模型预测敏感片段、只替换片段，保留周边任务相关上下文。

关键数字 在 Memory-EHR 与 Memory-RAP、两家供应商上测试：DeepSeek 下任务成功率 84.17%（Semantic-TVM）对 52.33%（整段替换），暴露度保持低位且流程可执行。

为什么值得看 Agent 隐私保护从"遮不遮"细化到"遮哪几个词"，是记忆型 Agent 落地的关键一环。
