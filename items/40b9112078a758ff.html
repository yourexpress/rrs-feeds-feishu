Ostinato: Fast CPU-GPU MoE Inference for Local Agents via Resident Experts in Every Forward Pass

arXiv cs.DC · 2026-11-08 · 论文PDF / 每日精选

研究问题 语言模型 agent 越来越多跑在工作站少量消费级 GPU 上，大 MoE 模型部分专家驻留主机内存；既有 CPU-GPU 引擎只能二选一——快 prefill 或快 decode。

方法 关键洞察：短 prefill 触及过多不同专家难以全部上传，但其 84% 的专家激活（路由）落在 GPU 内存放得下的稳定专家集。据此提出 Ostinato：每次前向都在 GPU 计算这些专家而不改变模型计算——短 prefill 拆分路由（每层每 token 六个路由专家中留给 CPU 的不到一个）、长 prefill 每个冷专家只上传一次、每个 decode 步作为每 GPU 一个定形 CUDA graph 执行。

关键数字 DeepSeek-V4-Flash 在四张 RTX 4090D 上跑真实编码与客服 agent 会话：相对 llama.cpp 与 KTransformers，工具输出后中位等待削减 22–55%，整场会话快 1.4–2.5x，两个阶段都是最快引擎。

为什么值得看 不改变模型计算就同时保住 prefill 与 decode 性能，消费级 GPU 跑大 MoE agent 的实用引擎设计。
