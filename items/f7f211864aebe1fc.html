LowRAM: Low-Rank Keys and Amortised Values for Composable KV Cache Compression at Test-Time

arXiv · 2026-11-04 · 论文PDF / 每日精选

研究问题：KV cache 随上下文线性增长、限制批大小与吞吐；已有方法利用 token/层/特征冗余与低精度，是否还有互补的压缩轴？

方法：观察到每个注意力头内 value 大体可由对应 key 预测——用测试时每头轻量预测器做 value cache 摊销，只存重建最差的 token 残差；配对跨层低秩 key 压缩构成 LowRAM 非对称管线，可再与量化、驱逐组合。

关键数字：4x 近无损 value 压缩；4x 压缩下峰值解码吞吐最高提升 5x；与量化和驱逐组合达 26.9x 压缩、长上下文上保持基线 94.5% 性能。

为什么值得看：把 key 与 value 结构性区分对待，给出可组合、可叠加的激进 KV 压缩，解码吞吐收益显著。
