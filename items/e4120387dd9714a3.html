Building a High-Performance and Portable vLLM Linear Backend with Helion

PyTorch Blog（Sean Chen, Red Hat / Shangdi Yu, Meta） · 2026-10-02 · 技术博客 / 每日精选

核心话题 vLLM 的量化 linear 层需要针对 FP8/INT8/INT4/NVFP4 等格式和不同硬件手工集成 CUTLASS、DeepGEMM 等内核库，能否用一个高层 kernel DSL 统一覆盖？

要点 将 PyTorch Helion（tile 级 GPU kernel DSL）接入 vLLM linear backend：单个 Helion GEMM 实现覆盖 Standard、Split-K、Swap-AB 多种算法变体，靠 per-shape AOT 自动调优+混合派发选最优配置，并支持 LLM 引导搜索进一步提升调优效率。

关键数字 H100 上对所评估模型全面超过 vLLM 默认 CUTLASS 与 DeepGEMM 后端，部分工作负载端到端吞吐提升超过 10%。

为什么值得看 "一次写 kernel、跨负载跨硬件自动调优"的路线在真实推理引擎里拿到端到端收益，对推理系统与 kernel 工程都有参考价值。
