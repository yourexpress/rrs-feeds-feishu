RASER: Resilient Agent Scheduling and Execution Runtime for HPC Clusters

arXiv（Sima Attar-Khorasani 等，cs.PF） · 2026-09-03 · 论文PDF

研究问题 LLM 驱动的长时程自主智能体需要大量算力，HPC 集群是理想底座，但 Slurm 等传统调度器并非为动态 agentic 工作流设计——任务时长不可预测、要调外部 API、还要求容错。

方法 RASER 是用户态框架，扩展 Slurm 内部原语：agentic job array 配合共享文件系统队列实现工作窃取；应用级状态序列化 + Slurm requeue 做用户态 checkpointing；Apptainer 容器隔离且无需改镜像。不需要内核权限或外部数据库。

关键数字 较静态划分 makespan 降低近 39%，CPU 利用率接近满载；checkpoint/restore 开销极小，可抗抢占与故障。

为什么值得看 不改基础设施、不要特权，就把 agentic 工作流搬进生产 HPC——对拥有集群存量、想跑 AI agent 负载的团队是低门槛方案。
