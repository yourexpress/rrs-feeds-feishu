Introducing Gemini 3.8 Live and 3.8 Live Extended Thinking

Google DeepMind · 2026-09-15 · 技术博客 / 每日精选

核心话题：Google 发布 Gemini 3.8 Live 与 3.8 Live Extended Thinking 两个近实时语音模型，分别主打规模成本效率与高复杂度任务。

要点：Extended Thinking 能边推理边说话——用"Let me check that…"等口语化提示承接请求、对后台多步任务做实时进度口播，保持对话不中断；支持 97 种语言的会话中自动检测切换；工具与 API 调用在后台执行；已接入 Gemini app、Workspace 与 Search，并有 Agora、LiveKit、LangChain 等平台生态与 Salesforce 等企业伙伴。

关键数字：Extended Thinking 在 Artificial Analysis 语音到语音质量指数排名第一（82.6）；agentic 任务完成率 τ-Voice 68.6%、Sierra τ-Voice-banking 35.1%；Big Bench Audio 97.7%；3.8 Live 居 Speech Agent Arena 第二。

为什么值得看："边想边说"是语音 agent 落地的关键体验短板，这套后台工具调用 + 进度口播的工程化方案为企业级语音 agent 设了新参照。
