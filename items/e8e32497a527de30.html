MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents（arXiv 2610.06830）

arXiv（Haozhen Zhang 等） · 2026-10-06 · 论文PDF

研究问题 LLM agent 记忆系统大多与查询无关地构建记忆，产生不必要预处理开销且丢弃后来关键细节；运行时自适应方案多局限于特定操作或固定处理流程。

方法 提出 MemPilot 灵活框架：用强化学习优化多步 LLM 策略，在"从查询无关记忆检索"与"委托查询特定 curation"之间迭代选择，按不同性能-成本-延迟偏好编排按需记忆整理。

关键数字 摘要未给具体数值；核心是可学习的检索/整理权衡策略与偏好调节。

为什么值得看 把记忆 curation 从固定流程变成可学习策略，对构建高效 agent 记忆系统（尤其多模态场景）有直接价值。
