SWE-sweep: benchmarking software engineering agents

Meta · 2026-10-01 · 技术博客 / 每日精选

核心话题 现有软件工程基准大多给 agent 一个明确的 issue 让其修复，而 SWE-sweep 考察更贴近真实委托的开放式设定：面对一个同时存在大量 bug 的代码库，agent 需要在没有任何提示的情况下自主发现并修复尽可能多的 bug。

要点 基准从开源仓库收集 issue-PR 对，定位多个 bug 共存的 commit，并严格过滤出仅凭阅读仓库即可发现的 bug；每个修复用对应 PR 的隐藏测试（fail-to-pass）加原有测试套件（防回归）评判，得分为所有仓库中被解决 bug 的比例。

关键数字 抓取到的页面正文未给出具体模型得分数值。

为什么值得看 代表 coding agent 评测从"完成指定任务"走向"自主判断该做什么"的方向转变，对关注 agent 能力边界与评测设计的人很有参考意义。
