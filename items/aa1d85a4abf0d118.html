GPU Acceleration of Awkward Arrays: Using Python cuda.compute

arXiv cs.DC · 2026-10-08 · 论文PDF

研究问题 高能物理广泛使用的 Awkward Array 库处理嵌套变长数据，早先 GPU 加速尝试受限于不规则访存、细粒度 kernel 启动开销与算子可组合性。

方法 基于 Python CUDA Core Compute Libraries（CCCL）为 Awkward Array 构建新 CUDA 执行模型：无需手写 CUDA kernel，用高层 Python 接口；可将多个 Awkward 算子融合成更少 kernel，缓解启动开销；惰性执行先构建并优化表达式图再生成 kernel；支持用户自定义 Python 代码进入 GPU 路径且不破坏分析语义。

关键数字 性能研究表明：对代表性 HEP 分析模式（jagged 数组、组合操作、归约），优于此前报告的即时（eager）GPU 执行策略；摘要未给具体加速比数字。

为什么值得看 面向 HL-LHC 时代 Python 分析工作流的可持续 GPU 后端路线，"免写 kernel + 算子融合"对科学计算库 GPU 化有借鉴意义。
