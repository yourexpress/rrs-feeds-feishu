BitPrefill: W1.58A4 Tensor-Core Acceleration for Compute-Bound LLM Prefill

arXiv · 2026-11-18 · 论文PDF / 每日精选

研究问题：低比特量化降低 LLM 推理成本，但为内存受限 decode 优化的实现把计算受限的 prefill 留在 BF16 tensor core 上；长上下文、多模态等输入密集场景 prefill 占推理延迟比重很大。

方法：提出 W1.58A4 算子：权重量化到三元值、激活 4-bit，线性投影在原生 INT4 GEMM tensor core 上执行，把 prefill 从全精度矩阵乘变成低比特矩阵乘；部署在单张 RTX 4090 与 Jetson Orin Nano 边缘设备，对比 bf16 与 BitNet/BitBLAS 基线。

关键数字：相对原始 BF16 prefill 阶段约 1.42× 加速，模型精度损失可忽略。

为什么值得看：补齐低比特推理的 prefill 侧缺口，输入密集场景直接受益。
