Scaling Architectural Simulation to Giga Instructions Per Second

arXiv · 2026-11-24 · 论文PDF / 每日精选

架构模拟扩展到每秒千兆指令

The cost of detailed architectural simulation constrains design-space exploration, while parallelization across simulated cores offers limited host concurrency for single-core and small multicore targets. We present GIPSim, an instruction-driven simulator that derives instruction timing from dependencies and resource constraints, reducing the overhead of updating pipeline state every simulated cycle. It applies synchronization-guided temporal decomposition to recorded execution, exposing host parallelism beyond the target core count. GIPSim replays the resulting segments in parallel and aggregates their durations through a dependency graph to estimate overall execution time, with replay contexts reconstructed using retained microarchitectural state, warmup, and synchronization-guided cache eviction. This accounts for synchronization waits without requiring host workers to follow target execution order. We evaluate GIPSim using QEMU traces of application and operating system execution on multi-core x86-64, AArch64, and RV64GC systems.
