PixelFlow: Token-Level Workload Management for Efficient Distributed DiT Serving

arXiv（Zhexiang Zhang 等，cs.DC） · 2026-09-17 · 论文PDF / 每日精选

研究问题：在线 DiT 图像生成既要满足延迟 SLO 又要高效利用 GPU：请求级批处理对批大小控制有限——太小喂不饱算力、太大违反 SLO；全局协调调度又要求各 GPU 同步接纳新请求、引入额外延迟。

方法：PixelFlow 用 token 级负载管理：以 DiT 生成图像的处理单位（图像 token）为粒度拆分与批处理请求负载，让每块 GPU 在延迟约束下承接一部分额外工作；运行时把请求切成变长分区并高效成批；优化 token 放置以限制跨 GPU 交换并均衡负载；利用去噪步之间的相似性把剩余传输与计算重叠；SLO 感知调度器把 GPU 分组共享算力，仅当需要合并资源接纳新请求时才跨组同步。

关键数字：在 H100 上以 Stable Diffusion 3 与 FLUX.1-dev 评测，SLO 达标率最高提升 43%，goodput 达到最先进 DiT 服务系统的 2.8 倍。

为什么值得看：把 LLM 服务里的细粒度调度思路移植到扩散模型服务，"token 级"这个抽象层选得漂亮——分布式生成服务方向的系统设计范本。
