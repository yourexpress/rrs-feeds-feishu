A Case Study of a Multi-Agent Kernel-Optimization Loop That Learns a New AI Accelerator

arXiv(cs.LG) · 2026-10-28 · 论文PDF / 每日精选

研究问题 前沿 LLM 能写对多数单算子 CUDA kernel，但在罕见架构（新加速器+冷门编程语言）上精度崩塌；稀缺设备时间下如何自动优化 kernel？

方法 面向 FuriosaAI RNGD NPU（Rust DSL）构建 LLM agent 优化循环：自建目标知识（总结 DSL 文档、微基准测芯片、记录编译器合法性规则并在工具链变化时复核）；按 kernel 维护 Design Tree 做角色化搜索；上机前用廉价检查筛选设计，后期仅在与最佳 kernel 反复对比后才采纳改动。

关键数字 12 天优化 Gemma-4-12B 三个 decode kernel，最终较官方基线几何平均提速 9.293×，每个 kernel 距离仅搬权重所需周期 1.25× 以内。

为什么值得看 稀缺设备+嘈杂测量约束下 agent 自动优化硬件的完整案例，代码已开源。
