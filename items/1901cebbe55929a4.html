Coding-Agent Benchmarks Should Match Their Users' Task Flows

arXiv cs.LG · 2026-10-09 · 论文PDF

研究问题 编码智能体评测力求贴近真实，但 issue 派生的基准任务与真实工程师的使用方式存在系统性偏差——真实会话任务类型更杂、且在会话中不断切换。

方法 收集 4782 个 JetBrains IDE 中真实软件工程师的 agent 会话（Production Sessions），分析其 Task Flow（会话长度、任务类型与类型间转移的分布）；提出 SWE-TaskFlow，把任意 issue 派生基准沿目标任务流方向改造，并用 TaskFlow Alignment Score（TFAS）挑选生成轨迹。

关键数字 至少 3 条用户消息的长会话占样本 33%；三个公开交互语料的长会话 Task Flow 差异显著；700 个 SWE-Bench Pro 任务试点中，分步顺序求解约使 agent 成本翻倍而 resolve rate 无稳定变化。

为什么值得看 提出"基准应点名目标用例并按其测量校准"的评测设计观，数据量与方法都可复用。
