AgentReplay: Token-Wise Trace Replay Is Essential for Fair Serving System Performance Benchmarking

arXiv (cs.DC) · 2026-09-26 · 论文PDF

研究问题 LLM 智能体多轮工作流交织模型推理与工具调用，服务优化评测却因"相同任务产生不同执行轨迹"而失真——生成 token 变化会改变后续 prompt、工具调用与推理轮次，难分系统改进与负载波动。

方法 提出 AgentReplay：可配置的 trace 记录-重放框架，记录输入/输出 token、专家选择、请求依赖与工具时长；重放时强制使用记录的输出 token 但保留正常自回归计算，可控制 MoE 专家选择与工具延迟；并把轨迹生成与性能评估分离，允许兼容小模型重放大模型采集的长程轨迹。

关键数字 摘要未给具体数值；核心结论是 token 级重放能消除贪婪解码与仅按长度重放无法避免的工作负载变化。

为什么值得看 为 agent serving 提供公平可复现的评测协议，是做 LLM 服务系统性能对比的人必读。
