DoSA: Dots Sparse Attention

arXiv · 2026-10-14 · 论文PDF

研究问题 稀疏注意力虽只访问少数 key，但定位它们仍需每个索引头给所有 key 打分，代价高昂。

方法 提出 DoSA（Dots Sparse Attention），无损地让该计算条件化并保持精确 token 选择：种子集给出获胜阈值下界，非负头投影与联合残差界约束正贡献上界，激活信息聚合界定负头减去的量，证书把全量打分导向仍具资格的候选，精确分数过滤再减写回与选择开销。

关键数字 GPU 实现中完整 Indexer 相对 SGLang 加速最高 2.74x、相对 LiteTopK 1.69x；GLM-5.2 与 DeepSeek-V3.2 端到端首 token 时延（TTFT）分别最高加速 1.94x 与 1.50x。

为什么值得看 在保持精确选择的前提下显著加速稀疏注意力，已在主流开源模型实测。
