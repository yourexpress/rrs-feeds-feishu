GPU Goldmines: Tunable WebGPU Kernels for Edge LLM Inference

arXiv · 2026-10-14 · 论文PDF / 每日精选

研究问题：WebGPU 提供跨平台可移植性与浏览器可达性，但同一实现难以在不同设备上保持高性能，如何兼顾？

方法：提出 GPU Goldmines 框架，用于指定、执行与调优 WebGPU 内核，并以矩阵乘、矩阵向量乘、flash attention 三个 LLM 关键算子实例化；在多设备、多形状、多浏览器上刻画性能并建库，加速后续自动调优与配置选择。

关键数字：取自 Llama 与 Qwen 的形状上，矩阵乘内核几何均值分别超 ONNX Runtime 7.0 倍、超 llama.cpp WebGPU 内核 1.41 倍；聊天负载下 llama.cpp prefill 阶段端到端提升 1.48 倍。

为什么值得看：为边缘 LLM 推理提供可调优的可移植内核方案，直击跨平台与高性能难兼得的痛点。
