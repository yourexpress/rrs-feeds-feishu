SHq: Learnable Grids for LLM Weight Quantization

arXiv (cs.LG) · 2026-11-02 · 论文PDF / 每日精选

研究问题 块缩放查找表（LUT）量化格式以索引表示权重，grid 定义本应灵活；但现有实现依赖固定 grid（INT/FP/NF/BOF），且不存在普遍最优的单一固定 grid。

方法 SHq 提出闭式 grid 家族，含两个自由度：压扩强度 α（在均匀与浮点式间距间插值）与偏移 c（引入不对称）；偏移让 FP8 块缩放中未用的符号位选择 grid 或其镜像，使每块可用不同值数量最多翻倍。SHq 只改查找表内容，可作任意此类格式的 drop-in 替换。

关键数字 五个模型（3B–35B，含 MoE）在 2–6 bits、RTN/GPTQ 下评估：3、4 bits 全部设置 KL 散度最低，多数 2、5、6 bits 设置亦最低；比最佳固定 grid 最高优 34%；4.5 bits 时相对 NVFP4 KL 降 41–67%。

为什么值得看 统一视角解释 LUT 格式 grid 设计的两自由度，即插即用且实测全面占优。
