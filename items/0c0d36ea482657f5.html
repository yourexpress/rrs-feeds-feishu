LLM Agents as Resilience Engineers for Scientific Applications

arXiv (cs.DC) · 2026-10-09 · 论文PDF

研究问题 HPC 科学应用的检查点/重启实现需大量专家知识（识别可恢复状态、选全局一致检查点、保持不变量），能否用前沿 LLM 编码 agent 自动化。

方法 16 个 MPI 应用基准套件 + 无人在环的生成-验证-修订流水线，自动化检查点/重启合成。

关键数字 产出 41 个可用弹性实现；成功运行平均 1 小时内完成、约 1,500 万 token、失败自由开销可忽略、恢复效率接近人类代码；模块化碎片化状态仍是主要限制，部分失败尝试消耗超 1 亿 token 与 300 分钟。

为什么值得看 量化评估 LLM agent 自动化 HPC 弹性工程的能力边界与成本。
