Strong Drafts Need Compact Memories: Long-Context Speculative Decoding with Compressed KV Cache

arXiv（Tong Yuan 等，cs.LG） · 2026-08-31 · 论文PDF

研究问题 长上下文（数万 token 前缀）下投机解码的两难：轻量 draft 快但抓不住长程依赖导致接受率低，强独立 draft 接受率高却在长前缀下 KV 访问成本上升——如何兼得？

方法 为强独立 draft 配压缩的 draft 侧 KV 记忆：轻量 adaptor 构建并增量更新这份记忆，同时保留远端信息与精确的近期上下文；target 验证器保留完整 KV cache、用标准接受/拒绝规则，保持投机解码的无损保证。

关键数字 Llama 3.1-8B/70B、前缀最长 32K：draft 侧内存降超 70%；相对自回归解码加速最高 2.08 倍（8B）与 3.33 倍（70B）。

为什么值得看 把「draft 强但 memory 要轻」拆成独立的压缩记忆模块，思路干净且无损，长上下文 serving 加速的实用组件。
