Using MTP to Accelerate RL Training of LLMs

DEV Community · 2026-09-26 · 技术博客

核心话题 多 token 预测（MTP）如何加速 LLM 的 RL 训练——不止是训练目标，还能让模型当自己的小型 draft 模型。

要点 RL 的 rollout 生成是自回归顺序过程，长尾轨迹（有的 200 token 就结束、有的到 8000）让 GPU 空闲、小批量下利用率低；MTP 让推理模型廉价提议多个 token、完整模型并行验证，把 rollout 从顺序瓶颈中解放；小米 MiMo-V2-Flash 技术报告明确用 MTP 加速 RL rollout、改善小批量利用率并降低长尾轨迹成本。

关键数字 最终模型用 3 个轻量 MTP 层，报告接受长度最高 3.6 token、解码速度最高提升 2.6×。

为什么值得看 MTP 在 RL 训练循环中的"投机解码式"用法，是降低推理型 LLM 训练成本的重要方向。
