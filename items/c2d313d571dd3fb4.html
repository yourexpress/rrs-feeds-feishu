Can KV Cache Be Reused Across Model Updates? A DeepSeek-V4-Flash Case Study

arXiv cs.DC · 2026-11-10 · 论文PDF / 每日精选

研究问题：LLM 更新后能否直接复用旧模型的 KV 缓存避免重复计算共享上下文？权重变化后缓存究竟保留了什么？

方法：研究四次模型更新间的直接缓存复用，重点案例 DeepSeek-V4-Flash→Flash-0731；提出 Functional Cache Divergence（比较复用与原生缓存下的 next-token 分布）刻画行为差异；用 answer-margin 分析解释正确检索决策如何在内部状态大变下存活。

关键数字：检索准确率跨更新差异很大（近原生到大损失不一）；已有源缓存时，三个长前缀 QA benchmark 上复用达到中位 TTFT 加速 2.10-5.08×；自然文本续写下复用更忠实原生行为，而单 token 检索任务中兼容性随前缀长度增长下降；首 token 一致也不保证答案内容或停止行为一致。

为什么值得看：首次区分"任务效用"与"原生推理保真度"两个判据，为跨版本 KV 缓存复用策略提供实证依据。
