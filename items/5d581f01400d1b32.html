MCF: A Memory- and Communication-Aware Co-Designed Framework for Long-Context LLM Inference

arXiv(cs.AR) · 2026-10-26 · 论文PDF / 每日精选

研究问题 长上下文 LLM 推理中 KV 布局转换昂贵、通信随上下文长度增长，如何端到端优化？

方法 MCF 是内存与通信感知框架：MARS 利用早期内存余量选择性复制高复用 KV 块、随 prefill 推进渐进排空冗余副本并收敛为分片 decode-ready 布局；解码采用 query-centric 执行模型（KV 分片驻留、轻量 query 跨 worker 路由）；FPGA compute-NIC 数据通路在网络路径内做元数据驱动 KV 路由与集合操作。

关键数字 摘要未给出具体数值；TTFT、吞吐与可扩展性优于 SOTA 分布式推理系统，上下文与集群规模越大收益越大。

为什么值得看 同时从 KV 布局生命周期与通信形态下手的长上下文分布式推理设计。
