HBFSim: A Simulator for Exploring HBF in Memory Hierarchies for LLMs

arXiv · 2026-10-16 · 论文PDF / 每日精选

研究问题：高带宽闪存（HBF）号称 TB 级加速器本地容量与接近 HBM 的带宽，但 NAND 的高延迟、异地更新与写入寿命又会直接影响性能与寿命——能否在系统层量化这些影响？

方法：HBFSim 是 LLM 感知的异构 HBM+HBF 内存系统事件驱动模拟器，联合 HBM、带 host-managed FTL 的 HBF 与常规容量层，以校准的 serving 前端驱动模拟；保留应用级内存语义同时建模闪存内部行为。

关键数字：在 Llama-3.1-70B 与 Qwen3-235B-A22B 三种负载上，HBF 较 host DRAM 快 11.0–19.0x 提供超 HBM 数据；HBM 更适合放运行序列的 KV 而非作为 HBF 的缓存；Llama-3.1-70B 在发布峰值负载下 HBF 寿命 2.0–6.9 年。

为什么值得看：把 HBF 这个新兴存储层级从规格表变成可量化的系统权衡，做 LLM 内存层级选型可以直接拿来用。
