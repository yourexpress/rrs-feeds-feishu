SysPilot: Cross-Library Performance Autotuning via Library Performance Contracts

arXiv · 2026-11-04 · 论文PDF / 每日精选

研究问题：现代科学/ML 应用组合多个独立开发库，各库独立管理的运行时会在共享资源上过度订阅（抢 CPU 核、争 GPU、争带宽）——跨库边界的争用配置如何自动优化？

方法：提出 SysPilot 跨库性能自动调优系统，基于 Library Performance Contract（LPC）：用 LPCL 规范语言描述库的资源需求、假设、控制与可观测信号；从文档与代码产物合成契约、按应用所用库组合契约、推导资源冲突假设、剖析验证并选择候选配置。

关键数字：在跨库争用基准套件上，性能匹配使用应用特定手工信息的调优器，同时保留跨应用复用；相比 OpenTuner 与 SMAC3，基准性能指标最高再提升 38%，且只用其 1/3 的调优次数。

为什么值得看：把库性能知识变成可复用的契约单元，让自动调优跨应用迁移，是系统级资源协调的新抽象。
