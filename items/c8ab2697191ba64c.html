Align, Integrate, and Fire: Efficient Token-Level Alignment for Zero-Shot SpeechLLMs

arXiv（Abderrahmane Issam 等，cs.CL） · 2026-09-16 · 论文PDF

研究问题 把 LLM 能力扩展到语音输入仍代价高昂：全模型微调算力贵，参数高效投影器则受困于 token 序列过长与全模型监督成本。

方法 提出 Aligned Continuous Integrate-and-Fire 零样本语音处理框架：利用显式动态时间规整（DTW）对齐，把连续声学帧动态压缩到目标文本的精确离散 token 长度；首阶段仅用轻量距离度量建立声学到语义的桥梁，完全绕过昂贵的 LLM 前向；后续微调采用面向单个 LLM 层的内存高效知识蒸馏目标，以很小算力达到与全模型交叉熵训练相当的水平。

关键数字 在自动语音识别与语音翻译上的大量评估显示，该方法优于先前的参数高效基线（摘要未给出具体数值）。

为什么值得看 "对齐驱动压缩 + 单层蒸馏"把 SpeechLLM 训练成本大幅压低，对语音大模型的高效接入有直接参考价值。
