Magnitude: self-optimizing AI agent inference engine (~2x on Apple Silicon/NVIDIA/AMD)

GIGAZINE · 2026-10-01 · 官方公告 / 每日精选

核心话题 开源自优化推理引擎 Magnitude 发布：在实际运行的设备上就地编译并调优 kernel 参数，为本地长时间运行 AI agent 的场景做优化，已支持 Apple Silicon、NVIDIA、AMD 及纯 CPU，并可对接 Pi、OpenCode、Hermes、Codex 等 agent 工具。

要点 团队认为数据中心引擎按批量请求设计、llama.cpp 优先广硬件兼容，都不适配 agent 长会话/多实例的场景；同一芯片不同产品内存配置各异，就地调优好过通用 kernel。

关键数字 4-bit 量化 Qwen 3.6 35B A3B、64K 上下文：M4 Pro（48GB）生成速度 llama.cpp 30 tok/s vs Magnitude 57 tok/s（+92%），prefill 466→507 tok/s（+9%）；DGX Spark 上 49→58 tok/s（+19%），prefill 2033→2507 tok/s（+23%）；单 agent 内存占用 Metal 降约 28%、CUDA 降约 27%。

为什么值得看 面向"本地跑 agent"这一新兴负载的推理引擎新玩家，实测数字可观，本地部署党值得实测对比。
