LLM Value Functions for Credit Assignment in Agentic RL

arXiv · 2026-10-14 · 论文PDF

研究问题 LLM agent 在长 horizon、稀疏结果奖励的强化学习任务中难以给单个动作分配信用：GRPO 给同一轨迹所有动作相同的优势，critic 类方法又要额外学习可能昂贵且不稳定的价值函数。

方法 提出 LLM Value Function RL（LVRL）：利用预训练 LLM 的上下文学习能力估计策略感知的状态价值，无需微调独立 critic；价值模型以组上下文为条件，并用初始/终止状态已知值校准预测，通过估计价值差实现 step 级信用分配。进一步扩展出 on-policy 蒸馏变体 LVOPD，聚焦教师监督到估计价值下降的动作。

关键数字 在 AppWorld 和 SWE-bench Verified 上比 GRPO 绝对提升最高 13.6 和 8.6 个百分点；BabyAI 上从完全失败提升到 75.0% 成功率；策略规模 4B 到 32B 均一致优于 GRPO 与 PPO。

为什么值得看 不训 critic 的价值函数方案为 agentic RL 的信用分配提供了轻量新思路，跨三个基准的稳定增益说明其通用性，对做 LLM agent 训练的人很相关。
