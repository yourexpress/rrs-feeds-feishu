Serve open models in production with Foundry Managed Compute

Microsoft · 2026-11-20 · 技术博客 / 每日精选

核心话题：微软 Foundry Managed Compute 正式 GA——把开放模型 serving 做得像调用托管模型 API 一样简单。

要点：用户选模型，平台负责供给 GPU、维护容器、运营 serving 运行时；目录中 150+ 开放模型可按"Managed Compute"筛选；部署模板定义上下文长度、serving 运行时与 GPU 配置，可选 NVIDIA A100/H100/H200 或 AMD MI300X；附 Python 部署 DeepSeek V4.1 Flash（4×MI300X）完整示例；GA 后扩展了容量、提示复用、GPU 与部署选项及美欧数据区。

关键数字：目录 150+ 开放模型；示例为单实例 4×MI300X。

为什么值得看：开放模型生产级托管平台进入 GA，降低自建 serving 的运维门槛。
