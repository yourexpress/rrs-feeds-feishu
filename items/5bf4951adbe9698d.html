Introducing ChatGPT Wallet

OpenAI · 2026-11-13 · 官方公告 / 每日精选

核心话题：OpenAI 推出 ChatGPT Wallet——首个让 agent 支付时不接触用户真实卡号、且每次购买需安全检查的钱包。

要点：与 American Express、Mastercard、Visa 合作，先通过 dots 面向美国 ChatGPT Pro 订阅者开放；用户加卡一次，每次购买前审阅商品/总额/所选卡并以 Face ID 或指纹等安全检查批准，形成清晰授权记录；支付网络签发替代真实卡号的 payment token；保留现有卡奖励与合格争议保护；同步发布 Commerce Partner Playbook 帮助商家适配 agent 交易。

关键数字：1.2B 人每周使用 ChatGPT（原文）。

为什么值得看：agent 化支付的基础设施定义，支付网络、银行与商家如何配合 agent 交易。
