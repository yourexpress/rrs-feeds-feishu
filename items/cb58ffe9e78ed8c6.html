FlashVector: Agent for Hierarchical Model Serving Stack Optimization

arXiv（Qi Wu 等，cs.AI） · 2026-09-15 · 论文PDF

研究问题 模型 serving 是生产推荐系统最大的成本项之一，但吞吐优化要穿透 GPU kernel、框架计算图、模型服务器、按需特征处理多层栈，跨层专家经验难以获得也无法随负载演进扩展。

方法 FlashVector：把单 kernel 优化 agent 范式推广到异构技术栈的可扩展框架，对 serving 栈各层做整体性能优化——优化发现不仅来自 GPU kernel 与计算图，还包括 Triton 推理服务器（C++）与特征变换服务（Python）等组件。

关键数字 部署于 Unity 的 Vector 广告平台后：模型服务器吞吐最高提升 2 倍、延迟最高加速 1.98 倍；特征存储吞吐最高提升 1.6 倍。

为什么值得看 AI agent 做系统优化的落地样本，证明了 agentic 优化能跨越语言与组件边界，serving 团队可借鉴其框架设计。
