llama.cpp Release v0.9.0

llama.cpp (GitHub) · 2026-11-04 · 技术博客 / 每日精选

核心话题：llama.cpp v0.9.0 与 ggml v0.29.0 的关键更新。

要点：新增 OCP FP8 E4M3 量化（saturating 模式）；flash_attn_ext_rows 让统一 KV cache 在多序列推理下恢复非统一 prefill 性能；ggml v0.29 加入 NCCL 多节点张量并行与 CPU SVE 内核，各后端（CUDA/SYCL/Metal/Vulkan/OpenCL/Hexagon）均有性能工作；多模态扩展 Chatterbox TTS、Nemotron 3.5 Transcribe 离线转录与 Pocket TTS 预置音色。

关键数字：4 个新架构（Clover、Limite、Metis-1.6、Mistral Large 4）；Nemotron 3.5 Transcribe 支持 40 种语言离线转录；连续第 3 年入选 GitHub Octoverse 报告。

为什么值得看：本地推理主力仓库的版本更新，FP8 E4M3 与多节点 TP 直接影响部署选型。
