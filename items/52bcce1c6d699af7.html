Token Latency Fairness: Performance Isolation for Multi-Tenant LLM Serving

arXiv（Dev Bali 等，cs.DC） · 2026-09-16 · 论文PDF

研究问题 LLM 推理服务通常是多租户共享的：一个客户端的高负载请求会导致其他客户端的时延 SLO 违约；现有性能隔离方案多在长期上拉平各客户端吞吐（排队与批处理公平），但并不提供时延隔离保证——守规矩的客户端 token 级时延仍可能被严重拖慢。

方法 提出 FairInference，给出新的 δ-token 公平性保证：对守规矩客户端，若某 token 在独占运行时 d 个时间单位内生成，则多租户运行下会在 d+δ 内生成。实现上调度器强制每 token 截止时间，同时界定 GPU 计算共享带来的延迟、并计入共享 KV 缓存占显存引入的额外延迟。

关键数字 摘要未给出具体量化数值；实验显示 FairInference 有效界住守规矩客户端的 token 级时延尖峰，同时相比现有 LLM 服务系统还提升了整体吞吐。

为什么值得看 把「公平」从吞吐维度精确到 token 级时延并给出可证形式（d+δ）的保证，在推理服务 QoS/SLO 工程上是很实用的形式化框架。
