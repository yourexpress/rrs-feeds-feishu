Spectral-MoE: Heterogeneous Per-Layer Expert Utilization in Dense-to-MoE Conversion

arXiv · 2026-10-15 · 论文PDF / 每日精选

研究问题：Dense 转 MoE 的现有方法在每一层都固定相同的激活专家数（utilization），忽略了层间异构分配的可能收益。

方法：提出 Spectral-MoE，学习跨层异构地分配 utilization 预算，含两种分配器：静态（每层一个标量、跨 token 共享）与动态（逐 token 输出调度）。

关键数字：25% FFN 利用率下，动态分配相对均匀分配在 learned base 上使 Llama-2-7B / Llama-3-8B / Qwen2.5-7B 的 WikiText-2 困惑度分别降低 1.04 / 2.96 / 2.71 点（analytic base 上为 2.45 / 6.26 / 2.17 点）；12.5% / 25% / 50% 利用率下六任务平均准确率平均提升 1.5 / 4.2 / 3.6 个百分点。

为什么值得看：把「每层专家利用率」确立为 dense-to-MoE 转换的新优化轴，且在解析式与学习式两类 SOTA 转换方法上都有效。
