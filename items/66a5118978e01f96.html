PReCache: Efficient KV Cache Sharing for Multi-LoRA Agents via Low-Rank Precomputation and Neutral Reconstruction

arXiv (cs.LG) · 2026-09-28 · 论文PDF

研究问题 多 LoRA agent 系统通过共享骨干模型实现高效角色专业化，但每个 agent 重复处理增长的共享轨迹并构建自己的 KV 缓存，长程任务下内存与计算冗余显著；直接复用缓存又会让当前 agent 依赖上一 agent 适配器产生的缓存状态，削弱自身 LoRA 编码的角色行为。

方法 PReCache 提出免训练 KV 缓存共享框架，含 PreLRShared 与 ReBaseShared 两设计：用预训练权重计算共享 base 缓存，并预计算紧凑的 agent 特定低秩（LR）缓存；首次处理共享上下文时预计算各 agent 的 LR 缓存，避免重复 prefill；ReBaseShared 从免适配器隐藏状态重建共享 base 缓存，降低上一 agent 适配表示的残余误差，并为单流推理与并发服务定制两种重建时机。

关键数字 多个模型与 agent 基准上，PreLRShared 相对无 KV 缓存共享 TTFT 最高加速 3.1x、每请求吞吐提升 2.3x；ReBaseShared 在评测缓存共享方法中整体精度保持最好，相对无共享推理平均仅降 1.1 点。

为什么值得看 免训练、按角色低秩预计算化解多 LoRA 共享上下文的缓存冗余，兼顾速度与角色保真，工程落地性较强。
