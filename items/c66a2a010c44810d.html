KVUse: Reusable-KV User Memory for Efficient LLM Recommenders

arXiv cs.LG · 2026-11-16 · 论文PDF / 每日精选

研究问题：基于 LLM 的记忆增强推荐系统把用户画像存为文本，每次 ranking 调用都要拼接画像并在 prefill 阶段重算其 KV cache；这类调用 prefill 重、反复发生，重复 prefill 主导服务开销，且前缀缓存因前缀文本不同而无法消除。

方法：KVUse 把用户画像存为可复用 KV cache 而非文本：自蒸馏训练轻量 LoRA writer，使画像更新调用在解码时直接产出可复用 KV；LLM 可在新位置、新上下文后读取这些 KV 而无需重算；定制 KV 调度器在当前 batch 计算时上传下一 batch 的 KV，把主机内存传输藏在 GPU 计算后。

关键数字：4 个 InstructRec 数据集 + Llama-3.1-8B-Instruct，排序质量与完整 prefill 无统计显著差异；饱和负载下打分路径吞吐提升 4.0-4.5×、画像更新路径提升 1.4-1.9×。

为什么值得看：直击推荐场景 prefill 重负载的根源——把"画像文本"换成"可复用 KV"，顺带给出 KV 传输隐藏的调度设计。
