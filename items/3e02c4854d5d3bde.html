IndexerStage: Staging Indexer-K across Memory Tiers for Sparse-Attention LLM Serving

arXiv · 2026-11-21 · 论文PDF / 每日精选

研究问题 长上下文稀疏注意力服务在注意力数据卸载后仍受 GPU 显存限制；DeepSeek Sparse Attention 的 Indexer-K 状态每层每解码步全量扫描，且逐步增长。

方法 IndexerStage 把 Indexer-K 状态外置到内存层级，保留原生 GPU score/top-k/attention kernel：完成页经共享执行缓冲分期、新条目本地保留；联合内存-传输准入检查在接收增长批前核对存储与各层传输需求；SGLang 实现，16 服务 + 16 后备 H800 GPU。

关键数字 16K–64K 输入下本地流式存储每服务 GPU 仅 0.65–0.70 GiB；较主机内存版 HiSparse 批增 12.28–23.08%、解码 TPS 1.08–1.14x；64K 固定 latent-KV 路径下 1.10x；混合长度动态服务平均批增 12.07%、1.31x 解码 TPS。

为什么值得看 为 DeepSeek Sparse Attention 的 Indexer 状态提供分层卸载运行时，工程实现完整可复现。
