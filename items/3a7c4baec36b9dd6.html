WAMpy: Efficient Synthesis of Prolog Programs in Python

arXiv (cs.PL) · 2026-10-05 · 论文PDF

研究问题 程序合成工作负载需要反复生成并评估大量小候选程序，通用 Prolog 系统并非为此设计，Python 侧调用存在端到端开销。

方法 提出 WAMpy，面向 Prolog 程序合成的 Python 框架：把 Prolog 子句编译为基于 NumPy 数组的 WAM 指令，支持对固定背景知识做假设的部分重编译；性能关键路径用 Numba JIT 加速。

关键数字 摘要未给出量化指标；在重复编译-评估工作负载基准上，相对通过 Janus 从 Python 调用 SWI-Prolog，端到端性能提升。

为什么值得看 为"反复生成+评估小程序"这一合成场景专门优化的 Prolog 实现，思路对做程序合成基础设施的人有借鉴。
