Auditing LLM Program Search for Bermudan Stopping with Primal--Dual Certificates

研究问题：LLM 程序搜索 agent 通常以驱动搜索的分数被评判，其真实进展需要可信审计方法。 方法：原始-对偶证书审计：可信评估器持有模拟与对偶上界 U，对任意策略 0≤V-L_π≤U-L_π，报告两边 Monte Carlo 估计与抽样误差；审计 24 次生成尝试、两个流水线、六对反馈表示消融，以及冻结选择后的留出集。 关键数字：无选中的生成程序一致优于 Ridge LSMC 或超出 Monte Carlo 不确定性；留出差距分数在其 0.002 内；6 个一维 put 上高精度二项参考显示 Ridge 在 MC 噪声内接近最优，99% 的估计差距归因于对偶界松。 为什么值得看：*示范"审计而非信任分数"的评估方法，是量化 LLM 搜索真实增益的严谨模板。 Auditing LLM Program Search for Bermudan Stopping with Primal–Dual Certificates
