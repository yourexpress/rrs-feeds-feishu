Towards Efficient HPC Systems for Agents: Challenges and Opportunities

arXiv / Yunjia Zheng 等 · 2026-09-30 · 论文PDF

研究问题 编码 agent 已成为 HPC 系统的真实用户，但现有抽象、接口与策略仍为人类驱动的工作流设计，导致调度器控制面压力、元数据密集 I/O、重复发现与新的提示注入面。

方法 实测量化 agent 负载特征，主张"共设计"：把 agent 作为一等公民、设施感知租户，并从计算、存储、agent 记忆与安全四方面梳理挑战与机会。

关键数字 编码 agent 用户仅占观测人群 19.5%，却贡献 55.8% 的作业提交、29.1% 的 CPU 核时与 42.7% 的 GPU 时；命令发出频率为人类的 20.8 倍。

为什么值得看 首个把 agent 工作负载量化到 HPC 层面的测量，为下一代 HPC 系统设计提供数据依据。
