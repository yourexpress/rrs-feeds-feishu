FuncCode: Compressing Kolmogorov--Arnold Networks in Function Space with Hardware-Aware Quantization

arXiv (cs.LG) · 2026-09-23 · 论文PDF

研究问题 KAN 用可学习的单变量函数替换标量边权，灵活性更强但参数显存也更大——每条边要存多个系数，通常还另带一条基分支。

方法 提出基无关的压缩方法 FuncCode：从采样的边响应构造共享码本，基分支与函数分支分别独立编码，再以量化、位打包的格式导出码本与逐边索引；另用重复对照实验澄清"函数空间聚类本身"并不优于系数空间聚类，一致的精度收益来自保留了两条分支各自不同的共享结构。

关键数字 采样边响应的有效秩比其系数表示低 13%~35%；十种子 MNIST 基准上 spline KAN 与 GRAM KAN 分别压缩 31.6 倍与 17.6 倍，精度仅损失 0.31 与 0.34 个百分点；在 610 万边的卷积 KAGN 上压缩 19.9 倍，与稠密模型精度差 0.54 个百分点（CIFAR-10）与 1.89 个百分点（CIFAR-100）；压缩后逐边索引最多占存储权重的 99.4% 比特，表示受索引界约束；在九个 bit-exact FPGA 加速器上，SplineKAN 布线后权重内存相对稠密 INT4 降低 3.87 倍，且周期数与时延不增加。代码开源在 github.com/OSU-STARLAB/FuncCode。

为什么值得看 "按函数响应而非系数聚类"把 KAN 压缩比推到 20~30 倍，且在真实 FPGA 上验证收益不只停留在纸面。
