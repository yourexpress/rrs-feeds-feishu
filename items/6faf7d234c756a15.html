EpiKV: Epiphany-Aware KV Cache Eviction Without the Attention Matrix

arXiv / Steven Kolawole 等 · 2026-09-29 · 论文PDF

研究问题 推理模型生成数万 token 的思维链，KV cache 成为吞吐瓶颈；现有驱逐策略依赖注意力权重排序，需要注意力矩阵、与快速推理 kernel 不兼容——能否不碰注意力矩阵做驱逐？

方法 研究紧缓存预算下注意力基驱逐的极限：发现最强的注意力基策略下，正常结束的生成出错率与不驱逐时相当，精度损失主要来自陷入循环跑到长度上限的生成，而按固定重要性分数多留 token 反而加剧循环；阻止循环的关键是保留模型近期 query 指向的 token，且前向过程无需注意力矩阵即可揭示它们。据此提出 EpiKV：结合隐状态偏移与近期 query-key 相关性给缓存 token 排序，不物化注意力矩阵。

关键数字 多个基准上与最强注意力基驱逐基线持平或更优，直接在 vLLM 未改注意力 kernel 下运行（摘要未给具体数值）。

为什么值得看 揭示注意力基驱逐在长推理链上的失效模式，给出与快速 kernel 兼容的替代，推理吞吐优化可直接用。
