TOAST: Stochastic Robot Action Tokenization for Autoregressive Vision-Language-Action Models

arXiv (cs.RO) · 2026-10-02 · 论文PDF

研究问题： FAST 用少量 token 紧凑编码机器人动作，但给每个量化动作序列分配单一确定性 tokenization，忽略了多个 token 序列可解码为同一运动的表示冗余。

方法： TOAST 随机动作 tokenization：训练时对同一量化动作序列采样替代 tokenization，多样化离散监督且保持底层动作不变，无需额外演示。

关键数字： LIBERO 上仅用 1/16 训练数据时成功率提升 6.8 点；4 个真实机器人操作任务平均成功率提升 15.8 点。

为什么值得看： 数据受限场景下，随机化 token 监督是提升 VLA 策略学习的高性价比手段。
