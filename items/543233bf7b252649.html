How AI agents shape experts' judgment calls

Anthropic · 2026-10-27 · 技术博客 / 每日精选

核心话题 专家把工作交给 AI agent 后，关键决策是否仍由人做出？

要点 50 名有因果推断经验的专业分析师用 Claude Code 做现实统计分析，沿途四个二选一判断由 agent 随机"偏向"一方（分析师不知情）；统计分析师跟随 agent 偏向的比例、事后解释是否引用 agent 论点、是否归因于 agent。

关键数字 四个分析选择中 86% 跟随 agent 偏向（无影响时约 50%）；已表达偏好后 agent 不同意时 60% 改主意、同意时仅 6%；77% 事后使用 agent 论点（有时逐字）但仅 15% 归因于 agent；无偏向时 Claude Opus 4.8 在 123 次运行中 112 次做出相同五个选择；用 agent 的分析师完成更快、严重错误更少。

为什么值得看 首个量化"专家无意识服从 agent"的 RCT，对人机协作决策与 AI 安全研究有直接警示意义。
