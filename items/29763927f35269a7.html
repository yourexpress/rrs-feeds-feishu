TASTE: Throughput-Aware Batch Size Tuning for On-Device Edge Learning

arXiv（Avik Bhatnagar 等，cs.LG） · 2026-09-07 · 论文PDF

研究问题 隐私保护 AI 推动模型在端侧设备上直接微调，但资源受限硬件上如何最大化训练吞吐同时保住精度，batch size 是关键且调优成本高。

方法 TASTE：基于贝叶斯优化的 batch size 调优，直接以硬件吞吐最大化为目标；在标准监督学习与在线持续学习两种范式下验证；配合梯度累积与线性学习率缩放使用。

关键数字 实验发现明确的吞吐天花板——超过后增大 batch size 不再提速；最优 batch size 相比最大 batch size 在树莓派 4 等平台上吞吐最高提升 2 倍且精度无损；持续学习下还维持稳定性-可塑性平衡，缓解灾难性遗忘。

为什么值得看 "更大 batch 不等于更快"的端侧实测结论 + 自动化调优方法，端侧训练工程可直接套用。
