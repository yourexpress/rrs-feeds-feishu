Asynchronous Byzantine Lattice Agreement with Logarithmic Response Time and Optimal Resilience

arXiv · 2026-11-20 · 论文PDF

异步拜占庭格点一致协议，对数响应时间与最优弹性

Lattice agreement is a fundamental coordination primitive in which processes decide on comparable values rather than identical ones. In the asynchronous message-passing setting with Byzantine failures, existing algorithms either require authentication or do not simultaneously achieve optimal resilience and logarithmic response time. We present an asynchronous Byzantine lattice agreement algorithm that tolerates up to $f$ Byzantine failures among $n>3f$ processes, requires no authentication, and completes in $O(\log f)$ time. The algorithm builds on the classifier-tree framework of Attiya and Rachman, replacing shared-memory communication with quorum-based message passing. The main challenge is preserving the information-flow invariants underlying the classifier tree despite Byzantine behavior. To address this challenge, we introduce Supported Reliable Broadcast (SRB), a communication abstraction that combines reliable broadcast with protocol-specific admissibility checks. Messages are disseminated using reliable broadcast, but are delivered to the protocol only after verifying that they are consistent with previously propagated information about the sender's state.
