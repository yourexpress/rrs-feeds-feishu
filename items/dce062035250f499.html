Towards Stream Learning on Embedded Systems: Benchmarking the Memory Consumption of Stream Learning Methods

arXiv（Sebastian Buschjäger 等，cs.LG） · 2026-08-31 · 论文PDF

研究问题 流学习评估普遍只盯预测性能与概念漂移适应，但嵌入式/近传感器场景要求长期运行下资源消耗可预测、有界——现有方法在内存预算下表现如何？

方法 对 7 个代表性流分类器、13 条真实/合成数据流、128KiB~8MiB 模型大小预算做基准：共 6,463 组实验，测量失败感知准确率、峰值模型大小、预算耗尽时间与预测+更新延迟。

关键数字 两类资源失效模式：自适应集成初始占容就超限；增量树初始能装但随流持续增长，HoeffdingTree 与 EFDT 大小中位增长 7.37 与 5.87 倍。最小预算下只有显式紧凑方法可行，预算放大后集成才有竞争力。

为什么值得看 用大规模实证把「有界资源」推上流学习的一等设计目标，并给出暴露/遵守资源预算的 API 提案——嵌入式 ML 从业者必读。
