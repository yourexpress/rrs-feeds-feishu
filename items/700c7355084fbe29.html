Warpline: Binary-Level Tracing and Unified Evidence for Agentic GPU Kernel Optimization

arXiv (cs.PF) · 2026-11-03 · 论文PDF / 每日精选

研究问题 LLM agent 正成为 GPU 内核工程师，但调内核时看不到时间花在哪：硬件 profiler 只报各单元忙碌程度，不报每个 warp 的时间去向；核内 tracer 能显示但要手工放置探针并重编译，改变被测内核本身。

方法 提出 Warpline：分析二进制决定记录哪些事件，直接把探针插入二进制（无需重编译、无需手工步骤）；把 trace 与硬件 profiling 数据对齐到统一时间线。因只需二进制，可在 agent 每次修改内核（源码/IR/PTX 层）后自动为每个新版本重新生成证据，闭环优化无需人工介入。

关键数字 NVIDIA B200 上跨 Triton、CuTe DSL、CUDA C++ 的 35 个内核：中位开销 1.2%，99.9% 执行指令保持不变（现有 tracer 中位开销 1.6%-13.2%、仅保留 4.6%-32.7% 不变）；还能 trace 闭源内核。10 个 SOL-ExecBench 问题上，用 Warpline 的 agent 比裸 coding agent 与 NVIDIA KDA 花更少时间与模型请求，几何平均提速 7.69x（KDA 为 6.94x）。

为什么值得看 二进制级、免重编译的 kernel 内追踪让 agent 获得"时间去哪了"的统一证据，且不干扰被测内核，是 agentic 内核优化的基础设施级工作。
