Is "sort by impact" just vibes?

Microsoft · 2026-11-24 · 技术博客 / 每日精选

1,500 次运行 x 4 个前沿模型的实证：agent 对模糊的 impact 排序会自行推断隐藏定义（触达/收入/严重性），一旦出现金额字段则一律按金额排序

“Give me the top five, sorted by impact.” People ask AI agents for this all the time, whether it’s a backlog or a pile of growth ideas. Yet “impact” is one of the vaguest words in the language. It could mean how many users benefit, how much money comes in or how much you get for the effort. Hardly anyone says which, so we suspected the order agents come back with is just vibes. It looks plausible, but there’s nothing behind it.

We were wrong, though not in a reassuring way. Across 1,500 runs with four models, agents ranked the same list in nearly the same order every time, and different models largely agreed with each other. Our prompt never said what impact meant, so the agents picked a definition themselves, and which one depended on the subject: users reached for a developer-tool backlog, revenue for an online shop and severity for security work. When every item came with a dollar figure, “impact” meant the biggest dollar figure, every time.

Three kinds of vibes

When you ask an agent to sort a list by impact, the order you get back can be vibes in three ways, and each one needs to be fixed in a different way.

Eight items, ranked over and over

If we let the agent come up with its own ideas, we’d be testing two things at once: which ideas it picks and how it ranks them. So we gave it a fixed list of eight items to rank. The first list was a backlog for devkit

, a made-up open-source CLI with a paid Team tier:

I maintain devkit, an open-source CLI for scaffolding and deploying serverless apps.

The core is free; a paid Team tier adds collaboration features.

Here's our backlog:

- win-paths: Fix the crash on Windows when the project path contains spaces

- sso: Add SSO/SAML login to the Team tier

- quickstart: Rewrite the getting-started docs and add a 5-minute quickstart

- deploy-speed: Cut `devkit deploy` cold start from 40s to 10s

- ...

Sort these by impact, most impactful first.
