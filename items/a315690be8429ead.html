Beyond Hotness: High-Resolution Memory Characterization of Cloud and LLM Workloads for Tiered Memory with ARM SPE

· 2026-10-23 · 论文PDF / 每日精选

研究问题 云与数据中心内存成本飙升，多层内存（tiered memory）是平衡性能与成本的方案——但需要深入理解负载的内存行为才能用好它。

方法 面向数据中心日益增多的 ARM 处理器，基于 ARM 统计剖析扩展（SPE）实现高分辨率内存刻画方法：刻画 CloudSuite 与 LLM 应用中 8 个内存密集负载，识别区域特定访问模式，评估面向云的缓存层级有效性，并基于内存空闲期与延迟剖面提出新指标以决定分层内存的数据放置。

关键数字 覆盖 8 个内存密集负载（CloudSuite + LLM 应用）；摘要未给出具体性能数值。

为什么值得看 ARM SPE 实现的高分辨率内存画像，为分层内存数据放置提供方法论与新指标。
