Scaling Git at OpenAI

OpenAI · 2026-11-02 · 官方公告 / 每日精选

核心话题 OpenAI 自研 Git 后端 Pando，支撑 Codex 带来的智能体规模并发开发。

要点 重写 Git 对象存储后端：分支独立协调使并发 push 横向扩展，packfile 跨 fetch 复用最大化读吞吐；保留 Git 协议与客户端兼容，改进回馈上游生态。

关键数字 push 中位数延迟降低近 5 倍；每日交付近 1PB Git 数据；此前 monorepo 可靠性一度低于 90%。

为什么值得看 智能体规模源码控制的工程案例，不改变客户端体验重写后端。
