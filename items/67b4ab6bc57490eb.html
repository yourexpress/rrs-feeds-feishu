AgentLoop: Runtime Control of Slot-closed Execution Loops for Tool-augmented LLM Agents

arXiv (cs.DC) · 2026-09-27 · 论文PDF

研究问题 工具增强 LLM agent 循环缺乏评估任务完成的显式运行时信号：运行时上下文停止变化后 agent 仍继续推理或调用服务，已收集证据却未综合成答案，资源浪费严重。

方法 AgentLoop 槽位封闭执行循环的运行时控制：维护紧凑运行时状态，模型辅助结构化验证检查答案完整性与缺失证据，对相邻 LLM/工具轮次应用有界稳定与低增益信号，三选一执行：继续调用、合成答案、终止迭代。

关键数字 总 token 成本最高降 88.44%，平均服务调用最高降 76.85%；消融显示槽位控制路径是核心，禁用后执行深度增加且准确率显著下降。

为什么值得看 把 agent 迭代从开放式改为状态驱动，为 agent 服务的成本与资源控制提供实用框架。
