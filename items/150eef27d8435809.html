A Local-Counting Approach for Distributed Induced Path Detection

A well-known application of the celebrated color-coding technique is fast detection of paths in a distributed setting with limited bandwidth, by propagating a signal along colorful paths [Even et al., DISC 2017]. However, since vertices of the same color are indistinguishable by this procedure, it cannot detect induced paths, as they appear the same as cycles. We make the following observation. If, for a given edge, we \emph{count} the number of such signals over all permutations of the random coloring that terminate at that edge, then we can separate an induced path from a cycle: an induced path contributes one to that count, while a cycle contributes two. Refining and generalizing this observation gives our \emph{local-counting approach}, which allows us to separate induced paths from any other subgraph. We establish the following end results, all improving upon the state of the art in their round complexities and refined detection variants. * An $O(1)$-round algorithm for induced $P_4$ detection. * $O(Δ)$-round algorithms for detection of induced $P_5$ and $P_6$. * An $\tilde{O}(n^{1/3})$-round algorithm for detection of induced $P_5$ in induced-$C_4$ free graphs.
