Bayes-Sufficient Compression Is Not Enough: How Does Communication Help Multi-Agent Systems?

arXiv cs.LG · 2026-10-06 · 论文PDF

研究问题：多 agent 系统中发送者持广上下文、执行者只有有限局部视图——短消息何时改善决策、何时原始上下文更好？ 方法：receiver-relative bounded coordination 框架，消息效用 = 接收者增益 - 协议税；三阶段分解（外部化、吸收、行动闭合）解释错误在内容到达后仍残留。 关键数字：同一 Qwen 协议把 ContextBench 联合准确率从 0.633 提到 0.775，但 ToolSandbox 从 0.889 降至 0.653。 为什么值得看：给多 agent 通信"压缩还是直传"量化判断依据。 阅读原文
