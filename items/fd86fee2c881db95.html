DFIP: Decision-Focused Inference Path for System One Models

arXiv(cs.PF) · 2026-10-27 · 论文PDF / 每日精选

研究问题 System One 决策模型返回小而结构化答案，但仍保留 host 分发、GPU 启动与全词表投影开销——既有推理技术在决策模型上值多少？

方法 DFIP 实证研究：在 PPLX-Decider、Liquid d1-3B、Clef-Flash、GLiNER2.5-Decide 上施加选择性 CUDA graph 重放、候选 token 投影、长度感知批处理，与更强原生基线对比并审计输出。

关键数字 装 Qwen 原生 kernel 后：Decider 短布尔驻留请求加速 2.47x（五容器）、Clef 1.45x（四容器）；GLiNER 长度感知批处理比原生 FIFO 快 1.40x 但到达 p95 更差；审计保留全部 1,112 个选择。

为什么值得看 不宣称万能加速，老实给出各技术的适用边界与失效场景。
