GPT‑6 and Intelligent UI for everyone

OpenAI · 2026-10-07 · 官方公告 / 每日精选

核心话题： OpenAI 宣布 GPT-6 向全体 ChatGPT 用户开放，并推出 Intelligent UI——让 ChatGPT 用完全交互式的界面回答问题的新能力。

要点： GPT-6 被训练为按问题自行组织文字、视觉与交互元素：对比类问题并排展示，解释类问题用可交互图示，也可以在对话中即时生成一次性小工具（储蓄计算器、聚餐账单拆分、小游戏等）；底层是一套原生可流式组件库加一个编译器，界面随模型生成渐进呈现、无需等待完整响应；训练中还专门评估所生成界面的清晰度、有用性与完整性，教模型做版式与交互决策。

关键数字： 文中口径 ChatGPT 每周用户超 12 亿；未披露 Intelligent UI 的其他量化指标。

为什么值得看： Chatbot 输出形态从"富文本"升级为"按需生成的交互界面"，可能是 LLM 产品交互的下一种默认形态，值得产品与前端同学关注。
