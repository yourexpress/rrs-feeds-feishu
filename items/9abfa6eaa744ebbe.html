Harness²: Recursive Agent Harnessing for an Open World

Google Research（google-research） · 2026-10-14 · 论文PDF / 每日精选

研究问题 LLM agent 的能力既取决于底层模型，也取决于其执行 harness（脚手架）。开放世界任务在 harness 设计阶段往往未见过、测试时又是新颖的，缺少 ground-truth 验证器来可靠指导 harness 在线编辑；递归自改进（RSI）过程任务特定、难以泛化。

方法 提出 Harness² 即插即用递归框架：任务级递归用对比式 Propose-Probe-Compose 步骤精化当前任务的 harness，无需 ground-truth 验证器，并可并行或串行扩展；harness 级递归从这些编辑中提取经验，更新持续改进 harness。

关键数字 3 个专业基准、4 种模型-harness 配置下，WorkBuddy-Bench 提升最高 11.5 分、JobBench 4.5 分、LAB 11.8 百分点；任务级递归预算增大可进一步获益。

为什么值得看 把 RSI 从「依赖 ground-truth」扩展到开放世界无验证器场景，对 agent 自改进方向是可落地的实证，4 个具体基准增益可作基线。
