Chain-of-Thought Compression Enables Extremely Efficient Black-Box LLM Inference

Microsoft · 2026-09-16 · 论文PDF

研究问题 黑盒调用 LLM 时，思维链（CoT）推理的 token 开销直接等于成本；能否在不访问模型内部的前提下大幅压缩推理 token 数、同时保住答案质量？

方法 来自微软的理论工作：分析 CoT 压缩的信息论极限，给出"信号集中"条件下的压缩上界结论，并结合束搜索采样策略逼近该极限（注：本条抓取到的摘要正文与标题不匹配，此处依据标题与入库要点撰写，细节请以原文为准）。

关键数字 在信号集中 + 束搜索采样下，推理 token 数仅需达到理论极限的 2 倍。

为什么值得看 给"推理成本能压到多低"这一实用问题提供了理论锚点，对做推理时计算压缩与成本优化的人有方向性参考价值。
