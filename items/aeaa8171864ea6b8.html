First-Order LoRA Training with Phone NPUs

arXiv/cs.LG · 2026-10-17 · 论文PDF / 每日精选

研究问题 端侧微调可让 LLM 学习用户私有数据而不外传，但 LoRA 每一步一阶训练仍要与冻结的基座权重相乘（前向、激活重算、输入梯度）；手机 NPU 为推理已驻留这些权重，其推理接口却不支持计算输入梯度。

方法 提出系统把三处冻结权重乘法全部放到 NPU 上，训练图、adapter 与优化器留在 CPU；输入梯度 kernel 复用驻留权重 tile 与前向反量化器，避免转置权重拷贝并保证前反向使用同一有效权重；按梯度敏感度选精度、对 FP16 输出施加按行范围保护；运行时融合剩余 CPU 算子并与 NPU 执行重叠，可恢复执行与温度节流让训练以后台任务方式推进。

关键数字 在两个高通骁龙平台、Qwen 与 Llama 家族的四个 LLM 上评测，覆盖夜间个性化与公开 LaMP-2 基准，对比对象含优化过的 CPU 训练器、手机 GPU 训练器、仅前向训练与 GPU 训练参考（摘要未给最终量化指标）。

为什么值得看 "把推理驻留的权重直接拿来训练"是端侧隐私微调最省资源的路径，对唤醒词这类常驻模型的端侧适配有直接启发。
