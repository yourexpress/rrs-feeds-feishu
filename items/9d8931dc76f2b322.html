Total Cost of Agency: Exact Attribution of Memory Injection Cost in Multi-Agent LLM Workflows

arXiv (cs.PF) · 2026-09-22 · 论文PDF

研究问题：多 agent LLM 工作流中，每个节点从记忆注入上下文的 token 被按输入 token 计费，但现有监控工具不分离这部分成本，团队对这项开销完全无感。

方法：提出 TCA（Total Cost of Agency）成本分解框架和精确归因方法——通过两遍非计费 token 计数直接测量注入量，而非用词数代理估算。

关键数字：记忆注入占可变成本的 13.6%，占总计费成本约 12%；占比随工作流深度从 0%（深度 1）线性增长至 27.6%（深度 6，R²=0.9974）；将检索窗口从 32 条降至 2 条可减少注入 token 28.7%。

为什么值得看：首次将多 agent 系统中的"隐形成本"透明化，并证明它是可控的——只需调整检索窗口即可显著降低。
