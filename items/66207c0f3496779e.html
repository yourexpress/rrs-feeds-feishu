AgentWeave: Efficient Distributed Agent Serving via Flow Decomposition

arXiv · 2026-10-14 · 论文PDF

研究问题：分布式 agent 系统的分离式架构因模块延迟不均产生流水线气泡；聚合架构虽消除气泡但引入请求阻塞（短请求与长请求锁步、新请求需等整批完成）。 方法：AgentWeave 聚合架构 + 流分解：把长 agent 请求分解为细粒度执行单元并保持 agent 语义，短请求与新请求无需被长任务拖住；流自适应调度器平衡分解的吞吐收益与调度开销。 关键数字：4 个代表性 agent 应用上，吞吐提升 1.81×、平均延迟降低 2.45×、P90 延迟降低 2.04×（对比 SOTA 基线）。 为什么值得看：直接针对 agent 工作流的分布式 serving 瓶颈，聚合架构路线的收益有实测支撑。 AgentWeave: Efficient Distributed Agent Serving via Flow Decomposition
