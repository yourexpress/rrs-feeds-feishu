SPIMOE: Exploiting Hybrid Sparsity for Reasoning MoE Inference on Heterogeneous PIM Architectures

arXiv (cs.AR) · 2026-09-28 · 论文PDF / 每日精选

研究问题：长推理 MoE 推理有两大耦合瓶颈：KV cache 增长把关键路径推向 attention，专家稀疏激活又造成负载不均；现有 PIM 加速器多孤立优化 attention 或 FFN。

方法：SPIMOE 是首个面向异构 PIM 的混合稀疏协同设计：自适应专家路由 + 块稀疏 attention + 物理 KV 驱逐，把 attention 与 FFN 分别卸载到 SRAM-PIM 与 HBM-PIM，静态专家映射加动态子批调度平衡通道负载并重叠两条路径。

关键数字：端到端相对 NVIDIA A100 最高加速 8.35 倍，MoE FFN 执行相对 PIMoE 加速 3.33 倍，推理精度与全注意力基线相当。

为什么值得看：attention 与 FFN 分置两类 PIM 的异构协同设计，为 MoE 推理的存算一体落地给出完整框架。
