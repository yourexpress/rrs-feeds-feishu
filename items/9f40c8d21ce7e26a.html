Towards Full Pipeline FP8 Reinforcement Learning for LLMs

arXiv · 2026-09-19 · 论文PDF / 每日精选

研究问题：FP8 量化能加速 RL 训练，但全管线 FP8 RL 仍会中途熵值激增、输出乱码——不稳定的真正来源是什么？

方法：溯源到"FP8 量化噪声复合 → 扭曲 importance ratio → 负优势 token 被推出信任域 → 梯度清零"。对策 Calibrated Clipping：让 FP8 截断界对齐 BF16 高精度分布。

关键数字：在 GRPO/DAPO、8B~32B、多种 FP8 缩放粒度上验证，成功消除熵激增、性能恢复到 BF16 基线。

为什么值得看：低精度 RL 训练稳定性必读。
