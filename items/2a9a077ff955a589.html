Exstill: The Most Efficient Single-Chip Processor for the Next Token

arXiv cs.AR · 2026-11-13 · 论文PDF / 每日精选

研究问题：生成一个 token 所需的算术能量构成任何硬件的下限，通用处理器远超此下限——能否让 token 生成贴近理论极限？

方法：软硬件协同设计，在 gate-level 搜索循环中同时优化硅片与模型；datapath 固定单一模型架构（权重仍可加载），权重与每会话 KV cache 全部放在片上。

关键数字：Qwen3-1.7B、16K 上下文下，5nm 门级测量下限为 0.89 mJ/token；NVIDIA B300 花费 391–1,120× 该能量。

为什么值得看：单芯片 token 生成能效的下限研究，定量揭示通用性/软件层的能效代价。
