A Night at the LLM Zoo: Data Conditioned Flow Matching for Generating Pretrained LLM Weights

arXiv · 2026-11-04 · 论文PDF / 每日精选

研究问题：Weight Space Learning 扩展到 LLM 时缺一个经过整理和分析的 LLM 权重种群——能否系统训练一个模型 zoo 并用于权重空间生成？

方法：在 51M/124M/355M 三档 GPT-2 模型上每档训练 N=100 个，系统变化 web 文本/书籍/数学/代码/法语的数据混合比例；用余弦相似度、功能多样性、留一混合建模与方差分解分析种群；把训练混合比例嵌入 Gram-PCA 压缩权重空间，训练 Flow Matching 模型生成完整预训练权重。

关键数字：零样本泛化到未见的混合比例；生成模型在 CRPS 技能上可测，下游测试集困惑度与通用能力基准分数变化极小。

为什么值得看：为 LLM 权重空间学习提供首个公开模型 zoo 与生成管线，代码与产物全开源，可支撑该方向继续扩展。
