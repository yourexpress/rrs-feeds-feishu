CB-Orchestrator: Adaptive Workflow Optimization for LLM Agents via Contextual Bandits

arXiv · 2026-10-09 · 论文PDF

研究问题 LLM agent 通过 agentic 工作流完成复杂任务，但手工设计工作流费力且难以适配多样查询，现有自动化优化方法在训练阶段反馈收集上 API 成本高昂。

方法 提出 CB-Orchestrator，把工作流生成与选择解耦：第一阶段用进化搜索构建多样候选工作流池；第二阶段把选择建模为上下文 Bandit 问题，通过探索-利用平衡实现样本高效学习；推理时按查询自适应选择最优工作流。

关键数字 在 5 个多样化基准上一致超越全部基线；MATH 上训练阶段 API token 开销至少降低 40.55%，端到端（含工作流池生成）token 开销至少降低 29.73%。

为什么值得看 用上下文 Bandit 把工作流选择做成自适应，成本数字显著。
