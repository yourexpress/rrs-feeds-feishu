An Empirical Analysis of CodeQL False Positives and Query Refinements for Java Vulnerabilities

arXiv（Amirali Sajadi 等，cs.SE） · 2026-09-03 · 论文PDF

研究问题 SAST 工具（CodeQL）的误报造成大量 triage 成本：Java 安全分析的误报是否存在可解释、可在查询层消除的重复模式？

方法 在 110 个项目的 167 个 CVE 实例上跑 CodeQL Java 安全查询套件，人工审 500 条误报路径构建源码级 taxonomy，据此实现查询级过滤改进；并评估 agentic 编码工具把改进模式迁移到新项目的能力。

关键数字 五类误报：路径约束/净化遗漏 36.6%、良性执行上下文 29.4%、信任边界建模缺失 27.6% 等；改进消除 81.8% 已审误报，全量数据集移除 15.8% 报告且保住 7/8 真阳性；有模板时两个 agent 工具成功率 56%/62%（无模板仅 28%）。

为什么值得看 「误报分类 → 查询改进 → agent 自动迁移」的完整工作流，安全工程团队可直接套用。
